### s0100 · 要件上传必须复用「机构基本信息」那一套组件，不要另造简化版

🔵 偏好 ｜ 验证于 苏房V3 ｜ 约定/偏好类，通常长期有效（记录于 2026-10-12）

与已知清单差异：已知第 89 条只覆盖 listAppendixPackage 的 busCode/busId 取数协议，没有「组件必须复用机构基本信息那套」的 UI 复用约定。

### s0546 · 用 ResizeObserver 监听容器自身再改容器尺寸会自激放大（登录页图片涨满全屏）

🟡 踩坑 ｜ 验证于 苏房V3 ｜ 距代码最后改动 18 天，引用前请核对

情况：登录页左侧图片需要「完整展示 + 左右两栏等宽 + 不留白」，于是用 ResizeObserver 监听登录盒，量出尺寸后回写 minHeight。结果图片不断变大直到撑满屏幕。为什么：回写 minHeight → 右侧 .login-container 被 height:100% 拉高 → 容器 scrollHeight 跟着变大 → 下一轮又算出更大的宽高，测量与写入互为因果，形成正反馈；用 scrollHeight 量「自己会影响的元素」必然自激。怎么做：1) 去掉对登录盒/表单的 ResizeObserver，不再用 scrollHeight 量表单；2) 高度取各登录模式固定的 min-height（如 500/520/560），宽度按图片宽高比推导；3) 加视口上限兜底（单栏 ≤ 约 42% 屏宽、盒高 ≤ 约 78% 屏高）；4) 只在 window resize 里重算一次，保证幂等。本改动同源复制到「门户」仓库的 login.vue，两边必须同步。

> 依据（摘）：会话 57edf49f 用户诉求 5「有问题，页面图片会不断变大直到撑满屏幕」；最终结论明确 ResizeObserver 正反馈链路与四条修复，并同步到门户 zhi2-web-admin/src/views/login.vue
