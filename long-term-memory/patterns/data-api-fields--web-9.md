🔴 踩坑 ｜ 验证于 产品2.0 ｜ 距代码最后改动 94 天，绑定具体实现，务必先核对代码

现象：列表页「业务状态」下拉显示可选，但选中其他状态点查询后结果仍是「已备案」，选什么都被打回原值。排查结论是两套代码叠加：2026-05-07 新建 resourcesLeaseContractFiling/index.vue 时把「业务状态」写进了 formItems（筛选区本身没坏），12 天后的 2026-05-19 又有人在 getQueryParams() 里补了一句「无值时默认已备案」，而该赋值写在校验之外、对被用户选中的值也直接覆盖。
