### x0043 · 嵌套 zs-dialog footer 溢出：calculateHeight 应设 height:auto 而非测量像素高度

⚪ 踩坑 ｜ 验证于 2-0 ｜ 无 git 基线，引用前请自行核对

情况：弹窗内再开 zs-dialog（如选择楼幢）时，内层 footer 被裁切或跑出可视区域。
根因：zs-dialog 的 calculateHeight 把 `dialogElement.style.height` 设为 `offsetHeight` 像素值，嵌套或绝对定位拖拽时 flex 布局无法随内容伸缩，footer 脱离预期流。
怎么做：calculateHeight 末尾改为 `dialogElement.style.height = 'auto'`，由 flex 自然分配 header/body/footer；保留 minHeight 等其它逻辑。改后复测「弹窗里再开选择弹窗」场景 footer 完整可见。
注意：与「zs-dialog 传 header="" 留空标题条」等不同问题，这里是嵌套高度计算。

> 依据（摘）：会话 7f3a94cb 诉求 3：用户反馈嵌套弹窗 footer 溢出；结论 calculateHeight 改为 height auto。

文件：`zhi2-web-admin/src/components/zs-dialog/index.vue`
