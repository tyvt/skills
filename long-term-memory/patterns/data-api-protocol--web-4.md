### x0801 · 我发起的流程撤回 405：流程配置 approvalApi 写成纯数字会拼成 /api/v2/2

🔴 踩坑 ｜ 验证于 园区公共收益 ｜ 距代码最后改动 119 天，绑定具体实现，务必先核对代码

现象：「我发起的」点撤回，前端提示 Request failed with status code 405；Network 为 POST `/api/v2/2`。
根因：工具 → 工作流 → 流程配置里该业务的 **审批接口（approvalApi）** 被配成 `2` 等不含 `/` 的非法值，与 baseURL 拼接后不是真实业务路径，网关返回 Method Not Allowed。旧版 `process.vue` 撤回还常缺当前节点 **key**，且未校验 approvalApi，错误配置会直接发请求。
做法：在 `flowApi.js` 收敛 `withdrawProcess`——① approvalApi 必须含 `/`，否则拒绝直调；② 异常时从业务详情 `path` 推导（如 `/benefit/xxx/123` → `/benefit/xxx/approval`）；③ 先调 `flowViewer` 取当前节点 key，再 POST 审批接口。`process.vue` 与详情页撤回统一走该函数。联调时到流程配置把 approvalApi 改成类似 `/benefit/pubAllotNotice/approval`，不要留纯数字。

> 依据（摘）：会话 b81ac1e2：撤回请求 URL `/api/v2/2`、POST、405；结论写明 approvalApi 错误配置为 `2`，并新增 withdrawProcess 校验与 key 补齐。
