### s0102 · 纯展示改版不要新增接口；卡片/网格只读展示的空值不显示占位符「-」

🔵 偏好 ｜ 验证于 苏房V3 ｜ 约定/偏好类，通常长期有效（记录于 2026-09-22）

什么情况：楼栋证书区块要按新设计图改版，agent 倾向于去调 file/appendix/listAppendixPackage 取数。用户明确否决：「不需要调用 listAppendixPackage，就是纯前端把现在展示形式换一下，字段名和值都是取现有的」。

结论一（范围约束）：这类「换展示形式」的改版属于样式/结构重构，禁止顺手引入新接口、新字段或新查询。做法是复用当前页面已拿到的数据对象（含既有 fallback 逻辑），只改模板结构与样式类名；确实缺字段时才回到接口层讨论。

结论二（空值规则）：卡片/网格式只读展示（如证书格）无值时不要显示占位符「-」。实现为：值存在时在灰色标题条下方渲染文本，值不存在时整块只留灰色标题条，不留任何占位；原先的 `{{ value || '—' }}` 要改成条件渲染。

与已知清单差异：已知第 74 条是「详情页字段要按业务顺序对齐、空字段显示 -」，那是字段清单（label/value 行）的规则；本条是卡片式只读展示网格的相反约定。区分口径：字段列表行用「-」，要件/证书展示格整块留空。

> 依据（摘）：用户诉求 2：「不需要调用file/appendix/listAppendixPackage，就是纯前端把现在展示形式换一下，字段名和值都是取现有的」；诉求 4：「没有附件不要显示-」；最终结论：证号为空时不再显示 —，只保留灰色标题条。
