已修复侧边栏再次出现「不存在的父级」的问题，原因与改动如下。

## 原因

1. **顶栏模式下侧栏被整棵菜单树覆盖**：`GenerateRoutes` 会先写入完整 `sidebarRoutes`；`TagsView.syncSidebarWithRoute` 在无法匹配当前模块时**不更新** store，侧栏会残留其他模块的父级节点。
2. **首页「热门应用」**：`activeMenu` 直接 `commit(item.children)`，未走 `getSidebarRoutesForTopNav`，也未过滤 hidden / 无标题占位目录。
3. **无标题父级**：隐藏 Layout 等节点没有 `meta.title` 时，仍会显示只有箭头的空父级。
4. **顶栏菜单被误关**：`Navbar.visibleMenus` 里存在 `return []`，顶栏主菜单不显示（顺带影响模块切换）。

## 修改

- `menuVisibility.js`：增加 `flattenPhantomMenuParents` / `normalizeSidebarRoutes`（过滤 hidden + 去掉无标题父级）。
- `permission.js`：开启 `topNav` 时初始侧栏按当前路由计算；`SET_SIDEBAR_ROUTERS` 统一规范化。
- `TagsView` / `Navbar` / `home/index.vue`：侧栏同步与首页切换与顶栏逻辑一致。

请重新登录或刷新后看侧栏：不应再出现其他模块的父级或空标题父级。若仍有某条菜单异常，把 `listRouters` 里对应节点贴出来即可继续查。
