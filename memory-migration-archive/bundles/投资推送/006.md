## 与回测如何对齐

回测本来就在**调仓日按收盘价 + 滑点**成交，不等回调。现在日程也对齐了：

```bash
# 实盘报告（默认建仓周年）
python -m dividend_lowvol_rotation.report --capital 200000

# 指定建仓日（例如已持仓，记录真实建仓日）
python -m dividend_lowvol_rotation.report --capital 200000 --entry-date 2026-08-17

# 用相同逻辑回测（起点 = 你的建仓日）
python -m dividend_lowvol_rotation.backtest --rebalance-mode entry_anniversary --start 2016-08-17 --years 10
```
