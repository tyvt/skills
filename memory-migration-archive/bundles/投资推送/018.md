## 算不算「已知价格买入」？

**半已知，不是完全已知。**

你周二上午能自己估算：

- 周一美股收盘（公开）
- 大概汇率（公开）

1. **估值汇率**：基金用自家规则（如彭博中间价、特定时点 CFETS），不一定等于你看的汇率

## 凯利公式本来解决什么问题

经典形式（单次赌局）：

\[
f^* = \frac{bp - q}{b}
\]

连续收益近似（更贴近指数）：

\[
f^* \approx \frac{\mu}{\sigma^2}
\]

含义：在**优势（期望收益）**和**风险（波动）**已知时，最大化长期几何增长率的最优仓位比例。

它适合的场景是：**重复博弈、优势可估计、下注规模可连续调整**（如量化交易、赌场）。

## 和「多指数定投/信号买入」的错配

你这套策略本质是**信号触发买入**（不是日历定投），但分配问题类似。凯利在这里会遇到几个硬伤：

| 问题 | 说明 |
|------|------|
| **参数极难估** | \(\mu\)、\(\sigma\) 随市场 regime 剧烈变化；用历史均值算出来的 \(f^*\) 往往过激进或过保守 |
| **全凯利回撤巨大** | 实务中几乎都用 **1/4～1/2 凯利**；全凯利对估计误差非常敏感 |
| **忽略相关性** | 红利、科创、纳指高度相关；逐指数单独算凯利会重复押注同一风险因子 |
| **与信号逻辑重复** | 你已在「低位 + 接近买入」时加大权重，这本质上已是**战术性加仓**，再叠凯利容易双重加码 |
| **频率不同** | 各指数买入次数差很多（红利约 14%、创业板约 6%），单纯按凯利权重不管「一年能买几次」，会导致实际仓位漂移 |

项目 README 也明确：**长期仓位会漂移，需手动再平衡**——这说明核心矛盾是**战略权重**，不是单次金额公式。

## 若仍想借鉴凯利，怎么用才合理

可以，但建议**降维使用**，不要直接当单次买入公式：

### 1. 战略层：主观目标权重（主框架）

先定各指数目标仓位，例如：
- 红利 40%（压舱石）
- 成长宽基 40%
- 美股 20%

单次买入只是在**当年剩余预算**里按权重切分，而不是每次重新算凯利。

### 2. 战术层：用凯利思想做「上限」而非「精确值」

对每个指数粗估：
- \(\mu\)：长期年化期望（如 6%～8%，或保守用 0）
- \(\sigma\)：近 3～5 年年化波动

算 \(f^* = \mu/\sigma^2\)，再取 **1/4 凯利** 作为**该指数仓位上限参考**。若算出来接近 0 或负数，说明「优势不清晰」，更应维持固定小额或观望。
