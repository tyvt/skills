你已经在行业差异化里写了“周期股改用跨周期均值”，但增长率门槛本身就不该是固定值。营收CAGR=0意味着企业五年零增长，但一个处于行业下行期的优质周期龙头，可能实际表现远超同行；而一个处于上行期的平庸公司，可能被动录得正增长。建议对周期股改为：营收增速的行业分位数 ≥ 30%，即跑赢至少三分之一的同行即可。
2. “派息率稳定在30%~70%”过于刚性
这个区间作为一般性参考没问题，但你把它写成了硬门控。银行股的分红比例可以长期稳定在28%~32%，完全在区间内；但有些公用事业或成熟制造企业的派息率可能稳定在20%~25%，这同样是健康的信号。建议把“30%~70%”改为参考区间，真正的硬门控是：派息率波动幅度小（如5年内标准差 < 10个百分点），且不是靠借钱或卖资产来维持分红。

你在行业差异化里写了“银行/保险/地产/开发商：标准FCF/D组不适用，改用监管资本/内含价值口径或整体跳过并标注”。但银行股恰恰是低频分红策略最经典的适用对象之一。中泰证券的红利筛选框架给出了很明确的银行股替代指标：核心一级资本充足率、ROE≥8%、不良率≤1.5%、拨备覆盖率≥180%、分红比例≥28%且稳定。不应该“整体跳过”银行，而是用这组替代指标替代FCF/D门槛。
