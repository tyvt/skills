## 结论

「编辑」是否显示由 `canEditRow` 决定。在**管理端**（你截图里有「行政区划」列，对应 `isManageMode === true`）时，只要业务状态不是 **审核中（`1`）** 和 **已注销（`3`）**，就会显示「编辑」——**已备案（`2`）也在允许范围内**。

```263:274:d:\repository\苏州市房地产监测V3\zhi2-web-admin\src\views\company\companyAdmin\index.vue
    canEditRow(row) {
      if (!this.checkPermission([this.perms.edit], '编辑')) return false
      const bizState = String(row.bizState)
      if (bizState === '3' || bizState === '1') return false
      if (this.isManageMode) return true
      if (bizState === '0') return true
      if (bizState === '2') {
        if (this.isAgency) return true
        return String(row.adminType) === '0'
      }
      return false
    },
```

和截图一致的行为：

| `bizState` | 常见含义 | 管理端能否编辑 |
|------------|----------|----------------|
| `0` | 暂存/草稿 | 能 |
| `1` | 审核中 | **不能**（第 266 行） |
| `2` | 已备案 | **能**（第 267–268 行直接 `return true`） |
| `3` | 已注销 | **不能** |

同一文件里「是否启用」开关在 `3` 时也会禁用，和把 `3` 当作终态一致；「注销」按钮则要求 `bizState === '2'`（第 277 行），说明**已备案后仍允许走注销**，管理端仍保留编辑入口，多半是方便监管侧改资料或配合后续注销流程。

## 企业端（对比）

`terminalType === 'B'` 时逻辑更严：

- `0`：可编辑  
- `2`（已备案）：经纪机构一律可编辑；开发企业只有 `adminType === '0'` 时可编辑  

所以企业端并不是「已备案一律不能改」。
