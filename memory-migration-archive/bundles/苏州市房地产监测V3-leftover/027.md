### [HIGH] 首次进入时可能与 `detailMixins` 重复请求（basic / `view` 或 `edit`）

**File:** `zhi2-web-admin/src/views/company/companyManagement/components/DeveloperBasicInfoDetail.vue:307-314`（及 `detailMixins.js:43-57`、`320-322`）

**Issue:** `formMode` 为 `view` 或 `edit`（路由带 `id`/`tableid` 或显式 `formMode`）时，挂载阶段会触发两次 `reloadDetail()` → `getDetail()` → `getOwnCompany`。

**Why:** Vue 2 中 `detailMixins` 的 `formMode` watcher 带 `immediate: true`，在 **`created` 之前** 就会执行；`view`/`edit` 分支会调用 `init()`，本组件已重写为 `reloadDetail()`。本次又在 `created()` 里无条件 `reloadDetail()`，与 watcher 路径叠加。  
**改前**（仅入网在 `created` 拉数）：basic + `view` 只有 watcher 一次请求。  
**改后**：basic + `view`/`edit` 为 **watcher + `created` = 2 次** `getOwnCompany`（回归）。

**Fix:** 仅在 mixin 不会拉数的场景在 `created` 里拉数，例如：

```javascript
created() {
  ensureSingleQualification(this.form, this.$set.bind(this))
  this.initDict()
  if (this.formMode === 'add') {
    this.reloadDetail()
  }
},
activated() {
  this.reloadDetail()
},
```

或去掉 `init()` 对 `reloadDetail` 的重写，让 `created` 成为唯一「无 tableid / add」补拉入口（需整体梳理，避免再漏拉）。
