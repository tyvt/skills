## 问题是什么

这是**微信登录接口请求被中途取消**，不是典型的“接口返回业务错误”。

- 报错：`MiniProgramError: Request aborted`
- 对应请求：`GET /estate/wechatOauth/getInfoByCode?code=...`
- 作用：用 `wx.login` 拿到的 `code` 去后端换 `accessToken` 和用户信息

```41:50:d:\repository\昆山市民\src\utils\wxLogin.js
export function loginWithWxCode() {
  const useUser = useUserStore()

  return getWxLoginCode()
    .then((code) => getInfoByCode({ code }))
    .then((userRes) => {
      useUser.setToken(userRes.data.accessToken)
      useUser.setUserInfo({ ...userRes.data, idNumber: userRes.data.idNumber })
      return userRes
    })
}
```

## 常见原因（结合你这个项目）

**1. 重复触发登录，请求互相打断（最可能）**

`loginWithWxCode()` 在多个地方都会调用：

- `App.vue` 的 `onShow`：每次小程序从后台回到前台都会调
- `home.vue` 的 `onLoad`：首页加载时再调一次

```63:75:d:\repository\昆山市民\src\App.vue
      }

```

截图里错误旁有红色 **2**，很像**同一类请求被触发了两次**，前一次还没完成就被取消。

**2. 页面切换过快**

进入「我的决策」时触发了 `pages_vote/vote/index` 的 `onShow`，如果此时登录请求还在进行，切页、返回、切 tab 都可能导致 `wx.request` 被中止，axios 就会报 `Request aborted`。

**3. 一般不是这些问题**

| 现象 | 通常报错 |
|------|----------|
| 域名未配置白名单 | `url not in domain list` |
| 请求超时 | `timeout` |
| 后端 500 | `status code 500` |

你这里是 **`Request aborted`**，更像是**请求被取消**，而不是服务器挂了或域名没配。

## 对功能的影响

- 如果**偶尔**出现：多半是并发/切页导致，用户重进或等一会儿往往就正常。
- 如果**每次**都出现：需要查后端 `getInfoByCode` 是否慢、是否稳定，以及登录是否被重复触发。

## 建议处理方式

1. **给 `loginWithWxCode` 做单例/防抖**：同一时间只保留一个登录请求，避免 `App.onShow` 和页面里重复调用。
2. **对 `Request aborted` 静默处理**：这类取消不必弹“网络错误” toast。
3. **确认是否影响实际功能**：登录后 token 是否正常、列表能否加载；若功能正常，可先当作调试噪音处理。
