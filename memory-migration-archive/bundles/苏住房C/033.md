**问题原因：**

`z-paging` 默认 `fixed: true`，会以全屏固定定位从页面顶部（`top: 0`）铺开，导致：
1. **列表遮挡顶部导航栏**（「新房」标题栏）

对齐二手房页（`stockHouse/index.vue`）的布局方式：

1. 给 `z-paging` 设置 `:fixed="false"`，避免全屏覆盖
2. 页面容器使用 `flex` 纵向布局 + `height: 100vh`
3. 列表区域 `flex: 1; min-height: 0`，只在剩余空间内滚动

修复后结构为：搜索框 → 快捷入口 → 筛选栏固定在顶部，列表在下方独立滚动，不再遮挡导航栏。

请重新编译后在 H5 或小程序中验证滚动效果。若「最新楼盘」「在售楼盘」等子页面也有同样问题，可一并按此方式调整。
