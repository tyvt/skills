## 三、后台菜单配置（苏住房版）

苏住房首页、慧物业、掌服务等 Tab 的菜单来自后台配置：

- **配置键**：`app.suzhufang.config`
- **接口**：`GET /system/config/getByKey/app.suzhufang.config`
- **本地兜底**：`src/static/menus.fallback.json`

菜单项示例：

```json
{
  "name": "公共收益",
  "url": "1_0_5",
  "level": "v3",
  "levelCode": "owner",
  "isShow": "0"
}
```

- `url`：填路由码（如 `3_1_19`、`1_0_5`），不要填完整路径
- `level`：权限等级（`v0` 无需登录 → `v3` 需身份认证）
- `levelCode`：身份要求（如 `owner` 业主）
- `isShow`：`"1"` 表示暂未开放，点击会提示 `showMsg`

在后台管理系统中修改 `app.suzhufang.config` 的 JSON 即可调整菜单入口，无需改前端代码。
