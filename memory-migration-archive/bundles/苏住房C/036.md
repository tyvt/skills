## 问题原因

流程指南详情通过 `ZsRichText` → `formatRichTextContent` → `rich-text` 渲染 HTML。

第二篇指南（业主大会相关）的正文里，书名号被写成了非法 HTML：

- 正确：`关于印发《业主大会议事规则》等示范文本的通知》`
- 实际：`关于印发<业主大会>议事规则》等示范文本的通知》`

其中的 `<业主大会>` 会被当成 HTML 标签，解析失败并出现 `Parse Error`，导致**标题能显示、正文白屏**。

## 修复方案

在 `formatRichTextContent` 中增加 `escapeInvalidHtmlAngleBrackets`，把**不是合法 HTML 标签**的 `<` 转义为 `&lt;`：

```248:252:d:\repository\苏住房C\zhi2-mobile-shimin\src\utils\index.js
/** 转义非 HTML 标签中的 <，避免书名号等内容被误解析为标签导致 rich-text 白屏 */
function escapeInvalidHtmlAngleBrackets(html) {
  return String(html).replace(/<(?!\/?[a-zA-Z!])/g, '&lt;')
}
```

该修复会作用于所有使用 `ZsRichText` 的页面（流程指南、政策法规、公告等）。
