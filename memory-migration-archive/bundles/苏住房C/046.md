## 问题原因

1. **微信小程序原生行为**：`ZsButton` 原先把 `type="primary"` 传给原生 `<button>`，微信默认主色是**绿色**（`#07c160`）。
2. **禁用态 CSS 失效**：禁用样式用了 `rgba(var(--primary-color-rgb), 0.5)`，小程序不支持这种写法，背景色回退为微信默认绿色。
3. **禁用样式范围过大**：`.zs-button[disabled]` 作用于所有按钮，连默认/取消按钮也会被加上主题色背景。

## 修复方案

**核心改动在 `ZsButton.vue`：**
- 不再向原生 button 传 `type` / `plain`，避免触发微信绿底
- 用 class（`zs-button--primary`、`zs-button--plain`、`is-disabled`）控制样式
- 增加 `hover-class="none"`，去掉微信默认点击态
- 禁用态使用预计算的 `--primary-color-disabled` 变量

**全局配套：**
- `styles/index.css`：新增 `--primary-color-disabled` 变量
- `uni.scss`：重置小程序 disabled 默认透明度，避免绿底透出
- `zs-button.scss`：补充取消/重置按钮的禁用灰色样式
- `App.vue` / `daily.vue`：主题色覆盖时同步设置禁用色变量
