## 原因分析

1. **路由名称不匹配**  
   点击「发起表决」后会跳转到维修资金表决新增页，但代码里写死了路由名 `OwnerDecision/maintain/:tableid`。近期重构后，后台菜单实际可能是 `MaintainDecision/maintain/:tableid` 或指向 `estate/maintainDecision/detail`，路由对不上会导致跳转失败或加载错误组件。

2. **页面初始化报错**  
   表决详情页（`maintainDecision/detail.vue`、`ownerDecision/detail.vue`）在多处直接使用 `$route.name.split('/')`，当路由没有 `name` 时会抛出异常，页面白屏。

## 修复内容

1. **新增统一跳转方法**（`decisionCommon/config.js`）  
   - `pushMaintainDecisionDetail()`：按后台菜单自动匹配正确路由（优先 `estate/maintainDecision/detail`）  
   - 兼容 `MaintainDecision` / `OwnerDecision` 两种历史路由名  
   - `parseMaintainVoteSession()`：安全读取发起表决时预填的 session 数据

2. **更新跳转入口**  
   - `fundUsageKs/steps/step4-5.vue`（预算/结算表决页的「发起表决」）  
   - `home/components/VoteTable.vue`  
   - `publicity/detail.vue`

3. **修复详情页崩溃**  
   - 对 `$route.name` 做空值保护  
   - 使用 `routeSegment` 计算属性替代模板里的 `.split()`  
   - 安全解析 `MAINTAIN_VOTE` session 数据
