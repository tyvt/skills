- 用 RSA 私钥解密 `res.data.key`，得到 AES 密钥
- 用 AES-CBC（零 IV）解密 `res.data.data`
- 将解密后的 JSON 写回 `res.data`，后续业务逻辑无需改动

构建已通过验证。

## 解密流程

```
响应头 x-encrypt: true
    ↓
RSA 解密 data.key → AES 密钥
    ↓
AES-CBC 解密 data.data → JSON 明文
    ↓
替换 res.data，继续走原有 code/msg 判断
```

当后端返回加密响应时，前端会自动解密，业务代码仍按原来的 `res.data.code`、`res.data.data` 等方式使用即可。
