## 真正原因

上次改的是错误字段。uni-app H5 地图在 `loadMaps` 里通过 `getMapInfo()` 读取的是：

```javascript
__uniConfig.qqMapKey  // 构建时从 manifest 写入，manifest 里为空则为空
```

而之前只改了 `__uniConfig.h5.sdkConfigs.maps.qqmap.key`，**`<map>` 组件根本不会读这里**。

因此会出现：

- 接口 `qq.map.key` 有值 → `localSearch` 正常  
- `__uniConfig.qqMapKey` 仍为空 → 控制台报 `Map key not configured`

## 本次修复

1. **`qqMapKey.js`**：注入时设置 `__uniConfig.qqMapKey = key`（这才是 H5 地图用的字段）
2. **`ZsMap.vue`**：增加 `:key="qqMapRenderKey"`，在 key 首次就绪后强制重新挂载 `<map>`，避免之前已执行过失败的 `loadMaps`
