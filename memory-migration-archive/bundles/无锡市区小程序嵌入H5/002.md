## 参数对照

| 文档参数 | 含义 | 当前代码 |
|---|---|---|
| `arg0` | 应用 appId | `jisnzjk`（`SFB_FACE_APP_ID`） |
| `arg1` | 用户 token | `getSfbToken()` 从 URL 或缓存读取 |

| `success` | 成功回调 | 已绑定，解析 `retcode` / `msg` |

实际调用等价于：

```javascript
lightAppJssdk.face.livenessFaceAuth({
  arg0: 'jisnzjk',
  arg1: token,      // 苏服办入口 URL 传入的用户 token
  arg2: '1',        // 个人用户
  success(data) { /* ... */ },
  fail(data) { /* ... */ },
})
```

## 成功判定

文档规定：**`retcode === '000000'` 为成功**。

| appId | 用途 |
|---|---|
| `wxzhwyypbjl` | 苏服办**包裹页**应用标识（getTicket、跳转 H5） |
