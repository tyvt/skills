/** 当前会话是否在有效期内完成过人脸识别 */
export function isSfbFaceRecentlyVerified(maxAgeMs = 5 * 60 * 1000) {
  /* #ifdef H5 */
  const ts = Number(readPersistedValue(SFB_FACE_VERIFY_SESSION_KEY) || 0)

## 实际生效场景

主要用于 **苏服办 → 不动产授权（bdc 页）** 流程。进入 bdc 时会校验：

```55:64:d:\repository\无锡市区小程序嵌入H5\zhi2-mobile-admin-h5-c-unlimited\src\pages\face\bdc.vue
  if (verifyResult !== 'true' || !isSfbFaceRecentlyVerified()) {
    console.warn('[苏服办人脸识别][bdc页面] 未完成有效人脸识别，跳转 face', {
      verifyResult,
      recentlyVerified: isSfbFaceRecentlyVerified(),
      options,
    })
    loadingText.value = '正在跳转人脸识别...'
    redirectToFaceVerify({ realName, certCode, mobile, portalPostAction })
    return
  }
```

含义是：

- **5 分钟内**：可直接进入不动产授权，无需再次扫脸
- **超过 5 分钟**：即使 URL 带 `verifyResult=true`，也会被重定向回人脸识别页

应用启动时还会清理过期状态（`App.vue` 调用 `clearStaleSfbFaceState()`），超过 5 分钟的记录会被清除。

| 项目 | 说明 |
|------|------|
| 存储位置 | `localStorage` + `sessionStorage`（键名 `sfb_face_verify_session`） |
