## 问题

- 接口路径：`businessName = 'permit/cancel'` / `'permit/extend'` → `/presale/permit/cancel/...`
- 权限字符：与菜单 component 一致 → `permitCancel` / `permitExtend`（如 `presale:permitCancel:edit`）

## 处理方式

沿用 `permsMixins` 已有设计，增加 `businessNameForPerms` 隔离权限与接口：

| 场景 | 配置 |
|------|------|
| 列表页 | `businessNameForPerms: 'permitCancel'` / `'permitExtend'` |
| 详情页 | `permission-business-name="permitCancel"` / `"permitExtend"` |
| 自定义按钮 | `CANCEL_PERMS` / `EXTEND_PERMS` 改为 `presale:permitCancel:*` / `presale:permitExtend:*` |

**接口拼接不变**，仍使用 `businessName: 'permit/cancel'` / `'permit/extend'`。

- `ListTemplate.js` — 操作列权限改用 `permissionBusinessName`
- `OperationBtnGroup/index.vue` — 新增 `permissionBusinessName` prop
- `permitCancel/*`、`permitExtend/*` — 列表/详情/常量文件

后续若有类似「接口带 `/`、权限用驼峰」的模块，只需设 `businessNameForPerms` 即可，无需改接口路径。
