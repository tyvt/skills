## 两次 `detail` 各是什么

机构入网信息变更详情 `getDetail` 会串行调两个接口：

1. **`/company/companyRecordChange/detail`** — 变更单，用来填 `form`、算工具栏状态  
2. **`/company/companyRecord/detail`** — 原备案，**只写入 `beforeForm`**，给变更对比用（没有 `originInfo` 时才拉）

你在 Network 里看到的第二个 `detail` 预览里的 `bizState: "2"`（或 `"1"`）是**原备案**的状态；DevTools 里两个请求都可能显示成 `detail`，容易误以为覆盖了表单。
