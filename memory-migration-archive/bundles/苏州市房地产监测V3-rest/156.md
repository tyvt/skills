### SurveyChangeHouseTable.vue

**[HIGH] 嵌套 `zs-table-column` 可能无法形成多级表头**

File: `zhi2-web-admin/src/views/presale/surveyChange/components/SurveyChangeHouseTable.vue:22-77`

Issue: 在「建筑面积 / 套内面积 / …」下嵌套子 `zs-table-column`，但 `zs-table-column.vue` 模板只在 `el-table-column` 内渲染 scoped 单元格插槽，**未把 `$slots.default` 转给底层 `el-table-column`**。

Why: Element UI 的多级表头依赖「父 `el-table-column` 的子列 VNode」。子列若被丢弃，页面上可能只剩带 group 标题、无「变更前/变更后」子列或空列，与需求不符。这是本仓库里**首次**嵌套 `zs-table-column` 的用法，风险较高。

Fix（择一）：

- 分组表头改用原生 `el-table-column` 嵌套（仍放在 `zs-table` 的 default slot 里）；或  
- 在 `zs-table-column` 内增加对默认插槽的转发（需评估与现有自定义 cell slot 的兼容）；或  
- 不用嵌套，改为扁平列名（如「建筑面积-变更前」）+ `formatter`（与产品确认）。

子列上的 `align="right"`、`:formatter="areaWithUnitFormatter"` 以及 `slot-scope="{ scope }"`（与 `zs-table-column` 的 `<slot :scope="scope">` 一致）在**子列能渲染的前提下**是正确的。
