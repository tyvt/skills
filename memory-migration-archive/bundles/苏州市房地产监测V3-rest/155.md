## 根因

`/company/shareholder/detail` 的请求体是**标量** `shareholderId`。`detail.vue` 里 `getDetailParams()` 曾写成：

```javascript

```

雪花 ID 超过 `Number.MAX_SAFE_INTEGER`（约 16 位）时会被截断，后端收到错误主键，详情就会异常。

项目里其实已有防护链路，但被这一步 `Number()` 绕过了：

- `getId()`（`ruoyi.js`）路由主键已是 **字符串**
- `jsonParseSafeIds.js`：响应 `parseJsonWithSafeIds`、请求 `coerceRequestBodyIds` + 详情标量 `serializeJsonRequestBody`
- 其它详情页（预售许可、房源限制等）`getDetailParams()` 直接 `return this.id`，没有转 number

## 全局排查（`zhi2-web-admin/src`）

| `building/houseLimit/limitFormMixin.js` | query 的 `companyId` / `companyRecordId` 用 `Number()` | 已改为 `String(...).trim()` |
