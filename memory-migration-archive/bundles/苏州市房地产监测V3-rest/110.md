## 如何区分 CRUD vs 非 CRUD

1. **函数命名**：`listX`/`getX`/`addX`/`updateX`/`delX` 通常对应 CRUD；`queryX`/`selectX`/`checkX`/`manualX`/`extractX` 等为业务操作。
2. **第三段是否为标准 CRUD 词**：`page`、`add`、`update`、`delete`、`detail`、`remove`、`info`（有时 `list`）→ CRUD。
3. **第三段是否为 camelCase 动词短语**（如 `queryBalanceAmount`、`openAccountRecord`）→ 非 CRUD，**不应**再拼第四段。
4. **可疑模式**：`/{模块}/{实体}/{业务方法名}/{page|add|detail|update|delete}` — 四段且末段为 CRUD 后缀，高度疑似批量迁移误改。

|------|------|

| `finance/account.js`: `.../openAccountRecord` | `property/propertyAccount.js`: `.../openAccountRecord/detail` |
| `benefit/pubBankDetailDay.js`: `.../manualReconciliation` | `capital/rec.js`: `.../manualReconciliation/add` |
