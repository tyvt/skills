**请求体**：

```json
{
  "personnelRecordId": "字符串",
  "adjustType": "cancel | freeze | unfreeze",
  "reason": "选填，≤500字",
```

| 值 | 含义 | 前端行为 |

| `freeze` | 冻结 | 仅禁止业务操作；不改变 `bizState` |
| `unfreeze` | 解冻 | 当 `freezeStatus === '1'` 时作为唯一选项 |

- `POST /company/agencyPersonnel/candidates`（无 body）— 注销备案绑定经纪人时，拉取本机构已备案替代人员列表
