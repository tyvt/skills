## 原因

`OperationBtnGroup` 里 `businessName` 是 **prop**（给接口路径用，如 `regProject`）。如果又在 `computed` 里定义同名 `businessName`（常见于想区分权限码和接口名），Vue 就会报：

> The computed property "businessName" is already defined as a prop.

正确做法是：**权限用另一个计算属性名**，不要复用 `businessName`。

## 修改内容

在 `OperationBtnGroup` 中：

1. 新增可选 props：
   - `permissionPrefix` — 完整权限前缀（如 `xmxx:jgxm`）
   - `permissionModuleName` / `permissionBusinessName` — 分段覆盖
2. 新增计算属性 `effectivePermissionPrefix`（**不叫** `businessName`）
3. 按钮 `:permission` 改用 `effectivePermissionPrefix`
4. 提交/审批仍传 `business-name="businessName"`，接口路径不变

在 `jgxm/detail.vue` 中补充：

```vue
:permission-prefix="permsPrefix"
```

这样权限走 `xmxx:jgxm:*`，接口仍走 `prefund/regProject/*`。
