### 最终结论
### 原因
`ResizeObserver` 监听登录盒后，每次把 `minHeight` 加大 → 右侧 `.login-container` 被 `height: 100%` 拉高 → `scrollHeight` 跟着变大 → 再次算出更大的宽高，形成**正反馈**，图片区域会一直涨到接近全屏。

### 修复（管理端 + 门户）
1. **去掉**对登录盒/表单的 `ResizeObserver`  
2. **不再用** `scrollHeight` 量表单，只用各登录模式固定的 `min-height`（如 500/520/560）与图片宽高比计算  
3. **增加视口上限**：单栏宽约 ≤ 42% 屏宽，盒高约 ≤ 78% 屏高  
4. 窗口尺寸变化时仅用 `resize` 事件重新算一次（不会自激）

**苏州市房地产监测V3** 的 `zhi2-web-admin/src/views/login.vue` 已是上述逻辑；**门户** `login.vue` 已同步同样修改。
