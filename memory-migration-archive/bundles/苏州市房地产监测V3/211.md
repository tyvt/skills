## 原因说明

   `registerFormConsumerMixin` 把 `form` 做成只读 computed（从父页 `inject` 的 `registerForm` 读取），但 `CompanyRegisterSingleForm` 还混入了 `detailMixins`。全局 `formMode` 在注册页为 `add` 时，`detailMixins` 会执行 `this.form = Object.assign(...)`，从而触发警告。单页注册表单并不依赖 `detailMixins`（字典、校验、`msgError` 等已在 `Vue.prototype` 上），父页也已用 `REGISTER_CACHE_KEY` 做缓存。
