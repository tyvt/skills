## 原因

`v-dialogDrag`（`src/directives/dialog/drag.js`）在挂载时会给 `.el-dialog` 写：

- `position: absolute`
- `top / bottom / left / right: 0`（等价于 `inset: 0`）

弹窗会被 **拉满整个 `el-dialog__wrapper`（约一屏高）**，所以你会看到 **1300 × 987**，分页和「关闭」之间大片空白。这和 `height: auto`、compact 类无关，是 **拖拽指令把盒子撑满了**。

## 修改

1. **重写 `drag.js`**：用 `top: 15vh` + `left: 50%` + `translateX(-50%)` 居中，**不再四边贴 0**；拖拽时用 `getBoundingClientRect` 计算位置。
2. **选择弹窗关闭拖拽**：`zs-select-dialog` / `zs-select-dialog-func` 增加 `:draggable="false"`，避免再被该指令改写尺寸。

请 **重启 dev** 并 **强刷** 后再打开「项目名称」弹窗，高度应接近内容高度。若仍异常，在 Elements 里看 `.el-dialog` 是否还有 `bottom: 0` / `right: 0` 的内联样式。
