2. **宽表强制可滚动**：内容超出可用区域时，设置 `overflow-x: auto`
3. **默认样式**：表格 `body-wrapper` 默认 `overflow-x: auto`

请硬刷新（Ctrl+F5）后打开品牌管理页面，应能：
- 看到底部横向滚动条
- 左右拖动查看所有列
- 右侧「操作」列完整可见
