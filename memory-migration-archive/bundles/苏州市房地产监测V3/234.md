## 结论：修复正确

Element UI 2 的 `el-dialog` 在 **`.el-dialog__wrapper`** 上用 `v-show="visible"` 切换可见性：隐藏时 Vue 会写内联 `style="display: none;"`。  
CSS 里对同一元素使用 **`display: flex !important`** 会压过这条内联样式（`!important` 规则优先于普通内联），关闭后 wrapper 仍表现为 flex 容器，出现弹窗关不掉、遮罩/内容仍占位或仍可点等问题。

当前代码已改为：

```449:457:d:\repository\苏州市房地产监测V3\zhi2-web-admin\src\components\zs-dialog\zs-dialog.vue
/* 选择弹窗：wrapper 垂直居中，避免固定 top 导致小弹窗贴顶、大弹窗顶栏留白过多 */

.el-dialog__wrapper.zs-dialog.scope-select-dialog {
