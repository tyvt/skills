### 2. 「不带竖线」的实际含义

不是「完全无边框」，而是：

| 层级 | 样式 |
|------|------|
| 外层容器 | `Headline` / `list-card` / Tab 卡片保留 `1px #f0f0f0` 外框 |
| 表格单元格 | **无竖线**（`border-right: none`） |
| 行分隔 | 保留 **横线** `border-bottom: 1px solid #f0f0f0` |
| 表头 | 浅灰底 `#fafafa`（由 `zs-table` 的 `header-cell-style` 提供） |

**关键**：若传了 `border`，会加上 `.el-table--border`，mixin 会**重新加回竖线**：

```419:435:d:\repository\苏州市房地产监测V3\zhi2-web-admin\src\styles\index.scss
    th.el-table__cell,
    td.el-table__cell {
      border-right: none;
    }

    &.el-table--border {
      th.el-table__cell,
      td.el-table__cell {
        border-bottom: 1px solid #f0f0f0;
        border-right: 1px solid #f0f0f0;
      }
```

因此「不带竖线」= **`zs-table` 不要写 `border` / `:border="true"`**。
