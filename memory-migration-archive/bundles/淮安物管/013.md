@zhi2-web-admin/src/views/autonomy/regulation/components/index.vue:142 自定义列显示里面调整顺序后没有生效

### 最终结论
## 原因说明

1. **Element UI 的 `el-table` 限制**：子组件 `el-table-column` 只是调换了 `v-for` 顺序时，表格内部列缓存往往**不会按新顺序重排**，界面看起来就像排序没生效。  
2. **刷新后配置丢失**：`displayColumns` 只从 Vuex 读配置，**整页刷新后 Vuex 里没有从 `localStorage` 恢复**，保存过的顺序在刷新后仍像没生效。  
3. **旧数据**：本地已存的配置可能没有 `order` 字段，`a.order - b.order` 会得到 `NaN`，排序不稳定。

## 修改说明

| 文件 | 改动 |
|------|------|
| `mixins/table.js` | 增加计算属性 `tableColumnsKey`（用当前列 `prop` 顺序拼成字符串）；`loadTableConfigFromStore` 在 Vuex 为空时从 `localStorage` 读出并 `commit` 到 store；排序改为 `(a.order ?? 0) - (b.order ?? 0)` |
| `mixins/ListTemplate.js` | 在 `<zs-table>` 上增加 `:key="tableColumnsKey"`，列顺序变化时重建表格 |
| `global-table-config.vue` | 拖拽列表改为 `v-model="localColumns"`，与 vuedraggable 2.x 用法一致 |

保存自定义列顺序后，表格会按新顺序显示；刷新页面后也会从本地存储恢复顺序。若你希望**草拟 / 定稿**等不同 `versionType` 使用**各自独立**的列配置，需要再给 `tableId` 加上 `versionType` 等后缀，需要的话可以再改一版。
