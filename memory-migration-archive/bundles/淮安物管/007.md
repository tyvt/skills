### 最终结论
原因是 `zs-search-form` 组件的自动布局逻辑：

当查询条件 **≤ 3 个** 时，会把 24 栅格均分给每个表单项。这里只有 1 个「物业管理区域名称」，所以计算结果是 `24 ÷ 1 = 24`，输入框就占满了整行。

相关代码在 `zs-search-form.vue` 的 `getItemLayout` 方法里：

```182:186:d:/repository/淮安物管/zhi2-web-admin/src/components/zs-search-form/zs-search-form.vue
      // 查询条件不足一行时，均分列宽
      if (count <= ITEMS_PER_ROW) {
        const span = Math.floor(TOTAL_COLUMNS / count)
        return { xs: 24, sm: 24, md: span, lg: span, xl: span }
      }
```

**修复方式**：给表单项显式指定 `layout`，覆盖自动计算：

```javascript
layout: { xs: 24, sm: 24, md: 8, lg: 8, xl: 8 }
```

这样在大屏上输入框约占 1/3 宽度，与系统里其他列表页的搜索栏一致。企业详情页和授权管理页都已同步修改。刷新页面后应能看到效果。
