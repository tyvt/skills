| 弹窗选择协议后 | `pick()` |
| 编辑/查看时拉详情 | `getData()` |

| 协议号前两位 `newStr` | 展示的区县前缀 |
|----------------------|----------------|
| `22` 或 `50` | 淮阴区 |
| `26` | 盱眙县 |
| `23` | 淮安区 |
| 其他 / 未选协议 | 界面保持默认 **淮阴区**（`pick`/`getData` 无匹配时不改 `split`） |
