## 原因

登录成功后会执行 `this.$router.push('/')`，流程大致是：

1. 守卫发现已有 token，进入 `handleAuthenticatedRoutes`
2. 首次登录时 `roles` 为空，会拉用户信息并 `GenerateRoutes` 动态注册路由
3. 注册完成后执行第 179 行的 `next({ ...to, replace: true })`，用新路由表重新进入 `/index`

```178:179:d:\repository\园区物管2.0\zhi2-web-admin\src\router\index.js
      // 确保新路由已添加完成后再跳转
      next({ ...to, replace: true })
```

Vue Router 3.4+ 会把这种守卫内重定向记为 `NavigationRedirected`，`router.push` 的 Promise 会 reject。原先只忽略了 `NavigationDuplicated`，所以控制台会出现：

> Redirected when going from "/login" to "/index" via a navigation guard

## 修复

已在 `router/index.js` 中同时忽略 `NavigationDuplicated` 和 `NavigationRedirected`，并对 `replace` 做了相同处理。
