   - **`scale-clip` 使用 `overflow: hidden`**，加上设计区写死 **`height`**，会把画布底部裁掉。  
   - **`.chart-block__canvas` 默认 `overflow: hidden`**，也会裁掉贴边的坐标轴。

2. **不能纵向滚动**  
   - **`stage` 使用 `flex: 1` + `height: 100%` + `overflow: hidden`**，高度被锁在视口内，内容再高也撑不开滚动条。  
   - 设计区固定高度时，**`scrollHeight` 与实际可视被裁内容**不一致，也不利于测量。

1. **ECharts 横向条形图**
