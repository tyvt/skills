## 2. 部署前端的服务器禁外网，地图还能用吗？

| 角色 | 是否需要访问外网 | 说明 |
|------|------------------|------|
| **部署前端的静态服务器**（Nginx 等） | 通常**不需要** | 只负责下发静态资源；不参与地图/业务 API 调用 |
| **访问页面的用户浏览器** | **需要**（若要用腾讯地图） | 需能访问 `map.qq.com`、`apis.map.qq.com` 等，以及你们的 `VITE_APP_BASE_API` |
| **后端 API 服务** | 由浏览器访问 | 浏览器 → 后端；与「前端静态机能否上外网」无直接关系 |

因此：

- **前端静态机禁外网**：一般**不影响**地图功能（用户能打开页面即可）。
- **用户环境禁外网**（纯内网、防火墙拦腾讯域名）：地图 SDK、区划边界、底图会失败；业务接口若走内网后端仍可能部分可用，但地图本身大概 …[truncated]
