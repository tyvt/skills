已按你的场景改好了，原因和做法如下。

**原因：** 上次改成 `scale(sx, 1)` 后，纵向不再缩放，设计稿总高度 `designMeasuredH` 往往大于 `calc(100vh - 84px)` 给出的可视高度，整块就会**竖向溢出**。
