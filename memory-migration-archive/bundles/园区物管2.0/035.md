## 问题原因

点击菜单后出现 **「页面未授权或不存在」**，来自路由守卫对 `/404` 的拦截（`router/index.js` 第 213 行），说明 **Vue Router 没有匹配到该菜单对应的路由**。

你的配置存在两个问题：

1. **外链地址含 `#`**（`https://www.kedowen.com:8666/#/share/...`）  
   项目使用 **hash 路由模式**，`#` 后的内容会被当作浏览器 hash，无法作为内部路由 path 注册，导致匹配失败 → 跳转 `/404`。

2. **组件路径应为 `InnerLink`，不是 `InnerLink/index`**  
   原代码只识别 `InnerLink`，`InnerLink/index` 会走普通组件加载逻辑，内链处理不完整。

## 正确菜单配置

在 **系统管理 → 菜单管理** 中建议这样配置：

| 字段 | 值 |
|------|-----|
| 菜单类型 | **菜单** |
| 是否外链 | **是**（`isFrame = 0`，表示 iframe 内嵌，不是新窗口打开） |
| 路由地址 | `https://www.kedowen.com:8666/#/share/2ee03216-f441-4a61-aa7c-11e14a33d8ec` |
| 组件路径 | **`InnerLink`**（不要写 `InnerLink/index`） |
| 上级菜单 | 需挂在 **Layout 目录** 下（不能单独作为顶级菜单） |

2. **`InnerLink/index.vue`**：正确处理带 `#` 的外链，在 hash 前拼接 `token` 参数。
