### 宽度留白原因
内容偏高时，缩放会按**高度**收紧（`scale = vh / 内容高度`），小于按宽度计算的 `vw / 1920`。此时若设计稿仍固定 1920px，实际显示宽度为 `1920 × scale < 视口宽`，右侧就会出现空白。

### 处理方式
1. **动态设计稿宽度**：在高度受限时，将设计稿宽度设为 `max(1920, ceil(视口宽 / scale))`，保证 `设计稿宽 × scale = 视口宽`，横向铺满。
2. **统一缩放**：`scale = min(按宽比例, 按高比例)`，一屏内完整显示且不变形。
3. **收紧默认高度**（减轻高度约束、提高可用缩放比）：
   - 柱图/画布：`188px` → `156px`
   - 饼图区：`276px` → `220px`，画布 `232px` → `196px`
   - 趋势图：`242px` → `200px`，容器 `200px` → `168px`
   - 区县柱图：`208px` → `172px`
   - 指标卡：`72px` → `64px`

侧栏收起/展开后仍会重新计算。请刷新查看：宽度应已贴边铺满；若仍觉得某列偏窄或图表偏小，可说明具体列（左/中/右），再单独调列宽比例。
