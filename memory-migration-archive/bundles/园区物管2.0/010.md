可以。腾讯位置服务提供 **WebService「行政区划」接口**，支持用 **6 位行政区划代码（adcode）** 作为 `keyword` 查询，并配合 **`get_polygon=2`**（及 `max_offset`）返回边界点串（文档：[行政区划 WebService](https://lbs.qq.com/service/webService/webServiceGuide/webServiceDistrict)）。轮廓在返回里是 **`polygon`：若干多边形，每个为 `[lng,lat,lng,lat,...]` 的一维数组**。

已在项目里接好，说明如下。

### 实现说明
1. **`map.vue`**  
   - 去掉本地 `YUANQU_AREA` 静态面。  
   - 新增 prop **`boundaryAdcode`**；父组件传入 store 的 `platformRegionCode`（6 位 adcode）。  
   - 使用 **`https://apis.map.qq.com/ws/district/v1/search`**，`keyword=adcode`、`get_polygon=2`、`max_offset=3000`，与现有 GL 地图 **同一 key**。  
   - 浏览器端用 **JSONP**（`output=jsonp` + `callback`）拉取（该 WebService 一般不能靠前端直连 JSON 跨域）。  
   - 将 `polygon` 转成原有 `getBuildingPaths` 所需的 **`lng,lat;lng,lat;...`** 再画 `MultiPolygon`；中心名称标签用接口里的 `location`。  
   - 维护 **`districtLayers`**，在重绘、`boundaryAdcode` 变化、`beforeDestroy` 时销毁，避免泄漏。

2. **`statisticsMap/index.vue`**  
   - `:boundary-adcode="platformRegionCode"`，与台账根区划一致。

### 使用与注意
- 在 [腾讯位置服务控制台](https://lbs.qq.com/) 为该 key 勾选并开通 **WebServiceAPI**（行政区划属于 WebService）。  
- **乡镇/街道四级轮廓**（`get_polygon=3`）文档写明需单独申请；当前用的是 **市/区县三级轮廓**（`get_polygon=2`），与「按市级 region 画底图」一致。  
- 若希望 **key 不出现在前端**，可再改为你们后端代理该 WebService 请求。

`@/constant/map.js` 里的 `YUANQU_AREA` 目前仅台账地图不再引用；若全项目无引用可再自行删除该常量以减负。
