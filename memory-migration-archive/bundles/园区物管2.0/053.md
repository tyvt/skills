## 原因

顶栏是 **flex** 布局时，子项默认 `min-width: auto`，宽度不能小于「内容最小宽度」。`title` 又用了 **`white-space: nowrap`**，整段标题算成一条超长内容，左侧整块最小宽度被撑满，中间 `flex:1` 被挤没空间，右侧整组（含昵称）就被推出视口。

## 改动要点

1. **整条顶栏** `.navbar`：加 `min-width: 0`，避免嵌套 flex 时再被父级卡死。
2. **左侧** `.navbar-left`、`.title-logo`：`min-width: 0`、`overflow: hidden`，并去掉 `.title-logo` 上原来的 `min-width: var(--sidebar-width)`（否则会一直占住一块最小宽度，不利于收缩）。标题区用 `flex: 0 1 auto` + `max-width: 100%` 参与分配剩余空间。
3. **标题** `.title`：`flex: 1 1 0%`、`min-width: 0`，并加上 **`text-overflow: ellipsis`**，长标题单行省略。
4. **Logo** `.logo`：`flex-shrink: 0`，避免被压扁。
5. **顶部导航容器** `.top-nav-container`：`min-width: 0`、`overflow: hidden`，避免和标题抢宽度时把布局撑爆。
6. **右侧** `.navbar-right`：`flex-shrink: 0`，保证右侧区域不会被 flex 压到「消失」；内部再用省略处理超长文案。
7. **昵称** `.user-nickname`：去掉固定 `width: 80px`，改为 **`max-width: min(240px, 32vw)`** + 原有省略，短名照常显示，极长昵称省略且不把栏位挤出屏幕。
8. **「返回账套」** `.black-account`：同样加了 `max-width` + 省略，避免长文案把右侧顶飞。
