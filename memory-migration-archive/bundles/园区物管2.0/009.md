但在 `v-for` + `v-if` 场景下，Vue 2 会为**每一列**都注册插槽函数，即使 `v-if` 为 false 不渲染内容，也会被误判为「自定义列」，导致整表列宽塌陷。

### 公共组件修复（`zs-table-column.vue`）

1. **`hasEffectiveCustomSlot`**：实际执行插槽函数，判断是否真的渲染了内容（过滤 `v-if=false` 的空插槽）。
2. **`isMeasurableFlexSlot`**：区分两类列
   - 文本类插槽（`span`、纯文本）→ 走弹性 `min-width`
   - 复杂组件插槽（`el-switch`、图片等）→ 仍用固定 `width`，可通过 `slot-width` 覆盖
3. **`measureSlotContentWidth`**：从插槽 vnode 提取文本，按实际展示内容计算列宽。
4. **弹性列注册**：用 `watch isFlexColumn` 动态注册/注销，保证表格 `fit` 正确开启。
