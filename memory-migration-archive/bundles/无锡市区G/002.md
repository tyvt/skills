## 问题原因

GitLab Runner 的 Linux 环境 glibc 版本较低（低于 2.32），而 Rollup 4.x 默认使用原生二进制 `@rollup/rollup-linux-x64-gnu`，因此加载失败。

## 修复方案

将 Rollup 替换为 WASM 版本 `@rollup/wasm-node`，不依赖系统 glibc。

在以下两个 `package.json` 中添加了 `overrides`：

**根目录 `package.json`**（npm workspaces 的 override 需在根目录生效）：

```json
"overrides": {
  "rollup": "npm:@rollup/wasm-node@4.62.3"
}
```

**`zhi2-web-admin/package.json`**（同步添加，保持子模块独立可用）：

```json
"overrides": {
  "rollup": "npm:@rollup/wasm-node@4.62.3"
}
```

相比原 262 分支的写法，做了两点调整：
1. 使用顶层 `"rollup"` override，而非嵌套在 `"vite"` 下，在 npm workspaces 中更可靠
2. 指定版本号 `@4.62.3`，避免 npm 不更新 lockfile 导致 override 未生效
