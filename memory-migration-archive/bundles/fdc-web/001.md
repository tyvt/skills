## 依赖分析

### 生产依赖（核心）

**框架与状态**
- `vue` / `vue-router` / `pinia` / `pinia-plugin-persistedstate` — 标准 SPA 三件套 + 持久化
- `@vueuse/core` / `@vueuse/integrations` — 组合式工具，HTTP 请求封装基于 `useAxios`

**Semi-Kit 内部组件生态**（项目 UI 基础）
- `@semi-kit/component` — 业务组件
- `@semi-kit/hooks` — 通用 hooks
- `@semi-kit/theme` — 主题样式
- `@semi-kit/utils` — 工具函数

**业务功能库**
- `echarts` — 图表（lot history、trend chart 等）
- `axios` + `qs` — API 请求与参数序列化
- `vue-i18n` + `@intlify/unplugin-vue-i18n` — 国际化
- `cropperjs` — 图片裁剪
- `sortablejs` — 拖拽排序（表格/菜单等）
- `print-js` — 打印
- `prismjs` — 代码高亮
- `decimal.js` — 高精度数值计算（半导体工艺参数常见需求）
- `crypto-es` — 加密（登录/鉴权相关）
- `dayjs` / `es-toolkit` — 日期与工具函数

### 开发依赖（ noteworthy ）

- `naive-ui` — UI 组件库（通过 `unplugin-vue-components` 按需引入）
- `unocss` — 原子化 CSS
- `unplugin-auto-import` / `unplugin-vue-components` — 自动导入 Vue API 和组件
- `vite@8.0.0-beta.16` — 使用 Vite 8 beta，构建配置用了 `rolldownOptions` 做代码分割
- `@semi-kit/config` — 内部工程配置
- `less` — CSS 预处理器
- Git 工作流：`commitizen` + `cz-git` + `commitlint` + `simple-git-hooks` + `lint-staged`
