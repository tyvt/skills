### 最终结论

## 问题原因

保存「项目楼盘」时，请求拦截器（`request.js`）会自动附加自定义请求头。其中 `getLandPlotCodeRequestHeaders` 会把表单里的 **宗地号（`landPlotCode`）** 写入 `zs-remark` 请求头。

HTTP 请求头只允许 ISO-8859-1 字符。当宗地号包含中文（或其他非 ASCII 字符）时，浏览器在调用 `setRequestHeader` 时会直接报错：

```
Failed to execute 'setRequestHeader' on 'XMLHttpRequest': String contains non ISO-8859-1 code point.
```

页面加载（GET）不会带 `landPlotCode`，所以只有**保存**时会触发。

## 修复方案

在 `pageRequestContext.js` 中，对 `zs-remark` 使用与 `zs-menu-name` 相同的 `toAsciiHeaderValue` 编码：

```178:180:zhi2-web-admin/src/utils/pageRequestContext.js
  return {
    'zs-remark': toAsciiHeaderValue(landPlotCode)
  }
```

非 ASCII 字符会被 `encodeURIComponent` 编码为 `%XX` 形式，浏览器可正常设置请求头。

请重新编译/刷新页面后，再试保存含中文宗地号的项目楼盘记录。若仍有问题，把具体宗地号值发我即可。
