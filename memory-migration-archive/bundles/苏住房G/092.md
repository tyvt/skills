[MEDIUM] 字体或排版晚到后不重新测量  
File: `zhi2-web-admin/src/layout/components/Navbar.vue:712-714`  
Issue: 仅对 `titleViewport` 做 `ResizeObserver`，并在 `title` 变化、`window.resize` 时调用 `updateTitleScroll`。  
Why: 平台名不变时，web 字体加载、fallback 替换等会改变 `scrollWidth`，但 viewport 宽度不变，RO 不会触发，可能出现「本应滚动却一直 ellipsis / 不滚动」，或 `titleScrollPx` 偏小、末尾被裁切。  
Fix: 在 `mounted` 中 `document.fonts?.ready.then(() => this.updateTitleScroll())`，或对 `titleText` 再挂一个 `ResizeObserver`（内容盒宽度变化时重测）。

---

[MEDIUM] 临界 overflow 可能反复开关 `title--scroll`  
File: `zhi2-web-admin/src/layout/components/Navbar.vue:450-457`  
Issue: 用固定阈值 `overflow > 1` 切换 `titleNeedsScroll`，无滞后。  
Why: 窗口缩放、DPR、子像素布局下 overflow 可能在 0～2px 间来回跳，class / CSS 变量 / 动画会反复重置，出现标题在「ellipsis ↔ 滚动」之间闪动（用户所说的 ping-pong 若指状态抖动，根因在这里；若指动画往返，那是预期行为）。  
Fix: 启用/关闭使用不同阈值（如开启 `> 2`、关闭 `<= 0`），或对 `updateTitleScroll` 做短 debounce。

---

[MEDIUM] 连续 resize 时动画反复从 0% 重启  
File: `zhi2-web-admin/src/layout/components/Navbar.vue:262-269`, `713`  
Issue: 每次 RO/resize 都可能更新 `titleScrollPx` 与 `--title-scroll-*`。  
Why: 自定义属性变化会使 CSS animation 重新计算并从头播放，拖拽改窗口宽度时标题滚动会「抽一下、归位、再滚」，体验不稳定。
