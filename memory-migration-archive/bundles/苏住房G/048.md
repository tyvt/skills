### 现象
B 端企业管理员进入 **企业管理 → 企业信息**（路由 `/#/toB/companyInfo`）时：
- 所有字段显示为 `-`（空白）
- 没有「变更」等操作按钮

### 根因

企业信息页使用 `toB/companyRecord/detail.vue`，通过 **`/company/companyRecord/getOwnCompany`** 获取当前登录企业的信息，**不需要路由上的 `id` 参数**。

但在 commit `01a0aa7cf` 中，`form.js` mixin 新增了详情接口参数校验：

```58:77:d:\repository\苏住房G\zhi2-web-admin\src\mixins\form.js
    validateDetailRequiredParams() {
      const params = this.getDetailRequiredParams()
      const missingKeys = Object.keys(params).filter(
        (key) => params[key] === undefined || params[key] === null || params[key] === ''
      )
      if (missingKeys.length) {
        console.warn(
          `[getDetail] 缺少接口必需参数，已跳过请求：${missingKeys.join(', ')}`,
          { missing: missingKeys, params, detailApiFull: this.detailApiFull }
        )
        return false
      }
      return true
    },
    // 获取详情方法
    getDetail() {
      if (!this.validateDetailRequiredParams()) {
        return
      }
```

默认要求 `id` 必须存在。而 `companyInfo` 路由没有 `id`，导致：
1. `getDetail()` 被直接跳过，接口从未调用
2. `form` 保持初始空值，页面全部显示 `-`
3. 「变更」按钮依赖 `form.bizState == 2`，数据为空时也不会显示

可在浏览器控制台看到类似警告：
`[getDetail] 缺少接口必需参数，已跳过请求：id`

### 修复

在 `toB/companyRecord/detail.vue` 中重写 `getDetailRequiredParams()`，去掉对 `id` 的校验，使 `getOwnCompany` 能正常请求：

```javascript
getDetailRequiredParams() {
  return {
    moduleName: this.moduleName,
    businessName: this.businessName,
  }
},
```
