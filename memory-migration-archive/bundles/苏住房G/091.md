## 问题原因

后端字典里「物业企业信用等级」的配置是：

```json
{
  "dictLabel": "物业企业信用等级",
  "dictValue": "propertyCompanyCreditRating",
  "remark": ""
}
```

而前端 `COMPLEX_FIELD_META` 里原来写的是：

```js
companyCreditLevel: { valueType: VALUE_TYPE.SELECT, selectKey: 'creditLevel' }
```

`mergeFieldOptions` 是按 `dictValue` 去匹配元数据的：

```js
const meta = COMPLEX_FIELD_META[item.dictValue] || {}
let valueType = meta.valueType || VALUE_TYPE.TEXT  // 匹配不到就默认 text
```

因为 **`propertyCompanyCreditRating` ≠ `companyCreditLevel`**，匹配失败，`valueType` 回退为 `text`，所以显示成了输入框。

`remark` 为空不会覆盖本地配置，问题不在 remark，而在 **字段 key 不一致**。

## 已修复

已将前端配置中的 key 改为与后端字典一致：`propertyCompanyCreditRating`。

修复后，选择「物业企业信用等级」时会：
1. 识别为 `valueType = select`
2. 从 `selectOptionsMap.creditLevel`（`credit_level` 字典）加载下拉选项
3. 渲染为下拉选择框
