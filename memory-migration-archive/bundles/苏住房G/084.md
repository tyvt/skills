## 问题原因

## 修复方案

在 `router/index.js` 的 `afterEach` 守卫中，每次路由切换后重置 `#app-main` 的滚动位置：

```235:248:d:\repository\苏住房G\zhi2-web-admin\src\router\index.js
// 重置主内容区滚动位置（实际滚动容器为 #app-main，非 window）
const resetPageScroll = () => {
  const mainEl = document.getElementById('app-main')
  if (mainEl) {
    mainEl.scrollTop = 0
  }
  window.scrollTo(0, 0)
}

// 路由后置守卫
router.afterEach((to) => {
  Vue.nextTick(() => {
    resetPageScroll()
  })
```

使用 `Vue.nextTick` 是为了等新页面 DOM 渲染完成后再重置滚动，避免时机过早。
