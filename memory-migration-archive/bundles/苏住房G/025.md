组件是挂上了，但 **`zs-region-select` 不适合这个页面的场景**，所以才会回显成 `320505`。

## 原因

`zs-region-select` 的选项来自**平台配置**下的 `areas` 树（当前市/区能选的范围），不是列表页左侧树选中的区。

本页行政区域是：
- 在列表左侧树选好区（如高新区 `320505`）
- 跳转新增页后**只读展示**，用户不能改

当 `form.regionCode = 320505`，但 `zs-region-select` 的 `regionOptions` 里没有这项时，`el-select` 找不到匹配 label，就会**直接显示编码**。

## 修复

这个页面不应使用 `zs-region-select`，改为用 `zs-select` + 根据当前数据生成的选项：

```vue
<zs-select :value.sync="form.regionCode" :options="regionDisplayOptions" disabled />
```

`regionDisplayOptions` 会用 `regionName`（或从 `allAreas` 反查名称）生成 `[{ dictValue: '320505', dictLabel: '高新区' }]`，这样 disabled 状态下会显示**高新区**而不是数字。

同时会同步补全 `regionName`，保存时 `regionCode` 仍有值。
