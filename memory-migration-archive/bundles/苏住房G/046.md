## 问题分析

这个报错**不是** npm 可选依赖没装上，真正原因是：

GLIBC_2.32 not found (required by @rollup/rollup-linux-x64-gnu)

GitLab Runner 的 Linux 系统 glibc 版本过低（常见于 Ubuntu 18.04 / CentOS 7），而 Rollup 4.x 的原生二进制需要 **glibc ≥ 2.32**。外层 “Cannot find module” 是误导性提示。
