`get_polygon=3` **不是单独一个接口**，而是腾讯行政区划 WebService 里两个已有接口的**请求参数**。

## 涉及的两个接口

### 1. 获取子级区划（大屏区级场景主要用这个）

```
GET https://apis.map.qq.com/ws/district/v1/getchildren
```

示例（拉惠山区下各街道轮廓）：

```
https://apis.map.qq.com/ws/district/v1/getchildren?id=320206&get_polygon=3&max_offset=100&key=你的Key
```

| 参数 | 说明 |
|---|---|
| `id` | 父级区划 adcode，如 `320206` |
| `get_polygon=3` | 要街道级轮廓 |
| `max_offset` | 抽稀精度（米），如 `100` |
| `key` | 腾讯地图 Key |

---

### 2. 按 adcode 搜索单条区划（兜底逐条拉街道时用）

```
GET https://apis.map.qq.com/ws/district/v1/search
```

示例：

```
https://apis.map.qq.com/ws/district/v1/search?keyword=320206001&get_polygon=3&max_offset=100&key=你的Key
```

| 参数 | 说明 |
|---|---|
| `keyword` | 街道 adcode 或名称 |
| `get_polygon=3` | 要街道级轮廓 |

---

## 和 `get_polygon=2` 的区别

- `get_polygon=2`：省 / 市 / **区县**轮廓（常规 Key 可用）
- `get_polygon=3`：**街道 / 乡镇**轮廓（需向腾讯提工单开通）

项目里对应代码在 `tencentDistrictBoundary.js`：

- `fetchDistrictChildrenByAdcode(code, '3')` → `getchildren`
- `fetchDistrictSearchByAdcode(id, '3')` → `search`

工单申请时可以说：为 Key 开通**行政区划接口的 `get_polygon=3`（街道级轮廓）**能力。
