## 能不能用？

**取决于运行环境**，不是 H5 里自己调摄像头完成的。

| 环境 | 是否可用 |
|------|----------|
| **生产环境 + 微信小程序 WebView** | 可用。会跳转到小程序的人脸识别页完成核验 |
| **本地开发（`npm run dev`）** | 会**自动跳过**人脸识别，直接走成功流程 |
| **普通浏览器 / 非微信环境** | **不可用**。依赖 `wx.miniProgram.navigateTo`，没有微信 JSSDK 会失败 |

H5 里的 `faceSuccess.vue`、`faceError.vue` 等页面只是**结果展示 UI**（静态图 + 提示文案），**没有**调用 `getUserMedia` 等浏览器摄像头 API，也不做人脸比对。

---
