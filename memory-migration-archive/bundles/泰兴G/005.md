## 原因说明

报错 **`Definition for rule 'duplicate-attributes/no-duplicate-vue-options' was not found`** 并不是因为 `VotingItemsDialog.vue` 写错，而是 **ESLint 实际加载到的本地插件是旧快照**。

你在仓库里的 `zhi2-web-admin/eslint-rules/index.js` 已经注册了第三条规则 `no-duplicate-vue-options`，但 Bun 把 `file:eslint-rules` 装进了 `node_modules/.bun/...` 里的**固定拷贝**，那次安装之后没有随你改 `eslint-rules` 自动更新。于是运行时 `require('eslint-plugin-duplicate-attributes')` 只有：

- `no-duplicate-attributes`
- `no-multiple-v-if`

没有 `no-duplicate-vue-options`，配置里却启用了这条规则，就会触发 “rule definition was not found”。

## 已做处理

在仓库根目录执行了 **`bun install`**，刷新本地 `file:` 包后，插件已包含三条规则，`eslint` 对该 Vue 文件已通过。

## 你本地需要做的

1. **以后改了 `eslint-rules/` 里的代码**，若仍用 Bun，记得再执行一次 **`bun install`**（或删掉 `node_modules` 后重装），避免 `.bun` 里仍是旧拷贝。  
2. 当前 **`bun.lock` 有变更**，若团队以 Bun 为准，提交时把 **`bun.lock` 一并提交**。

完成上述步骤后，pre-commit 里的 `eslint --fix` 应能正常通过。
