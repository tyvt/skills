## Ticket 怎么获取

Ticket 通过**江苏政务服务平台 JSSDK**（`lightAppJssdk`）获取，在 `App.vue` 的 `initUser()` 里：

```34:46:src/App.vue
      lightAppJssdk.user.getTicket({
        success: (data) => {
          if (data == '未登录') {
            this.openUserLogin()
          } else {
            const obj = JSON.parse(data)
            this.verifyTicket(obj.ticket)
          }
        },
        fail: (data) => {
          showError(data)
        }
      })
```

流程是：

1. 应用启动（非开发环境）→ 调用 `initUser()`
2. 调用 `lightAppJssdk.user.getTicket()` 获取当前用户 ticket
3. 若返回 `"未登录"` → 调用 `lightAppJssdk.user.loginapp()` 拉起登录
4. 登录成功后同样解析 `obj.ticket`，再调用 `verifyTicket(ticket)`
5. `verifyTicket` 把 ticket 发给后端 `/transaction/user/sfb/loginByTicket` 换取业务 token

JSSDK 在 `index.html` 中引入：

```17:17:index.html
    <script type="text/javascript" src="https://www.jszwfw.gov.cn/jmopen/jssdk/index.js"></script>
```

**前提**：H5 必须运行在苏服办/江苏政务服务 App 的 WebView 里，由宿主 App 提供登录态；本地浏览器直接打开通常拿不到 ticket。


这两个接口只传了 `success` / `fail` 回调。宿主 App 会根据当前打开的轻应用上下文识别应用，一般不需要前端再传 appId。

## app_id 用在哪里

`config.js` 里的 `app_id`（当前为 `clfwqhtcxtokfa`）**不是给 JSSDK 用的**，而是给**政务网关接口**用的，在 `gateway.js` 请求拦截器里：

```53:54:src/api/gateway.js
  const formData = new FormData()
  formData.append('app_id', _c.app_id)
```

也就是说：

| 用途 | 是否传 appId |
|------|-------------|
| `lightAppJssdk.user.getTicket()` | 否 |
| `lightAppJssdk.user.loginapp()` | 否 |
| 政务网关 `gateway.do` 接口 | 是（`config.js` 的 `app_id`） |
| `loginByTicket` 后端接口 | 否（只传 `ticket`） |

注释里还保留了旧方案：用 `app_key` / `app_secret` 调 `verifyTicket.do`，现已改为走后端 `loginByTicket`。
