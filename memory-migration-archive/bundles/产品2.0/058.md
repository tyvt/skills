## 问题原因

- 将 `path` 转换为合法的内部路由路径

1. Vue Router 无法正确注册 `https://` 开头的路径

3. 侧边栏可能把该菜单当成纯外链，用 `<a target="_blank">` 打开，绕过了 SSO 跳转逻辑
