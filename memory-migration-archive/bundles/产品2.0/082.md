## 实现说明

在 `Vue.use(Element)` 之后、`$message` 已挂到原型上，因此在 **`createInstance` 里根实例挂载完成后** 用 `instance.$message.error(...)`，效果与组件里写 `this.$message.error` 一致。

   - 若没有，再读 **`vm.$route.query.errorMsg`**（适合 `#/login?errorMsg=…`）。  
   - 若 `query.errorMsg` 是数组（重复参数），取第一个。

2. **`$nextTick`**  
   保证路由完成首次解析后再读 `$route.query`。

访问示例：

- `https://域名/?errorMsg=登录已过期`
- `https://域名/#/login?errorMsg=无权限`
