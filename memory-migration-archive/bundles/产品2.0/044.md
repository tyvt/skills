## 原因

上次修复后虽然能滚动，但 flex 父级没有明确高度，`flex: 1` 的表格区域只会收缩到约 **120px**（最小高度），所以每页 10 条时只能看到 2～3 行，弹窗下方大量空白未被利用。

## 本次调整

1. **弹窗内容撑满视口**：`dialog-box` 高度设为 `var(--zs-dialog-content-max-height)`（约 88vh），让内容区默认占满可用空间。
2. **打通 flex 高度链**：`el-dialog` → `el-dialog__body` → `dialog-box` → 表格区域逐级传递高度。
3. **动态同步表格高度**：通过 `ResizeObserver` 将表格高度与容器实际高度对齐，避免被 `zs-table` 的固定行高计算覆盖。
