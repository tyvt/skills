### 用户诉求 2
@zhi2-web-admin/src/views/property/workOrder/order/index.vue:149-156 我点了全部，为什么orderStatus传的0？

### 最终结论
**原因**

`el-tabs` 的 `el-tab-pane` 用 `:name` 标识当前 Tab。你把「全部」设成了 `value: ''`，空字符串在 Element UI 里不是合法 `name`，点击后会把 `v-model` 绑定的 `queryParams.orderStatus` 写成 Tab 的**索引** `0`，而不是「不限状态」。

请求里出现 `orderStatus=0`，是因为：
1. Tab 把值改成了 `0`（或 `'0'`）
2. `getQueryParams` 里原来的 `this.queryParams.orderStatus || undefined` 对字符串 `'0'` 仍为真，会原样传给接口

**修改**

- 「全部」改用专用值 `'all'`（常量 `ALL_ORDER_STATUS`）
- 初始 `orderStatus` 也改为 `'all'`
- 在 `getQueryParams` 里把 `'all'` 转成 `undefined`，表示不按状态筛选

刷新后再点「全部」，接口应不再带 `orderStatus=0`。若之前页面缓存了错误的 `orderStatus`，可点一次「重置」或重新进入页面清掉旧缓存。
