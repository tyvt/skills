### 最终结论
**原因不是你配置的问题，而是 Playwright 对 Firefox 的“已知限制 / Bug”，加配置也解决不了。**

结合你现在的情况：

- `playwright.config.js` 里已经是 `video: 'on'`，**三种浏览器的配置完全一样**。
- Chromium、Edge 都在 `test-results` 里有 `.webm`，说明配置生效、录像功能正常。
- Firefox 下用例是 **通过的**，但没有生成视频文件。

根据 Playwright 官方文档和已知 issue（特别是 “No video is recorded for Firefox” 这一类），目前在某些平台/版本组合下，**Firefox 的视频录制功能存在缺陷：测试能跑、但不会产出可用的视频文件**。这是 Playwright 本身的问题，而不是你项目脚本写错。

所以现状可以这么理解：

- **Chromium / Edge**：你现在的配置是正确的，所有用例都会录像。
- **Firefox**：即使配置了 `video: 'on'`，在你当前的 Windows + Playwright 版本组合下，很可能就是“不会产生日志里可看的录像”，这属于 Playwright 的已知局限，你在项目里没法修复，只能等 Playwright 后续版本修复或变更实现。

如果你想在 Firefox 下也有“可回放”的调试资料，可以考虑：

- 依赖 **trace** 而不是视频（你已经开了 `trace: 'on-first-retry'`，也可以手动 `--trace on` 跑一遍 Firefox 专用调试），用 `npx playwright show-trace ...` 查看；
- 或者主要以 Chromium / Edge 的录像为主做行为回放，Firefox 只用来做兼容性验证。
