    - 清空选择并对 `checked == 1` 的行调用 `toggleRowSelection` 勾选；
    - 同步完成后在 `nextTick` 里把 `isSyncingSelection` 设回 `false`。
  - 在 `onListSelectionChange` 里：
    - 开头增加 `if (this.isSyncingSelection) return`，忽略同步过程里的那次 `selection-change` 事件；
    - 只有用户真正勾选/取消列表行时，才会把选择结果反写到 `buildingTableData` 的 `house.checked` 上。

这样：  
- 打开弹窗时，`table` 视图按 `exist` 全部选中；  
- 切换到 `list` 视图后，会自动勾选同一批行，不再丢失；
