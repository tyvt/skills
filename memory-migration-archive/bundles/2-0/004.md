### 1. 建议统一改的场景

下面这些属于“具体日期 / 日期时间”，可以统一从 `yyyy` 小写改成大写：

- **日期**：
  - 模板里：`value-format="yyyy-MM-dd"` → `value-format="YYYY-MM-DD"`
  - JS 配置里：`'value-format': 'yyyy-MM-dd'` → `'value-format': 'YYYY-MM-DD'`
- **日期时间**：
  - `value-format="yyyy-MM-dd HH:mm:ss"` → `value-format="YYYY-MM-DD HH:mm:ss"`
  - `value-format="yyyy-MM-dd HH:mm"` → `value-format="YYYY-MM-DD HH:mm"`

顺带一并把对应的 `format="yyyy-MM-dd..."` 也改成 `format="YYYY-MM-DD..."` 会更一致。

这些地方都是标准的 `el-date-picker` 或 `zs-date-picker`，用的是 dayjs，**必须大写 `YYYY` / `DD` 才不会出现你之前看到的 `yyyy-03-Sa` 这种情况**。

### 2. 不要统一改成 `YYYY-MM-DD` 的场景

下面这些是“别的类型”的选择器，**不能**改成 `YYYY-MM-DD`：

- **年度选择**（`type="year"` 或 考评年度等）  
  - `value-format="yyyy"` / `'value-format': 'yyyy'`：保持不变或改成 `YYYY`，但绝对不要变成 `YYYY-MM-DD`。
- **月份 / 月份周期**（`type="month"` 或只选月份）  
  - `value-format="yyyy-MM"`、`value-format="MM"`：保持为“年-月”或“月”，不要变成带日。
- **季度**  
  - `value-format="yyyy-Qq"`：这是自定义格式，改成 `YYYY-MM-DD` 会直接失效。
- **纯时间 / 时段**  
  - `value-format="HH:mm"`：这是时间，不是日期，不能动。

### 3. 你可以怎么全局处理

在 Cursor 里全局查找两类：
