# zhi2-web-admin
Projeto front-end Vue.js para administração de receitas públicas de parque.

## Descrição
- Sistema web administrativo para o projeto "园区公共收益" (receitas públicas de parque).
- Caminho do repositório: d:/repository/园区公共收益/zhi2-web-admin.

## Propósito
- Gerenciar imóveis, unidades, vagas de estacionamento e diálogos relacionados.
- Fornecer componentes reutilizáveis como OperationBtnGroup e UnitDialog.

## Relações
- Contém módulos building, benefit, unit e complexSearch.
- Inclui correções de bugs registradas em eventos de memória.
