**说明：**  
`window.location` 属于浏览器 **BOM（Browser Object Model）** 里的 `Location` 接口。`window.location.origin` 会返回当前页面的「协议 + 主机名 + 端口」（例如 `http://172.21.9.61:5777`），等价于原先写死的地址，但会随用户实际访问的域名/端口自动变化，部署到别的环境也不用改代码。

当前逻辑是：无 token 时仍跳到**站点根**（与原来只写 `http://IP:端口` 一致）。若你希望与其它页面一致、明确跳到登录页，可以改成：

```javascript
window.location.replace(window.location.origin + '/login.html')
```
