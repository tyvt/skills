### 三种初始化路径

**A. 推荐（策略/SDK 层）——零配置本地**

```python
from stock_sdk import rd, bk, zb  # 或 from stock_sdk import *
```

- `rd` 是 `_DefaultRdProxy`（`stock_sdk.py` L755-776, L797-798），懒连接默认 `127.0.0.1:7899`。
- 本地示例 `d:\repository\stockdb\调用方式\python\sdk_test.py` L18-25：**不调用 `init()`**，直接 `rd.get(...)` / `rd.get_data(...)`，前提是 `stockdb.exe` 已启动。

**B. 显式配置本地端点**

```python
from stock_sdk import init, rd

init(
    host="127.0.0.1",
    port=7899,
    socket_timeout=None,  # 本地默认 1s（L26-27）
    password=None,
    warm=True,            # 预加载复权因子+板块（L45-46, L738-744）
)
```

- 定义：`stock_sdk.py` `init()` L20-47。
- `warm=True` 会创建 `StockDBClient` 并调用 `zhibiao.warm_default_connection()`。

**C. 原生二进制客户端（进阶）**

```python
from stockdb import rd, init
# rd = init(host="127.0.0.1", port=7899, password="")
```

- 见 `d:\repository\stockdb\调用方式\python\rd_test.py` L15-18、`http\rd_test.py` L17-20。
- `stock_sdk` 内部：`from stockdb import *` 取 `_raw_rd`（`stock_sdk.py` L7-8）；默认本地时 `self.rd = _raw_rd`（L74-75）。

### `rd` 能力分层

| 对象 | 来源 | 能力 |
|------|------|------|
| 原生 `rd` | `stockdb.pyd`（二进制，仓库内未展开） | `get/vals/keys/pipe/set/...` |
| `stock_sdk.rd` | `_DefaultRdProxy` | 原生能力 + `get_data()` / `get_data_async()`（L755-761） |
| `StockDBClient` | `stock_sdk.py` L50+ | 高级 K 线/复权/周期聚合 |

### 与在线 API 的区分

- `init()` → **本地** StockDB（`AI策略python开发接口文档.md` L91）。
- `set_init()` → **在线** RemoteProxy，不是 `rd` 连接（同文档 L93-113）；`sdk_test.py` L8-11 为远程体验，**不适合批量落库**。
