- 用 `/_TMapService`、`/_TMapService_ws` 替代原来的 `/map`
- 本地需在 `env/.env` 配置（勿提交到仓库）：

```env
VITE_APP_TMAP_PROXY_KEY = 你的腾讯地图key
```

## 生产部署（Nginx）

你提供的 Nginx 配置方向正确。建议对照官方文档补全子路径，否则 `TMap.service`（如 `ZsTencentMap` 里的 Search、Geocoder）可能异常：

| location | 代理目标 |
|----------|----------|
| `/_TMapService` | `https://pr.map.qq.com/pingd?appid=jsapi_v3` |
| `/_TMapService/checkKey` | `https://apikey.map.qq.com/mkey/index.php/mkey/check` |
| `/_TMapService/oversea` | `https://overseactrl.map.qq.com` |
| `/_TMapService/service` | `https://apis.map.qq.com/ws` |
| `/_TMapService_ws/` | `https://apis.map.qq.com/ws/`（你已有，供 axios 直连） |

若站点域名不是 `www.sipihome.com`，可在 `env/.env` 覆盖：

```env
VITE_APP_TMAP_SERVICE_HOST = https://你的域名/_TMapService
```

同源部署时用默认 `/_TMapService` 即可。
