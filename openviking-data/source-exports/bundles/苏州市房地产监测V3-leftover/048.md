### 回归与边界

| 点 | 评估 |
|----|------|
| 仍只靠 `query.projectId`、路径末段为模块名（如 `unit`） | 仍会走 query，行为不变 |

| 纯字母主键被 `isModulePathSegment` 当成模块名 | **既有风险**，非本次引入 |
| `getRouteIdSignature` 仍用 query 的 id/projectId，不含「路径末段 ID」 | path 已在签名里，保存后 path 会变，缓存会失效；同 path 仅 query 变而末段已是详情 ID 时，解析结果仍稳定 |
