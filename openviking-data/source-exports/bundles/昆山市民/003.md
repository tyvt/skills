已修复鹿路通 `code` 重复调用的问题。

### 原因

`App.vue` 的 `onShow`、`home.vue` 的 `onLoad` 等多处都会调用 `loginWithWxCode()`，而 URL 里的 `code` 每次都会被读取，导致 `/llt/getInfoByCode` 被重复请求。

### 修复策略（`wxLogin.js`）

1. **请求去重**：用 `loginPromise` 合并并发调用，`App.vue` 和 `home.vue` 同时触发时只发一次请求。

2. **已有 token 则跳过**：H5 已登录时直接返回本地用户信息，不再调接口，并顺带清除 URL 中的 `code`。

3. **code 一次性使用**：
   - 登录成功后，将 `code` 记入本地存储并标记已使用
   - 用 `history.replaceState` 从 URL 中移除 `code` 参数

4. **已使用 code 拦截**：若检测到 `code` 已被消费，直接拒绝，不再请求接口。

### 效果

| 场景 | 行为 |
|------|------|
| 首次带 code 进入 | 只调用 1 次接口 |
| `onShow` + `onLoad` 同时触发 | 共享同一请求 |
| 登录后切换页面/回前台 | 有 token，不再调接口 |
| 刷新页面（token 已持久化） | 有 token，不再调接口 |
| 同一 code 再次使用 | 直接拦截，不请求接口 |
