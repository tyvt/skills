## 原因说明

登记证明地址形如 `/zhlz/2026/0/d/f/....pdf`（住房租赁文件桶），但前端有两处缺口：

1. **网关/Nginx 未代理 `/zhlz`**  
   在 `http://58.210.252.230:9002` 上访问该路径时，返回的是 **200 + `text/html`（SPA 的 index.html）**，不是 PDF。用 `el-image` / `<img>` 加载会失败，页面上就会出现带路径的红色错误块。

2. **附件 `fileType` 常为字典码（如 `0`）**  
   `getAppendixFileExtension` 原先优先用 `fileType`，会把 PDF 误判为图片，走 `el-image` 去加载 `.pdf`，同样会报错。

路径在对象存储里是对的，但 **浏览器请求的是前端站点**，没有 `/zhlz` 反代就会拿到 HTML。

## 已做修改

| 文件 | 改动 |
|------|------|
| `vite.config.js`、`deploy/nginx.conf` | 增加 `/zhlz`、`/zhlz-dev`、`/zhlz-test` 静态资源代理（与 `/zhi2*` 一致） |
| `resolveServerAssetUrl.js` | `/zhlz*` 按站点根路径拼 URL，并处理误带 `/api/v3.0/zhlz/...` 的情况 |
| `appendix.js` | 优先用 `fileSite`/文件名后缀；PDF 不再当图片缩略图 |
| `agencyBasicInfoContent.js` | 有 `leaseRegisterCertSite` 时展示「开业信息登记证明」（PDF 以可点击链接打开，不用图片预览） |
