## 共享模式与注册机制

| 模式 | 说明 |
|------|------|
| **全局注册** | `main.js` 用 `import.meta.glob('./components/**/*.vue')` 按**父文件夹名**注册，如 `zs-button/zs-button.vue` → `<zs-button>`，`Headline/index.vue` → `<Headline>` |
| **排除全局注册** | `Process/*.vue`、`MenuTree/*.vue`；`zs-editor` 在 glob 中写为 `ZsEditor`（路径不匹配，实际靠文件夹名 `zs-editor` 注册） |
| **同步注册** | `SvgIcon` 单独同步注册（避免首屏抖动） |
| **命名风格** | 表单/表格基础件多为 `zs-*`（kebab）；业务封装多为 `Zs*`（PascalCase 文件夹） |
| **Mixin 局部注册** | `formComponents.js`（zs-input/select/date/button 等）、`tableComponents.js`（zs-table/column/pagination/Headline）、`listMixins.js`（zs-search-form）、`detailMixins.js`（Headline/HeadTitle/DetailTemplate） |
| **Element UI 封装** | 多数 zs 组件为 `el-*` 的权限/样式/行为增强封装，`v-bind="$attrs"` + `v-on="$listeners"` 透传 |
