### 2. 全局 Form 默认配置

| 层级 | label-position | label-width | 说明 |
|------|----------------|-------------|------|
| Element UI 全局（`main.js`） | 未配置 | 未配置 | 仅 `size: "mini"` |

平台配置选项（`platformConfig/detail.vue`）：

- `top` → 上下布局
- `left` → 左右布局（标签在左、输入框在右）

**注意**：Element UI 没有 `label-align`（那是 Element Plus）。左右布局下 label 文字对齐由 `label-position` 控制：
- `right`（Element 默认）：标签在输入框左侧，**文字右对齐**
- `left`：标签在输入框左侧，**文字左对齐**

### 3. 弹窗封装是否统一包裹表单

**否。** `zs-dialog` 只包一层 `.dialog-box` 容器，不自动包 `zs-form` / `el-form`。

典型结构（以 `ParcelDialog` 为例）：

```
zs-dialog
  └── div.form-box
        └── zs-form (label-width="140px")
              └── el-form-item ...
```
