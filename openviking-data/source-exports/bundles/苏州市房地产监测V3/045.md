## 原因

`OperationBtnGroup` 的「返回」默认逻辑是去掉 URL **最后一段**：

- 限制单：`…/limitAdd/add` → `…/limitAdd`（正好是**审核列表**菜单 path）
- 解除限制：`…/limitCancel/add` → `…/limitCancel`（**没有列表页**，只有详情路由）

所以会关掉 tag，但路由落在空的 `limitCancel` 上，看不到列表。

## 修改

1. **进入表单时带 `backUrl`**  
   - 审核列表 → 表单：`backUrl` = 当前列表 `path`  
   - 项目详情 → 表单：`backUrl` = 当前详情 `path`  
   - 保存后 `changeFormState` 会保留 query，`backUrl` 仍在。

2. **`limitAdd` / `limitCancel` 使用 `@back="handleOperationBack"`**  
   优先走 `query.backUrl`；解除限制若无 `backUrl`，则解析 **`building/houseLimitAudit/index`** 对应列表 path（菜单上的 `limitAdd` 列表）。
