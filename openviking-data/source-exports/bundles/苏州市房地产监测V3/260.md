### 最终结论
## 原因

公共组件 `zs-dialog` 里，选择弹窗（`zs-select-dialog` / `SelectDialog`）为了给 wrapper 做垂直居中，写了：

```css
.el-dialog__wrapper { display: flex !important; }
```

Element UI 的 `el-dialog` 靠 **`v-show`** 关闭，会在 wrapper 上写内联 `display: none`。带 **`!important` 的 `display: flex`** 会压过这条内联样式，结果是：

- 弹窗逻辑上已关闭，但 DOM 仍显示  
- 在列表页/详情 flex 布局里，就像一块普通内容贴在页面底部（你截图里「选择录入数据」那种空壳标题 + 取消/确定）

所有走 `zs-select-dialog` 的页面都会中招，所以看起来是「很多页面都有」。

## 修复

已在 `zs-dialog.vue` 中去掉 wrapper（及 compact 内层）上 **`display` 的 `!important`**，保留 `align-items` / `justify-content` 的居中。关闭时 `v-show` 的 `display: none` 能正常生效；打开时仍用 `display: flex` 居中。

请 **硬刷新**（或重启 dev）后看住房租赁合同备案等列表页：未点开时不应再出现底部弹窗条；点「选择录入数据」应正常浮层弹出。
