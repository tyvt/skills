### 技术栈
- **框架**：Vue 2.7 + Vue Router 3 + Vuex 3 + Element UI（封装为 `zs-*` 组件）
- **构建**：Vite 5（`zhi2-web-admin\vite.config.js`）
- **HTTP**：Axios 封装于 `zhi2-web-admin\src\api\index.js`

### 目录约定
```
zhi2-web-admin/src/
├── views/          # 页面（按业务模块分子目录：property、benefit、maintenance…）
├── api/            # 部分模块有独立 API 文件，多数页面直接调 request
├── mixins/         # listMixins、table.js、permsMixins、area.js 等
├── components/     # zs-table、zs-search-form、zs-button 等
├── router/index.js # 仅 constantRoutes，业务路由动态加载
├── store/modules/permission.js  # 动态路由/菜单
└── layout/         # 布局：Navbar + Sidebar + TagsView + AppMain
```

### 路由机制
- 静态路由：`zhi2-web-admin\src\router\index.js`（登录、首页、404 等）
- 登录后：`store.dispatch('GenerateRoutes')` → `GET /system/menu/listRouters` → `router.addRoute()`
- 组件懒加载：`loadView()` 用 `import.meta.glob('./../../views/**/*')` 按 `component` 字段匹配 `views/` 下路径

### 全局 Mixin（`zhi2-web-admin\src\main.js`）
- `currentRoute`：`router.currentRoute.name.split("/")[0]`，用于同一组件服务多个菜单
- `this.download()`：全局导出方法
- `this.$get / $post / $del`：HTTP 快捷方法
