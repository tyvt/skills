### 最终结论
已修复「取消全选楼幢」不联动的问题，核心改动在 `decisionRangeBuildingSelectMixins.js`：

### 问题原因

1. **取消全选时只更新了部分户室**：原先遍历时会跳过 `exist == 1` 的户室，而这些户室默认就是已勾选状态，导致右侧楼盘表仍显示选中。
2. **缓存刷新是异步的**：左侧楼幢 checkbox 依赖 `buildingCheckCache`，异步更新导致 UI 不能及时反映取消状态。
3. **遍历路径不完整**：未始终从树节点的 `building.floorHouses` 源数据批量更新。

### 修复内容

- 新增 `applyCheckedToAllBuildings` / `applyCheckedToBuilding`：取消全选时将所有户室（含 `exist==1`）统一设为 `checked = '0'`；勾选全选时设为 `'1'`。
- `refreshBuildingCheckCache` 改为**同步**执行，并递增 `buildingSelectRevision`，驱动左侧 checkbox 和右侧楼盘表单元格头部刷新。
- `syncSelectionViews` 在批量操作后同步刷新缓存 + 列表视图勾选状态。

请重新打开「选择户室」弹窗验证：

2. **取消**「全选楼幢」→ 所有楼幢 checkbox 应取消，右侧楼盘表户室勾选也应全部取消
