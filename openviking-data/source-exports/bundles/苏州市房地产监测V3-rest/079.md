### 1. `el-row` + `el-col`（最常见，如「备注」在 `el-col` 里）

- 在 **任意宽度** 下都有弹窗专用规则：带 `.el-textarea` / `.zs-textarea` 的列强制 `width: 100%`（`detail-collapse-col-full-row`）。

### 2. 弹窗里直接用 `el-form` / `zs-form` > `el-col`（无 `el-row`）

- 同样在 ≥768px 应用上述 mixin，文本域列仍是整行。

### 3. `section-form` / `scheme-form-grid`

- 全局已有：含文本域的 `.section-field` 使用 `grid-column: 1 / -1`（占满整行）。
- 弹窗只是把网格改成 **2 列**，`1 / -1` 仍是**一整行**，不是半列。

### 4. 模板写成 `span=24` 的备注列

- mixin 里 `el-col-24` 也是整行，与文本域规则一致。

若你在某个弹窗里仍看到备注只占半宽，多半是结构异常（例如文本域不在带 `el-col` 的表单项里，或用了自定义组件类名而不是 `.el-textarea` / `.zs-textarea`）。把该弹窗对应的 Vue 片段发我，我可以帮你对一下选择器是否命中。
