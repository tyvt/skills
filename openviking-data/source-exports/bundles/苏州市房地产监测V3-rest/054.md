## 根因

`styles/index.scss` 里 `.detail-container` 默认 `height:100%; overflow:hidden`，而 `.detail-from-container` 自带 `overflow-y:auto`。原有 CSS 只提供了两种「整页内滚」出口：

| 结构 | 原有规则 |
|---|---|
| 表单 + 底部 Tab | `:has(> .zs-tabs)` ✅ |
| 无表单区 | `:not(:has(> .detail-from-container))` ✅ |
| **表单 + 底部子表块** | **无规则** ❌ |

承办银行页是 `operation-btn-group + el-row.detail-from-container + YhwdTable(网点列表)`，三个都不命中 → 落回「表单区内滚」：表单区靠 `flex: 0 1 auto` 吃掉全部剩余高度并内滚，网点列表作为兄弟节点被父级 `overflow:hidden` 整体裁掉。

1. `> .zs-tabs` — 底部 Tab（存量行为不变）
2. `> .collapse-container` / `> .sub-container` — 底部子表块（Headline 子表、明细表）
3. 第二个 `> .detail-from-container` — 第二个展示块行

## 组件路径怎么写

本项目的动态路由由**后台菜单**下发，菜单里的「组件路径」对应前端文件：

`zhi2-web-admin/src/views/<组件路径>.vue`

写法约定（与 `personnel-record-menu-routes.json`、`MEMORY.md` 一致）：

- **不要**写 `@/views/`、**不要**写 `.vue`
- 列表菜单：`<模块>/.../index`
- 详情子菜单（隐藏、`path` 带 `:tableid`）：`<模块>/.../detail`

同目录下已有变更详情薄页：

- `company/companyAdminChange/developer/detail` → `src/views/company/companyAdminChange/developer/detail.vue`
- `company/companyAdminChange/agency/detail` → 经纪机构
- `company/companyAdminChange/detail` → 共用内核（靠菜单标题推断机构类型，开发企业更推荐 `developer` 薄页）

详情页通过 `is-change="true"` 走变更单逻辑（`businessName = companyAdminChange`、要件 busCode `qyglybg` 等），见：
