### 最终结论
这是 **PM2 开机自启残留项** 导致的弹窗，不是「投资推送」项目本身的问题。

## 原因

Windows 登录时会执行注册表里的这条启动项：

```
wscript.exe "D:\nvm\v22.17.1\node_modules\pm2-windows-startup\invisible.vbs" ...
```

但当前环境是：

| 项目 | 状态 |
|------|------|
| 当前 Node 版本 | `v22.23.2`（NVM） |
| 启动项指向的版本 | `v22.17.1`（已不存在） |
| `pm2-windows-startup` | 未安装 |
| `pm2` 命令 | 未安装 |

NVM 升级 Node 后，旧版本目录被删了，但 PM2 的启动注册表项还在，所以每次开机都会弹「无法找到脚本文件」。

## 已处理

已删除失效的注册表项：

`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `PM2`

**重启或下次登录后，这个弹窗应该不会再出现。**

## 如果你还需要 PM2 开机自启

当前项目（tdai-memory gateway 等）用的是 `.bat` 脚本，不依赖 PM2。若你确实还要用 PM2，需要在新 Node 版本下重新安装并注册：

```bash
npm install -g pm2 pm2-windows-startup
pm2-startup install
pm2 save
```

否则保持现状即可，不必重装 PM2。

需要的话，我可以帮你检查是否还有其他类似的失效启动项。
