### 最终结论
这次做了**一类问题的全局修复**，不再逐页打补丁。

## 根因

小程序里 `ZsButton` 是自定义组件，页面 **scoped 样式**（如 `.btn-login { display: block }`）作用不到组件内部的 `<button>`，所以 width/padding/margin 大量失效。登录按钮只剩文字宽度，就是典型表现。

## 全局方案

新增 [`styles/zs-button.scss`](d:/repository/苏住房C/zhi2-mobile-shimin/src/styles/zs-button.scss)，在 `uni.scss` 中全局引入，统一维护所有按钮布局规则：

| 场景 | 规则 |
|------|------|
| **默认尺寸**（非 mini） | 自动 `width: 100%`，覆盖登录、提交等主按钮 |
| **mini** | 保持 `inline-flex` + 自适应宽度，用于列表操作 |
| **`.btn-login`** | 全宽 + 上下间距 |
| **底部固定栏** | `.page-button-container` / `.submit-button-wrapper` 内全宽 |
| **并排双按钮** | `.button-group` / `.btn-container` 内固定 `300rpx` |
| **弹窗底部** | `.popup-footer` 内 `220rpx × 90rpx` |
| **搜索栏** | `.reset-button` / `.search-button` 固定宽度 |
| **装饰按钮块** | `.btn-block` 内 `fit-content` |

同时调整了 `ZsButton` 组件：去掉会覆盖全局规则的 `width: auto` / `display`，只保留高度、padding、颜色等基础样式。

## 预期效果

重新编译后应恢复：
- **登录页**「登录」按钮全宽
- **决策详情**底部「参与决策」全宽
- **列表页** mini 按钮仍紧凑，不会误撑满

若还有个别页面不对，告诉我页面名和按钮用途，往 `zs-button.scss` 里补一条规则即可。
