## 问题原因

错误路径 `/pages_main/announcement/url(%22data:image/svg+xml,...%22)` 说明小程序把 **CSS 的 `url(...)` 语法** 当成了相对路径图片。

在 `detail.vue` 里：

```vue
<img :src="watermarkSrc" />
```

而 `makeWatermark()` 返回的是：

```js
url("data:image/svg+xml,<svg>...</svg>")
```

这是给 **`background-image`** 用的 CSS 值，不是 `<img src>` 能直接用的地址。小程序会把它拼到当前页路径下，于是出现 500 错误。

## 修复方式

已把水印层从 `<img>` 改为 `<view>`，用 `backgroundImage` 渲染：

```vue
<view v-if="watermarkSrc" class="watermark-layer" :style="{ backgroundImage: watermarkSrc }" />
```

样式也改为 `background-repeat: repeat`，让水印平铺显示。

请重新编译小程序，进入公告详情页验证。如果水印仍不显示（部分基础库对 SVG data URI 支持有限），可以再改成 Canvas 绘制方案。
