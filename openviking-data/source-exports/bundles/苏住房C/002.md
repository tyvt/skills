### 关键信息

微信打开的地址是：
```
index.html?token=8767277449bd4814bfa4d7378ef6c1c4a...
```

这个 `?token=`（在 `index.html` 后面、**hash 之前**）是苏服办小程序传入的 **certify_token**，专门用于扫脸，**不是**苏住房的业务 `accessToken`。

### 之前代码的问题

1. **`App.vue` 只读 hash 里的 token**（`#/pages/...?token=`），读不到 `index.html?token=`，微信带的苏服办 token 从未被正确识别。
2. **`loginWithSfbTicket` 登录后**若后端没返回 `sfbToken`，会用空字符串 **覆盖** `localStorage.tokenjssdk`，把 SDK 从 URL 写入的正确 token 清掉。
3. **扫脸凭证优先级错误**：优先用了登录接口返回的空/错误 `sfbToken`，而不是 URL 里的苏服办 token。
4. **支付宝无 URL token**：只能靠 `getTicket` → 换 token；若 `my.onMessage` 未绑定，会表现为「没反应」。

### 本次修复

| 改动 | 说明 |
|------|------|
| `initSfbTokenFromPageUrl()` | 启动时读取 `?token=`，写入 `sfbToken` + `tokenjssdk` |
| `ensureFaceCertifyToken()` | 优先：URL token → SDK 缓存 → store → ticket 登录 |
| `loginWithSfbTicket()` | 不再用空值覆盖已有苏服办 token |
| `App.vue` | 区分页面 `?token=`（苏服办）与 hash `?token=`（业务 accessToken） |
