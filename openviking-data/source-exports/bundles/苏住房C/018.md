### 最终结论
**问题原因**

苏找房页用了 z-paging 的 **页面滚动模式**（`use-page-scroll=true`），需要页面级 `onReachBottom` 转发到组件。但该页是 **自定义 AppTabBar** 的 Tab 页，页面高度和滚动容器与首页、掌服务不一致，导致触底事件经常触发不到，加载更多失效。

1. **`project.vue`**：改为 `height: 100%` + `overflow: hidden` 的 flex 布局，去掉 `onPageScroll` / `onReachBottom` 转发。
2. **`Project_Suzhufang.vue`**：改为 `use-page-scroll=false`，由 z-paging 内部 `scroll-view` 监听 `scrolltolower` 加载更多；补全高度链样式。
3. **`pages.json`**：为 project 页增加 `disableScroll: true`，避免页面与内部列表双重滚动。

重新编译运行后，在列表内向下滚动到底部应能自动加载下一页；底部会显示 z-paging 的「加载中 / 没有更多了」状态。

若仍无新数据，可能是接口 `total` 返回异常（首屏后就被判定为没有更多），可以把网络请求响应贴出来继续排查。
