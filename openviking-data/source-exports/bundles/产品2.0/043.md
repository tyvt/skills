## 功能说明

### 列表页 (`index.vue`)
- API：`GET /maintenance/accRefund/apply/page`
- 支持关键字、退款申请类型、业务状态查询
- 支持导出：`POST /maintenance/accRefund/apply/export`

### 详情页 (`detail.vue`)
- **基本信息**：物业管理区域、账户类型（业主基本账户 / 电梯消防资金专户）、出款账号及自动带出字段
- **退款申请信息**：退款类型、申请人、收款信息、退款原因、备注
- **通知书信息**：备案后展示（是否补录记账、通知书编号、退款状态等）
- **操作按钮**：保存/提交/取消提交、打印、作废、人工记账（跳转存款登记）

### 账号退款列表 (`AccountRefundTable.vue`)
- **选择历史退款通知书**：多选导入，调用 `importFromHistory`
- **新增**：选择账户（余额 ≠ 0 且冻结金额 = 0），调用 `addList`
- **退款利息计算**：选行后输入结息时间，依次调用 `calAmountRefund` + `refundAmountInterest`
- **部分退款**：退款申请类型为 `9` 时可编辑退款金额
- 表格含合计行，字段与需求/图片一致

### 退款记账明细 (`TradeDetailTable.vue`)
- 按退款通知书编号查询 `GET /maintenance/tradeDetail/list`
- 支持查看记账明细详情
