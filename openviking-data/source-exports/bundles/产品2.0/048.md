## 问题原因

账单列表页的 `handlePay` 在打开收款弹窗前会校验 `row.complexId`：

```479:486:zhi2-web-admin/src/views/property/spFeeBill/components/index.vue
    handlePay(row) {
      if (!row?.id) {
        this.$message.error('账单信息异常')
        return
      }
      this.currentBillRow = row
      this.isCollectionDialogVisible = true
    },
```

列表接口返回的数据里通常只有 `complexName`，没有 `complexId`，因此会直接提示「缺少物业管理区域信息」，收款弹窗和 `/property/spFeeBill/payDetail` 都不会被调用。

1. **`index.vue`**：收款时只校验账单 `id`，不再依赖列表行的 `complexId`。
2. **`collectionDialog.vue`**：

   - 从接口返回中取出 `complexId`，再加载支付渠道
   - 避免列表缺少 `complexId` 时支付渠道加载失败

修复后点击「收款」会正常打开弹窗，并依次请求：
- `GET /property/spFeeBill/payDetail/{billId}`
