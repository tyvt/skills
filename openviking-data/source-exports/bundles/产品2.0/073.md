## 是否存在「点确定后关不掉」

**存在**，主要原因与全局 `request` 行为一致（与 `ScopeSelectDialog` 类似）：

| 场景 | 是否可能不关 |
|------|----------------|
| 业务码非 200、网络错误、HTTP 异常等（拦截器 `Promise.reject`） | **会**：`then` 根本不走，`close()` 不会执行 |
| `then` 已执行，但 `res.code != 200` | 理论上若将来某条链路绕过拦截器仍 `resolve` 非 200 体，会不关；当前封装下失败一般会 **reject**，进不了 `then` |
| `then` 里 `res.code == 200` 为假（例如成功体里缺少 `code`，变成 `undefined == 200`） | **可能**：极少见，属于数据契约异常 |
