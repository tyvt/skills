原因是 **标题颜色继承了系统主题色，在深色模式下变成了白色**，而卡片背景也是白色，所以标题“看不见”了。

## 原因分析

`loginBox.vue` 里：

- **标题** `.title-class`：只设置了 `font-size: 18px`，**没有指定颜色**，会继承全局文字色
- **副标题** `.content-class`：写死了 `color: #999`，所以一直能显示

在 `style.css` 里，深色模式会设置：

```css
@media (prefers-color-scheme: dark) {
  :root {
    color: #fff;  /* 白色文字 */
  }
}
```

卡片背景是 `#fff`，标题就变成 **白字白底**，看起来就像没显示；副标题仍是灰色，所以只有描述文字可见。

## 已修复

在 `loginBox.vue` 中为标题补上固定样式：

```css
.title-class {
  font-size: 18px;
  font-weight: 600;
  color: #333;
  line-height: 25px;
}
```

同时给第一个「我的房屋」入口也显式补上了 `title` 和 `content`。
