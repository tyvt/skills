## 原因

这是 **Node.js 与 pnpm 版本不兼容** 导致的：

| 环境 | 版本 |
|------|------|
| Node.js | v22.23.2 |
| pnpm（安装前） | 7.16.0 |

pnpm 7.x 在 Node.js 18+ 上请求 registry 时会出现 `ERR_INVALID_THIS` / `Value of "this" must be of type URLSearchParams`，与 `registry.npmmirror.com` 本身无关。

项目里的 `build.sh` 已经使用 `pnpm@8.15.8`，说明团队之前也遇到过类似问题。

## 处理

已将全局 pnpm 升级到 **8.15.8**，`pnpm i` 已成功完成（约 26 秒，1206 个包）。

同时把 `package.json` 中的 `packageManager` 从 `pnpm@7.16.0` 更新为 `pnpm@8.15.8`，与 `build.sh` 保持一致，避免以后通过 corepack 又装回旧版本。

## 后续使用

如果其他机器也遇到同样问题，执行：

```bash
npm i -g pnpm@8.15.8
pnpm i
```

或者直接用项目构建脚本的方式：

```bash
npx --yes pnpm@8.15.8 install
```
