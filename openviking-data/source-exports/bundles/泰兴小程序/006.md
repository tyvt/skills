### 最终结论
已修复两个问题：

## 1. 选举记录详情显示「暂无数据」

根因是 `getList` 里变量名冲突：

```javascript
const recordId = recordId.value  // 局部变量遮蔽了 ref，导致请求失败
```

接口未成功调用，`list` 一直为空，页面就显示「暂无数据」。

**修复**：改为 `currentRecordId`，并增加分组匹配失败时平铺展示选项的回退逻辑。

## 2. 选举提交成功无提示

`form.vue` 在提交成功后同时执行了：

- `showPopup.value = true`（显示成功弹窗）
- `uni.navigateBack()`（立即返回上一页）

页面一返回，弹窗来不及显示。

**修复**：提交成功只弹出「选举成功」提示；用户点击「我已知晓」后再清空投票数据并跳转到选举首页。

请重新编译后验证：

1. 参与业委会选举并提交 → 应弹出「选举成功」提示
