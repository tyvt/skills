### 最终结论
已优化 `regionTree.vue`（`RegionTreeLayout` 实际使用的树组件）中「全部展开」的性能问题。

## 原因

原先虽做了 `requestAnimationFrame` 分批，但仍对每个节点调用 `treeNode.expand()`。在 Element UI 中，`expand()` 会触发加载检查、父链更新和子节点 DOM 创建；子节点多时，会在单帧内产生大量 DOM，导致主线程长时间阻塞、页面卡死。

## 方案

1. **直接设置 `node.expanded`**，不再调用 `expand()` / `collapse()`，减少多余逻辑。
2. **按层级展开**：先展开浅层，再展开深层，避免子节点在未展开父节点下重复渲染。
3. **每层内再分批**：每帧最多处理 40 个节点，把渲染压力分散到多帧。
4. **收起时自深到浅**，与展开顺序相反。
5. **交互**：展开/收起过程中显示 loading、禁用按钮，并显示「展开中...」「收起中...」。

若树节点总数极大（例如上万叶子节点），全部展开后 DOM 仍会很多，可能略慢，但展开过程应不再长时间无响应。若仍觉得慢，可优先使用右侧的「平铺展示」模式。

请在页面上再试一次「全部展开」，看卡顿是否明显减轻。
