## 原因

`index.vue` 里写了 **两个 `computed`**。在 JavaScript 里，对象里重复的键会 **后面的覆盖前面的**，所以 **`districtStatsByName` 被后面的 `threeAssetsMax` 整块顶掉了**，`this.districtStatsByName` 变成 `undefined`。

## 修改

已把 **`districtStatsByName`** 和 **`threeAssetsMax`** 合并进 **同一个 `computed`**，两个计算属性都会存在，悬停弹窗会恢复正常。

以后若再加 `computed`，请只保留 **一个** `computed: { ... }`，在里面并列写多个属性即可。
