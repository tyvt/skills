### 最终结论
已修复。报错 **「所传入参数并非 TMap.Map 的实例」** 是腾讯地图 GL API 在创建 `MultiPolygon` / `MultiMarker` / `MultiLabel` 时对 `map` 做 `instanceof TMap.Map` 校验失败导致的，常见原因有两类：

## 原因

1. **Vue 2 响应式破坏实例**  
   `TMap.Map`、图层对象若放在 `data()` 里（或作为响应式对象的属性），会被 Vue 代理，原型链被破坏，`instanceof` 校验失败。  
   原组件虽把 `map` 移出了 `data`，但 `marker`、`label`、`districtLayers` 仍在 `data` 中，仍可能间接影响。

2. **重复加载地图脚本**  
   `created` 与 `mounted` 各调一次 `loadMap`，可能插入多份 `gljs`，`window.TMap` 被替换后，旧 `Map` 实例不再属于新的 `TMap.Map` 构造函数。

3. **异步竞态**  
   `initPolygon` 在 JSONP 返回前组件已销毁，仍用已销毁的 `map` 创建图层，也会触发该错误。

## 修改内容

1. **`mapLoader.js`**：单例加载，已存在 `window.TMap` 则直接 resolve，避免重复插入脚本。

2. **`components/map.vue`**：
   - 用非响应式的 `_tmapCtx` 统一存放 `map`、`marker`、`label`、`districtLayers`
   - 创建图层前增加 `map instanceof TMap.Map` 校验
   - `initPolygon` 增加 `_mapViewToken` / `_destroyed`，防止销毁后仍绘制
   - 去掉 `created` 里多余的 `loadMap` 调用
