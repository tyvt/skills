对应当前生产包里的逻辑（`index-BiYbvZRJ.js`）：

```javascript
fetch(`./map/ws/district/...`).then(r => r.json())  // 实际拿到的是 HTML
```

原先通过 `import.meta.env.DEV` 区分环境，但在 **terser 压缩后 DEV 分支被错误保留**，JSONP 分支被当成死代码删掉。

## 修复方案

已修改 `zhi2-web-admin/src/utils/tencentDistrictBoundary.js`：**统一使用 JSONP 直连腾讯行政区划 API**（与 `statisticsMap` 的 `map.vue` 一致），不再依赖 `import.meta.env.DEV` 和本地 `/map` 代理。

本地重新构建后，地图总览 chunk 为 `index-FBZTF3mV.js`，其中已包含 `apis.map.qq.com` 的 JSONP 调用，且不再包含 `fetch('./map')` 和 `.json()`。
