## 问题分析

`index-DUzdsYzz.js` 是 **地图总览页（`mapOverview`）** 的路由懒加载 chunk，由 `module-main-*.js` 在进入该页面时动态加载，**不能**在浏览器里单独当页面打开。

### 1. 生产环境 404（最常见）

Vite 每次构建都会给文件加**内容哈希**。当前本地重新构建后：

| 文件 | 状态 |
|------|------|
| `index-DUzdsYzz.js` | 旧构建残留，**已不再被引用** |
| `index-BhqbH2RD.js` | 新构建的 mapOverview chunk |
| `index.html` | 已指向 `index-kcqN0yOc.js`、`module-main-DDxEcmow.js` |

若生产环境出现以下情况，访问 `index-DUzdsYzz.js` 会 404：

- 只更新了 `index.html` / `module-main`，未完整部署 `assets/`
- 浏览器或 CDN 缓存了旧的 `module-main`（仍引用 `index-DUzdsYzz.js`），但服务器上已是新包
- 部署路径不对（例如应用在 `/xxx/` 子路径，却访问了 `https://域名/assets/index-DUzdsYzz.js`）

**处理方式**：用本次完整 `dist`（或 `dist.zip`）**整包覆盖**部署，并清理 CDN/浏览器缓存。
