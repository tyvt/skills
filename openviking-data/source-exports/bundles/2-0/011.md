本次做了这些修改，解决「弹窗打开时单元表头不显示选中」的问题：

## 修改说明

1. **用 `v-model` 绑定单元勾选状态**  
   Element UI 的 `el-checkbox` 在单独使用时，主要靠 `v-model` 更新显示，仅用 `:value` 可能不会刷新视图。因此改为：
   - 使用 `v-model="unitCheckState[unit.unitId]"` 绑定表头复选框。

2. **用 data + watch 同步单元状态**  
   - 在 `data()` 中增加 `unitCheckState: {}`，用来存每个单元是否选中。  
   - 用 `watch` 监听 `tableData`（`deep: true`，`immediate: true`）：  
     - 弹窗打开、传入带 `checked` 的 `tableData` 时，会立即根据数据算出每个单元是否「全选」，并写入 `unitCheckState`。  
     - 之后 `tableData` 再变化（例如勾选/取消房屋）时，也会重新同步一次。  
   - 同步逻辑在方法 `syncUnitCheckState()` 里：遍历 `units`，对每个 `unit.unitId` 用现有的 `isUnitChecked(unit.unitId)` 结果更新 `unitCheckState`。

3. **兼容 `checked` 为数字 1**  
   接口有时会返回 `checked: 1` 而不是 `'1'`，判断时改为同时认可 `== '1'` 和 `=== 1`，避免漏判。

这样在弹窗打开时，只要传入的 `tableData` 里某单元下所有可勾选房屋都是选中状态，该单元表头的复选框会通过 `unitCheckState` 和 `v-model` 正确显示为选中；若只是部分选中，仍会显示为半选（`indeterminate`）。请再在「打开弹窗」的场景下试一次，看表头是否已经和房屋勾选一致。
