### 最终结论
这个报错是因为在 `AppMain.vue` 里用的是 `router.currentRoute.query.formMode`：

```12:21:zhi2-web-admin/src/layout/components/AppMain.vue
computed {
  formMode() {
    return router.currentRoute.query.formMode
  }
}
```

在 Vue Router 4 里，`router.currentRoute` 是一个 `ref`，并不是直接的路由对象，所以这样访问时会出现 `undefined`。

我已经改成直接使用组件自带的 `this.$route`，并加上空值保护：

```8:42:zhi2-web-admin/src/layout/components/AppMain.vue
<script>
export default {
  name: 'AppMain',
  mounted() {
    this.makeWatermark({
      loginName: this.$store.state.user.name || sessionStorage.getItem('name'),
      userName: this.$store.state.user.nickName || sessionStorage.getItem('name')
    })
  },
  computed: {
    formMode() {
      // 使用组件内置的 $route，兼容 Vue Router 4（currentRoute 是 ref）
      return this.$route && this.$route.query
        ? this.$route.query.formMode
        : undefined
    }
  },
  ...
}
</script>
```

这样 `formMode` 读取不到时会返回 `undefined`，不再触发 `Cannot read properties of undefined (reading 'formMode')`，`AppMain` 上的 `:class="[formMode == 'view' ? 'is-disabled-form' : '']"` 也能正常工作。
