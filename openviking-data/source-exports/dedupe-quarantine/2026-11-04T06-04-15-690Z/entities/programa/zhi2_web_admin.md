# zhi2-web-admin
Projeto web de administração para o portal "门户" (portal).

## Descrição
- Sistema admin front-end baseado em Vue2 (vite:vue2).
- Repositório em d:/repository/门户/zhi2-web-admin.
- Inclui views de home, manutenção, login unificado e componentes de tabela.

## Componentes relevantes
- zs-table: componente de tabela com container de espaçamento inferior.
- UnifiedLogin.vue: tela de login com menuList de entradas.
- HomeNoticeList.vue: lista de avisos com padrão zebra.

## Contexto
- Alterações registradas em docs portal/021.md e portal/022.md.
- Testes e2e localizados em tests/e2e.
