## 1. 详情页「不存在无法查看」✅

**根因**：历史列表「查看详情」跳 `/pages/detail/index?id=FX-20260712-0005&kind=pre`，但详情页走 `store.getRecord(id)`（本地无此 demo id）→ 回退 `getRecordAsync` 请求真实后端 `/v2.0/safety/flood/inspection/FX-...` → 404 → 弹「记录不存在」。

参考站 8443 的详情页是**静态页**（`InspectionDetail`/`RescueDetail` 渲染写死内容，不查数据），所以本端也应对齐为静态还原页。

**修复**：
- 新增 [Ref8443Detail.vue](<src/components/flood/Ref8443Detail.vue>)——按 `kind` 分派，1:1 还原参考站「汛中巡检工单详情」与「求援工单详情」（摘要、明细卡、自救处置、照片网格、工单信息、处置时间线、底部操作栏）。
- [detail/index.vue](<src/pages/detail/index.vue>) 在 `isRef8443()` 下渲染该组件，并**跳过后端查询**（`onLoad` 早返回），不再触发「记录不存在」。
- 补齐 5 张详情图（6e68b/d7427/230fe/95178/248ae）与整段详情页 CSS。

## 2. 历史记录 tab 高亮缺失 ✅

**根因**：`.tab-btn` 基础规则用了 `background:transparent!important`，而 `.tab-btn.active` 的 `background:#fff` **没带 `!important`**，被基础规则压掉 → 激活 tab 无白底。chip 同理。

**修复**：给 `.tab-btn.active` / `chip-btn.active` 加 `!important`。验证 computed：
- 激活 tab：`background rgb(255,255,255)` + `color rgb(0,79,208)`（与 8443 一致）
- 激活 chip：`rgb(0,79,208)` 蓝底白字
