# 禅道 Bug 6421
禅道缺陷 6421：登录页图形验证码占位文案有误需改为「请输入图形验证码」，且验证码填错仍能登录问题已按后半段要求修复。

## Description
- 登录页输入框占位文案原为「请输入4位验证码」，用户要求改为「请输入图形验证码」
- 禅道 6421 还记录：验证码填错仍能登录，正确行为应为刷新图片并提示「验证码输入错误，请重新输入」

## Fix
- 登录页图形验证码输入框占位文案已从「请输入4位验证码」改为「请输入图形验证码」
- 未填写时的提示本来就是「请输入图形验证码」，本次未再改动
- 改动文件：src/pages/login/index.vue

## 验证码校验修复
- 有验证码图片时必须填写，错码不会再进入登录成功流程
- 测试环境网关回传明文答案至 `captcha` 字段，提交前先比对，不一致则不发起登录
- 生产环境仍把 `code` 和 `uuid` 交给网关校验
- 网关返回验证码错误时，前端统一提示「验证码输入错误，请重新输入」并自动刷新图片

## 状态
- 占位文案修改与验证码校验均已修复（截至 2026-11-10 会话）
