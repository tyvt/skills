**最终交付**

现场图片（项目检查-检查填写页）已从普通 `PhotoPicker` 改为水印相机，满足截图中的水印要求：

- **拍照即加水印**：`src/utils/watermark.ts` 用 canvas 在原图底部叠加半透明条，写入「时间：YYYY-MM-DD HH:mm:ss」「地点：xxx」。
- **位置授权获取**：`src/utils/geo.ts` H5 走 `navigator.geolocation`（配 `VITE_AMAP_KEY` 可反查中文地址，否则回退经纬度），小程序走 `uni.getLocation`。
- **无位置不可拍照/提交**：`WatermarkCamera.vue` 定位未成功时禁用拍摄按钮，点击仅提示并重试定位，不调起相机；提交时仍需每项有图片。
- **重新获取位置权限**：定位栏提供「重新获取位置权限 / 重新获取位置」，小程序走 `uni.openSetting` 引导，H5 触发浏览器权限弹窗。
- **限制相册选图**：`sourceType: ['camera']`，只能拍照，不能从相册随意选已有文件。
- **数量/格式**：压缩拍摄，最多 5 张；`manifest.json` 补充小程序 `scope.userLocation` 授权与 `getLocation` 私有信息声明。

构建 `npm run build` 通过（仅有依赖既存 Sass 弃用警告，非本次引入）。

**改动文件**：[geo.ts](src/utils/geo.ts)、[watermark.ts](src/utils/watermark.ts)、[WatermarkCamera.vue](src/components/WatermarkCamera.vue)、[form/index.vue](src/pages/project-check/form/index.vue)、[manifest.json](src/manifest.json)。

> 提示：如需真实中文地址水印，需在环境变量配置 `VITE_AMAP_KEY`（高德 Web 服务 Key），未配置时水印地点显示经纬度。
