# 求援工单详情
苏住房防汛C端移动查询H5中的求援工单查看详情页面及其对应后端接口。

## 代码位置
- 详情页：`src/pages/rescue-workorder/detail.vue`；列表页：`src/pages/rescue-workorder/index.vue`。
- 求援相关代码分布在 `rescue`、`rescue-workorder`、`detail` 等目录，`src` 下没有直接以 rescue 命名的文件，需用中文关键词检索定位。
- 前端接口调用集中在 `api/portal.ts`。

## 接口
- 详情加载函数 `loadDetail` 使用 `options.id` 作为路径参数，请求 `/v2.0/safety/flood/rescue/{id}`（完整路径 `/api/v2.0/safety/flood/rescue/{id}`）。
- 后端按数字主键 `rescueId` 查询；G 端 `api/flood/index.js:251` 的 `getRescue(rescueId)` 与列表 `row-key="rescueId"` 全链路只用 `rescueId`，`rescueNo` 仅作编号展示列；对照仓库为本地「苏住房G」。

## 根因与修复
- 2026-11-24 反馈点击查看详情提示「未找到该工单」：列表 `index.vue:56` 原为 `id: String(r.rescueNo || r.rescueId || '')`，把工单编号 `rescueNo` 当主键传参，后端查不到 → 请求抛错 → 详情页落空态「未找到该工单」（`detail.vue:93`）；接口路径与 G 端一致，错在传参值。
- 修复：`index.vue`/`detail.vue` 的 `id` 改取 `rescueId`，新增 `no` 字段承载 `rescueNo`；编号展示模板用 `no || id` 兜底；`openDetail` 空 id 不跳转并 toast 提示；grep 残留检查通过。
