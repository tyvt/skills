# 禅道
苏住房防汛C端移动查询H5项目使用的缺陷跟踪与项目管理系统。

## 用途
- 用于登记和回写代码提交对应的缺陷（Bug）事务。
- 回写时将事务状态置为 resolved、resolution=fixed、resolvedBuild=trunk。

## 相关字段
- resolvedBy：处理人（如 tiany）。
- assignedTo：后续处理人（如 lichandan）。
- 操作记录表 zt_action 记录 action=resolved 等。
