# 路南苑
Residential property management area in Baiyangwan Subdistrict, Gusu District, Suzhou, used as the real-machine reproduction site for ZenTao bug 6931.

## Location & Property
- Administrative division: Gusu District / Baiyangwan Subdistrict (姑苏区/白洋湾街道).
- Property service company: 苏州荣盛物业管理有限公司.
- Grade shown on the 发起检查 form: 市标二级; check frequency 每半年开展一次.

## Role in Verification
- Among the property areas tried on 2026-11-24 it was the only one with registered service grades; others were blocked by 「该物业管理区域暂无已备案的物业服务等级，无法发起检查」.
- Matches the ZenTao 6931 screenshot scenario (街镇检查 on this area).
- Inside its check form the 01 综合能力 grade picker defaults to 市标三级, and after a grade change the backend still returned 市标三级 (2026-11-24).
