- 希望骨架屏只覆盖图片和接口返回数据的动态区域，导航、表单结构、固定菜单标题、tab 等静态部分保持可见、不使用骨架屏。
- 要求缺失骨架屏的动态区域一并补齐。
- 所有骨架屏须在对应接口返回后的第一时间立即关闭。
- 所有骨架屏只根据需要展示数据的接口来源独立计时，不等待全部接口。
