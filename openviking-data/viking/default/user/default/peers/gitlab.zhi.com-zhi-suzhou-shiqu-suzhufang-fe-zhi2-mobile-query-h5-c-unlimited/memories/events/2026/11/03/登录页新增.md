### 登录流程

1. App 启动 → 判断本地 token：
   - 有 token → `reLaunch` 到工作台
   - 无 token → 停留登录页
2. 用户输入账号密码 → 点「登录」→ 调用现有 `store.login()`（AES 加密密码 → `POST /v2.0/security/auth/login` → 取令牌存本地）
3. 成功 → 进工作台；失败 → 页面内红色错误提示（如「账号或密码错误」）
4. 工作台「我的」→ 确认退出 → 清除 token → 回登录页
