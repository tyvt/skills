## 对齐过程中解决的三个关键问题

1. **uni-app 根字号 16.64px vs 参考稿 16px** → 所有 rem 间距放大约 4%（main 高 3568 vs 3479）；注入 CSS 里强制 `html{font-size:16px!important}`。
2. **图标字号被覆盖** → 动态注入的 Google Fonts CSS 晚于 Tailwind 生效，`.material-symbols-outlined{font-size:24px}` 盖掉了 `.text-[18px]/[22px]`；改为 `index.html` 静态声明，保证 CSS 顺序与参考稿一致。
3. **Vue 模板 `ref` 在 uni-app 自定义元素上不生效** → 改用 `document.getElementById` 注入。
