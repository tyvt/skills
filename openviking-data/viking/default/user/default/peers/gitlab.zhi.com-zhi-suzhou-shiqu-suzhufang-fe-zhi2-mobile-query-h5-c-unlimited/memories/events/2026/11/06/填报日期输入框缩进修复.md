## 根因

不是 label 有 padding，而是**输入框本身左缩进**：
- `<uni-input class="ref-input">` 外层被 `.ref-input{padding:12px}` 加上了 12px 内边距，导致内层 `<input>` 灰框从 **x=44、宽 302** 开始（每边缩进 12px）。
- 参考站原生 `<input>` 灰框是 **x=32、宽 326**（撑满卡片内容宽）。
- 所以视觉上「填报日期」框相对上下元素明显右移、两边留白更大。

经实测两处 label 文字起点一致（ref 43 / mine 42，都因 `* ` 前缀），真正偏移的是输入框灰框（ref 32/326 vs mine 44/302）。

## 修复

把灰底 + 内边距从 `uni-input` 外层下沉到内层 `.uni-input-input`，外层 `padding:0`，使灰框撑满 326、起点对齐 32——与下方 counter、卡片内边距完全左对齐（做法与之前 textarea 一致）。

验证：`inpX=32 inpW=326`（与参考站一致）。

汛前检查像素差 **5.06% → 4.92%**，其余页无回归。
