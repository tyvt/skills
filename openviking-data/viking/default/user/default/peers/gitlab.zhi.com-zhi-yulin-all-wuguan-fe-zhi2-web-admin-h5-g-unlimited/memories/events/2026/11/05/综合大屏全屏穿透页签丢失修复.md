## bug 6217 修复完成

**问题**：系统监控-综合大屏，全屏模式下穿透后会自动把大屏页签（综合大屏）关掉。

### 根因
大屏全屏用的是「内容全屏」机制，`layout/index.vue` 里 `tags-view` 用 `v-if="... && !contentFullscreen"` 控制：
1. 进入全屏 → 页签组件被**整体卸载**；
2. 全屏下点击统计数字穿透（`goMenu` 先 `setContentFullscreen(false)` 再 `router.push`）→ 页签组件被**重新创建**，其 `mounted()` 里的 `delAllVisitedViews()` 会清空所有非固定页签；
3. 时序竞态下「综合大屏」页签就被误关。

### 修复
`zhi2-web-admin/src/layout/index.vue`：把 `tags-view` 的显示控制由 `v-if` 改为**保留挂载 + `v-show="!contentFullscreen"`**（外层仍 `v-if="outLink != 1 && needTagsView"`）。全屏切换只做显隐、不再卸载重建，彻底消除重建导致的页签清空竞态。

### 验证（Playwright + nginx 部署真实构建）
复现「进入全屏 → 点物业管理区域总数穿透到物业管理区域备案」：

| | 页签容器事件序列 | 结果 |
|---|---|---|
| 修复前 | `[false,true,false,true]` | 全屏卸载、穿透返回**重建**（触发竞态窗口） |
| 修复后 | `[false,true]` | 全程**不卸载**，穿透后页签栏为「首页 / 综合大屏 / 物业管理区域备案」，大屏页签不再丢失 |

lint 通过，构建成功。
