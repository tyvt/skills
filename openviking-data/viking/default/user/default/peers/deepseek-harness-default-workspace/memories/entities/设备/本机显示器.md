# 本机显示器
本机当前接入两块 1920×1080 的 Generic PnP Monitor，可通过 DDC/CI 调亮度/对比度，色温只能走软件 Gamma。

## 设备信息
- 主屏：\\.\DISPLAY5，1920×1080，Generic PnP Monitor。
- 副屏：\\.\DISPLAY1，1920×1080，Generic PnP Monitor。
- WmiMonitorBrightness / WmiMonitorBrightnessMethods 返回空，未通过 Windows WMI 暴露背光控制。

## 控制能力
- DDC/CI 可读写亮度与对比度；两屏亮度、对比度均可调。
- 硬件色温不支持；颜色/色温观感只能通过 Windows Gamma 软件层调整，不改变硬件背光。
- 显示器物理 OSD 按钮中的硬件设置无法通过程序直接操作。

## 当前设置
- 2026-11-26 微调后两屏亮度均为 52/100（DDC/CI 硬件背光）。
- 2026-11-26 微调后两屏 Gamma 为 R 1.0 / G 0.99 / B 0.94，较原暖白方案减少黄暗感。

## 注意事项
- Gamma 是软件层，登录或重启后可能失效；DDC/CI 亮度通常写入显示器，重启后仍在。
- 若重启后颜色回退，可重新应用 Gamma 或设置开机脚本。
