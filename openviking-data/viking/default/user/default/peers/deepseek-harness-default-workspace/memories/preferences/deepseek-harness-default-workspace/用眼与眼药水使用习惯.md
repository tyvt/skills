- 日常使用无防腐剂人工泪液（单支装）缓解眼睛干涩，关注每日可用的安全频率。
- 因职业需白天全天盯屏幕，倾向采用长期护眼方案（如定时远眺、刻意增加眨眼），而非仅靠滴眼药水。
- 重视用眼健康风险，接受"单日用量过高应就医排查干眼症"的提醒。
