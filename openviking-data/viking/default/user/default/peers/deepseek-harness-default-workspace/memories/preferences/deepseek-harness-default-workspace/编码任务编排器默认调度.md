- 偏好所有编码/修复/重构/实现类任务默认先走编排器（orchestrate 的 op=full 或 op=tool），由模型池负责故障转移。
- 例外可直连主会话工具：纯只读、极小改动、格式微调、或编排器网关不可用时，并需在回复中说明原因。
- 以下操作一律先走 orchestrate（op=full / op=tool）：全仓或跨目录 grep、单文件 >300 行整读、npm run lint 全量、npm run build、账单/大结果查询。
- 单文件 ≤300 行、单条窄命令（npx eslint <file>、git status）可直接执行，无需编排器。
- 编排器不可用时，直连前必须在回复中写明「网关 127.0.0.1:3425 不可用」及原因；不得静默降级为主模型亲自跑重活。
