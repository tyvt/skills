**assistant [peer=deepseek-harness-default-workspace]**: 跨请求的会话记忆已经接到 `src/api.py`、`src/jsonbridge.py` 和插件 `lib/index.js` 上。没有用 LangGraph 的 `MemorySaver`，因为它只存在进程内存里，而 `jsonbridge.py` 每次调用都是新进程，进程一退记忆就没了。改成按 `session_id` 把 `environment_context` 写到项目下的 `.sessions/<id>.json`，下次同 ID 启动时读回来。

`session_id` 由插件从宿主上下文读取，取 `exec.sessionId`、`exec.session.id` 或 `exec.session.sessionId`，不接受模型在参数里传入。这样模型无法指定别人的会话 ID。ID 必须匹配 `^[A-Za-z0-9_-]{8,128}$`，否则视为无效，不读写文件。没有拿到 ID 时也不落盘，每次都从项目根目录开始。

隔离规则有三条：

- 新的或未知的 `session_id` 从项目根目录启动，也就是 `config.yaml` 所在目录。
- 读回来的 `cwd` 必须位于项目根内，跑到外面（例如 `C:\Windows`）就重置回根目录。
- 只保存 `cwd` 和命令写过的 `env`，不保存整份系统环境变量。

本地验证了三种情况：会话 A 能恢复到 `src` 并带回变量 `X`；会话 B 保存的 `C:\Windows` 被重置回项目根；一个从未出现过的会话也从项目根开始。

核心代码在 `src/api.py`：

```python
def load_environment(session_id: str, root: str) -> Dict[str, Any]:
    fresh = {"cwd": root, "env": {}, "recent_env": {}}
    key = _session_key(session_id)
    path = _STORE / f"{key}.json" if key else None
    if path is None or not path.is_file():
        return fresh
    try:
        saved = json.loads(path.read_text(encoding="utf-8"))
        ctx = saved.get("environment_context") or {}
        cwd = ctx.get("cwd") if isinstance(ctx.get("cwd"), str) else root
        env = ctx.get("env") if isinstance(ctx.get("env"), dict) else {}
    except (OSError, json.JSONDecodeError):
        return fresh
    if not _inside(root, cwd):
        return fresh
    return {"cwd": os.path.abspath(cwd), "env": {str(k): str(v) for k, v in env.items()}, "recent_env": {}}

def save_environment(session_id: str, ctx: Dict[str, Any], root: str) -> None:
    key = _session_key(session_id)
    if key is None:
        return
    cwd = ctx.get("cwd") if isinstance(ctx.get("cwd"), str) else root
    if not _inside(root, cwd):
        cwd = root
    _STORE.mkdir(exist_ok=True)
    target = _STORE / f"{key}.json"
    payload = {"environment_context": {
        "cwd": os.path.abspath(cwd),
        "env": {str(k): str(v) for k, v in (ctx.get("env") or {}).items()},
    }}
    tmp = target.with_suffix(".tmp")
    tmp.write_text(json.dumps(payload, ensure_ascii=False), encoding="utf-8")
    os.replace(tmp, target)
```

`run_full` 在编排前调用 `load_environment`，结束后调用 `save_environment`。Python 侧下次调用就生效，但插件 `index.js` 的改动需要重启 DSH Web 才会加载。
