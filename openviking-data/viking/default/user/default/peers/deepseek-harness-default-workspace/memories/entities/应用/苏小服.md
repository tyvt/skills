# 苏小服
苏小服是将指定网页地址封装为鸿蒙 HAP 应用的 WebView 套壳项目。

## 基本信息
- 目标网址为 https://szfmh.szzfcjj.cn:8999。
- 应用名为「苏小服」。
- 项目目录为 suxiaofu-harmony。
- 包名为 com.szzfcjj.suxiaofu，版本为 1.0.0。

## 功能与权限
- 通过 WebView 加载目标网页。
- 支持网页定位授权，使用 event.geolocation.invoke(event.origin, true, true) 回调位置权限。
- 支持网页保存图片，下载图片并存入相册。
- 已配置 INTERNET、定位和图片读写权限。

## 构建与交付
- 使用 HarmonyOS API 26 / Stage 模型构建。
- 签名方案为 DevEco 自动签名；首次构建因命令行未找到证书，交付未签名 HAP。
- 已通过 hvigorw assembleHap 构建出未签名 HAP。
- 交付文件为 suxiaofu-unsigned.hap，约 28KB。
