## 三、排查结论：**迁移不正确，三个分支都只做了"签字携带"，榆林版业主倡议主体未迁移**

1. **榆林版页面完全没迁移。** 三个分支的 C 端仍是旧版 `pages_owner/propose`（mp 分支 `pages_vote/propose`）14 个页面；参考实现 `D:\repository\泰兴小程序` 的 `src/pages-suggest/`（`list/create/detail/detailResponse/proposal-item-detail` + `components/CancelPopup、DecisionList`）在 `zhi2-mobile-shimin` 全部分支中**都不存在**（`git ls-tree --all` 无 `pages-suggest`）。菜单仍映射旧路径：`menuRouteMap.js` → `/pages_owner/propose/index`（mp → `/pages_vote/propose/index`）。

2. **写接口未换成榆林版新接口，且旧接口在后端已不存在。** 后端 `zhi2-autonomy` 分支 `develop/v2.6.2-suzhufang-dev`（最新提交 `206d8a9f`，即 1977 后端任务）里：
   - `batchSaveSuggestTopic`（前端发起倡议用的）**无任何 Controller 映射**；
   - `addSuggestResponse`（前端"我要响应"用的）**也无映射**；
   - 实际存在的是 `addAppSuggest` / `appSuggestResponse` / `hasResponded` / `cancelSuggestV2`。
   → 前端三个分支调用的 `/autonomy/suggestTopic/batchSaveSuggestTopic`、`/autonomy/suggestResponse/addSuggestResponse` 在新后端已消失，**发起倡议与我要响应无法落库**（与"迁移榆林版本"必须换接口的结论一致）。

3. **字段名错一处，会丢签字。** 文档特别强调"撤回倡议是 `revocationSignatureUrl`，撤回响应是 `signatureUrl`"。三个分支的 `formRevoke.vue` 中，`cancelTSuggest`（撤回倡议）传的是 `signatureUrl`，而后端 `SuggestCancelDto` 只认 `revocationSignatureUrl` → **撤回倡议签字被静默丢弃**。

4. **响应/撤回响应未走 `appSuggestResponse`。** `formResponse.vue` 调 `addSuggestResponse`（应 `appSuggestResponse` + `suggestResponseStatus=1`）；`formRevoke.vue` 撤回响应调 `cancelTSuggestResponse`（应 `appSuggestResponse` + `suggestResponseStatus=2`）。按文档，撤回响应的签字只写留痕表、主表保留响应签字，走错接口则留痕无签字。

5. **发起倡议的 `signatureUrl` 位置不对。** 文档要求 `addAppSuggest` 顶层一个 `signatureUrl`（后端对每个议题写同一张）；当前实现把 `signatureUrl` 塞进 `batchSaveSuggestTopic` 数组的**每一项**里，且用的是已下线的接口。

6. **C 端回显与文档冲突。** 三个分支 `detail.vue` 都加了"发起人签字"卡片，但文档第 5 条写明 C 端不展示签名（且 `GET /autonomy/suggest/{suggestId}` 是 G 端权限接口），该卡片恒为空，属无效代码。

7. **撤回倡议的前置校验缺失。** 文档 2.3 列出后端四项校验（状态、创建超 24 小时、自动核验下有他人响应、超过响应截止日），建议前端提前拦截；现有 `formRevoke.vue` 无任何预校验。

8. 参考实现侧（`泰兴小程序`，`dev-ui-yulin-v2.6.8`）的 `pages-suggest` 本身**也不含签字采集**（`create.vue` 无 `signatureUrl`，`detail.vue` 仅声明未渲染），所以"迁移 + 签字"是两件事：迁移页面/接口后，还需在发起、撤回倡议、响应、撤回响应四处补签字采集与上传。

**参考实现位置**（供后续迁移取用）：`D:\repository\泰兴小程序` 分支 `dev-ui-yulin-v2.6.8`，`src/pages-suggest/**`；接口封装在 `src/api/autonomy.js`（`addAppSuggest` / `cancelSuggestV2` / `hasResponded` / `appSuggestResponse`）；签字组件苏住房 C 端已有 `src/pages/components/SignBoard.vue`（mp 分支为 `src/components/shared/SignBoard.vue`）+ `pages_owner/decision/components/StepSign.vue`。
