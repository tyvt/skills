```html
<zs-button
  v-if="isFormDisabled && form.tradeStateCode != '0000' && form.tradeStateCode != null"
  :v-haspermi="['benefit:pubAllotNotice:cancel']"
  ... @click="toVoid">作废</zs-button>
```

**要同时满足 4 个条件才显示：**

| 条件 | 含义 | 来源 |
|---|---|---|
| `isFormDisabled` | 页面处于**查看态**（`mode == 'view'`） | mixins/form.js:23 |
| `tradeStateCode != '0000'` | 交易状态码不是"已完成/成功" | 详情接口 `response.data` |
| `tradeStateCode != null` | 交易状态码不为空 | 同上 |
| `v-haspermi` | 当前账号有 `benefit:pubAllotNotice:cancel` 权限 | 权限体系 |

所以**有的单据没有作废按钮，通常是这三种情况之一**：走在线支付且交易状态已是 `0000`（缴款完成）、单据没有交易流水导致 `tradeStateCode` 为空（如线下支付/未发起在线交易），或该账号没有 `cancel` 权限。你截图这张就是没有作废按钮的那类。
