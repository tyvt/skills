# Bug 6559 资金拨付详情字段消失
禅道 Bug 6559（惠山物管 · 资金拨付详情）：北村合同金额保存后「本次支取合同金额」字段在查看态消失。

## 问题现象
- 编辑态输入「本次支取合同金额」500 元，保存后查看态该字段整行消失
- 累计/剩余可用合同金额在查看态显示「-」空值占位
- 支出合同编号 ZQHT2026111300029，支出合同金额 800.00 元

## 根因定位
- detail.vue 的 contentInfo 计算属性 displayAsWithContract 分支漏 push noticeAmount 项
- 编辑态模板有 noticeAmount，查看态缺失导致切换时该行消失
- haveWithdrawAmount/remainWithdrawAmount 仅在选合同时赋值，getDetail() 无兜底
- 苏住房同源实现（task 2393 移植来源）存在同一缺陷

## 后端状态
- 惠山 Dameng 库 T_JG_ALLOT_NOTICE 无合同支取相关列（HAVE_WITHDRAW_AMOUNT/CONTRACT_FLAG 等）
- 苏住房测试库 PUB_ALLOT_NOTICE 有 CONTRACT_FLAG 和 HAVE_WITHDRAW_AMOUNT
- 惠山后端可能未实现 task 2393 服务端部分

## 修复进展
