**要同时满足 4 个条件才显示：**

| 条件 | 含义 | 来源 |
|---|---|---|
| `isFormDisabled` | 页面处于**查看态**（`mode == 'view'`） | mixins/form.js:23 |
| `tradeStateCode != '0000'` | 交易状态码不是"已完成/成功" | 详情接口 `response.data` |
| `tradeStateCode != null` | 交易状态码不为空 | 同上 |
| `v-haspermi` | 当前账号有 `benefit:pubAllotNotice:cancel` 权限 | 权限体系 |
