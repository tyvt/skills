# 完成态基本信息置顶 (completion-state basic info on top)
Layout requirement for the Huai'an property-management general-vote detail page, raised by the user on 2026-11-25: in the completion state the 「基本信息」 block must appear at the top of the page.

## Requirement and cause
- Rendered order was 决策分析 → 表决明细 → 基本信息, but the user wants 基本信息 first.
- Root cause: global style `index.scss:256` sets `.detail-container { flex-direction: column-reverse }`, reversing the DOM where Headline/基本信息 is first.
- Outside the approved bug-6522 scope (which only changed `detail.vue:103`), so it is handled as a new change.

## Approach and review
- Chosen approach: a scoped visual-order override inside `detail.vue` for the completion state only, not a change to the global `.detail-container` rule.
- Plan review: first round 84/100 with two P1 suggestions (scope the override by a completion-state class, add verification detail); the revised plan was re-approved at 94/100 and bound a fresh approved_sha256.
- API returns `bizState` as the string `'2'` for the completion state.

## Status
- 2026-11-25 用户确认作为新改动实施，方案已批准（修订版 94/100，绑定新的 approved_sha256）。
- hop3 已完成：代码落地（detail.vue:2 加 basic-first 类、778 行 scoped 覆盖 column）、重建、实机验证（`flexDirection=column`、基本信息 top=128 高于决策分析/表决明细 top=621，截图 `detail-basic-first-full-20261125-104318.png`）并经用户确认；禅道写回附件 fileID 24311；子模块提交 `9bcf6c207`、父仓 gitlink `82c920e` 均已推送；链 3/10 终止无待办。
