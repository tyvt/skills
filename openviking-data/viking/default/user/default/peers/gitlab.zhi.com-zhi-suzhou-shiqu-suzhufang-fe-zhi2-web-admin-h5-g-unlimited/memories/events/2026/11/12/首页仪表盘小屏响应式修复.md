## 问题根因
首页仪表盘（`src/views/home/`）的栅格和卡片**完全没有响应式断点**：
- 主栅格固定 `1.33fr 1fr 1fr` + 固定 `grid-auto-rows: 416px`，任何宽度都保持 3 列，小屏下被压成极窄的三栏；
- 顶部「区域选择 + 统计周期」一行 `flex` 不换行，窄屏会重叠/挤出视口；
- `公共收益` 的环形图/趋势图容器是 `min-height:0` 的 `flex:1`，一旦取消固定行高就会塌缩为 0；
- `双晒公示` 表格列宽固定（合计约 376px），压缩后行政区划列被裁切。

## 改动（4 个文件，均为 scoped 样式，未动逻辑/接口）
- `index-v2.vue`：新增断点 — ≥1200px 维持 3 列；768–1199px 降为 2 列且**首卡整行铺满**（关键数据导航/公共收益），后两张并排；≤767px 单列堆叠、取消固定行高、容器外边距收敛；区域栏 `flex-wrap` 换行（tab 整行在上、周期整行在下）。
- `KeyDataNav.vue`：≤575px 卡片两列改单列、企业卡片纵向排列。
- `PublicBenefit.vue`：≤767px 侧栏统计与图表区上下堆叠，并给环形图/趋势图**显式高度**（200/240px），避免自适应卡片下塌缩。
- `SunshinePanel.vue`：≤991px 排名表格横向滚动（`min-width:460px` + `overflow-x:auto`），覆盖中屏半宽与手机窄屏。

验证：`npm test`（test 模式 Vite 构建）通过；真机/浏览器窄屏联调未执行（无账号与窄屏环境），建议你在 DevTools 设备模式或手机 WebView 里过一遍 320 / 768 / 1200 三档。
