## 结论

截图的"其他租赁合同"列表页，顶部"新增"按钮用的是公共按钮 `this.addButton`，它自带真实权限字符：

- **权限字符：`benefit:pubRevenueContract:add`**（`moduleName=benefit` + `businessName=pubRevenueContract` + `:add`）

| 显隐执行 | [zs-button.vue:2](<zhi2-web-admin/src/components/zs-button/zs-button.vue#L2>) | `v-if="checkPermission(permission, buttonName)"` |

## 提示

如果实际是"某角色看不到这个按钮"，属预期权限控制，需检查后台菜单/角色是否给该角色分配了 `benefit:pubRevenueContract:add`；若是"无权限角色也能看到"，那要查 `permission.js` 里该字符是否被误判命中。
