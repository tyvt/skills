## 诊断结论

红框处（x≈330–443）是**品牌区（442px）与标题容器（实测 372.55px）之间约 70px 的"无容器裸底带"**——`.title-logo` 是内容自适应宽度，没有铺满设计预留的 442px 品牌区，右缘与菜单/箭头起点之间没有任何元素接管。

## 修复方向

把 `.title-logo` 拉伸到整个品牌区（`.navbar-left` 定宽 442px + `title-logo` 改 `flex: 1 1 auto`），使容器右缘与箭头/菜单起点齐平；移动端断点（[:1423](zhi2-web-admin/src/layout/components/Navbar.vue#L1423)）同步加 `width` 重置。视觉零变化，纯结构对齐。
