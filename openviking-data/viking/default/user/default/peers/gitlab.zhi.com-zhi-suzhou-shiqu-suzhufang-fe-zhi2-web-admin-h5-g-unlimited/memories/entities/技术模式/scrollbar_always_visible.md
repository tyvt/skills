# 滚动条始终显示（overflow: scroll）
将横向顶栏与表体纵向区改为 `overflow: scroll`，使滚动条始终显示。

## 实现方式
- 横向顶栏改为 `overflow: scroll`
- 表体纵向区改为 `overflow: scroll`

## 目的与效果
- 使横向与纵向滚动条始终显示
