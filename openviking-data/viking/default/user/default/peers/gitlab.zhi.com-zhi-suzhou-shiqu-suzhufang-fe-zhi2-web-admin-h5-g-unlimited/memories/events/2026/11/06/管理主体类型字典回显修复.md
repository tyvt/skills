**现象**：共有资金 → 开户申请 → 新增 → 选择「管理主体名称」弹窗里，「管理主体类型」列显示 `1`，未显示字典文案。

**根因**：[`pubRegulatoryAccount/detail.vue`](<worktrees/bug6259-web/src/views/benefit/pubRegulatoryAccount/detail.vue>) 中 `showCompanyDialog` 的表格列只绑了 `prop: 'benefitCompanyRecordType'`，没有 formatter；列表页/子表用的是 `dictFormatter`，弹窗漏了。

**修复**：为该列增加 formatter，用已加载的 `benefitCompanyRecordTypeOptions`（字典 `benefit_management_subject`）把 `dictValue` 转成 `dictLabel`，写法与同模块 [`pubRegulatoryAgreement/detail.vue`](<worktrees/bug6259-web/src/views/benefit/pubRegulatoryAgreement/detail.vue>) 一致。
