**为什么 PDF 会变成 .txt**：这是两处问题叠加的结果：

1. `src/api/index.js` 的 `saveBlobToFile` 用 `new Blob([data])` 重建 Blob 时**没传 type**，服务端的 `Content-Type: application/pdf` 被丢弃；同时也没有像 `utils/zipdownload.js` 那样解析 `Content-Disposition` 获取真实文件名。
2. `detail-template.vue` 的 `downloadAttachmentFile` 只用 `file.name || URL 末段` 计算文件名。这条数据的 `planFileName` 是“访问地址和账号密码配置”（无扩展名），因此 `a.download` 的值为无后缀名称，浏览器只能按 MIME 推断；而 MIME 已经被上一步丢掉，浏览器就默认成了 `.txt`。

另外发现：**2026-11-11 那版修复没有合入主干**。提交 `8d5f9c0ce` 在 `fix/bug6369-download-txt-ext` 分支上，从未合入 `develop/v2.6.2-suzhufang-li` 和 `develop/v2.6.2-suzhufang`；当前主仓子模块指针 `e8e82a8496` 里仍是旧代码，所以线上依旧复现。
