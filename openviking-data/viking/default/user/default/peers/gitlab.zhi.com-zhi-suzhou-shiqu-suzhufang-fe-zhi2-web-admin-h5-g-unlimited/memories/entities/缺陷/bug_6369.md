# Bug 6369 应急预案上传后打不开
苏住房防汛模块（产品 79 G端安全管理）缺陷：防汛应急预案上传后打不开，2026-11-10 完成修复。

## 根因
- DetailTemplate.downloadAttachmentFile 使用裸 fetch 且未带 token，请求返回 401 后触发 <a> 导航跳转登录页。
- 三个 download:true 的调用方均为防汛详情页。

## 修复
- 改用鉴权 downloadGet 下载；失败时 reject 并降级为 window.open。
- ESLint 通过，common-errors.md 增加 E21 条目。
