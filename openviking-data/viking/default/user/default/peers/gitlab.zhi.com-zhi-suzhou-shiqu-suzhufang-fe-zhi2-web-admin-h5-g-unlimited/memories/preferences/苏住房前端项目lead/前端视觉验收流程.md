- 视觉验收以全图 E2E 相似度 99.5% 为硬门槛，低于门槛不提交、不推送，仅把候选改动留在 worktree 供审阅。
- 诊断性的排除区域分数（如排除图标区域）不作为正式验收分数。
- 调试用临时诊断钩子用完即清除，并把本机站点恢复到基线提交后再交接。
- 验收前需通过 lint、E2E 脚本语法检查和构建三项检查。
- 收到明确“提交推送”指令时以指令为准：即使全图 E2E 相似度未达 99.5%（如 92.707%）也照常提交并推送主分支；视觉验收结论仍按门槛判定，不称其为验收通过。
