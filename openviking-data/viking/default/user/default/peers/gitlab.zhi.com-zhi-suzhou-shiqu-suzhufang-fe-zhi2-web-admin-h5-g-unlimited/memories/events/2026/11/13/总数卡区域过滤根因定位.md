**assistant [peer=gitlab.zhi.com-zhi-suzhou-shiqu-suzhufang-fe-zhi2-web-admin-h5-g-unlimited]**: 找到根因了：即使是在全市状态下，`portalQueryParams()` 仍然会返回 `{ parentDeptId: <市级部门id> }`。对于本地企业，这个条件能匹配；而对于**不挂在市级部门树下的非本地企业**，它会把它们全部排除掉。这正是 bug#5819 的机制，只是它现在影响到了总数卡。

修复方式：总数卡跳转时不应该带上 `parentDeptId` 区域过滤条件，就像 `companyNonLocal` 那样。
