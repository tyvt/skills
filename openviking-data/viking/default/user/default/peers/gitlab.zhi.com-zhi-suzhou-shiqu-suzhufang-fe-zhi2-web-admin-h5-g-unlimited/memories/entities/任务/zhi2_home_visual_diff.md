# zhi2-web-admin 首页视觉差异走查
2026-11-14 起对 zhi2-web-admin 首页做视觉比对，记录差异、决策与逐轮复测。

## 差异与目标基线
- 2026-11-14 三处不一致：品牌区偏窄、菜单项间距与激活框尺寸过小、头像回退未按夹具呈现；已定调整顺序。
- 基线：401px 品牌区、120px 菜单项、8px 间距、144×72 激活框、40px 箭头栏；调整前先核实头像数据来源与滚动容器尺寸。
- 空头像在 Vuex 被替换为系统默认女性照片；仅 Navbar 默认占位头像显示通用蓝色人像，不影响真实用户头像。

## 构建与像素核验（2026-11-14）
- 完成头像占位、品牌区与导航几何调整，Scoped ESLint 通过；按候选构建流程重跑 test 与生产构建，输出限定在 worktree `dist` 后部署拍图。
- 按品牌区、菜单、箭头、头像四区域统计像素 diff 而非目测；背景与箭头区接近基线，剩余差异在品牌文字与菜单图标。
- 核实目标夹具由 3× 原图缩小、E2E 要求 1× 截图，采样流程正确，无需匹配 3× 密度。
- 判定菜单整体偏右，品牌区宽度退回 401px；按 worktree 快照规则先核实父仓与子模块状态。

## 宽度对比与复测（2026-11-15）
- 交互检查通过（左右滚各 2 次到边界、空权限场景也通过）；相似度 88.052% 低于上一版，先核对截图与站点恢复状态再按像素判断品牌区宽度。

- 442px 修正版 test 与 production 构建均成功（E2E 上轮已通过）；确认新 `dist` 无测试标记后重新部署复测。
- 442px 版相似度升至 90.100%，左右滚动与空权限检查再次通过，包装器已还原站点；下一步看差异热区，区分文字、图标与尺寸偏差。
