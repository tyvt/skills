- 长链路任务按 hop 分段推进，成本到达交接档位即停手，先写交接文档再排下一跳新会话接续。
- 交接文档固定分节记录：已完成项、剩余未完成项、下一跳目标与投递时间，并对未完成项编号清账。
- 登录、验证等已打通流程写入交接文档固定章节，供后续 hop 复用而不重复摸索。
- 遇到工具通道被门禁拦截时先换形态（如改走 MCP 服务或 read/write 工具），而不是反复重试同一 CLI 形态。
- 会话交接先加载 `session-handoff` 流程，交接文档写成 9 节。
- 排下一跳 hop 排程时 DTSTART 必须取未来时刻；若因 DTSTART 滞后失败，改用更晚的未来时刻重试。
