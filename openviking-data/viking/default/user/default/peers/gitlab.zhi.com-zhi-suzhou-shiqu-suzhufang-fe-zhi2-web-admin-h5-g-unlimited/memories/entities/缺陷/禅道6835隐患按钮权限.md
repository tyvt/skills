# 禅道 bug 6835 隐患处置按钮安全权限
苏住房 zhi2-web-admin（Vue 2.7）中 electrocar 隐患模块列表/详情页操作按钮未接真实安全权限码的缺陷修复。

## 改动点
- index.vue 编辑/删除改用公共 mixin 的 editButton/deleteButton，并将删除的 permissionType 由 mixin 默认 remove 覆盖为 delete
- detail.vue 的“反馈进度”“处置完成”保留自定义按钮结构，补 :permission 真实权限码（保留 bug 6902 的并发吸底结构）
- 两个改动文件 ESLint 通过（exit 0）

## 权限链路
- 权限码格式 moduleName:businessName:permissionType，隐患模块为 electrocar:hazard:edit / delete / feedback / finish
- 权限判断走 store.getters.permissions，管理员账号 zsbase 持有 *:*:* 通配，因此权限码校验必通过

## 验证与证据
- 2026-11-24 实机验证（MCP agent-browser 通道）：列表页 buttons computed 与详情页按钮 Vue props 均绑定正确
