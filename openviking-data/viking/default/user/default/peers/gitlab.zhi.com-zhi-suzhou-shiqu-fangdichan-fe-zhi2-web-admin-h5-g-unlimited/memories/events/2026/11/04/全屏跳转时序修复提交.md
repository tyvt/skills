## 问题根因
[HomeStatsBar.vue](<zhi2-web-admin/src/views/home/components/HomeStatsBar.vue>) 点击「查看更多数据」发出 `more` 事件，父页 [index-new.vue](<zhi2-web-admin/src/views/home/index-new.vue>) 的 `handleStatsMore` 原逻辑是：**先 `requestFullscreen()`，等全屏 Promise 完成后才 `.then(nav)` 跳转** —— 所以首页先进入全屏、页面还停在原处，然后才切到市场监测大屏，造成「先全屏了才跳转」的观感。

## 修复
改为**先发起路由跳转 `$router.push('/market-monitor')`，紧接着在同一点击手势内请求全屏**。两点关键：
- 跳转在前，视觉上页面先切走；
- `requestFullscreen` 仍保留在同步的点击手势里（浏览器要求用户手势才能进全屏），只是不再等它的 Promise 才跳转，避免延迟。

改动仅 [index-new.vue](<zhi2-web-admin/src/views/home/index-new.vue>) 一个文件（+10 −1）。编译产物 `dist/assets/index-new-*.js` 已确认新顺序生效。
