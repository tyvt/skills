## 根因

上一轮我把内容栈改成了 `min-height:auto` 按内容自然撑高。但图表用 `height="100%"` + `ResizeObserver` 监听自适应——当整条高度链没有**确定高度**参照时，图表元素高度被内容反推着不断增大，`ResizeObserver` 又触发 resize，形成无限膨胀。

## 修复

[supplement.css](zhi2-web-admin/src/views/property/marketMonitor/assets/supplement.css#L13-L15)：把 `.mmd-content` 从 `min-height:auto` 改回**确定高度** `flex:1 1 0%; min-height:800px`，行 `flex:... 0%`：

- 视口够高（如 1920×1080）：内容栈撑满 main，各面板按比例分摊 —— 图表 `height:100%` 有确定参照，铺满不滚动。
- 视口偏矮（如 1920×953 / 1366×768）：内容栈被 `min-height:800px` 兜底，高于 main，由 `.mmd-main` 内部滚动消化 —— 图表仍拿到确定高度，不再膨胀。
