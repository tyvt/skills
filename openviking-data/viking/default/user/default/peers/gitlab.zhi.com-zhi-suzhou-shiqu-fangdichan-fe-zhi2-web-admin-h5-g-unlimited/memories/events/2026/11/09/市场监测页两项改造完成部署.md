## 改动内容

**1. logo 从配置读** — [MarketHeader.vue](<zhi2-web-admin/src/views/property/marketMonitor/components/MarketHeader.vue>)
- 左上角图标改为读 `platformConfig.sysLogo`（`mapState` + `resolveServerAssetUrl` 渲染 `<img>`），`w-9 h-9` 容器加 `overflow-hidden` 约束图片。
- 未配置或图片加载失败（`@error`）时回退原来的静态 house SVG；标题仍为静态文字「苏州市房地产市场数据分析平台」。
- `/market-monitor` 在路由白名单内、守卫不会拉平台配置，因此 `mounted` 里主动 `dispatch('app/getPlatformConfig')`（store 已做请求去重）。实测线上配置返回 `sysLogo=/zhi2/.../70383a8b-...png`，图片正常加载（48×48，无破图、无异常弹窗）。

**2. 返回首页后退回对内主页** — [MarketHeader.vue](<zhi2-web-admin/src/views/property/marketMonitor/components/MarketHeader.vue>) + [index.vue](<zhi2-web-admin/src/views/property/marketMonitor/index.vue>)
- 按钮由 `reset-overview`（重置全域）改为 emit `go-home`，tooltip 改「返回对内主页」。
- `goHome()`：先退出浏览器全屏，再判断来源——用 `beforeRouteEnter` 记录 `from.fullPath`（`from.matched` 有值＝从门户内页 SPA 进入），有来源时 `$router.go(-1)` 真正**后退**；直接打开/新标签打开时兜底 `$router.replace('/index')` 回对内主页（未登录态守卫转到 `UnifiedLogin?redirect=/index`）。
- 没有用 `history.state/length` 判断：实测直接打开时 `history.length=2` 且 `history.state` 非空，用它判断会误走后退而离开站点，故改用路由来源判断。
