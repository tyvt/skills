**现象**：门户 AI 智能问答超过一屏后再点热点，问题和答案会先贴底，问题被滚出可视区。

**原因**：`HomeAiChatDialog.vue` 在发出问题和答案到达时都执行 `scrollTop = scrollHeight`。列表超过一屏后，新问题被顶到可视区上方，用户先看到底部，看不到完整问题。

**改动**：消息行增加 `data-msg-id`。发出热点或输入后，先把该问题行对齐到列表顶部；答案出现后仍对齐这条问题，不再贴底。问题本来就完整可见时不滚动。

**提交**：`zhi2-web-admin` 分支 `develop/v2.6.2-portal`，`71853aca7`，已推送到 `origin`。父仓库的 gitlink 未更新，禅道仍是 active（客测未验收）。
