## 问题根因

`marketMonitor/assets/supplement.css` 里原来的样式，在 `@media (min-width:1024px) and (min-height:900px)` 条件下把容器和 `.mmd-main` 都设成了 `overflow:hidden`。你的屏幕 1920×953（高度刚过 900 就命中了这条），但各面板内部有硬性最小高度（`min-h-[210px]`、`min-h-[150px]` 等），内容总高超过了视口 → 被 `overflow:hidden` **裁切溢出，且无法滚动**。

## 修改方案

改为「头部固定 + 主内容区在视口内自成滚动容器」：屏幕高度充足时面板照常铺满、不滚动；高度不足时在主内容区内部纵向滚动，绝不溢出裁切。

- [supplement.css](zhi2-web-admin/src/views/property/marketMonitor/assets/supplement.css#L8-L16)：媒体查询由 `min-height:900px` 放宽为 `min-width:1024px`，`.mmd-main` 设为 `flex:1 1 0%; min-height:0; overflow-y:auto; overflow-x:hidden`；内容栈 `.mmd-content` 按内容自然撑高；给 `.mmd-row1 / .mmd-row2` 加最小高度兜底（460px / 300px），让矮屏时内容超出即触发内部滚动而非被压扁裁切。
- [index.vue](zhi2-web-admin/src/views/property/marketMonitor/index.vue#L20)：内层内容容器加上 `mmd-content` 类名挂接上述规则。
