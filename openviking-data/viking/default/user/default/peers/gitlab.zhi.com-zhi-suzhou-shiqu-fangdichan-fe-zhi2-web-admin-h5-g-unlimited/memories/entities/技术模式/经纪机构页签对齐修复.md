# 经纪机构页签对齐zs-tabs修复
2026-11-09 修复 BrokerPages.vue 中「交易记录/信用记录」tab 样式，使其对齐项目通用 zs-tabs 下划线风格。

## 根因
- `.portal-tabs` 使用 `align-self: stretch`，父级 `.portal-table-toolbar` 高 60px，将按钮从 `height:40px` 撑成 60px，`height` 失效。
- 激活下划线为按钮 `::after { bottom:0 }`，落到 60px 容器底边，离文字很远，视觉像「带下划线的文字」而非 tab。

## 修改
- `align-self: stretch` → `center`：按钮锁回 40px 并在 60px 工具栏内垂直居中，下划线贴回文字下方 2px。
- 未激活文字色 `#333` → `rgba(0,0,0,0.65)`，与 zs-tabs 一致。
- 其余指标（2px 下划线、激活色 #3f669c、500 字重、32px 间距、20px 字）本就对齐 zs-tabs，保持不变。

## 验证与归属
- 独立 worktree `zhi2-web-admin-wt-tabui`（分支 `fix/portal-broker-tab-ui-note`）生产构建 + nginx 私有站点 + Playwright 打桩实测：按钮高40px、上下留白各10px、下划线2px/#3f669c、间距32px、字重500，全部符合。
- 提交 `330a474df` 合并入子模块 `develop/v2.6.2-portal`（合并 `85c948dd5`），后由并行任务推送远程。
- 既有 e2e `public-portal-interactions.spec.ts` 该用例引用已不存在的 `.broker-index-link` 且依赖 dev mock 数据层，属过时用例，未改动。
