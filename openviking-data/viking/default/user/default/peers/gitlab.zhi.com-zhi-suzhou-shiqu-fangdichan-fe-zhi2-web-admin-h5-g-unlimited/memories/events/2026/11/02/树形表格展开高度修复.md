**问题根因**：`zs-table` 在固定行高（`tableTr`）场景下，按**根级 `data` 长度**算可视行数。部门管理是懒加载树，根级只有「苏州市」1 条，子行存放在 `lazyTreeNodeMap` 里不进 `data`；`tableData` 数组引用不变，所以 `data` watcher 不会重新计算高度，展开多少行都只能看到两行。

**改动**（仅 [zs-table.vue](<zhi2-web-admin/src/components/zs-table/zs-table.vue>)，+69/−2）：
- 新增 `countRenderedTreeRows()`：按 `treeData` + `lazyTreeNodeMap[key] || row.children` 递归统计，判定条件与 el-table 自身的 `wrappedRowRender` 对齐（父节点 `expanded` 才计子行）。这样懒加载行和多层展开都被正确计入。
- `getBaseTableHeight()` 在固定行高分支改用 `Math.min(tableTr, renderedRows)`：行数超出 `tableTr` 才出现滚动条，行数少时随内容收缩，不会出现大片空白。
- 监听 el-table 的 `@expand-change` → `treeRowsVersion` → `renderedTreeRows` 计算属性 → `handleLayoutChange()`，解决懒加载后对象引用不变导致的 watcher 不触发。
