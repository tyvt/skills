**问题**：开业信息公示「基本信息」弹窗左列各字段取值左缘参差（企业名称/注册地址/注册资本/租赁类别/开业信息登记编号 的值不在同一条竖线上），而右列（统一社会信用代码列）取值是整齐左对齐的。

**根因**：[RentalDetailDialog.vue](<zhi2-web-admin/src/views/home/publicPortal/components/RentalDetailDialog.vue>) 用 `em` 计算标签定宽。`em` 随字体度量，往往小于中文字形的实际宽度（中文≈1个16px字高），标签盒比文字窄，导致值左缘跟着每行标签实际宽度参差；而独占整行的字段（注册地址、开业信息登记编号）又只用自身标签宽度，更与双列字段对不齐。

**修复**：
- 标签宽度改用 **px** 计算（字数 × 16px，即中文字符实际字宽），保证标签盒不窄于文字；
- 独占整行的字段归入第一列，与该列双列字段共用同一「最长标签」定宽 —— 整列（含注册地址、开业信息登记编号、经营范围）取值共用同一条左缘，与第二列一致。
