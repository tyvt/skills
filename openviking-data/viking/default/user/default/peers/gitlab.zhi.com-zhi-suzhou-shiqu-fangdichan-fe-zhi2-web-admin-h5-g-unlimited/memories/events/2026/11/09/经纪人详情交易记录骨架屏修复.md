## 问题根因

「从业人员信息公示 → 经纪人详情」页的**交易记录**列表骨架屏一直转，是因为交易记录接口 `/portal/public/broker/records` 在开发环境**请求挂起**（后端不可达/无响应），而 `transactionLoading` 要等请求返回才会复位——请求不返回就一直转（axios 超时 100s 才报错）。同时还有两个连带缺陷：
- 早退分支（切到「信用记录」/分支机构、或取不到归属 ID）不复位 `transactionLoading`，会残留 loading 导致骨架屏常驻。
- 人员清单/详情返回的 `personnelId` 恒为占位 `"0"`（无效），交易记录按 `ownerId=0` 查询必然查不到数据。

## 修改（仅 1 个文件）

[BrokerPages.vue](zhi2-web-admin/src/views/home/publicPortal/pages/BrokerPages.vue) 的 `loadTransactionsIfNeeded`：
1. **骨架屏有界**：接口挂起时最多展示 3s 即揭开显示「暂无数据」，真实数据返回后再补填（`TRANSACTION_SKELETON_MAX_WAIT = 3000`）。
2. **加载态全路径复位**：所有早退分支统一 `transactionLoading = false`。
3. **归属 ID 兜底**：`personnelId` 为占位 `"0"`/空时退化为 `personnelRecordId`（真实主键），机构同理退化 `companyRecordId`。
