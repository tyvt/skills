## 根因
- 「室号」的值用了 `<strong>` 且被单独设成 **40px / 700 字重**的大字，和其他字段值（21px）完全不同，还带 `line-height:1.15`；
- 室号这一列的 label→值 `gap` 是 `0`，其他列是 `10px`，导致它的值比其他值高 10px、不齐；
- 普通值上还挂着 `margin-bottom:17px`，`align-items: end` 又让整排按底部对齐，进一步放大错位。

## 改动（[PropertyDetailDialog.vue](zhi2-web-admin/src/views/home/publicPortal/components/PropertyDetailDialog.vue)）
- 室号值字号/字重改为与其余值一致：`40px/700` → `21px/400`；
- `.portal-house-number` 的 `gap: 0` → `10px`，`align-items: center` → `flex-start`（与普通列一致）；
- 概览行 `align-items: end` → `start`，普通值去掉 `margin-bottom`，并统一 `line-height:1.15`，保证同一行标签、值基线一致。
