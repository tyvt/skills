**assistant [peer=gitlab.zhi.com-zhi-suzhou-shiqu-fangdichan-fe-zhi3-web-admin-h5-g-unlimited]**: ## 禅道 Bug #6099 处理结果

**现象**：预售资金监管 → **银行名单**，按「银行名称」筛选后点「查看」进详情，返回后列表变 **暂无数据**，筛选条件仍在。

**根因**（与 [common-errors.md](<docs/frontend/common-errors.md>) **E-030** 一致）：

1. `AppMain` 无 keep-alive，从详情返回会**重建**列表页。
2. `table.js` 的 `init()` 会立刻 `getList()`，而 `CBYH_BANK_NAME` 字典是异步的。
3. `listMixins` 缓存的 `bankName` 实际是下拉的 **dictValue（银行代码）**；字典未就绪时 `getQueryParams()` 转不成 **dictLabel**，接口按错误条件查，返回空；`getList` 开头还会清空 `tableData`。

**修复**（子模块 `develop/v3.0.0`）：

| [superviseBank/index.vue](<zhi2-web-admin/src/views/supervision/bank/superviseBank/index.vue>) | 覆写 `init()`：字典加载完再 `getList()`；`resolveBankNameForQuery`；筛选项 `valueKey: dictValue` |
| [cbyh/index.vue](<zhi2-web-admin/src/views/supervision/bank/cbyh/index.vue>) | 同上（银行管理列表同类问题一并修） |
