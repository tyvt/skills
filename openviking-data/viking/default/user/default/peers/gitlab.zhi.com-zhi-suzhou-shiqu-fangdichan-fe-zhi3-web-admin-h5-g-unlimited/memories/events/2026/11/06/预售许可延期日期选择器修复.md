**assistant [peer=gitlab.zhi.com-zhi-suzhou-shiqu-fangdichan-fe-zhi3-web-admin-h5-g-unlimited]**: ## 禅道 #6254 处理结果

**现象**：预售许可延期申请新增页，「变更后有效期止」点开后面板停在**当前月**（如 2026-11），而「原发证有效期止」为 **2028-11-05**，`disabledDate` 要求必须**晚于**原有效期止，导致首开月份**整月置灰**，看起来像不能选。

**根因**：[`detail.vue`](<zhi2-web-admin/src/views/presale/permitExtend/detail.vue>) 只配了 `disabledDate`，未给 `zs-date-picker` 设 `default-value`；Element UI 默认展示「今天」所在月。选证回填用了 `formatDateOnly`，详情 `normalizeDetail` 对 `origValidTo` 未统一截取，存在不一致风险。

**修复**（已合入 `develop/v3.0.0` 并推送）：

| 文件 | 改动 |
| --- | --- |
| [`permitExtendConstants.js`](<zhi2-web-admin/src/views/presale/permitExtend/permitExtendConstants.js>) | 新增 `getExtendValidToDefaultValue`（原有效期止 **+1 天** 所在月作为面板默认月） |
| [`detail.vue`](<zhi2-web-admin/src/views/presale/permitExtend/detail.vue>) | `:default-value="extendValidToDefaultValue"`；`normalizeDetail` 对 `origValidTo` / `extendValidTo` 做 `formatDateOnly` |
| [`common-errors.md`](<docs/frontend/common-errors.md>) | 登记 **E-039** |
