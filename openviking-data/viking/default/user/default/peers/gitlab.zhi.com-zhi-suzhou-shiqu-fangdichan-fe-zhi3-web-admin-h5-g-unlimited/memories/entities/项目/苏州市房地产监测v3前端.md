# 苏州市房地产监测V3前端
苏州市房地产监测V3 的前端代码仓库，以 git 子模块 zhi2-web-admin 形式存在于父仓库中，主分支 develop/v3.0.0。

## 代码结构
- 价格备案模块位于 src/views/commercialHousingSales/priceFiling/recordPriceMngSuzhou/
- 流程记录面板由 showApproval 组件渲染，顶部节点条为 showApprovalHeader.vue（价格备案本地组件，非共享 ApprovalProcess/components/ApprovalHeader.vue）
- 变更详情 changeDetail.vue 复用 showApproval，共用同一节点条

## 构建与部署
- 构建脚本将产物写至父仓库根 dist/，本地 nginx 监听 8098 以该 dist/ 为根提供服务
- 子模块拥有独立 node_modules（vite 8.3.5），构建需在子模块目录内进行

## 协作风险
- 多个并行缺陷任务共用同一 develop/v3.0.0 分支与同一父仓库根 dist/ 输出，并行构建会互相覆盖产物
- 子模块 .git 标记文件偶发丢失会导致 git 误判为父仓库普通目录，需重建标记并 git restore 恢复缺失文件
