## 结论：不是代码 bug，是 9002 上跑的是旧构建

**根因（已定位并验证）**

「返回首页」按钮来自 [Navbar.vue](<zhi2-web-admin/src/layout/components/Navbar.vue>)，当前源码 HEAD（`ad2319ce4`）的实现是**正确的**：

```
goHome() {
  this.$post('/system/config/getByKey', { configKey: 'sys.portal.index.url' })
    .then(res => { url = res.data; isHttpUrl(url) ? redirectToPortal(url) : pushDefaultIndex() })
    .catch(() => pushDefaultIndex())
}
```

即：读参数配置 `sys.portal.index.url`，拿到 http 地址就整页跳门户首页；读不到才兜底回本系统首页（=/todo 待办）。
