# 详情页内容溢出滚动修复模式
园区房产 zhi3-web-admin-h5-g 监管账户等详情页在卡片过多、内容超出视口时被裁切，需改为内容区自身滚动。

## 问题根因
- 详情页结构为 `.detail-container`（overflow:hidden）内含 `.detail-from-container`
- 全局 `index.scss` 整页滚动触发条件 `&:has(> .detail-from-container):has(> .collapse-container, > .sub-container)` 要求 `.collapse-container` 为直接子级；Headline 卡片位于 zs-form 内（即 `.detail-from-container` 内部），不匹配，故不触发整页滚动，内容超出即被裁切
- 仅表单分支让 `.detail-from-container` 收缩（flex:0 1 auto），但 `.detail-container` 仍 overflow:hidden，超出部分被裁掉
- 第一版把 `overflow-y:auto` 加在 `.detail-container` 上无效：因 `.detail-from-container` 为 flex:0 1 auto 会收缩到容器内，外层 scrollHeight 恒等于 clientHeight（实测 795=795），永不溢出，auto 不触发；滚动必须由 `.detail-from-container` 自身承担

## 修复方案
- 按 AGENTS.md §10，不修改全局 `index.scss`，改用页面级 `scoped` 样式
- 让 `.detail-from-container` 在内容溢出时 `overflow-y:auto` 自身滚动；内容未溢出时无滚动条、保持撑满
- 监管协议页因 `AgreementDetailsTable` 已命中整页滚动分支，仅补充滚动条槽位，不重复加表单区滚动

## 应用与验证
- 四个详情页（regulatoryAccountNew、mainAccount、regulatorOrg、superviseAgreementNew）均加 scoped 样式使 `.detail-from-container` 溢出时 `overflow-y:auto`，随提交 9ea426a11 落地
- 监管协议页因底部 `AgreementDetailsTable` 已命中整页滚动分支，仅补 `scrollbar-gutter`，不重复接管
- 新增 Playwright 用例 prefund-detail-scroll.spec.js，合并后主线 19/19 全部通过
- 已通过 `--no-ff` 合并至 develop/v3.0.0（合并提交 588f0c434），父仓库 gitlink 同步至 588f0c434（提交 a2071cc）
