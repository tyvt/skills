# AppendixPackageSection
预售方案页使用的要件上传组件，现售修复后亦采用此组件实现竖向宫格布局。
## 功能
- 提供 requirement-grid 宫格展示必填要件。
- 暴露 validateRequired() 方法返回布尔并自行告警。
## 用法
- 接收 busCode、busId、detail={projectId,planId} 等属性。
- 现售与预售均使用相同 busCode 'ysfawh'。
