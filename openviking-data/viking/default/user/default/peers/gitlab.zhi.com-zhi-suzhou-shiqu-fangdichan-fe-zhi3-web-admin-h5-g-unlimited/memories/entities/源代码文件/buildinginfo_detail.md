# buildinginfo_detail
房产管理系统楼幢信息详情页，与 building/building/detail.vue 为不同页面。

## Description
- 路径：zhi2-web-admin/src/views/projectManagement/buildinginfo/detail.vue
- 楼幢维护模块下的楼幢信息详情页

## 界面特征
- 左侧菜单：「楼幢维护」「项目备案申请」
- 顶部页签：「楼幢维护」「测绘成果变更」「户室查询」
- 同步按钮文案为「同步」，第 193 行 icon="el-icon-refresh"（刷新图标）

## Relations
- 与 building/building/detail.vue 易混淆：后者同步按钮文案为「同步房屋信息」
- 某 bug 截图经比对确认来自本页面，而非 building/building/detail.vue
