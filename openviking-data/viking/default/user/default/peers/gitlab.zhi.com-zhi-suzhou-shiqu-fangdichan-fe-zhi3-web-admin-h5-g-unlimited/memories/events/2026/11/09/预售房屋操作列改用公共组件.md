- **页面**：预售许可申请 → 预售房屋列表 → 操作列
- **依据**：项目标准操作列公共组件 `zs-operate-column`（`ListTemplate.js` / `DetailSubTableTemplate.js` 均用 `<zs-operate-column ... :buttons="buttons" />`，由 `table.js` 的 `buttons` 契约驱动；全站 370+ 处使用）

## 问题
原 [PresaleHouseTable.vue](<zhi2-web-admin/src/views/presale/permit/components/PresaleHouseTable.vue>) 是**自绘操作列**（手写 `<zs-table-column label="操作">` + 内联 `<zs-button>删除` 直接 `$emit('remove')`），未走公共组件的列宽/样式/权限/多按钮折叠等能力，与全站其余列表不一致——正是你截图圈出的部分。

## 改动
- 模板：`<zs-table-column v-if="operable" label="操作">…` → `<zs-operate-column v-if="operable" :buttons="buttons" />`
- 脚本：新增 `buttons` computed，返回单条「删除」按钮配置，保留原 `data-testid="presale-permit-house-remove-btn"` 与 `$emit('remove', row)` 语义；`zs-operate-column` 对「删除」统一补 `danger + plain`。`operable` 显隐逻辑、父级 `@remove` 链路不变。
