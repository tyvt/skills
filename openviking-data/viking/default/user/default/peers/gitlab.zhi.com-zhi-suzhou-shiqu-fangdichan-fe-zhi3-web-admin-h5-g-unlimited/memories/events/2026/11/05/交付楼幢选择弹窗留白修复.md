**问题**：交付使用备案申请 → 点「选择楼幢」弹出的「选择交付楼幢」弹窗，表格右侧大段空白、末行与底部按钮之间留白过多（截图附件 fileID 21672）。

**根因**（自研 `zs-dialog` 弹窗的两处缺陷）：
1. **右侧留白**：弹窗 `width="1300px"` 被拉宽，但内部表格未启用 el-table 原生 `fit`（`zs-table` 默认 `fit:false`，弹窗首开过渡等场景剩余宽度分配易遗漏）→ 表格不撑满。
2. **底部留白**：表格 `auto-height` 且无分页兄弟节点，触发 `.zs-table-container--bottom-spacing` 的 24px margin，叠加 body 30px padding。

同类「选楼幢」弹窗（`PresaleSelectBuildingDialog`、`CashsaleSelectBuildingDialog`）已统一改用公共组件 `zs-select-dialog` + `building-table-mode`（`auto-height` + `fit:true` + 紧凑内边距），本弹窗遗漏。

**修复**（采纳你的要求「使用公共组件、公共写法」）：[DeliverySelectBuildingDialog.vue](<zhi2-web-admin/src/views/supervision/projectDelivery/components/DeliverySelectBuildingDialog.vue>) 整体改用公共组件 `<zs-select-dialog building-table-mode>`，列走 `#columns` slot、底部走 `#footer` slot，数据 `@opened` 内经 `beginDialogAsyncLoad` 拉取；**对外 `confirm` 事件契约、`dialogTestId`/`confirmTestId`、行字段归一化全部保留**，`DeliveryScopeSection` 无需改动。
