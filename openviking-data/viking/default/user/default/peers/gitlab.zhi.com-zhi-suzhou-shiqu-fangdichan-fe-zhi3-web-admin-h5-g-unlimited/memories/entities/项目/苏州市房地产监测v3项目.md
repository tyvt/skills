# 苏州市房地产监测V3
本地前端仓库，含 E2E 基础设施，用于还原商品房平台管理端页面。

## 位置与构建
- 工作目录：D:\repository\苏州市房地产监测V3
- 含 Playwright e2e 结构（e2e/ 目录、fixtures/auth-helpers.js、.env.e2e.example）
- nginx 部署 dist 于 8098 端口，但后端 API 代理 502 不可用

## E2E 约定
- 默认本地 E2E 需 npm run dev(8081)，但项目禁止启动 dev server，须连真实环境 9002
- 登录辅助：loginWithRealAccount（管理端）、loginAsDeveloperCompanyOnce（企业端）
- 交付物：D:\out\real_html\ 下 4 个静态 HTML 还原稿，D:\out\real\ 下真实截图
