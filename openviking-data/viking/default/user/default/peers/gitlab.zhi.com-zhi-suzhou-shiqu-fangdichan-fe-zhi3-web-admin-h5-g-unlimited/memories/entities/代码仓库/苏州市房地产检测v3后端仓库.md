# 苏州市房地产检测V3后端仓库
苏州市房地产监测V3的后端源码仓库，独立于前端子模块zhi2-web-admin。

## 描述
- 多模块 Maven 项目，承载现售备案、预售许可等业务逻辑
- 与前端子模块 zhi2-web-admin 分属不同仓库，修复缺陷常需改此仓库

## 模块
- zhi3-presale：现售备案模块，含 SaleRecordServiceImpl.saveCashsale
- zhi3-presale 同时含预售许可 savePresale（校验顺序模式正确，可作现售修复参照）

## 关联
- 前端子模块：zhi2_web_admin
- 相关缺陷：禅道6306（现售备案保存校验顺序缺陷，根因在后端）
