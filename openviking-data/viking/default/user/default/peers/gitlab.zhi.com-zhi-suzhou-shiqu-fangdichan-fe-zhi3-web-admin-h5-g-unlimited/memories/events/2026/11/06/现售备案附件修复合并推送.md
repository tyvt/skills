## 禅道 #6306 结论

**现象**：现售备案申请里营业执照已自动带出，保存仍提示「营业执照」等必填。

**根因**：`AnnexUpload.getList()` 在**已有进行中的拉取**且**本次签名与进行中的不一致**（例如 `busId`/上下文刚变）时，原先直接 `return` 旧的 `appendixFetchPromise`。`AppendixPackageSection.reload()` 里 `getList().then(() => applyPrefillToUpload())` 会在**旧请求结束**就执行 prefill，而**新签名对应的列表尚未拉完**，`fileList` 仍是旧状态，导致带出未写入校验用的列表。

**修复**：
1. **[zhi2-web-admin/src/components/AnnexUpload/index.vue](<zhi2-web-admin/src/components/AnnexUpload/index.vue>)** `getList()`：签名不一致时 `appendixFetchPendingSignature = signature` 且 `return this.appendixFetchPromise.finally(() => this.getList())`，保证最终等到**当前签名**的拉取完成。
2. **[zhi2-web-admin/src/components/AppendixPackageSection/index.vue](<zhi2-web-admin/src/components/AppendixPackageSection/index.vue>)** `validateRequired()`：有 `prefillContext` 时先调用 `applyPrefillToUpload()`（幂等），降低「保存瞬间列表未对齐」的误报。
