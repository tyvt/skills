# zhi2_web_admin
房地产前端管理后台 H5 子模块，使用 Vue 开发。

## Description
- 苏州房产前端管理后台子模块，分支为 develop/v3.0.0
- 构建命令为 npm run build，产物输出到父仓库 dist 目录

## Relations
- 作为子模块被父仓库引用，父仓库通过 gitlink 指向其提交
- 父仓库 dist 由 nginx 8098 提供静态服务
- 缺陷在禅道（zentao-biz.zhi.com）跟踪，例如 bug 6096
