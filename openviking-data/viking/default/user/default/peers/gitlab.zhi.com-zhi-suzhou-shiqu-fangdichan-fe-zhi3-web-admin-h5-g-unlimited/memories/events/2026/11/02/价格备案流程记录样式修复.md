## 根因

价格备案申请详情右侧的「流程记录」是**独立实现**的 `showApproval.vue` + `showApprovalCard.vue`，没有使用系统统一的 `components/ApprovalProcess` 组件。因此，它与其它业务模块的样式不一致：

| # | 差异 |
|---|---|
| 1 | **状态文案映射错误**：旧 `statusShow` 把 `0` 当作通过、`1` 当作退回，取值使用 `item.optionResult`；统一组件使用 `item.comment.type` |
| 2 | **没有状态颜色**：无法区分通过和驳回 |
| 3 | **缺少「操作人员」行**：统一组件显示 `部门-操作员`，本页只显示「意见说明」 |
| 4 | **折叠面板边框未清除**、header 样式位置不一致、状态列 `min-width: 50px` 偏窄导致换行 |
| 5 | 节点光晕使用 `rgba(var(--primary-color-rgb), 0.4)`，与统一组件的 `--primary-color-light-6` 不一致 |

## 修复

只改动这两个页面级组件，**不改动公共组件**（因此不影响其它模块）：

- `statusMap` + `colorMap` 改为统一映射（1 通过、2 退回、3 驳回、4 委派、5 转办、6 终止、9 驳回至起点），新增 green、yellow、red、black 样式类
- `showApprovalCard` 新增 `deptName`/`taskName` props 和「操作人员」行
- 清除 el-collapse 边框、把 header 样式外提、状态列 `min-width` 改为 80px、光晕改用 `--primary-color-light-6`
