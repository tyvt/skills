## 结论（禅道 #6324）

| 项 | 内容 |
|----|------|
| **现象** | 「预售转现售申请」详情里，「现售楼幢列表」页签下两列仍为 **「预售套数」「预售总面积(㎡)」**，与现售场景不符。 |
| **根因** | 现售详情复用 [`PresaleBuildingTable.vue`](zhi2-web-admin/src/views/presale/permit/components/PresaleBuildingTable.vue) 时，这两列的 `label` **写死**为预售文案；[`CashsaleDetail.vue`](zhi2-web-admin/src/views/presale/cashsale/components/CashsaleDetail.vue) 只改了页签名「现售楼幢列表 / 现售房屋列表」，**未覆盖列标题**。 |
| **修复** | ① `PresaleBuildingTable` 增加可选属性 `houseCountColumnLabel`、`houseAreaColumnLabel`（默认仍为「预售套数」「预售总面积(㎡)」，**预售许可不变**）。② [`PresaleBuildingSection.vue`](zhi2-web-admin/src/views/presale/permit/components/PresaleBuildingSection.vue) 向子表透传。③ `CashsaleDetail` 传入 **「现售套数」「现售总面积(㎡)」**。 |
| **台账** | 已记 [docs/frontend/common-errors.md](docs/frontend/common-errors.md) **E-042**。 |
