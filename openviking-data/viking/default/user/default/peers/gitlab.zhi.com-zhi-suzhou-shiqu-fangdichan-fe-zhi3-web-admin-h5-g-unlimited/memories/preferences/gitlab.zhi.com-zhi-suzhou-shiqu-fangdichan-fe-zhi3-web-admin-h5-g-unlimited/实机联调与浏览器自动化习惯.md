- 验证前端上传/预览类缺陷时坚持在真实浏览器实机复现（进页面、传真实文件、抓网络请求），不只读代码下结论。
- 偏好用 agent-browser 的 fill、click 等原生命令以正确触发 Vue 的 v-model，而非直接设置 input 值的原生 setter。
- 等待页面跳转时使用 agent-browser 原生 wait，而不是 PowerShell 的 Start-Sleep。
- 读算术型验证码时先截图并裁剪放大、必要时交给视觉模型识别，然后在同一页面生命周期内立即填入并提交。
- 点击前先关闭“操作按钮组”等引导浮层，避免点击被遮挡导致路由不生效。
- 主会话 pwsh 被 verify-loop 拦截时，改用 context-mode.ctx_execute 执行浏览器操作。
- 处理验证码时只刷新页面走原生流程，不手动请求 `/code`；对视觉模型给出的答案自己放大读图复核后再提交。
