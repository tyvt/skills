### 根因
价格备案申请的项目选择弹窗里，「项目所在地」列配置为 `prop="regionName"`，但 `/building/project/page` 返回的项目实体行政区划字段名是 **`region`（行政区划编码）**，根本没有 `regionName` —— 取值为 `undefined`，所以整列空白。截图里箭头指的正是这个空列。

已用三处独立证据交叉确认：项目列表页写的是 `prop: 'region'`、项目详情页写的是 `prop="region"`、楼盘表页显式做了 `regionName: data.region || ...` 的兜底映射。

### 改动
`prop="regionName"` → `prop="region"` + `formatter="fullRegionFormatter"`，按编码解析为区级行政区域名称，与项目列表页行政区划口径一致。共用到同一弹窗配置的 4 个页面一起修正：

| --- | --- |
| [detail.vue](<zhi2-web-admin/src/views/commercialHousingSales/priceFiling/recordPriceMngSuzhou/detail.vue>) | 价格备案申请（bug 截图页） |
| [changeDetail.vue](<zhi2-web-admin/src/views/commercialHousingSales/priceFiling/recordPriceMngSuzhou/changeDetail.vue>) | 价格备案申请变更 |
| [detail.vue](<zhi2-web-admin/src/views/commercialHousingSales/presale/template/detail.vue>) | 合同模板 |
| [detail.vue](<zhi2-web-admin/src/views/commercialHousingSales/presale/contractRevoke/detail.vue>) | 合同撤销 |

`zs-table-column` 的 `getCell` 同时承担单元格渲染和列宽测量，改 `prop` 两处都覆盖到了。
