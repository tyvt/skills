# 苏州市房地产监测V3
苏州房地产市场监测系统的第三版父级仓库，包含前端子模块与 nginx 部署。
## 描述
- 父仓库位于 D:\repository\苏州市房地产监测V3。
- 包含子模块 zhi2-web-admin，整体通过 nginx 8098 端口提供服务。
## 部署
- nginx 站点根目录指向父仓库 dist。
- 构建产物 version.json 记录 gitBranch 与构建时间。
- 本地调试时前端 dist 构建时间为 2026-11-24 10:24，后端 framework jar 于同日 11:31 启动。
## 服务与接口
- 本地 gateway 转发到注册在 Nacos 的 framework 实例 192.168.1.129:9211（本机）。
- 文件服务：上传 POST /file/file/upload；旧预览 GET /file/file/preview；新预览 GET /file/file/previewByTicket（需后端签发 previewTicket）。
- 登录页为算术型验证码（如 9+9=?），验证码图片由前端本地以 base64 data URL 渲染，无独立网络请求。
