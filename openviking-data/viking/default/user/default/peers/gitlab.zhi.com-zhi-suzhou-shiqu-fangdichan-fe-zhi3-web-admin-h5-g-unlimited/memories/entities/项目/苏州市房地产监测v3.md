# 苏州市房地产监测V3
苏州房地产市场监测系统的第三版父级仓库，包含前端子模块与 nginx 部署。
## 描述
- 父仓库位于 D:\repository\苏州市房地产监测V3。
- 包含子模块 zhi2-web-admin，整体通过 nginx 8098 端口提供服务。
## 部署

- 构建产物 version.json 记录 gitBranch 与构建时间。
