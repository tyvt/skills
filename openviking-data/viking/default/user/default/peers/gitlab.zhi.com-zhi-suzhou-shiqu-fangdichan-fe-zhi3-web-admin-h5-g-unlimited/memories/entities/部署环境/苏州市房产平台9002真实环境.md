# 苏州市房地产综合服务平台（管理端真实环境）
真实可用部署环境，用于 E2E 抓取与页面还原。

## 访问信息
- URL：58.210.252.230:9002（苏州市房地产综合服务平台，管理端/管理员视角）
- 管理员账号：zsbase / ZS001Aa!（loginType=account）
- 本地 localhost:8098 虽部署 dist 但后端 API 代理 502 不可用，真实环境须用 9002

## 登录机制
- 登录页含算术图片验证码，/api/v3.0/code 返回 base64 JPEG，需 OCR 识别答案（如 5+4=9）
- captchaOnOff 为 true，uuid 随验证码返回，提交需验证码+uuid
- 登录按钮 .login-button 被底部浮层遮挡，普通 click 失效，须用 el.click() 原生 DOM 点击提交

## 关键页面路由
- P1 预售合同签订：/#/xsht/contractMainInfo/contractMainInfo/pre
- P2 项目备案申请详情：/#/projectmanage/customerProject/{id}?formMode=view
- P3 楼盘表应用：/projectmanage/buildingTable?id={projectId}
- P4 楼幢维护：/projectmanage/building/buildinginfo/{buildingId}?formMode=edit（正确路径含 /building/）
