# bug#6084 监管账户开户弹窗分页遮挡
房地产监管后台模块中监管账户开户页选择开户网点弹窗的分页条被滚动遮挡缺陷。

## Description
- 禅道 bug#6084，2026-11-03 上报。
- 监管账户开户页「选择开户网点」弹窗（BranchOneDialog.vue）分页「共85条记录」与翻页未在一屏显示，需滚动才能看到。
- 弹窗经路由 /spfzjjg/zjjg/ACCOUNT_OPEN/account/add 进入 supervision/agreement/account/detail.vue，由 openUnionBankBranchSelect 打开。

## RootCause
- Playwright 登录测试站点 58.210.252.230:9002（zsbase/ZS001Aa!，算术验证码）复现确认。
- 弹窗 body scrollHeight 741 > clientHeight 591，分页条被推到滚动区下方不可见。
- 接口返回 total=85、rows=10，分页元素已渲染只是被滚动遮挡，非 total=0。

## Fix
- worktree wt-bug6084 中，BranchOneDialog.vue 新增 tableScroll 布尔属性（默认 false，避免影响 7+ 共用页面）并透传至 zs-select-dialog 的 table-scroll。
- unionBankBranch.js 转发 options.tableScroll。
- agreement/account/detail.vue 与 regulatoryAccountNew/detail.vue 的 showVisionOfBank 调用传入 tableScroll:true。
- table-scroll 为代码库既有方案（ExtractDialog 已用）：弹窗占满视口高度、表格内部滚动、分页固定底部可见，满足「一屏显示」诉求。
- 并行任务 wt-bug6085 不触碰。

## Relations
- 属于 zhi3-web-admin-h5-g 的房地产监管模块（见 zhi3_regulatory_module）。
