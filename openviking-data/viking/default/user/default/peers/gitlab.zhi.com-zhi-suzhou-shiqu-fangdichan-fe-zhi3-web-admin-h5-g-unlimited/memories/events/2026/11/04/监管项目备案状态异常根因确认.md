## 根因
截图页面（门户「预售资金银行监管 → 监管项目备案」）业务状态列渲染成数字 `0`，是因为**业务状态字典类型写成了大写 `BIZ_STATE`**，而公共字典是小写 `biz_state`（见 [bizState.js](<zhi2-web-admin/src/utils/bizState.js>)、[common.js](<zhi2-web-admin/src/store/modules/common.js>) 的 `saveBizStateOption`）。

客测环境 `58.210.252.230:9002` 实测 `/system/dictData/listByType`：

- `BIZ_STATE` → 仅 1 条：`4 银行开户中`
- `biz_state` → 完整 5 条：`0 待提交 / 1 审核中 / 2 已备案 / 3 作废 / 4 银行开户中`

查库确认 `COMMON_FRAMEWORK.SYS_DICT_DATA` 两个类型并存，`BIZ_STATE` 的 0/1/2/3 已被删除。列字典取不到值 → `dict-tag` 回退渲染原始码值 `0`（即截图中的蓝色数字角标）。

## 修复
`src/views/supervision/**` 共 42 个文件，把 `getDicts('BIZ_STATE')` 与 `dictUrl: 'BIZ_STATE'` 统一改为 `biz_state`，覆盖 agreement（jgxm/xy/xy_version/version/end/account/allocation）、account、deposit、progress、riskmanage、unblock 的列表页与详情页。`projectDelivery` 本就走全局 `biz_state` 别名映射，未动。参照同项目先例：价格备案 commit `c9c9e2a74`。
