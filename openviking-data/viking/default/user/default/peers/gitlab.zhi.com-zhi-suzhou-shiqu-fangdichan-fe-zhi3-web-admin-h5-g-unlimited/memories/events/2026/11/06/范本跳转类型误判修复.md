### 根因

苏州 2016 版合同页在 [`contract/index.vue`](<zhi2-web-admin/src/views/contract/index.vue>) 里用「菜单标题 / 路径是否含 `/cash`」推断 `contractType`。**从合同范本「范本内容」跳入**时，菜单 `meta.title` 往往不含「预售/现售」，容易**误判为现售**，页面标题显示「现售合同签订」。

### 改动

1. **范本跳转显式带合同类型**（与字典 `wq_presale_contractType` 一致：`0` 预售、`1` 现售）：

```415:446:zhi2-web-admin/src/views/commercialHousingSales/presale/template/detail.vue
    gotoContractTemplate (contractNo) {
      if (!this.form.contractType) {
        this.msgError('请选择合同版本')
        return
      }
      this.$store.commit('contract/UPDATE_EDITABLE', this.form.bizState)
      this.$store.commit('contract/UPDATE_ROUTE_PATH', this.$route.name)

      const typeHint = this.form.contractType == '1' ? 'cash' : 'pre'
      const target = buildNavigationByFilePath('contract/index', {
        pathHint: typeHint,
        preferDetail: true,
        routeId: this.getId(),
        query: {
          formMode: this.form.bizState == '0' ? 'edit' : 'view',
          projectCode: this.form.projectCode,
          contractNo: contractNo || this.form.contractNo,
          from: 'template',
          contractType: String(this.form.contractType)
        }
      })

      if (!target) {
        this.msgError('没有授权相关菜单，请联系管理员')
        return
      }

      this.$router.push(target).catch(() => {})
    },
```

2. **从范本进入时优先读 `query.contractType`**：

```365:382:zhi2-web-admin/src/views/contract/index.vue
    contractType () {
      // 苏州 2016 版范本：预售/现售共用同一套章节，按合同类型区分（预售=0，现售=1）
      if (this.isSuzhou2016) {
        // 从合同范本「范本内容」进入时，菜单 meta 可能不含预售/现售字样，
        // 以跳转方显式传入的 query 为准（与范本页字典 wq_presale_contractType 一致）
        if (this.comeFromTemplate) {
          const q = this.$route.query?.contractType
          if (q === '0' || q === '1') return String(q)
        }
        // 菜单标题是最可靠的用户可见标识（预售合同签订/现售合同签订）；
        // 路由路径仅作兜底（现售菜单路径含 /cash）
        const title = String(this.$route.meta?.title || '')
        if (title.includes('现售')) return '1'
        if (title.includes('预售')) return '0'
        return this.$route.path.includes('/cash') ? '1' : '0'
      }
      return this.$route.path.includes('/pre/') ? '0' : '1'
    },
```
