## 本轮修复结果

**页面**：小区管理 → **物业管理区域变更详情**（`property/complexChange/detail.vue`，新增态 `formMode=add&complexId=...`），保存报 **"行政区划不能为空"**。

**根因**：该页面表单只有 `region`（单一区划编码，截图里表单 payload 就是 `region: "320214"`），但后端保存校验要的是 `regionCode` + `regionName`，前端从未组装这两个字段 → 缺 `regionCode`/`regionName`。且如用户所说，部分原始数据连 `regionCode` 都没有。

**修复（按用户明确方案实现）**：
1. 表单增加 `regionCode` / `regionName` 字段；
2. 新增 `syncRegionCodeName()`：
   - `regionCode` 缺失时先用 `region`（页面区划编码）兜底；
   - 若 `region`/`regionCode` 都缺、但有 `complexId`（或路由 `complexId`），则查 `/property/complex/{complexId}` 取返回的 `region` 字段兜底；
   - `regionName` 用全局行政区划 `allAreas` 经 `getFullRegionNameByRegionCode` 按编码反查补齐；
3. 在 `created`（新增，从 complexId 加载）、`detailCallback`（详情/编辑加载）、`onCascaderChange`（区域变化）三处均调用同步；
4. `getForm()` 本就 spread `this.form`，故新字段自动随提交带上。
