### 问题根因
用户管理页 [index.vue](zhi2-web-admin/src/views/system/user/index.vue) 是自定义的「左部门树 + 右用户列表」两栏布局，右侧列靠 `.main-box-right { height: 100% }` 撑开，**依赖 `.list-container` 有确定高度**。

但提交 `2801389aa`（"列表外框高度随内容收缩"）把全局 `.list-container` 的固定高度 `calc(100vh - 120px)` 去掉了，只对 `:has(> .region-tree-layout)` 的页面保留。本页不是标准区域树布局，于是容器高度塌陷 → 右侧列 `height:100%` 解析为约 0 → 搜索表单、操作按钮、用户表格整体被压扁到看不见（截图里右侧全白、左侧树正常）。

### 修复
在本页 `<style scoped>` 里补回容器高度（最小、精准改动，等价于恢复改动前状态）：
```css
.list-container { height: calc(100vh - 120px); overflow: hidden; }
```
