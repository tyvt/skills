## 本次修复结果

**新问题**：上个"行政区划不能为空"已解决后，保存又报 **"小区位置不能为空"** —— 后端 `PubManagementOrgSaveDto` 对 `projectAddr`（小区位置）与 `regionName`（行政区划）、`projectName`（小区名称）都是 `@NotBlank`。海悦花园B区这条"同步数据"记录的 `projectAddr` 为空，前端编辑页也不展示该字段，故提交体缺 `projectAddr`。

**修复思路**（更彻底，不再逐字段打补丁）：三个编辑页 `getDetail` 加载详情后统一调用 `fillProjectInfo()`：
- 先按记录自带 `regionCode` 同步推出 `regionName`；
- 若 `projectAddr / regionName / subdistrict / community` 任一缺失，则用 `projectId` 拉 `/property/complex/{projectId}`（与项目内 `pubParkingRate` 编辑页同一成熟做法），按 `row.address / row.region / row.subdistrict / row.community` **只补缺失项、不覆盖已有值**。

这样一次覆盖后端所有必填的小区相关字段，避免再出现"这个空了→再那个空了"。
