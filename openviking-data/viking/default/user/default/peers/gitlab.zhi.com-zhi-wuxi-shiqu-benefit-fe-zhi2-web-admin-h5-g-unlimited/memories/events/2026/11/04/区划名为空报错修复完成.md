## 问题根因

"行政区划不能为空" 是**后端校验**报的错（"异常提示"弹窗，而非前端表单内联红字）：

- 后端 `PubManagementOrgSaveDto` / `PubRegulatoryAccountChangeSaveDto` / `PubRegulatoryAccountSaveDto` 对 `regionName` 均有 `@NotBlank(message = "行政区划不能为空")`。
- 三个编辑页（管理主体、监管账户/开户申请、开户变更）的表单里**根本没有渲染行政区划字段**，编辑加载详情时也从不回填 `regionName`。当记录本身（如截图里"同步数据"的记录）`region_name` 为空时，提交体里 `regionName` 缺省 → 后端 `@NotBlank` 直接拒绝。这与同事说的"regionName 前端没传、后端校验必填"一致。

## 修复方案（编辑详情时自动回填 regionName）

三个页面 `getDetail` 加载详情后统一调用 `fillRegionName()`：
1. 已有 `regionName` → 保留；
2. 否则用记录的 `regionCode` 经 `getFullRegionNameByRegionCode(allAreas, code)` 拼全名（同步，覆盖绝大多数记录）；
3. 仍为空且存在 `projectId` → 拉 `/property/complex/{projectId}` 用其 `region` 补齐。

这样提交时 `regionName` 稳定带上，用户无需额外操作。
