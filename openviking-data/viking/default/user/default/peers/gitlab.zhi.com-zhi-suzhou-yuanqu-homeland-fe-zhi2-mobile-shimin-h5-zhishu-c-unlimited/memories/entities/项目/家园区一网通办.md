# 家园区一网通办
家园区一网通办的 uni-app H5 移动端项目仓库，VITE_APP_TITLE 为“家园区”。

## 技术与部署
- 项目为 uni-app H5 移动端应用，不是标准 zhi2/zhi3 web-admin。
- 本地 nginx 部署在端口 8093，站点前缀 /wechatapph5/，站点根目录为 D:/repository/家园区一网通办/dist/。
- 使用 UnoCSS，换行类实际为 word-break-break-all，不存在 break-all；text-24、min-w-0 类也未生成。
