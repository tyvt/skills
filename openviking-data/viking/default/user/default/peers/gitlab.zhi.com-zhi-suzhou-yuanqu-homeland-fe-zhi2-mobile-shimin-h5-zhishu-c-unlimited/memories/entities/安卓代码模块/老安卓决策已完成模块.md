## 修改决策文案

## 禁用条件
- DecisionsRecyclerItemPresenter.java:145-192 中，可点性只看 voteState 加截止日，没有“已完成 Tab 一律禁用”的规则。
- voteState == 已过期 时，“修改决策”灰色且 setClickable(false)。
- voteState == 已表决 且今天晚于 voteEndDate 时禁用；compareDate 使用 yyyy/MM/dd，截止日当天仍可点。
- voteState == 已表决 且未过截止日时可点，同时“决策结果”被灰掉；voteState == 表决中/未表决 时也可点，但在 type=1 中少见。
