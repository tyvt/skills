## 直接回答

**老 app 没有「点决策详情后，参与决策变修改决策」这个逻辑。** 两边文案切换机制根本不同：

| | 老 H5（园区表决H5 / iOS WebView） | 新一网通办 |
|---|---|---|
| 参与/修改判定 | **按 Tab 分两个独立按钮**：未参与 Tab 显示「参与决策」，已参与 Tab 显示「修改决策」 | **单个按钮按 `voteState` 动态切换**：`未表决/未选举`→参与，其余→修改（`components/index.vue:51-53`） |
| 点「决策详情」 | 跳 `/decision/{type}/{id}`（**不带 pageType**），详情页不显示参与按钮；返回列表也不重新拉数据，标签不会变 | `goDetail` 只存 tableId 后跳转（`components/index.vue:202-208`）；返回时 `onShow` 触发 `reload()`（`:195`），重新按新 `voteState` 渲染 → 标签翻转 |

所以新端的「点详情回来变修改」是**列表 onShow 重载 + 后端 voteState 已变**的结果；老端是静态 Tab 分流，不存在这种翻转。
