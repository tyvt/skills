# 园区表决H5
园区表决H5 是 1.0 H5，决策按钮按 CardList 的 type 分流，与 voteState 无关。

## 决策列表
- 园区V0APP后端是该 H5 的后端，提供 /h5decision/* 决策接口。
- 使用另一套 estate 接口。
- 页面按未参与、已参与、已完成 Tab 分流；详情接口只读不改状态。
- 按钮按 D:/repository/园区表决H5/src/views/decision/components/CardList.vue:19-26 的 type 分流：0 参与、1 修改、2 详情。

## 边界
- 该 H5 不是 homeland-android 老 app。
- 不能用它代替安卓原生实现来判断老 app 逻辑。
- 老 app 链路 iOS→老H5→V0后端没有“点详情后参与变修改”。
- 新一网通办的点详情回来变修改不能归因于该 H5 或园区V0APP后端。
