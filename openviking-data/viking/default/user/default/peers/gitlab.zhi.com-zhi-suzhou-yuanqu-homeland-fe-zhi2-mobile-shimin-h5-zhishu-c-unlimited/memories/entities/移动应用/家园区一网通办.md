# 家园区一网通办
新 app 的决策详情参与/修改文案由服务端 voteState 驱动，进入详情会触发后端写状态并在列表刷新后改变按钮文案。

## 决策列表
- 列表按钮由 voteState 决定：未表决/未选举显示「参与」，否则显示「修改」。
- 证据锚点为 src/pages-decision/components/index.vue:51-53。
- index.vue:202-208 仅负责跳转详情，index.vue:195 的 onShow 会重载列表。
- voteState 文案逻辑于 2026-01 引入。

## 详情与接口
- 决策详情 src/pages-decision/decision/detail.vue:143,162 调用 SmUserVoteDetail。
- src/api/common.ts:138 等接口路径与后端 /version/1/app 对齐。
- 列表接口为 SmCastVoteListApp。

## 行为结论
- 进入详情触发详情接口后，后端会改变 busiState/voteopinion，列表重拉时 voteState 变化，按钮从「参与」变「修改」。
- 这是前端显式按 voteState 设计的行为，不等同于安卓按 Tab 固定文案。
