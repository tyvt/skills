# 业主决策模块
业主决策模块是一网通办 H5/小程序中的表决与选举模块，“参与/修改”按钮文案由后端返回的 voteState 决定。
## 展示逻辑
- 按钮文案在 src/pages-decision/components/index.vue:51-53 根据 voteState 计算。
- voteState 为“未表决”或“未选举”时显示“参与”，再与 typeLabel 拼成“决策/选举”。
- 其他 voteState 显示“修改”，再与 typeLabel 拼成“决策/选举”。
## 请求链路
- 列表页在 onShow 时 reload，通过 SmCastVoteListApp（/version/1/app/SmCastVoteListApp）重新获取 voteState。
- 详情页通过 SmUserVoteDetail（common.ts:162）渲染字段，没有参与或修改按钮。
- 提交链路为 goForm→阅读须知弹窗→form 页→SmCastVoteSubmitApp（common.ts:179）。
## 详情行为
- goDetail（components/index.vue:202-208）只设置 decisionStore.setTableId 和 setOwnerVoteOpinCode 后跳转详情页。
- goDetail 不修改 voteState，也不直接改变按钮文案。
