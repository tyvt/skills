- 缓存文件（select.json/result.json）已知精确路径却被探索门禁拦截时，改用带 offset/limit 的分页读（门禁豁免项），不整目录探索也不放弃读取。
- 精确路径 read 被探索门禁拦下时换形态改用 ops_inspect_local_file 直接读取该路径，不重复原形态、不整目录探索也不放弃。
- 全仓 glob 会超文件预算失败，改用已知项目目录的窄命令批量核对；记忆路径省略子目录前缀时在项目目录内窄定位；精确 symbol 核对并行但控制批量避开门禁。
- 后台全仓 grep 大目录会卡住，kill 后改用 ops_grep（有扫描预算、更快）做最后核对；成本升高时用 offset/limit 局部行读收窄范围。
- 审计时宽泛的仓库级 glob 会撞上 dist/ 压缩产物与 file-limit 并污染结果；收窄到 src/ 子路径，按具体文件与行段精读核对；同时避开记忆 dump 目录以免假阳性。
