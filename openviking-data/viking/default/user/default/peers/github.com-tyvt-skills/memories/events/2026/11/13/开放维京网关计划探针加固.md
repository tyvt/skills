## 你这条又对了 —— 两个缺陷已修

**缺陷 1：探针单向 → 假阴性风险**。原 S4b 只测"A 写的 B 搜不到"，若 gateway 单一 peer 是第三身份，B 搜不到 A 标记会被误判为"隔离正常"。现改为**三控**：
- ① 正控：A 写 A 标记 → A 搜得到
- ② 负控：A 标记 → B 搜不到

**缺陷 2：回退路径矛盾 → 决策树**。原 S4b 单点回退 `direct`，但 R1 还留着"增强或 direct"二选一死文字。现在加 **S4c 失败归因决策树**：

- **② 查不到但 ③ 失败**（B 搜不到 A 也搜不到自己 B）= **身份错位** → 直接回退 `direct`
- R1 的缓解/回退列同步成这棵决策树，"或"字删除。
