- 不喜欢 agent 靠猜地址或反复改代理来修部署，希望本地前端部署地址有注册表这类单一事实来源。
- 防汛C端本地验证必须以本机 dist + localhost（如 localhost:8162）为准，不能用远程域名替代本地部署；远程网关域名只应放在 backend_gateway 与 nginx proxy_pass，不得写入 frontend_url。
