- 处理线上故障时偏好先做最小化止血（如把 OpenViking 的 embedding.max_concurrent 从 10 调到 2），暂不调整超时、OLLAMA_NUM_PARALLEL 等二次参数，观察后再评估
- 认可"有界但偏慢"优于"快但会雪崩断连"的取舍，接受限流后单条嵌入仍需 6–16s
