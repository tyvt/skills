## 为什么面板看不到编排器模型的 token

**模型面板（dsh-token-models）的数据源是 `dsh-context` 的 `contextTimeline.cost`——它只记录"宿主会话进程内经 DSH LLM 层发出的模型请求"。**

而编排器（`orchestrate`）的模型调用：
- 发生在**独立的 Python/LangGraph 子进程**里（`jsonbridge.py` → magpie 网关 `127.0.0.1:3425`）
- **完全不经过宿主 DSH 的 LLM 层，也不经过 dsh-context**
- 它的用量只写进自己的 `.costs.jsonl`（`langgraph-orchestrator\.sessions\`），DSH 面板不知道

所以——**面板里看不到编排器模型的 token，是因为数据源根本不采集它们，而不是它们没跑。** 这两件事已经彻底分清了：
