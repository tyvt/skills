- 要求部署看板为每个项目固定展示五个环境槽位：本地、公司开发、公司测试、客户测试、生产，端口分开并分别代理到不同网关。
- 希望看板以后台静默方式开机自启，不要出现控制台黑窗。
- 认为有部署看板后不再需要 nginx UI 项目，倾向直接移除。
- 取消“未收录”概念：部署后即收录进面板，坏了就从注册表移除。
- 曾倾向用 WASM CDN 做纯前端查询 sqlite（参照持仓面板），但因探活与磁盘扫描等需求最终保留后端。
- 已不存在的项目要从看板、注册表各表、归档 conf 与迁移脚本中彻底清理，避免重跑迁移时复活。
