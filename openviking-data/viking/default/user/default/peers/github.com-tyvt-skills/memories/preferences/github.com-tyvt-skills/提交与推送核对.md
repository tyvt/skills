- 提交前核对 diff 范围，只提交任务相关文件；历史遗留改动、注册表数据与来源不明的临时文件不纳入本次提交（来源不明者先核对时间戳再判断）。
- 提交含 SQLite 的改动前用 python 做字段级对比（git diff --stat 只显示「Bin 73728->73728」，看不出字段变化）：只输出差异列名+计数、绝不输出 cell 值；若仅 last_health_at/last_health 等运行时字段变化，判定为纯运行时脏状态、不再提交以避免每帧刷脏。
- 推送/拉取遇网络故障时不重复同形态重试：远端 SHA 复核（git ls-remote，间隔 2s）最多 3 次，仍不通即按「本地 HEAD 与提交 SHA 一致 + push exit=0，远端核对受网络阻断」结案，如实报告、保留本地提交，留网络恢复后人工核一次。
