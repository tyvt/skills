Line 465 is `const disposer = ctx?.tools?.guard?.((exec) => {`. In **cordis**, accessing a service property like `ctx.tools` requires the service name to be declared in the plugin's `inject` array. The plugin declares `export const inject = []` (empty), so cordis **throws** `cannot get property "tools" without inject` when `apply` touches `ctx.tools`. The throw aborts `apply`, the entry **does not activate** ("1 entry did not activate"), and no guard is registered — hence not loaded at runtime.

That's the bug. The fix: `export const inject = ['tools']`.
