- 偏好关键流程用硬约束落地（可校验 checklist，缺一即视为未通过），而不是依赖执行者临场发挥的软规则。
- 重视验证证据在对话中稳定可见（截图必须内嵌正文），不接受时隐时现。
- 要求格式／流程规范先做实测样例给他肉眼确认，确认后再执行强制合规检查；规范本身要能逐条机械判定 PASS/FAIL。
