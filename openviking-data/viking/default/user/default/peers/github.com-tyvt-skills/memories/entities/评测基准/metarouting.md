# MetaRouting
评估元决策策略的基准，最贴近“planner 该不该自己答”。

## Description
- 直接评估何时分解、检索、执行代码、委托、验证或直接回答。
- 区分“可执行基准”和“合成负载基准”。

## Purpose
- 适合做 success–cost–latency 权衡分析。

## Significance
- 对应编排器“planner 50% 直接回答”问题，即何时该直接答 vs 走工具。
