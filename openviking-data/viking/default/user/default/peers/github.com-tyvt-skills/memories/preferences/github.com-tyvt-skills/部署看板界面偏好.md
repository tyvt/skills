- 环境 URL 区域只展示 http:// 开头的跳转链接，不要重复显示端口号。
- dist 属于项目公共信息，应上提到项目标题处、每个项目只展示一次。
- 每个项目固定最多 5 个环境槽位，多余环境合并进已有卡片而不是新增第 6 张卡；槽位少时卡片可以加宽（采用 300px）。
- 项目列表按最新部署时间倒序排列，缺少时间的项目排在末位。
- 一环境一端口：看板里不存在需要合并的端口，合并去重产生的重复端口行（如已删除的 local-8098）不保留。
- 构建时间也属于项目公共信息，应和 dist 一样放在项目分组标题处（空值回退 -），不要在每个环境卡片内重复。
