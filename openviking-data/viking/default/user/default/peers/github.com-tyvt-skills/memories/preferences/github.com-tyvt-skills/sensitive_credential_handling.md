- 用户已确认 storage=明文入库 时以用户确认为准，覆盖旧「密码不入库」约定。
- 明文凭据只落 DB 与本地交接文档，不回显在最终回复、日志与截图说明中。
- 探查 state/API 时若输出含明文，只回报“已渲染/已入库”的事实，不贴具体密码值。
