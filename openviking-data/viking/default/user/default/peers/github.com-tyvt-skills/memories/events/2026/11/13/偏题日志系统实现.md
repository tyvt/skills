### 3 — 日志是主体

**[graph.py](dsh/langgraph-orchestrator/src/graph.py) 的 `log_offtask`**：每次代码类工具调用**都记一行**，命中与否都记。

这是关键设计——**分母必须包含未命中的调用**，否则算不出触发率。记录字段：

| 字段 | 用途 |
|---|---|
| `ts` / `session_id` / `tool` / `model` | 分组维度 |
| `hit` / `matched` | 分子 + 特征聚类 |
| `chars` | 区分“短正常回答”和“长偏题成稿” |
| `instruction_head` / `head` / `tail` | 人工复核用，不落全文 |

**命中后自动降级重跑**到池内下一个模型（composer → glm → deepseek），trace 标 `[OFFTASK]` / `[OFFTASK-RETRY]`。

**[offtask_stats.py](dsh/langgraph-orchestrator/scripts/offtask_stats.py)** 直接出报告：

```
样本总数: 3
总触发: 1/3 = 33.33%  (95% CI 6.1%-79.2%)
--- 按 model ---
  cursor/composer-2.5       1/2 = 50.00%  CI 9.5%-90.5%  (样本<30，区间很宽，不可作结论)
```

用 Wilson 区间而不用裸比例，并**硬编码“样本<30 不可作结论”的警示**——避免过几天看到“50%”就误判。...
