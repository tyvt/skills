- 变更优先落地低风险部分，缺少切换或兜底机制的高风险项暂缓，待出现可切预设机制后再议。
- 决策前用量化数据衡量收益与风险，例如以使用率（8.8%）和 token 节省量（848 与 994）判断是否值得动手。
- 明确不为了小幅收益承担不可回退的风险，宁可先拿确定性收益落地。
