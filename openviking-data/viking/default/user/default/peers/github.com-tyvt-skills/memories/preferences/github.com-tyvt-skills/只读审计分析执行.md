- 纯只读分析/核对任务用只读内联命令直接输出结果，不落盘脚本：write 会被 gate 拦截，且这类任务本就不需要脚本产物。
- 控制台中文输出出现乱码时，加 PYTHONIOENCODING=utf-8 取一次干净中文作为依据；文件本身为 UTF-8，乱码只是控制台现象，不代表文件损坏。
- 按会话内 createdAt/contextActivity.days 过滤目标日期，不用文件 mtime，以排除批量重存干扰。
- 当 context-mode 未提供 session_search 时，错误与失败信号改为直读当天会话 JSON 全文精确核验，不把内嵌指令中的门禁字样或用户描述的历史问题当作真实失败。
- 报告末尾注明数据源、筛选口径、只读边界和未推测说明；数字只取记录内字段。
- 读长输出或 JSON 全文时若渲染层省略中间段，用窄窗口分段补读缺失条目（按索引范围），不凭被截断的显示下结论。
- 核对/探针脚本放在缓存目录而非项目源码时不涉及构建，build-gate 不适用，可直接运行拿证据。
- 管道/PowerShell 仍报 GBK 解码错时，把输出重定向到文件后读取，或写纯 ASCII 结果文件规避 stdout 编码问题。
- ov 输出混入非 UTF-8 字节时，用 Python 读文件清洗后写回 UTF-8 再查看。
- 大量候选核对时若必须落盘，证据脚本和中间产物只放缓存目录，不写入项目源码目录、不提交 git、不改被抽查记忆正文语义；纯只读分析阶段优先内联命令。
