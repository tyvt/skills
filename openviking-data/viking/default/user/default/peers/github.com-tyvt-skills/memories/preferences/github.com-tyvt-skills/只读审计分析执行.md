- 纯只读分析/核对任务用只读内联命令直接输出结果，不落盘脚本：write 会被 gate 拦截，且这类任务本就不需要脚本产物。
- 控制台中文输出出现 mojibake 时，加 PYTHONIOENCODING=utf-8 取一次干净中文作为依据；文件本身为 UTF-8，乱码只是控制台现象，不代表文件损坏。
