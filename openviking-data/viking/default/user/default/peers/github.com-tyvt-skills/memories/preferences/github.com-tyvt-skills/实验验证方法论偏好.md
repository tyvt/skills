- 对模型行为等经验性结论，要求做 N× 复现（如关键任务复现 3 次）而非凭单轮裸测直接下结论
- 单轮裸测结论不等同于 agentic 多轮落地表现，落地前需用真实会话对关键任务各抽 ≥3 真实任务端到端复核
