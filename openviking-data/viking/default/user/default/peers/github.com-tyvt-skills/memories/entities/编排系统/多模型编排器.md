# 多模型编排器
基于 LangGraph + Magpie 的 DSH Web 多模型编排系统，由用户开发维护。
## 模型池（2026-11-14 四池改造）
- planner 池：gpt-6-luna、gpt-5.4-mini、dsv4.1-flash（替换已下线的 gpt-5.6-luna）
- code_edit_with_signal 主选 kimi-k3.1-pro（替换 composer-2.5）
- plan_reviewer 与 verifier 使用 grok-4.7@500k（替换已下线的 @256k）
- workbuddy 兜底统一 space-bunny（file_reader / code_editor / summarizer / pwsh）
- security_guard 主选 kimi-k3.1-pro
- config 启动时读死，改动需重启 DSH Web 才生效
## 评测资产
- A/B 对照模型 auto/glm-5.3-flash（按量计费）
- T1–T7 执行层题、planner 归因样本 #1–#15、route_miss 日志、controller-bench（35 题×多模型，2026-11-14 M6–M10 落地）
- 网关可用模型共 39 个（含 codex 全系、workbuddy 全系），用于主控快筛与全量测试
