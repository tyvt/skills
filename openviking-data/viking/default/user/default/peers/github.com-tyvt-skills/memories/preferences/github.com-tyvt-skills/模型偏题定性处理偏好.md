- 不将模型偏题/失效轻描淡写为"偶发"来收尾；低频不等于无害，不能靠"改个 prompt 就好了"糊过去
- 最低成本验证步骤：将偏题输出加入 off-task 语料并跑正则，先于重放或复杂实验
- 用多次重放（如 11 次：5 baseline + 3 注入 + 3 max_tokens）区分"不可通过请求参数复现"与"偶发噪音"
- 偏题成稿若形似正常交付（如"虚构交付物型"整篇博客），必须靠正则拦截而非人工快扫
- 偏题触发率必须靠真实流量日志统计（分母含未命中调用），这是估计触发率的唯一手段，价值高于再跑多次重放
