- 当同一动作需对 ≥3 个同类对象（多 Bug、多页面、多文件、多查询）执行时，首选 orchestrate {op:"full"} 扇出并行（2026-11-24 全库实测 8.9k 等效/步、命中率 0.957，三组最优），禁止主模型循环串行；主模型只做汇总与验收
- spawn_teammate/workflow 仅 full-tools 预设可用且默认不选（建团实测 16.0k 等效/步、命中率 0.925，性价比为负），其余预设已禁用
- standard 会话需要异构模型时改走 orchestrate 子任务或回退主控，workflow agent() 限 full-tools
- 单会话 steps>300 或等效成本>5M 时，剩余任务必须改用子智能体并行拆片，不允许继续主循环
