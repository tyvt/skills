- 当同一动作需对 ≥3 个同类对象（多 Bug、多页面、多文件、多查询）执行时，必须先 spawn_teammate 扇出并行或 workflow 编排，禁止主模型循环串行；主模型只做汇总与验收
- 单会话 steps>300 或等效成本>5M 时，剩余任务必须改用子智能体并行拆片，不允许继续主循环
- 要求将 fanout-gate 逻辑加入 dsh_orchestrator_gate 插件：检测连续 ≥5 次对同类对象的重复工具调用（如连续 read 不同文件）时拒绝并提示扇出
