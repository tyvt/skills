# Web Presets
Web presets control tool-workflow availability in the peer's web environment.

## Tool Workflow
- preset-standard disables tool-workflow.
- preset-cordis and preset-full-tools still enable tool-workflow.

## Skill Directory
- The skill directory has 40 items, with dsh-harness-dev-context disabled.
- Each step carries a fixed context of about 14.6k tokens.
