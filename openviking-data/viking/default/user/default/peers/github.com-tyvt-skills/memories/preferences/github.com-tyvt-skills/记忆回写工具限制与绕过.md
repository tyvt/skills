- `ov write --wait` 会触发 embedding，Ollama 断连时失败；改用 `ov write --from-file` 不带 `--wait` 后 `ov read` 回读校验，frontmatter 写入不依赖 embedding。
- `--processing-mode vectors_only` 可跳过语义生成以避免断连；逐条 write+回读每条含两次 ov 调用，批量较慢属正常。
- 后台 apply 卡住或反复 embedding 断连时先停掉旧进程，重新执行（幂等，跳过已完成），并先统计实际落盘条数再决定补写范围。
- CLI/MCP 写含空格 URI 时服务端把空格规范化为下划线，无法直接写含空格旧文件；MCP write 会误建下划线重复空壳文件且正文丢失，被误覆盖文件须恢复完整内容。
- 含空格 URI 确实无法写入时如实标注为 skipped，不谎报成功。
