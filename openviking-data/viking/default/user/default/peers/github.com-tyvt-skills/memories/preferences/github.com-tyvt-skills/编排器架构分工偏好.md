- 主张多模型参与与降本是同向的，不是矛盾的；编排器应承担检索、读文件、改代码、跑命令、判读输出等可分流工作，宿主只保留判断方向、审 diff、写结论。
- 编排器优化顺序：先改配置级低成本项（guard 白名单、模型池对调、code_editor 启用），再做代码级改动（返回体裁剪、targets 扇出、op:read 窄读）。
- guard 对只读/低风险命令按命令前缀直接 ALLOW，避免 escalate→defer→ALLOW 双重评审循环浪费延迟。
- execute（格式转换类）用 flash 模型，summarize（长输出判读）用强模型，二者模型不应配反。
- 白名单不新增任何写/执行类命令，不可逆操作（如 git push --force、npm run build 执行任意脚本、npx eslint --fix 改源码）必须保留评审。
- 异构模型分工优先用 workflow agent({provider,model}) 而非 spawn_teammate；后者 request 无 model 字段、成员硬继承 Lead 模型无法换模，workflow 路径绕开 policy 白名单且 spawn 支持 agentOptions，零配置可用 (as of 2026-11-14)
