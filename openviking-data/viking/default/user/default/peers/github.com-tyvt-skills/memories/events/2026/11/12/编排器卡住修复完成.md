### 1. 编排器卡住的根因与修复
**根因（已定位到代码行）**：`dsh/orchestrator/lib/index.js` 用 `spawn(python -m src.jsonbridge)` 一次性等 stdout，中途**零进度输出**；config 里 `code_editor/planner` 单请求 300s、`max_retries_per_model=1`、池内多模型串行（最坏 300×2×N 秒）；`pwsh_timeout=30` 让 `npm run build` 必超时。真实会话 `session-74f4898d` 的 build 在 180s 处直接 `调用被取消`、**无 partial 输出**——这就是"疑似卡住"。

**修复**：

- [config.yaml](dsh/langgraph-orchestrator/config.yaml)：`pwsh_timeout` 30→**180**（build 不再必然超时）、`code_editor/planner` 单请求 300→120（故障转移更快）、`request_timeout` 120→90。
