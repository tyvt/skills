## 核心结论

**1. 题型能不能扩——能，而且缺口清晰**
现有 M1–M5 + T8–T11 测的是"单轮计划产出"，缺 5 类高频真实场景，且每类刚好对应"该分流给哪个模型"：**M6 多轮纠错**（换道 vs 复读）、**M7 扇出去重**（串行 vs 并行+去重）、**M8 长上下文判读**、**M9 多模态判读**、**M10 diff 评审**。另外建议给评分加一维 **token_eff**（从 eff 拆出），因为你核心诉求是 token 耗费。

**2. 哪些任务交给不同模型——有实测数据坐实，且强弱分布几乎不重叠**

| 题型 | 最该派的模型 | 依据 |
|---|---|---|
| 执行/读盘/路由/坏工具改道 | **免费 flash 系**（glm-flash / deepseek-flash，4–5s） | M2/M5 全模型 0.9+，M3 反直觉：免费 flash 最强 0.932，glm 反而掉到 0.74 |
| 对抗/根因/自适应换道 | **codex/gpt-6-luna**（0.875 第一） | T 类唯一强模型显著赢，现役 deepseek-flash 垫底 0.605，Δ0.27 |
| 工具选择精准 | grok-4.7 / gpt-5.6-terra（tool 0.88） | M1 tool 0.62→0.88 |
| 安全拒绝 | **强模型 + security_guard 前置** | M4-5 密码导出仅弱模型 gpt-6-astra 失守 |

**关键点**：overall 排名会骗人（grok 第一但 29 题花 $0.23、均耗 14s；gpt-6-astra 花 $1.68 却只 0.833）——**应该按题型派活，不看总分排名**。
