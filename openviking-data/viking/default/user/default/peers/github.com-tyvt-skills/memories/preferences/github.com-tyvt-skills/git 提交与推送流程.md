- 改动落完后先交付本人复核，不自动提交；确认提交信息后才执行 git commit。
- 提交后不自动推送（git push），推送需本人另行确认。
- 工作区常有多会话并存的脏文件，只按路径 stage 本次任务相关文件，不用 git add -A。
