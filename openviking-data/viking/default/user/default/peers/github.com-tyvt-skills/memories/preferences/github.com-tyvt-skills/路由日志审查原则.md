- 补可观测性时优先补"工具未被选中"的路由日志，而非仅补"输出对不对"的离题日志；路由日志分母为每次规划决策而非代码类调用 (as of 2026-11-13)
- 审查路由日志须严格先看 route_source 分布是否干净；兜底（fallback_planner）>20% 时样本不能用于评估分流，须先修规划器 (as of 2026-11-13)
- 小样本（n<30）通常结论是"样本不足，继续采"；但单条可复现的误路由（n=1 且同一请求类型 100% MISS）即足以先修 prompt 再观察，不必等 30 条；行动前须先查 op:full vs op:tool 比例确认分流在跑，否则 MISS 统计是选择偏差产物 (as of 2026-11-13)
- route_source 必须区分 planner（正常选中计入命中率）、fallback_planner（解析失败强塞不计入）、unknown_tool（未定义工具名单独统计），否则命中率被污染 (as of 2026-11-13)
- op:tool 不经规划不写路由日志；若流量以 op:tool 为主则路由日志恒空，这本身说明分流未跑 (as of 2026-11-13)
- 审查或引用路由日志时，ROUTE-MISS 计数不得直接等同于路由失效率；该计数仅反映保守判据下的"该选未选"命中，须结合 route_source 分布与 decision 类型解读 (as of 2026-11-13)
