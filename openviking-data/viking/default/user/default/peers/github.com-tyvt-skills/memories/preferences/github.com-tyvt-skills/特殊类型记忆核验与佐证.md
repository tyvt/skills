- bug 记忆用 DBX 或 ZenTao 记录作佐证，核对匹配的标题和日期。
- 用 DBX 或 ZenTao 佐证时，还要精确核对关联的 action 和 file 记录：action ID、files 数量、objectID 和文件附件。
- 记忆治理或治理原则类记忆按当前系统判定：用 VALID/INVALID 二元判定，不设 archived/stale 归档、不设 `suspect` 状态、不做 `forget` 操作；主张归档或遗忘前需人工确认的旧原则为 INVALID。
- 用户陈述的偏好或态度自洽且非幻觉时，偏好类记忆保持 VALID；不需要代码符号证据。
- 定稿判定前运行隐私或敏感信息扫描。
