- 新建文件用 `write`，已有文件一律 `edit`；禁止对已存在文件整篇 `write`（v2 整篇覆盖 v1 为典型反例）
- 计划/方案文档先出骨架（≤1.5k），再增量补章节；禁止「想清楚后一次性 5k 全文 write」
- 写前先定结构：骨架 → 逐节 `edit` → 定稿，全程不重读全文；单节改写只 replace 该节
