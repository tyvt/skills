## 顺手记一下

脚本的默认值是从 `$PSScriptRoot` 推导的（`<repo>/dsh`），profile 路径默认使用 `$HOME`，因此换用户或更换 profile 都能工作。也可以显式覆盖：

```powershell
.\link-plugins.ps1 -NodeModules 'D:\other\.dsh\profiles\web\node_modules'
# 或环境变量
$env:DSH_PLUGIN_ROOT = 'D:\repository\skills\dsh'
$env:DSH_PROFILE_NODE_MODULES = '...'
```
