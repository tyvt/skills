## 关于"环境变量"的落点说明

我查了实际进程：编排器的 `jsonbridge` 是**每次 orchestrate 调用按需 spawn 的 python 子进程**，每次读最新 `api.py`。所以：

- **改默认值 = 下一次 orchestrate 调用立即生效**，无需重启 DSH Web，也不用设系统环境变量
- 运行中的 DSH Web（PID 17800）无法改已运行进程的环境；若真去设 Windows 用户级环境变量，反而要重启才生效、还会机器级污染、后人看不见
