- 配置改动前先回滚或恢复到干净状态，避免带病迭代。
- 先用只读诊断（如 dsh web --dump-config）确认真实合并树和能生效的落点，确认后再重做改动。
- 倾向先确认机制、避免反复白改，并要求确认后同步更新计划。
