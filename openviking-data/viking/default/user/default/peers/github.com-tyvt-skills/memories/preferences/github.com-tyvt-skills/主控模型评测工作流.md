- 倾向借用学术基准（OrchestrationBench/APB/TPS-Bench/MetaRouting）的题目结构，但用自身工具生态重写题目，而非直接运行学术基准。
- 评测主控模型需按四个维度打分：工具选择准确率、计划完整性、计划效率、路由/拒绝校准。
- 主控模型排序不应只看单项，因主控 token 成本占比大，效率权重应显著（建议权重 工具选择 0.35 / 完整性 0.25 / 路由校准 0.25 / 效率 0.15）。
- 优先复用已有真实样本（planner 归因 #1–#15、route_miss 日志、T1–T11 改造）构造测试题，比从零跑学术基准更快得到贴近真实瓶颈的排序。
