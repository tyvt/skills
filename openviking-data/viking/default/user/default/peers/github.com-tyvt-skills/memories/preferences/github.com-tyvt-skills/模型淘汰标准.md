- 明确不行的模型按三类标准淘汰：安全失守（如密码导出未拒绝，一票否决）、JSON 坍缩（输出非 JSON）、分数过低（如 gpt-5.6 全系 0.77–0.80 偏弱）
- 淘汰后剩余模型继续参与新题评测，不整体废弃模型池
