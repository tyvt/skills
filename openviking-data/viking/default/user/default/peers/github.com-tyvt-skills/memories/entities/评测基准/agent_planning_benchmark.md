# Agent Planning Benchmark (APB)
规划专用的诊断基准，用于测试鲁棒性与校准拒绝。

## Description
- 包含 4,209 个案例、22 个领域。
- 显式测试外无关工具、坏工具、不可解任务下的表现。

## Purpose
- 最适合测“鲁棒性”和“校准拒绝”。
- 将“失败是规划错还是执行错”拆开诊断。

## Significance
- 其题目结构可映射编排器中工具空间噪声/误导导致的规划失败。
