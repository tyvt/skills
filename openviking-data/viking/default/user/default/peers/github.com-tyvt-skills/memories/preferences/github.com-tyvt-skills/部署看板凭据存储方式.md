- 要求 deploy-env 看板的账号（login_user）与密码两类凭据都补齐，历史凭据从对话记录与隐私库中恢复。
- 接受为账号展示调整表结构与 api.py，但生产文件改动仍须先走计划审批；密码保持不入库、由隐私库与 secret_ref 承载。
