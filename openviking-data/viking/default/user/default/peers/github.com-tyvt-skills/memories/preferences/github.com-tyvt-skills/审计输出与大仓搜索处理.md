- 候选很多、输出被截断或读取大型筛选结果时，先把大批量候选解析成紧凑清单和索引，再按有界批次检查缺失条目，不凭被截断的显示下结论。
- 定向搜索可用 `ripgrep`，它比慢速全仓扫描更快。
- 大仓 grep/glob 触发文件数限制或精确正则扫描过慢时，停止慢任务，改为扫描业务仓一次建立文件名索引，再用精确文件名快速核验。
- 摘要脚本遇到 GBK stdout 编码问题时，改为写入 UTF-8 文件后读取该文件。
- glob 工具因模式必须是数组而报错时，纠正调用形状并补读缺失范围。
- 运行批量核验脚本前先修正空仓库映射，否则会退化为全盘扫描。
