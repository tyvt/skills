- 免费模型（如 glm-5.3-flash）作 A/B 对照；复杂规划降级场景保留强模型（如 grok-4.7）
- 模型分配优先级：先免费版（hy4flash-free），其次积分版（hy4flash），只有高级/复杂任务才上 grok-4.7 或 kimi-k3.1-pro
- composer-2.5 套餐量大、消耗低，可以多分配任务（如高频代码生成），但因其输出「非 JSON 坍缩」不用于纯 JSON 角色
