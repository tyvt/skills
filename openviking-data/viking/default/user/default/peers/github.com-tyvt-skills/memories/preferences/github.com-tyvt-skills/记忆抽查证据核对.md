- 记忆抽查逐条核对：用特征字符串在 D:\repository 对应项目内 grep 精确定位并读指定行段，按实机代码证据判有效/无效，不凭记忆描述本身下结论；输出被截断时收窄到具体文件与行段。
- 核对时某文件名未命中不要立即判无效：先确认是否改名、移走或内容特征变化，按内容特征复核后再定论（face.vue 初次未命中，复核后仍成立）。
- 文件在某仓库找不到时按记忆里的仓名/别名线索换仓或换子目录定位（业主倡议前端从苏住房后端转到苏住房G 的 zhi2-web-admin），不要直接判无效。
- 记忆描述文件与实际实现文件不一致时（写 index.vue 调用方、实现在 chartRenderers.js），只要特征命中且描述成立即判有效，不要求文件名严格对应。
- 穷尽换仓/换子目录及全库 glob 仍无果，且记忆声称的具体文件路径不存在、归属自相矛盾时（如账户自动带出的 guaranteeDeposit/AddDialog.vue），判 INVALID；多仓复核无果是判无效的前提。
