- 要求 dsh web 拉起的 OpenViking 等服务在后台运行，不要出现 cmd 窗口或任务栏窗口。
- 偏好“完全隐藏”而非最小化：选用 VBS（WScript.Shell.Run 窗口样式 0）包装启动，因为 -WindowStyle Minimized 仍会闪窗并保留任务栏图标。
- 改造启动链时希望保留原有启动命令与日志重定向，原脚本可回滚（备份 .bak），范围外的启动项（如 Ollama）可维持原样。
