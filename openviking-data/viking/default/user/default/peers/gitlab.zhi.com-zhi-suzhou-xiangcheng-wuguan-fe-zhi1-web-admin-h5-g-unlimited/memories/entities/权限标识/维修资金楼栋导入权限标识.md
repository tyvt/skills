# 楼栋导入按钮权限标识
维修资金模块中「导入小区基础信息」按钮（用户称「楼栋导入」）的前端权限标识与配置。

## 权限标识
- 主按钮「导入小区基础信息」（含小区/楼幢/单元/房屋四页签的基础楼盘导入）：`lpgl:projectinfo:buildingimport`
- 同页「导入」（`build.ispropertysys=1` 时才显示，项目信息导入）：`lpgl:projectinfo:import`
- 已从「楼幢信息」列表去掉的旧「导入」按钮：曾用 `lpgl:buildinginfo:add`

## 代码位置
- 前端依据：`src/views/projectManagement/project/projectinfo/components/table.vue` 约第 16–24 行，`v-hasPermi="['lpgl:projectinfo:buildingimport']"`

## 配置与变更
- 后台给角色/菜单配权限时按 `lpgl:projectinfo:buildingimport` 勾选；菜单名若叫「楼栋导入」，以库里 perms 字段字符串为准
- 2026-11-23：「导入小区基础信息」按钮从楼幢列表迁到小区列表
