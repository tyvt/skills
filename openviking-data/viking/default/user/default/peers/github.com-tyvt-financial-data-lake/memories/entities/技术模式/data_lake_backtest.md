# 数据湖分组回测
数据湖选股模块按组推进的策略回测流程，输出各组策略候选数与基础池等权基准收益的对比。

## 流程
- 逐组完成深沪两市筛选与候选提取，再读取精确前复权（qfq）起止价计算收益
- 空策略组在报告中标为 N/A，同时保留该组基础池等权基准收益
- 汇报时明确各组候选数与有效收益数；样本小只做核对，不放大结论
- 收尾复核保护文件哈希、报告与最终 diff，再按仓库提交/推送清单收尾

## 筛选输出读取
- 筛选输出列顺序固定：首列为代码，倒数第二列为阶段二标志
- 改为按这两个列位置取值，避开表头编码差异；并用带 BOM 的合成 CSV 覆盖该路径自检
- 曾因筛选后的临时表索引导致沪市代码列查找失败，改为在原表上按布尔位置掩码提取代码，避免中间表重建

## 运行观察
- 2026-11-15 回测共八组；前三组策略候选均为 0，基础池等权基准分别为 +12.54%、+3.61%、−8.15%
- 2026-11-15 第四组深市出现 1 只候选，等权收益 +18.10%，同日基础池基准 −5.73%；沪市候选仍为 0
- 价格查询覆盖 186 只标的的精确 qfq 起止价；看门狗每 30 秒心跳确认查询存活
