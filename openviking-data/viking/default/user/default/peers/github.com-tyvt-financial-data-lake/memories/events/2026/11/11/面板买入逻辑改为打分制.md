**怎么买**

- 治理缺失、家族或外资实控、OCF 连续两年越线、支付率越线、行业红线，仍然整只剔除。
- 其余按总分排序。总分 = 基本面（最高 60）+ 价格（最高 40），必须高于 70 才买。
- 现价不高于目标价：价格折价 25 分，按本次均分额全额买。
- 比目标价高 0%～5%：折价 15 分，只买一半（提前建仓），不再抬回满仓。
- 比目标价高超过 5%：折价分低于 10，不买。超过 10% 折价分为 0。
- 全部价格分都不够时，本轮不买，剩余资金仍提示可放逆回购。

**分数口径（写进 `planScore`）**

- 绝对股息率：>5% 得 20，4%～5% 得 15，3%～4% 得 10。
- OCF/分红：>2 得 15，1～2 得 10；字段缺失记 10（只降权，不按越线记 0，和原来「缺数据仍可买」一致）。银行等 `ocfdMin≤0` 的行业这项给满分。
- 波动率：<18% 得 15，≤22% 得 10，≤25% 得 5。
- 治理：`central` 10、`state` 8、`none` 4。现有池子没有中央/地方分档，国资统一按 8 分。
- 股息率分位：≥80 得 15，≥60 得 10，≥40 得 5。
