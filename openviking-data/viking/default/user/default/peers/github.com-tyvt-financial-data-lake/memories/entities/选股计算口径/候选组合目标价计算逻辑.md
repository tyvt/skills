# 候选组合目标价计算逻辑
数据湖选股与持仓面板中「目标买价」的完整计算口径，定义在 final_portfolio_v3.py 与持仓面板 config.js/index.html，两端一致。
## 目标股息率
- 目标买价 = 每股分红 DPS ÷ 目标股息率 targetYld，即要跌到该价股息率才达标
- targetYld 按申万一级行业取参数（getMarginParams：行业优先，未命中回落全局 margin），分 fixed 与 dynamic 两种模式
- fixed 模式：targetYld = targetYldFixed，金融 5.5%、周期 8.0%
- dynamic 模式（默认）：targetYld = max(targetYldFloor, 近3年年末股息率均值 + yldPadPct)，样本不足 250 日按 floor 兜底；行业参数：公用/交运 pad 0.3、下限 3.0，消费医药 pad 0.2、下限 3.0，全局兜底 pad 0.5、下限 3.0
- 近三年均值按财年 DPS（除权日回溯 8 个月归年）÷ 当年末不复权价；面板逐日重建为滚动 12M 分红 ÷ 当时价算分位，样本 ≥250 日才计入
## 目标价与判定
- DPS：config 配 dps 则直接用，否则 DPS = 现价 × 当前股息率 / 100 反推（唯一用现价的量）
- targetBuyAbsolute = DPS × 100 / targetYld；保守版 targetBuyConservative = DPS ÷ (近3年均值股息率 × 1.1 / 100)，放 10% 安全垫，仅展示不判定
- 距买点 buyToTgtPct = (targetBuyAbsolute − 现价) / targetBuyAbsolute × 100，>0 表示现价低于目标价
- yldHit = buyToTgtPct ≥ 0 是买入唯一硬门槛；分位 ≥80%、布林下轨仅加分，不单独触发
## 入选门槛与代码位置
- Python 端按 score（波动率倒数）排序取最多 min(3, floor(金额/min_ticket)) 只（10万/3000 → 3）写入 buy_list
- 两道一票否决：上市不满 3 年剔除；现价高于目标买价超过 10%（max_gap_pct，gap = 现价 ÷ targetBuyAbsolute − 1）剔除
- 代码位置：final_portfolio_v3.py:1117-1191（目标价剔除）、:1176（gap 判定）；config.js:378-399（_doc 口径注释）；index.html:1525-1562（targetYld/targetBuyAbsolute）、:1712-1742（距买点与 yldHit）
