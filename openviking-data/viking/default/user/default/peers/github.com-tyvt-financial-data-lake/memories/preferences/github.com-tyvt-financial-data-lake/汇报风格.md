- 偏好精简汇报：先给结论和关键数字，再补必要细节，不要长篇过程叙述。
- 问「你做了什么」时希望得到一两句话的摘要：做了哪件事、关键结果、产出位置。
- 认为回测或分析汇报必须先说清口径与限制（样本口径、数据可用性），再给数字。
