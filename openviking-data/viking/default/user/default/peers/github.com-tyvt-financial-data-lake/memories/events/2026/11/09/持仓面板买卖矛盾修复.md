## 根因：两套分母在打架

| 区块 | 代码 | 占比分母 | 当前值 |
|---|---|---|---|
| 风险预警 | `renderAlerts` | 已投入市值 `T.mv` | ≈ 4.38 万 |
| 买入推荐 | `buildPlan` | 总本金 `total_capital` | 10 万 |

因为只投了 4.38 万、还有大把现金没建仓，用「已投入市值」当分母时每只都显得超配；而买入侧用「总本金」当分母又都还有额度。**同一只标的于是既被预警判"超配需卖出"，又被买入推荐选中买入** —— 你截图里兴蓉环境（环保）正是如此。你 11-09 的流水也是这个矛盾的实盘结果：卖了兴蓉1000股又买回1200股。
