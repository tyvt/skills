### 2. 配置权重 ≠ 买入指令，但日志没写清这一层

建议在日志里加一列 `本次动作：买入 / 持有不买 / 剔除`，把两层分开。否则“配置 8 只、推荐 1 只”看起来像漏了 7 只。

### 3. 25000 元只投 7632 元（30.5%），max_buys=3 均分预算是主因

洪城环境 900 股 = 7632 元。按 25000/3 ≈ 8333 元、8.48 元/股，8333/8.48 ≈ 982 股，取整 900 股 ≈ 7632。**这说明预算是按 max_buys=3 均分的，但实际只推荐 1 只，于是 2/3 资金闲置。**

三种处理，选一种并写进文档：

- **按实际推荐只数均分**：只推荐 1 只就 25000 全给洪城（约 2900 股），但会超 23.92% 权重；
- **按目标权重分配**：洪城 23.92%×25000=5980 元，约 700 股=5936 元，剩余现金留存；
- **维持 max_buys 均分 + 明确留存**：日志加一行“本次留存现金 17368 元，原因：仅 1 只触发 marginBuy 且不在排除清单”。

现在是第三种，但日志没写“留存”两个字，读者会以为买漏了。
