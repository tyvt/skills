# 分行业择时矩阵
用户于 2026-11-09 提出的红利底仓分行业股息率择时方案，放弃「一套参数打天下」，在 config.js 引入 margin_by_ind 按申万一级行业覆盖参数，并配套行业专属一票否决风控。

## 四大类与择时算法
- 金融类（银行、非银金融）：绝对底线法，targetYldMode=fixed、targetYldFixed=5.5%、ocfdMin=0；看当前无风险利率而非历史均值
- 公用事业/交运（公用事业、交通运输、环保）：动态均值+分位双重保护，dynamic、yldPadPct=0.3、targetYldFloor=3.0（用户选 3.0%，原提案 4.0%）
- 消费/医药/制造（家用电器、食品饮料、医药生物）：相对高位法，dynamic、yldPadPct=0.2、targetYldFloor=3.0
- 周期类（煤炭、钢铁、基础化工、有色金属、石油石化）：极端防线法，fixed 8.0% 或放弃择时；底仓尽量少碰强周期

## 行业专属风控红线
- 银行：核心一级资本充足率<9% / 不良率>1.5% / 拨备覆盖率<150% → 一票否决或强卖
- 公用/交运：OCF/分红<1（连续两年）或支付率>80%（连续两年）→ 透支分红卖出
- 消费/医药：ROE<8%（连续两年）或 OCF/净利<80% → 盈利恶化预警
- 周期：毛利率/净利率拐点或负债率>60% → 卖出
