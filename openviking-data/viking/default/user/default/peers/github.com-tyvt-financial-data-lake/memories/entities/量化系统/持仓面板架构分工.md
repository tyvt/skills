# 持仓面板架构分工
持仓面板（分析产出/持仓面板/）由 github.com-tyvt-financial-data-lake 维护；2026-11-11 将选股/打分/压权/买入清单逻辑外移至 Python，面板退化为看板与无脑执行者。

## 架构分工
- Python（数据湖脚本）= 决策大脑：门禁过滤、打分、风控、生成买入清单
- SQLite（holding.sqlite）= 事实真相：沉淀所有交易与分红
- HTML（index.html）= 观测仪表盘：展示结果、录入流水、仅执行 Python 下发的 buy_list
- 面板只显示组合与价格/权重信号，不在面板层重复过滤治理、现金流或选股标准
- 名单与权重沿组合生成链路更新，更新后需核对面板配置，配置核对共 19 项校验
