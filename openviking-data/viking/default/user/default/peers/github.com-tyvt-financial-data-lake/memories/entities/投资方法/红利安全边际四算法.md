# 红利安全边际四算法
用户为「红利收息+打新底仓」系统提出的、替代 60 日均线（VWAP）的四套安全边际算法方法论。

## 算法一：股息率绝对阈值法
- 逻辑：分红短期不变，股价越低股息率越高、安全垫越厚
- 做法：设目标买入股息率（洪城环境>5.2%、格力>8% 闭眼加仓）
- 目标买入价 = 预期每股分红 ÷ 目标股息率，现价低于此价即亮绿灯

## 算法二：估值历史分位法
- 逻辑：估值处自身历史极低位时向下空间被锁死
- 做法：当前 PE/PB 处过去 3-5 年 20% 分位以下视为安全边际充足
- 银行股看 PB（农行 PB<0.5 倍）、交运/环保看 PE

## 算法三：布林带下轨法
- 逻辑：跌破下轨属非理性杀跌，抓错杀机会
- 做法：20 或 60 日均线减 2σ，股价触及/跌破下轨买入

## 算法四：动态网格与回撤买入法
- 逻辑：用空间换时间，不预测底部
- 做法：每下跌 5% 或 8% 买一份（格力 38/36/34 元分批）

## 用户结论
- 低波红利底仓最实用的是「股息率绝对阈值 + 分批网格」
- 面板实际落地算法一、二（股息率分位替代 PE/PB）、三；网格（算法四）未纳入面板
