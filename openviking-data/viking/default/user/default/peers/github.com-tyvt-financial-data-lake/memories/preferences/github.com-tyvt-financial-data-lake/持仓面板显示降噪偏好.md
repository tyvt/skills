- 面板显示追求降噪：全局统一规则（如固定4.5%股息率）不重复写在每一行，只在表头声明一次
- 底部说明需分层结构化：行动指令（加粗显眼）→ 一句话买入理由 → 压缩的未买清单，避免「报菜名」式大段文字
- 辅助指标（股息率分位、布林带）应弱化处理：灰色/小字号，仅关键阈值（如分位>80%）才高亮
- 距买点列用直观语义：「安全垫 +X%」(达标) 或「需跌 X%」(未达标)，不用易误读的「达标 +X%」
- 面板设计目标：打开后 3 秒内看清操作指令即可下单，历史分位/布林带仅作辅助底噪
