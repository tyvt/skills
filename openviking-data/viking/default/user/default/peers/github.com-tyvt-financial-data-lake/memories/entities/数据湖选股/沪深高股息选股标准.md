# 沪深高股息选股标准
数据湖选股模块统一使用的沪深两市高股息筛选标准，两市脚本已按新门槛运行成功并产出入选清单。

## 门槛规则
- 沪深两市普通股息门槛统一为：三年平均股息率 >4%，且当前 TTM 股息率 >4%，两项均按严格大于判断
- 银行股须先通过上述两项通用门槛，并继续满足三年平均股息率 >5% 的专项要求

## 筛选结果
- 沪市入选 6 只：渝农商行、申能股份、沪农商行、菜百股份、洪城环境、青岛港
- 深市入选 4 只：格力电器、平安银行、粤高速Ａ、五粮液
- 沪市两家入选银行三年均值 5.69%、5.45%，当前 TTM 4.38%、4.74%
- 深市平安银行三年均值 6.03%、当前 TTM 5.05%，通过银行专项门槛
