# 沪深高股息选股标准

## 共用门槛
- 2026-11-15 起深市原专项条件全部上升为沪深共用 C1–C7；共用 C2 最终口径：近三年连续分红、三年平均股息率严格高于 3.5%、三个完整财年均须有有效 DPS 与年末价格，TTM 仅作参考、不作共用淘汰门
- 其余共用条件：上市满 3 年、年化波动率 <25%、三年经营现金流/分红 >1、累计支付率 <100%
- 银行股先过通用门槛，再满足三年平均股息率严格 >5% 的银行专项；沪市原有附加条件与银行专项仍按原标准执行；深市平安银行三年均值 6.03%、TTM 5.05% 通过银行专项
- 沪市「连续三年净利同比为正」与深市「连续三年分红」是不同条件，不可混写为共用盈利增长
- 2026-11-15 曾采用三年均值与 TTM 均 >4% 的股息双门槛，随后被上述 3.5% 旧深市口径取代
