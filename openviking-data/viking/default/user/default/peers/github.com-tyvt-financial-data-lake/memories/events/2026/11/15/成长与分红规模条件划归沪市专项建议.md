- **连续三年净利同比为正**和**三年净利 CAGR >3%** 从共用标准中移出，暂列“沪市专项候选”。前者要求逐年增长，后者要求三年整体增长；公用事业利润稳定但低增长，用这两条硬筛可能误伤。
