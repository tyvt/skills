# 数据湖选股模块
用户自用的 A 股选股与分析模块，位于 D:\repository\数据湖 仓库内。

## 组成
- 主要脚本：final_portfolio_v3.py（最终组合）、annual_review.py（年度复盘）、screen_sh.py（沪市筛选）、screen_sz.py（深市筛选）
- 筛选门槛按 C1–C7 等编号分类管理
- 历史文件按“已被替代”依据清理，保留当前组合、治理数据与有效正式输出

## 口径与规则
- 回测只使用精确前复权价，深沪 PIT 去重，回测输出隔离
- 2026-11-15 起把深市现行专项门槛并入沪深共用标准，深市不再单列专项标准

## 筛选清单
- 分别产出沪市、深市筛选清单；2026-11-15 需按共用标准重筛沪市当前符合标准的清单
