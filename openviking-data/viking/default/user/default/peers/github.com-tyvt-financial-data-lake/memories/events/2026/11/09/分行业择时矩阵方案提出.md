### 一、 行业分类与择时算法设计

我们将底仓池分为四大类，每一类设定不同的 `targetYldMode`（目标股息率模式）：

#### 1. 金融类（银行、保险）—— 适用【绝对底线法】
*   **痛点**：历史均值包含了过去几年的“破产定价”，均值失真；且银行业用 OCF 评判毫无意义。
*   **择时参数**：`targetYldMode = "fixed"`，`targetYldFixed = 5.5%`（或 6.0%）。
*   **底层逻辑**：不要看银行历史最高股息率是多少，就看**现在的无风险利率**。只要它的当期股息率达到了 5.5% 以上，且资产质量没崩，就具备买入价值。如果死等均值的 6.2%，极可能踏空整个降息周期的估值修复。
*   **专属风控（红线）**：核心一级资本充足率 < 9%、不良率 > 1.5%、拨备覆盖率 < 150%。触发即一票否决（不买）或强行卖出。

#### 2. 公用事业/交运（水务、高速、港口）—— 适用【动态均值 + 分位双重保护】
*   **痛点**：重资产特许经营，现金流极其稳定，几乎没有成长性。
*   **择时参数**：`targetYldMode = "dynamic"`，`yldPadPct = 0.3%`，`targetYldFloor = 4.0%`。
*   **底层逻辑**：这类公司的业务没变，历史均值是非常有效的锚。只要跌到历史均值之上稍微加一点安全垫，就值得买。但为了防止买在极端估值底部，加上 4% 的绝对下限兜底。
*   **专属风控（红线）**：OCF/分红 < 1（连续两年），支付率 > 80%（连续两年）。说明在吃老本，强行维持分红，必须卖出。

#### 3. 消费/医药/制造（食品、家电、医药）—— 适用【相对高位法】
*   **痛点**：成长股的分红往往不如成熟股高，且受经济周期影响大，如果死卡 5% 绝对股息率，可能永远买不到优质资产。
*   **择时参数**：`targetYldMode = "dynamic"`，`yldPadPct = 0.2%`，`targetYldFloor = 3.0%`。
*   **底层逻辑**：不强求绝对高息，但只要它的股息率处于自身历史的相对高位（跌到了历史均值附近），且基本面（ROE、OCF）没问题，就可以建仓。
*   **专属风控（红线）**：ROE < 8%（连续两年），或者 OCF/净利 < 80%。说明盈利能力恶化。

#### 4. 周期类（煤炭、钢铁、化工）—— 适用【极端防线法】
*   **痛点**：周期顶部利润高、分红高，股息率看似 10%（最危险）；周期底部亏损无分红。
*   **择时参数**：直接放弃择时（或者要求极端的 `targetYldMode = "fixed", targetYldFixed = 8.0%` 以上）。
*   **底层逻辑**：底仓系统**应尽量少碰强周期股**。如果一定要碰，必须在全行业亏损、估值极低（PB分位 < 10%）时买入。
*   **专属风控（红线）**：毛利率或净利率出现拐点、负债率 > 60%。

### 二、 工程实现方案（一步到位）

你不需要修改面板的底层代码（`index.html`），只需要在 `final_portfolio_v3.py` 和 `config.js` 的架构上做升级。

#### 1. 数据结构改造：新增 `margin_by_ind`
在你的 `config.js` 中，保留全局 `margin`，同时新增按“申万一级行业”分类的 `margin_by_ind` 字典：

```javascript
{
  "meta": { "base": "2026-11-09", "generated": "2026-11-09 15:00" },
  "rules": { ... },
  "margin": {
    "targetYldMode": "dynamic",
    "yldPadPct": 0.5,
    "targetYldFloor": 3.0
  },
  "margin_by_ind": {
    "银行": { "targetYldMode": "fixed", "targetYldFixed": 5.5, "ocfdMin": 0 },
    "公用事业": { "targetYldMode": "dynamic", "yldPadPct": 0.3, "targetYldFloor": 4.0 },
    "交通运输": { "targetYldMode": "dynamic", "yldPadPct": 0.3, "targetYldFloor": 4.0 },
    "家用电器": { "targetYldMode": "dynamic", "yldPadPct": 0.2, "targetYldFloor": 3.0 },
    "医药生物": { "targetYldMode": "dynamic", "yldPadPct": 0.2, "targetYldFloor": 3.0 }
  },
  "targets": [
    { "code": "000001", "name": "平安银行", "ind": "银行", ... },
    { "code": "600461", "name": "洪城环境", "ind": "公用事业", ... }
  ]
}
```

#### 2. 面板逻辑微调（在 `index.html` 的 `_mComputeOne` 函数中）
当面板计算某只股票的安全边际时，先看它的 `industry`（行业）是否在 `margin_by_ind` 中，如果在，就用该行业的参数覆盖全局参数：

```javascript
function getMarginParams(t) {
  const globalParams = CFG.margin || {};
  const indParams = CFG.margin_by_ind && t.ind ? (CFG.margin_by_ind[t.ind] || {}) : {};
  // 行业参数优先，其次全局
  return Object.assign({}, globalParams, indParams);
}

// 在 _mComputeOne 内：
const params = getMarginParams(t);
// ... 后续计算完全沿用 params
```

*(注：如果你的面板目前只传了全局参数，只需要在调用 `_mComputeOne(t, params)` 之前，根据 `t.ind` 把 params 替换掉即可。)*

### 三、 风控系统的“分行业闭环”（最关键）

不同行业用不同的择时标准，**必然带来不同的风控兜底**。由于面板已经支持 `governance` 一票否决，我们可以在数据层补充行业专属的风控字段：

在 `targets` 的每只股票对象里，加入 `risk_type`：

*   **银行类**：面板预警读取 `core_tier1` (核心一级)、`npl` (不良率)、`provision` (拨备率)。如果 `core_tier1 < 9.0` 或 `npl > 1.5`，直接打上红色警告。
*   **公用/交运类**：继续读取 `ocfd2y` 和 `payout2y`（连续两年规则），触发就判定为“透支分红”。
*   **消费/医药类**：面板预警读取 `roe`、`ocf_to_profit` (OCF/净利)。如果 `roe < 8`，触发预警。
