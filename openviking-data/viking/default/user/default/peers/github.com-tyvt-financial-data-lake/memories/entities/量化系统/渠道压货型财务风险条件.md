# 渠道压货型财务风险条件
用户于 2026-11-15 提出的三条纯数据补充筛选条件草案，用于拦截五粮液这类渠道压货型标的；确认前仅为草案，不改变现有筛选结果。

## 条件一：合同负债骤降而营收未同步下滑
- 数据条件：近两个报告期合同负债环比降幅 >15% 且同期单季营收同比 >-20% → 标记剔除
- 逻辑：蓄水池快速放水而利润表仍撑住，说明收入靠消耗渠道预付款确认，非真实动销

## 条件二：单季净利同比断崖
- 数据条件：最近一个季报单季净利同比 <-30% → 暂停入选资格，等下一期数据恢复再议
- 理由：底仓不需要在业绩剧烈波动时赌其没事

## 条件三：收现比恶化（可选）
- 数据条件：近两个报告期收现比 <0.9 且营收同比未同步大幅下滑 → 标记
- 收现比 = 销售商品收到现金 ÷ 营收；白酒健康收现比应 ≥1.1；若数据湖无销售收现科目，前两条已够用

## 实施约束
- 只使用数据湖已有科目，不额外引入新数据源
- 所需科目、报告期或计算基数不合格时跳过且不标记
- 「剔除 / 暂停 / 标记」三种效果不可混为一谈
- 截至 2026-11-15，条件②（单季净利同比）已在两份筛选脚本中落地为暂停+自动恢复，两脚本各自输出独立观察池；条件①③因合同负债、销售收现无对应科目仅注明不可计算
