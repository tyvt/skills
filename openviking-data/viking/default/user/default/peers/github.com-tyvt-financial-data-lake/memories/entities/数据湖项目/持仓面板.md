# 持仓面板
数据湖项目「分析产出/持仓面板」下的静态 HTML 持仓监控面板，用于红利底仓的买入推荐与风险预警。

## 功能定位
- 展示持仓/待建仓标的的买入推荐、占比、风险预警
- 原买入逻辑基于 vwap60（60 日均价）折溢价与 skip_premium 过滤
- 2026-11-06 升级后新增三列安全边际指标，vwap60 降级为无指标时的兜底

## 文件结构
- index.html：面板主页面与买入推荐表渲染（9 列）
- config.js：面板配置，含 margin 参数块
- _selftest.js：自测脚本，13 项指标单测 exit 0 通过
- panel_margin_metrics.js / .json：数据脚本生成的指标
- README.md：使用说明

## 数据关联
- 生成脚本：分析产出/panel_margin_metrics.py
- 数据源：数据湖 duckdb 的 daily_bars_adj、corporate_actions

## 配置要点
- config.js 的 margin 参数块中固定股息率阈值 `targetYld`/`targetYldFixed`/`targetYldFloor` 与华润三九 `targetYldRef` 均为 4.8%
- index.html 无 `margin.targetYld` 时回退默认 4.8；安全边际 localStorage 缓存键为 `panel_margin_v3`
