
# 持仓面板
数据湖项目「分析产出/持仓面板」下的静态 HTML 持仓监控面板，用于红利底仓的买入推荐与风险预警。

## 功能定位
- 面板含 renderAlerts 风险预警与 buildPlan 买入推荐两套逻辑
- 当前买入逻辑基于股息率安全边际（margin），支持分行业覆盖参数 margin_by_ind 与行业专属风控 risk_type
- 原买入逻辑基于 vwap60（60 日均价）折溢价与 skip_premium 过滤；2026-11-06 升级后新增三列安全边际指标，vwap60 降级为兜底

## 矛盾根因与修复（2026-11-09）
- 原矛盾：renderAlerts 占比分母用已投入市值 T.mv（约4.4万），buildPlan 用总本金 total_capital（10万）
- 未建满仓时每只都被预警判超配卖出，同时买入侧都还有额度，导致买卖信号自相矛盾（如兴蓉环境被同时提示超配卖出又被推荐买入）
- 修复：新增 capitalBase(T)=Math.max(total_capital, T.mv)，预警单只/行业/权重偏离统一改用该口径与买入对齐
- 修复：新增 recentTradeMap() 近期交易互斥护栏（rules.recent_trade_days 默认3天）
- 护栏规则：预警不催刚买入的卖出、不催刚卖出的补仓；买入不推荐刚卖出的买回、今日已买不重复建仓
- 改自测 _selftest.js 新增11条用例全量通过；分支 fix/panel-split-base-guard 已 ff 合并入 main，commit a0a8e508

## 文件结构
- index.html：面板主页面与买入推荐表渲染（9 列）；getMarginParams(t) 行业参数优先、_mThresh 行业感知、indRiskFlags 进一票否决与持仓置顶红条；无 margin.targetYld 时回退默认 4.8
- config.js：面板配置，含 margin（全局）与 margin_by_ind（13 个申万一级行业覆盖）；由 final_portfolio_v3.py 生成；缓存键 panel_margin_v4
- _selftest.js：自测脚本（曾因 CRLF 致主脚本正则失配、测试 #25 写死 fixed 差异检测）；现含矩阵断言
- panel_margin_metrics.js / .json：数据脚本生成的指标
- README.md：使用说明
- holding.sqlite：本地账户/流水/分红持久数据，面板运行时以库内 cfg 为准

## 数据关联
- 生成脚本：分析产出/panel_margin_metrics.py、final_portfolio_v3.py（生成源，重跑覆盖 config.js）
- 数据源：数据湖 duckdb 的 daily_bars_adj、corporate_actions

## 配置要点
- 全局 margin 默认：targetYldMode=dynamic、yldPadPct=0.5、targetYldFloor=3.0（原 4.8/1.0）
- 动态公式：目标股息率 = max(targetYldFloor, 近3年股息率均值 + yldPadPct)
- targetYld: 4.8 仅保留为参考值，dynamic 下不参与计算；targetYldFixed 已移除
- margin_by_ind 按申万一级行业覆盖：银行/非银金融 fixed 5.5%（ocfdMin=0）；公用事业/交通运输/环保 dynamic 垫0.3 下限3.0%；家用电器/食品饮料/医药生物 dynamic 垫0.2 下限3.0%；周期 fixed 8.0%
- 面板运行时以 holding.sqlite 库内 cfg 为准，需与 config.js 同步（「设置 → 从 config.js 同步」）；不同步等于没改
- configStale() 比对矩阵、行业标签、risk_type
