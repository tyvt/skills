# 筛选标准_最终版.md
沪深选股的正式筛选标准文档，位于 D:/repository/数据湖/分析产出/。

## Description
- 记录沪深选股准入条件、筛选条件说明与漏斗口径，是脚本对齐的正式真相源
- 2026-11-14 在第 104–114 行补充银行专项股息率门槛：近三年平均股息率 yld3 须严格大于 5%
- 明确该门槛使用严格大于比较，缺失或无效股息率按不通过处理
- 2026-11-14 股息率口径核对：沪市要求三年均值 >3.5%，另有「当前股息率÷三年均值<2」但无当前股息率下限；深市同为三年均值 >3.5%、无当前股息率下限；文档中仍保留深市当前股息率 >2.5% 的旧表述，与脚本口径不一致
