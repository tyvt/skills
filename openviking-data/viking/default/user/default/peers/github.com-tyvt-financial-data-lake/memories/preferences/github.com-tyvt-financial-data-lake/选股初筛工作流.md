- 选股筛选时优先只跑零/低计算量条件（上市年限、股息率、连续分红等取数成本低者）做初筛看候选池，再决定是否继续跑低波复权、财务取数、治理等重计算关卡
- 明确要求「不要大计算量」时，仅执行廉价过滤，不碰复权收益波动率、财报取数、外抓治理等昂贵步骤
- 对选股筛选设硬约束：低波/财务/支付率等单轮筛选耗时必须 ≤2 分钟，超过则不可接受
