# 数据湖
用户维护的 A 股金融数据湖项目，仓库路径 D:epository\数据湖，远程 origin/main。

## 数据结构
- consolidated DB：data/cnequity/duckdb/cnequity.duckdb
- daily_bars / daily_bars_adj：前复权 qfq_close，2016→2026-11-05 全量
- corporate_actions：现金分红历史齐全
- valuation_metrics：PE/PB 日度表，但整表为空（0 行），无法算 PE/PB 分位
- instruments：代码带交易所后缀（如 300643.SZ）

## 工作状态
- 仓库长期存在 7000+ parquet 未提交改动（数据湖本身脏状态，非本次产物）
- holding.sqlite 为用户早前未提交改动，非面板改造产物
