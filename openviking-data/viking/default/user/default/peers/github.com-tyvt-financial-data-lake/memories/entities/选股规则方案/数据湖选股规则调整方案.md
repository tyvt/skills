# 数据湖选股规则调整方案
2026-11-15 审阅并修订的数据湖选股规则重组方案，核心是待决规则风险标注与渠道压货识别三条件分级。

## 规则结构
- ③连续三年净利正增长、⑩CAGR>3% 列为待决规则，保持现行适用范围，草案不启用、不改结果。
- 需注明这两条对公用/交运类低波底仓存在结构性误伤可能，待决期间不改变适用，复核时优先看这类标的。

## 渠道压货三条件
- 主条件②：单季净利同比 < −30%，最简单可靠，优先实现。
- 辅条件①：合同负债环比 > 15% 且营收同比 > −20%，逻辑更强但依赖合同负债科目覆盖。
- 可选增强③：收现比，依赖“销售商品收到现金”科目。
- 三者不同权重并列，否则科目缺失时易误判为“无风险”；缺科目时条件①降级为仅标记不剔除。

## 恢复机制
- 暂停期内标的不进入组合、不占名额，但保留在观察池。
- 连续两期单季净利同比均 ≥ −30% 后自动回归候选，无需人工重新审批。

## 数据与验证
- 截至 2026-11-15，两份筛选脚本均已按单季净利同比执行暂停与自动恢复，并各自输出独立观察池；脚本目前只读 net_profit / net_profit_yoy，未读营收、合同负债、销售收现科目。
- 五粮液 2025Q3 单季净利同比 −68.4931%，在两条脚本路径上均算出该值并触发暂停；合同负债与销售收现因无对应科目，只在规则中注明不可计算，不用经营现金流替代。
- 合同负债环比需季节性校正：降幅同时高于过去三年同期环比降幅中位数，或标注季节性行业人工复核。
- 验证保持窄范围，不重跑正式选股组合；截至 2026-11-15 仍在做两条脚本的差异与文档一致性核对，未运行正式选股或组合生成。
- 2026-11-15 规则重组已落地：基础池、连续分红、股息率双门槛与治理准入集中在《筛选标准_最终版.md》定义，沪深专项条件分列，并标注公用/交运低波标的复核优先级；改动随本地提交 e2fd61c2 落库，尚未推送。
