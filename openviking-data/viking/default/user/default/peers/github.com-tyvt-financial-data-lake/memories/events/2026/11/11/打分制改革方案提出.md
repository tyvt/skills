你现在的系统用的是**“一票否决制”**：只要现价没有跌破“目标买价”，哪怕差 1 分钱，系统都不让你买。再加上池子只有 9 只股票（深市甚至只有 2 只），很容易出现“一直等不到极端低价，导致仓位永远建不满”的窘境。

要彻底解决这个问题，我们需要把系统从**“硬性门槛过滤”**升级为**“池子扩容 + 综合打分”**。下面是具体方案：

---

### 核心改革一：池子从 9 只扩大到 20~30 只（宽进严出）
不要只盯着现在的 9 只。当你限制了“单票不超过 25%”、“行业不超过 35%”时，9 只股票是绝对不够轮动的。
**做法**：让选股脚本（`final_portfolio_v3.py`）放宽条件（比如入选线降回 3%），筛选出 **20 只以上的“候选池”**，但**不要给它们固定权重**（或者只给上限）。
只有池子足够大，你才能在里面挑“当前价格最便宜、综合分最高”的股票去买。

### 核心改革二：引入“双轨打分制”（基本面分 + 价格分）
现在的面板逻辑是“价格不达标直接踢出”。新逻辑应该是：**只要基本面不暴雷，都可以留下来算个分，谁分高买谁。**

我们定义每只股票的总分 = **基本面分（60分） + 价格分（40分）**。

#### 1. 基本面分（满分 60）—— 决定“好公司”
这部分基于你的宪法硬指标：
*   **绝对股息率（20分）**：>5% 得20分，4-5% 得15分，3-4% 得10分。
*   **现金流安全垫（15分）**：OCF/分红 > 2 得15分，1-2 得10分，<1 直接 0 分（甚至一票否决）。
*   **波动率（15分）**：<18% 得15分，18-22% 得10分，22-25% 得5分。
*   **治理加分（10分）**：中央国企 10分，地方国企 8分。

#### 2. 价格分（满分 40）—— 决定“好价格”
这里不再死磕“目标买价”，而是看**距离目标的折溢价率**：
*   **距目标价折价率（25分）**：
    *   现价 ≤ 目标买价：得 25 分（说明有安全垫，直接达标）。
    *   比目标价高 0~5%：得 15 分（可容忍的微小高估）。
    *   比目标价高 5~10%：得 5 分（偏贵，作为备胎）。
    *   比目标价高 >10%：得 0 分（太贵，短期不看）。
*   **股息率历史分位（15分）**：≥80% 得 15 分，60-80% 得 10 分，40-60% 得 5 分，<40% 得 0 分。

### 核心改革三：放弃“死等极端低价”，改为“分批网格建仓”
如果你算出来一只股票基本面得 55 分，但价格差了 5%（价格分 15，总分 70），怎么买？
**允许买入底仓的 1/3 或 1/2**。
如果它真跌到了目标买价，再补足剩下的仓位。这样既保证了不会因为差那 5% 永远买不到，又贯彻了“越跌越买”的纪律。

### 💡 这些逻辑如何落地面板（工程实现）

你需要让 Agent 修改面板 `buildPlan` 的核心逻辑，大概改动如下：

**原逻辑（硬门槛）：**
```javascript
if (!r.marginBuy) {
  skipped.push({ r: r, why: '未达股息率目标价' });
  return;
}
// 只有 marginBuy = true 的才进 cands 排序
```

**新逻辑（评分制）：**
1. **取消一票否决**：除了 `governance` 暴雷和 `OCF/分红 < 1` 这种红线直接踢掉，其他全进候选。
2. **算分**：对每只股票算出一个 `TotalScore`。
3. **排序与分配**：
   - 把 `TotalScore > 70` 的挑出来，按分数从高到低排。
   - 如果最高分的股票，价格只比目标价高出 0~5%，**允许它占用本次投入的资金**（甚至可以标记为“提前建仓”）。
   - 如果所有股票的价格分都是 0（都比目标价高出 10% 以上），说明市场太贵，本轮全员不买，闲置资金买逆回购。
4. **强制截断**：为了防止追高，可以加一条硬规则：**价格分 < 10 分的（即溢价超过 10% 的），就算基本面再好，也绝对不允许买。**

### 这样改的好处是什么？

用你截图里的例子来算：
*   **青岛港**：基本面 50 + 价格分 25 = **75分**。（现价 ≤ 目标价，极优资产极优价，**买**）。
*   **平安银行**：基本面 55 + 价格分 15 = **70分**。（现价比目标价高 7%，属于可容忍的波动，如果池子里没有更高分的，**允许分批建底仓**）。
*   **渝农商行**：基本面 50 + 价格分 0 = **50分**。（现价比目标价高 22.9%，价格分0分，基本面再高也不买）。
*   **兴蓉环境**：基本面 40 + 价格分 25 = **65分**。（绝对股息率不高，但胜在正处于安全买点，**买**）。

通过这种打分制度：
1. **你不会永远等不到**：只要基本面足够好，差几个点的价格，系统会让你先建一半底仓，不至于错过整段行情。
2. **你依然有铁律**：如果是差 20% 多的那种（比如渝农商行），系统依然会死死拦住，不让你去接飞刀。
3. **池子必须扩容**：选股端输出 20 只以上的备选，系统每天在这 20 只里算分排序，总会有几个“好公司遇到好价格”的标的跳出来，你就能把仓位建满了。
