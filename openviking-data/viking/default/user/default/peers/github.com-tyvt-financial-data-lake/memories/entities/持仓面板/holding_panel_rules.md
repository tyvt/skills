# 持仓面板执行层规则
面板实际运行的「买入价约束 + 行业分组目标股息率」规则集，定义在面板 README 与 config.js，不属于《筛选标准_最终版.md》§5。

## 规则口径
- 目标股息率：公用交运 dynamic 均值+0.3；消费医药均值+0.2；金融 fixed 5.5%
- 目标价：每股分红 ÷ 目标股息率
- marginBuy：现价 ≤ 目标价 即判定通过（仅为状态标记，不代表已买入）
- 价格分：折价分 < 15（溢价超过 5%）绝对不买，对所有能算出指标的标的统一生效
- max_buys：从 rules.max_buys 读取（默认 3，与 config.js 一致）

## 价格与预算
- 价格门槛：高于目标价 5% 以内按半仓，超过 10% 释放权重（不占用预算）
- 预算按已过价格门槛的候选只数均分，未买成的份额记为留存现金，不回补给已买标的
- 排序：先看低于目标价的幅度，再看配置权重

## 配置与买入分层
- 配置权重（w）是目标权重，不是本次下单指令
- 诊断日志含「本次动作=买入 / 持有不买 / 剔除」列与「成交 / 留存现金」原因
- 面板不再二次筛选：进了面板的标的即视为可买，不再过 buy_list、治理、OCF、支付率、行业红线或总分；这些字段仍在，持仓预警照常显示，但不挡买单

## 买入清单生成
- buy_list 由选股脚本按 score 取前 max_buys 只，先去掉上市不满三年、高于目标买价超过 10% 的（脚本侧剔除，面板不重算）

## 文档归属
- 《筛选标准》§5.4 只管「高于目标买价 10% 不占组合名额」
- §5.5 已写明面板执行层口径以面板 README 为准，不并入筛选标准
