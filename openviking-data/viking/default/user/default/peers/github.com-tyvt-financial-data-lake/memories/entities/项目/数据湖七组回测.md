# 数据湖七组回测
数据湖选股模块将深市原门槛并入沪深共用标准（C1–C7）后重跑的七组分组回测。

## 评估结构
- 七组逐组计算，深沪分别做阶段二候选筛选，两市口径独立；每组给出策略收益与对应基准收益，并汇总平均策略收益、平均基准与平均超额。
- 基准为 PIT 基础池等权收益；`index_bars` 为空，无指数基准。
- 回测跳过治理门与银行专项指标，并按基准日行业快照排除银行，因历史治理与银行监管数据缺少可靠 PIT 版本。

## 2026-11-15 结果（深市共用 C1–C7）
- PIT 回测覆盖 7 个基准日（2025-05-30 至 2025-11-13）；沪市历史样本均为 0 只，深市 0–2 只。
- 七组回测以退出码 0 全部跑完并生成报告；深市 4 组有候选且均跑赢同期深市基础池等权基准，沪市在 7 个基准日均无通过阶段二的候选、收益记 N/A；因叠加原沪市专属条件与阶段二筛选，不代表只用共用门槛时沪市也无候选。
- 最后四个有候选基准日（只数，策略/基准）：2025-08-29 1只（+18.10%/−5.73%）；2025-09-30 2只（+12.17%/−10.69%）；2025-10-31 2只（+14.22%/−23.78%）；2025-11-13 2只（+10.96%/−25.10%）。
- 四组策略算术平均 +13.86%；按上述基准计算，基准均值约 −16.33%，平均超额约 +30.19 个百分点。
- 前三组两市均无候选按口径记 N/A，因此不是七组完整平均；重叠的一年期样本也不能视为独立观测。
- 报告表格、治理/净利暂停说明尚在核对，最终差异检查待完成。
