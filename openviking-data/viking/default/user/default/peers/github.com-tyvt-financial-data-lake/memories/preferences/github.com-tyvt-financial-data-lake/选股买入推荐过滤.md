- 选股买入推荐应排除现价高于目标买价超过 10% 的标的（生成买入清单时即剔除，不再留到面板里再挡）；用户称此类为「好公司但价格太差」，按波动当前季度难有买入可能
- 持仓面板「未买入」行仅展示距买点 10% 以内的标的，超过 10% 的连兜底名单也不出现（面板容忍线已由 15% 改为 10%）
- 数据湖选股模块（final_portfolio_v3.py 等）沪深统一硬性标准：上市不满 3 年、创业板（30x 开头）、科创板（688 开头）的标的在基础池层面直接剔除
- 银行类须单独设门槛：近三年平均股息率严格高于 5%（yld3 > 5%）才可入选，否则无法触发买入条件；该门槛与核心一级资本、不良率、拨备率等原银行专项指标并行，缺失或无效股息率按不通过处理
- 主张沪深两市统一加严股息率门槛：把「三年股息率」与「当前股息率大于 4%」两项标准同时加到沪市和深市
