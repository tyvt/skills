## 复权价口径
- 抽查确认 `qfq_close` 在贵州茅台 2025-06-26 除权日已反映分红，且 `adj_is_exact=true`
- 复权价与原始收盘价价差明显不同，筛选脚本中"qfq 与 close 相等"的注释已过时
- 回测只用 `adj_is_exact=true` 的精确前复权价
- 相关文档注释已同步修正

## 统一口径改动
