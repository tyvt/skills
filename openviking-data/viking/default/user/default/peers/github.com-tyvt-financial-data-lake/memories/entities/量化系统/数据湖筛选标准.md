# 数据湖筛选标准
数据湖选股模块（分析产出/）的最终筛选标准，2026-11-11 由代码 TH 字典与文档双向核对确认。

## 筛选规则
- 核心哲学：统一代码可以，标准绝不统一——沪、深各用一套准入，再统一打分。
- 沪深统一基础池（2026-11-11 新增）：仅主板 A 股（沪剔科创板 688、深剔创业板 30x）、上市满 3 年、剔 ST/退市；适用于 screen_sh.py、screen_sz.py 基础池及初筛探针。
- 沪市准入 11 条（screen_sh.py）：①②连续三年分红且三年均股息率>4%、当前 TTM 股息率>4% 双条件；③三年净利同比为正；④资产负债率<60%（银行豁免）；⑤支付率 30%–80%（公用事业豁免）；⑥⑦⑧ OCF/分红>1、ROE>8%、现金流/净利>80%；⑨⑩⑪近 12 月收益>-20%、净利 CAGR>3%、三年累计分红>10 亿；⑫⑬⑭年化波动<25%、63 日均额≥5000 万、股息率/均值<2 倍。
- 沪市条件成本分级：零/低成本②⑪⑭；中成本③④⑤⑥⑦⑧⑩⑬；高成本⑨⑫。

## 沪深准入细则
- 深市专用 7 条（screen_sz.py）：①主板+满 3 年+剔创业板+剔 ST；②国资/无实控人；③低波<25%；④三年均股息>4% 且当前 TTM>4% 双条件、须连续分红；⑤OCF/分红>1；⑥三年合计支付率<100%；⑦治理须明确通过。
- 沪深统一附加：银行专项核心一级≥9.5%、不良≤1.5%、拨备≥180%（另需近三年平均股息率 yld3>5%）；治理底线个人/家族/民营/外资一票否决。

## 打分与实施
- score=1/√(年化波动×|最大回撤|)；沪取前 5/深取前 3→归一化→沪 60/深 40→单只≤25%、行业≤35%。
- screen_sz.py 拆两道私设门对齐文档 7 条。
- 2026-11-14 基准日重选方案定为沪 2 只、深 3 只：50/50 市场权重，两只沪股合计不得超过 50%（否则单只 25% 上限无法满足），深市三只按现有评分分配；重选脚本保留既有默认值，仅为该基准日增加显式参数。
- 《筛选标准_最终版.md》新增 §2.1、§5.4（目标买价约束）；《深市打新底仓专用标准.md》①与第 7 条同步；py_compile 全通过，改动未提交 git。
