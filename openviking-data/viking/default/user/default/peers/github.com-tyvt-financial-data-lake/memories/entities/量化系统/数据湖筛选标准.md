# 数据湖筛选标准
数据湖选股模块（分析产出/）的最终筛选标准，2026-11-11 由代码 TH 字典与文档双向核对确认。

## 核心哲学
统一代码可以，标准绝不统一——沪、深各用一套准入，再统一打分。

## 沪深统一基础池（2026-11-11 新增）
- 仅主板 A 股（沪剔科创板 688，深剔创业板 30x）、上市满 3 年、剔 ST/退市
- 适用 screen_sh.py、screen_sz.py 基础池及初筛探针

## 沪市准入 11 条（screen_sh.py）
- ①②连续三年分红且三年平均股息率>3.5% ③三年净利同比为正 ④资产负债率<60%（银行豁免）
- ⑤支付率30%–80%（公用事业豁免） ⑥⑦⑧ OCF/分红>1、ROE>8%、现金流/净利>80%
- ⑨⑩⑪近12月收益>-20%、净利CAGR>3%、三年累计分红>10亿
- ⑫⑬⑭年化波动<25%、63日均额≥5000万、股息率/均值<2倍

## 沪市条件成本分级
- 零/低成本：②⑪⑭；中成本：③④⑤⑥⑦⑧⑩⑬；高成本：⑨⑫

## 深市专用 7 条（screen_sz.py）
- ①主板+满3年+剔创业板+剔ST ②国资/无实控人 ③低波<25%
- ④三年均股息>3.5%且连续分红 ⑤OCF/分红>1 ⑥三年合计支付率<100% ⑦治理须明确通过

## 沪深统一附加
- 银行专项：核心一级≥9.5%、不良≤1.5%、拨备≥180%；治理底线：个人/家族/民营/外资一票否决

## 打分与权重
- score=1/√(年化波动×|最大回撤|)；沪取前5/深取前3→归一化→沪60/深40→单只≤25%、行业≤35%
