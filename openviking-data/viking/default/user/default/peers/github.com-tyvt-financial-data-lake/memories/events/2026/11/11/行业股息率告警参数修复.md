### 7. 分行业矩阵的 `yldWarnPct` / `pctYears` **只读全局，未走 `getMarginParams`**

**位置**：`renderAlerts` 安全边际段

```javascript
const YLD_WARN = (CFG && CFG.margin && CFG.margin.yldWarnPct != null) ? +CFG.margin.yldWarnPct : 20;
// ...
esc(r.name) + ' 股息率处近 ' + (CFG && CFG.margin ? CFG.margin.pctYears : 3) + ' 年 ...'
```

**影响**：如果 `margin_by_ind[行业]` 配了不同 `yldWarnPct`/`pctYears`，计算时 `_mComputeOne` 用了行业值（`histYldN`/`yldPct` 按行业 `pctYears` 算），但**提示阈值和文案仍用全局值**——阈值与分位口径错位，可能出现「按行业 5 年算的分位 ≤ 全局 20% 阈值」误报或漏报。

**修复**：`const mp = getMarginParams(r.t); const YLD_WARN = mp.yldWarnPct ?? 20; const yrs = mp.pctYears ?? 3;`。
