# 面板执行规则
持仓面板前端执行规则。

## 规则
- buildPlan 不再做二次筛选：进了面板的标的即视为可买，仅按价格因素（现价相对目标买价）与配置权重执行；高于目标价 5% 以内半仓，超过 10% 释放权重；金额按已过价格门槛候选只数均分，未买成份额记为留存现金
- 买入后单票>25% 或单行业>35%，该行标红「超限跳过」，资金退回不占用（前端最后防线）
