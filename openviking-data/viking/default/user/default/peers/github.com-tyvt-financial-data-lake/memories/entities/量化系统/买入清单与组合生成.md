# 买入清单与组合生成
Python 侧生成买入清单与组合。

## 逻辑
- final_portfolio_v3.py 按 score（波动率倒数）排序，取前 min(3, floor(金额/3000)) 只写 buy_list，max_buys=3（例：投入 10 万最多取前 3 只）
- 永兴股份(601033)走 screen_sh.py 未被深市门槛拦，进沪市池拿环保权重 11.2% 排第三
- 组合按分数取沪市前 5、深市前 3；2026-11-11 改为先剔除现价高于目标买价 10% 的标的再递补，递补后组合 6 只：青岛港25%、农业银行20.80%、湖北能源19.20%、洪城环境14.20%、兴蓉环境12.13%、城发环境8.67%
