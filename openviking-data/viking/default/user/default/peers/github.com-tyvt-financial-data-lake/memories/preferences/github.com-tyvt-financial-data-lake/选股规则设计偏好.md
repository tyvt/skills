- 多条件风控规则要区分主条件、辅条件与可选增强，反对同权重并列，避免科目缺失时误判为“无风险”。
- “待决/暂停”类规则必须写死自动恢复路径：暂停期内保留在观察池、不占组合名额，连续两期满足阈值后自动回归候选，无需人工重新审批。
- 规则复核时优先检查公用/交运类低波底仓等易被结构性误伤的方向。
- 季节性行业指标（如白酒、家电的合同负债环比）需做季节性校正或标注人工复核，防止正常波动误杀。
- 数据缺失时宁可将条件降级为“仅标记不剔除”，不接受用经营现金流等替代科目顶替。
- 规则改动验证偏好窄范围核验（字段与样例命中），不重跑正式选股组合。
