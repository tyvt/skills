- 修改持仓面板或组合文件前必须先通过计划审查（审批门），审查未通过就停在审批门前，不直接改文件。
- 计划审查器卡住（如 120 秒无输出）时，先检查审查任务状态，确认无遗留审查任务后再原样重送同一计划一次。
- 若重送后审查仍卡住，则保留已写好的计划文件并暂停执行，等待审批，不绕过审批强行推进。
- 送审前会先确认编排器能正常列出审查池，作为审查服务可用的判断依据。
