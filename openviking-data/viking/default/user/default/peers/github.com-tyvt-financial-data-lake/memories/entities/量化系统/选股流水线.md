# 选股流水线
数据湖选股模块中从基础池筛选到生成持仓面板最终配置的执行链条。

## 执行顺序
- `screen_sh.py` → `screen_sz.py` → `reselect_portfolio.py` → `打新底仓_成员权重_<BASE>.csv` → `final_portfolio_v3.py` → 最终 HTML + CSV 配置
- `screen_sh.py` 以相对路径写出，须在分析产出目录运行；`screen_sz.py` 已改用绝对路径
- `reselect_portfolio.py` 按 score=1/√(波动率×|最大回撤|) 排名并硬剔除现价高于目标买价超 10% 的标的，产出成员权重 CSV 与 buy_list
- `final_portfolio_v3.py` 硬编码 `BASE='2026-11-06'`，读取 `打新底仓_成员权重_2026-11-06.csv` 生成 8 只最终配置

## 基准日期
- 数据湖最新完整交易日为 2026-11-06（无 11-09/10/11 数据），全量重跑须统一以 2026-11-06 为基准
