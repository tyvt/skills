- 偏好选股规则按「沪深共用标准 + 沪市专项 + 深市专项」分组展示，共用条件只写一次，避免两套标准重复。
- 偏好两市可统一的口径尽量统一，减少仅因历史实现不同而产生的差异。
- 认为「三年累计分红>10 亿」这类规模偏好条件应归为沪市专项，不放入共用标准。
- 认为「连续三年净利同比为正」「三年净利 CAGR>3%」等成长硬筛对公用事业类可能误伤，倾向先观察筛除结果再决定是否豁免，而非一律豁免。
