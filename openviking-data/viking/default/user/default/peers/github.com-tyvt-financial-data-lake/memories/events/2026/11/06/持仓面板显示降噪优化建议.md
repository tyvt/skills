### ✂️ 一、 表格列的“去重与降噪”

**1. “目标买价”列：删掉重复的“(固定4.5%)”**
*   **现状**：`13.54 / 4.5% (固定4.5%)`。这在每一行都重复，极度碍眼。
*   **建议**：表头直接写 `目标买价 (股息率4.5%)`。列内只保留数字 `13.54`。因为你的规则是全局统一的，没必要在每一行强调。

**2. “距买点”列：把“达标”转化为“空间”**
*   **现状**：`达标 +12.8%`。很容易让人以为还要跌 12.8% 才达标。
*   **建议**：既然现价已经低于目标价，直接写 **`可买空间 12.8%`** （或者写 `安全垫 12.8%`）。如果是不达标的，写 `需跌 10.8%`。这比单纯的正负号直观一万倍。

**3. “股息率分位”列：降级为弱化提示**
*   **现状**：平安 `35%位`，青岛港 `97%位`。这容易让你产生错觉：“青岛港都97%分位了，是不是比平安更值得买？” 实际上，按你现在的算法，青岛港的绝对股息率刚好卡在 4.5%，而平安是 5.16%。
*   **建议**：绝对股息率才是王道。把这一列字号缩小，改成灰色（`dim`）。或者只在分位 >80% 时用亮色标出，否则一律灰色。甚至可以直接放到悬浮提示（Tooltip）里。

**4. “布林带”列：看不懂的 8.2% 8.4**
*   **现状**：`10.91 8.2%` 和 `8.44 15.6%`。完全没有表头解释这个百分比是什么意思（应该是距下轨的距离）。
*   **建议**：只保留数值 `10.91`（下轨），如果现价接近或跌破了，标红或标绿提示。不需要那个百分比，它是干扰。

**建议拆分为：**

*   **第二行：为什么买（一句话总结）**
