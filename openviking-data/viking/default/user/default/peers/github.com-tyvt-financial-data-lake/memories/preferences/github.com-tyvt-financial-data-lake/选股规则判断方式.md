- 倾向用纯数据条件判断，明确「不用加人工判断」，不在筛选流程中保留人工裁量环节。
- 优先使用数据湖里已有的会计科目，不额外引入新数据源；某科目不存在时可接受减少条件（如无销售收现科目则收现比条件可省）。
- 期望每条条件配明确动作并区分语义：标记剔除、暂停入选资格、标记，三者不可混用。
- 底仓策略下不接受在业绩剧烈波动时赌标的没事。
