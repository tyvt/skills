- 历史快照类数据必须先按 `date <= base` 过滤，再在过滤结果中选最新版本，不允许先取最新版再判断是否符合公告时点
- 若某标的在指定公告时点没有符合要求的必需财报，则该标的不得入选，不能以其他时点财报替代
- 回测结果中必须显式标明数据缺失情况，不得静默跳过缺失数据
- 结果要区分两种数据缺失情形：单只标的缺必需财报时剔除该标的；整组标的都没有可计算收益时整体标为 N/A，两者不得混为一谈
- 快照去重必须在计划与自检中写明分区键
