- 回测中只使用 `adj_is_exact=true` 的精确前复权价，不用原始收盘价或近似复权价替代
- 深沪历史状态与财报查询统一按 PIT（时点）去重，避免使用未来数据
- 回测输出需要隔离，并排除无时点治理数据与银行数据
- 口径改动放在隔离 worktree 中实现，并保留独立回测入口
- 数据口径调整后同步更新文档注释，避免注释与实际口径不一致
- 银行排除必须按历史时点的证券名称判断，不能用当前证券名称回溯历史
- 股本/财报回退复用调用时传入的基准日，不切换到当天
