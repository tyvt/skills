### 9. 删除分红**不清理再投资生成的买入记录**

**位置**：`saveDiv` 再投资写 `trade`（备注「分红再投资（自动）」）；`delDiv` 只 `DELETE FROM dividend`

**影响**：删分红后，买入记录残留、持仓不变、分红消失——账务凭空多出一笔无来源的买入。无外键、无提示。
