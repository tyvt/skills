# 数据湖选股模块
由 github.com-tyvt-financial-data-lake 维护的沪深选股与回测分析模块，覆盖初筛、组合生成和年度回测。
## 回测口径
- 回测窗口内确认有 1,937,181 条精确前复权记录。
- 收益直接比较 `qfq_close`，避免现金分红、送转或配股重复计入。
- 选七个基准日分别做独立回测。
- 回测入口已于 2026-11-15 写好，语法检查与公式自检均通过。
- 上海样本同时套用上海专项与阶段二流动性条件。
## 筛选脚本
- `screen_sh.py` 与 `screen_sz.py` 已完成首轮实现（2026-11-15）。
## 数据完整性
- 采用明确的 PIT 去重顺序。
- 回测前后执行文件哈希保护，治理缓存的湖内快照也纳入前后哈希对比。
- 股本/财报回退复用调用时传入的基准日，不切换到当天。
- 银行排除按历史时点的证券名称判断，不能用当前名称回溯历史。
