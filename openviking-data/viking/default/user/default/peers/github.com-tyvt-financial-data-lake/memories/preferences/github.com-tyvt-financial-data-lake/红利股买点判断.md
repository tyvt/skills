- 围绕「红利收息 + 打新底仓」的低波红利底仓，主张把买点判断从看均线切换到看「这个价格每年能分多少股息」。
- 判断红利股买点更看重股息率带来的安全边际，而非 60 日均线；认为均线只是趋势与成本指标，无法反映估值高低和分红安全垫。
- 偏好用股息率绝对阈值定目标买价：目标买入价 = 预期每股分红 ÷ 目标股息率，现价低于目标买价即视为达标可买。
- 偏好用近 3 年股息率历史分位（分位越高越便宜）和布林带下轨作为辅助买点信号。
- 对低波红利底仓认为「股息率绝对阈值 + 分批网格」最实用；资金未到位时主张先买逆回购等待。
