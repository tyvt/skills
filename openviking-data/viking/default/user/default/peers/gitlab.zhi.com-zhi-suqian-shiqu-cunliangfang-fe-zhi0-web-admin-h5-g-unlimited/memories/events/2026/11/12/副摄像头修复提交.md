## 真正根因（已用厂商官方 demo 证实）

你打开的 `indexDouble.html` 是**厂商 SDK 自带示例页**——它的第二个摄像头（副头）**同样没画面**，必须手动点「打开副视频」才有图。对照它源码看到：
- `html_loaded("faceDetect_two")` 只是初始化控件，**不会自动打开副摄像头视频流**；
- 真正让副头出图的是 `dialog.devChanged("subDev_:<副头设备名>")`（就是「打开副视频」按钮干的事），之后才会推送 `send_subImgData` 帧。

我们之前的 Vue 代码只调了 `html_loaded` + `closePriVideo`，**从来没调 `devChanged("subDev_:...")`**，所以在这台机器的客户端上副头根本不推帧 → 人证比对/视频签字副画面空白、loading 卡死。别的机器能出图是因为其客户端版本行为不同（机型差异）。

> 这也解释了为什么我先前的"撤遮罩"修复只是让界面不卡，但副头画面仍空——因为流根本没被打开。

## 修复（提交 3965a593，已推送）

在 `sendPrintInfo` 监听到设备回 `subDevName:USB Camera RGB` 后，主动调用 `devChanged("subDev_:" + 副头设备名)` 打开副视频流（完全对齐官方示例）。两个组件同步修改：
