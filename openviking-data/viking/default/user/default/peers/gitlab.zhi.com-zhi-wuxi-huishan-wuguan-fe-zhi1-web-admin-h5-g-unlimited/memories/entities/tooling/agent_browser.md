# agent-browser
Browser automation skill used for on-machine reproduction and read-only evidence gathering in web projects.

## Usage
- Load the skill reference docs by grepping exact known paths before running; first-time channel probing for known precise reference paths is exempt.
- Untrusted or self-signed certificates make navigation fail; relaunch with the `--ignore-https-errors` parameter to proceed.
- Used on 2026-11-24 for read-only reproduction of task 2768 (Huishan maintenance fund voting URL) on https://180.101.184.99:8280.
