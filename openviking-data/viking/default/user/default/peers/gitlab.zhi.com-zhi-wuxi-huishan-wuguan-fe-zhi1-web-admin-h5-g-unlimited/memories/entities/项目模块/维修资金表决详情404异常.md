# 维修资金表决详情页 404 异常（禅道 task 2769）
惠山物管 V1 前端在「预算备案申请-发起表决」后跳转「维修资金表决详情」页弹出「系统接口404异常」的缺陷。

## 现象与定位
- 触发接口：`GET /prod-api/estate/onlineDecisionProperty/hasOnlineDecisionPush?propertyProjectId=287` 返回 404
- 链路：`ownerDecision/detail.vue:828` watch `form.propertyProjectId`（immediate）→ `isDisabled()`（调用点 :1045）
- 前端 API 定义 `src/api/estate/ownerDecision.js:12-18`，由 2023-10-23 提交 7493fb17c「任务24438 增加在线决策小区清单功能」引入
- 404 弹窗是 axios 拦截器对真实 HTTP 404 的格式化（`src/request/index.js:250`），非前端文案问题

## 根因
- 该接口唯一实现为太仓物管后端 dev 分支 `TMfOnlineDecisionPropertyController.java:82`（2023-10-23 task#2215）
- 惠山生产后端 180.101.184.99:8280 未包含该接口，estate-manage 等 11 个候选仓全历史亦无，故惠山必然 404
- 接口用途：`detail.vue:429`「推送业主在线表决」单选框（onlineVote）已推送过则禁用，防重复推送；404 时 `voteDiasbled` 恒为 false，防护从未生效
