|---|---|---|
| `22` | 涟水县 | **淮阴区** |
| `25` | 未识别 | **涟水县** |
| `50` | 涟水县 | 删除（无依据） |
| 26、23、27 | 盱眙、淮安区、金湖 | 保持不变 |
