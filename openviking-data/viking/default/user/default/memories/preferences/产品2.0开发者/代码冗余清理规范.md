- 在 Vue 页面整理时，只删除冗余代码、不改动既有行为。
- 移除重复混入的 mixin（如 detailMixins 已含 area 时不再重复引入 area）。
- 删除 data 中与 mixin 已声明重复的字段（如 form mixin 已声明 originForm 时本页不再重复写）。
- 移除对不含 visible 字段的数组做恒为全保留的 .filter(visible=>...) 调用，直接返回数组。
- 保留覆盖 mixin 默认值的本页字段（如 currentRegionCode、currentSubdistrictCode 覆盖 area 里的 regionCode、subdistrictCode）。
