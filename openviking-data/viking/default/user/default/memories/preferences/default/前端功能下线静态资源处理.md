- 移除前端功能时只删代码与样式，保留静态资源文件（如 public/assets/images/ 下的 svg），等确认全仓（后端配置 + 各端）无引用再单独清理
- 静态资源路径由后端配置动态拼接（统一走 img() 助手），编译期无法校验引用，删掉会让其他端 404 且本页面测试看不出
- 删除功能后全仓搜索确认无残留引用，并 npm run build 验证产物不含相关 class
- 用 nginx 部署站点（非 dev server）跑 Playwright 验证全链路
- 汇报时把「保留的静态文件及其理由」写清楚，避免后人以为漏删
