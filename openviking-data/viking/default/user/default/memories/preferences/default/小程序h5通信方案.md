- 小程序与 H5 双向通信场景，倾向以后端中转作为可靠业务主链路（可追踪、可重试、可审计、端间解耦），轮询作为短期过渡方案。
- 登录结果等必须可靠到达的场景优先后端中转；wx.miniProgram.postMessage + web-view @message 为官方低成本方案但非强实时，URL 参数仅适合小程序到 H5 初始化，wx.miniProgram.navigateBack + 页面栈参数/全局状态偏流程式，WebSocket（经后端）强实时但服务端复杂度更高。
