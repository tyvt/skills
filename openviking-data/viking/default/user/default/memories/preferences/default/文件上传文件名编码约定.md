- 使用 `FormData.append('file', file, fileName)` 时，第三参数 `fileName` 需为 `encodeURIComponent(file.name)`，使 multipart 请求中的文件名为 URL 编码形式（如 `%E6%88%BF...`）。
- 仅传 `FormData.append('file', file)` 未指定第三参数时，浏览器会用自带 `file.name`，中文文件名不会被编码。
- 服务端从 multipart 取到的文件名将是编码后的字符串，若业务需展示或落库原始中文，后端需对文件名做一次 `decodeURIComponent`，或与现有约定保持一致。
- 若 Spring 等框架已按 `filename*` 规则解析，需与后端确认是否采用此写法。
