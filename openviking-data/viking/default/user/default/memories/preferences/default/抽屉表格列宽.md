- 抽屉内列较多时表格压缩弹性列宽会导致「单据编号」「合同编号」表头换行，习惯为这些列设固定 width="110" 避免挤压，内容过长仍显省略号。
- 示例：assetLease.vue 的「单据编号」列与 leaseContract.vue 的「合同编号」列均设 width="110" 固定宽度。
