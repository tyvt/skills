- 处理新禅道（http://zentao-biz.zhi.com）中 type=task 的任务工单时，不能只在 zt_action 里留 comment/备注就算完成。
- 完成一个禅道任务工单必须同时做到三件事：①把任务状态改为已完成（finished/closed）；②填写实际消耗工时（consumed）；③把任务指派给创建人（openedBy）。
- 该规范适用于禅道「任务」类工单，是对「只备注不落地」做法的纠正。
- 禅道的查询与回写统一走 MCP dbx，连接名使用「新禅道」；老禅道库禁止写入。
