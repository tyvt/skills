- 子路径（如 `/test/`、`/sz/`）部署时，网络图片/附件路径须通过 `resolveServerAssetUrl` 按当前页面地址解析，禁止写死子路径或仅用 `window.location.origin + path`
- `resolvePublicAssetUrl` 应改为调用 `resolveServerAssetUrl`（内部用 `new URL(relative, window.location.href)`），自动适配任意子路径
- 批量导入错误文件下载等场景的原生 `window.location.origin + path` 写法需替换为 `resolveServerAssetUrl`，避免丢失子路径前缀
