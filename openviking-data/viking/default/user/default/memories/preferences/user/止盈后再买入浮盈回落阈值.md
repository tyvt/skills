- 止盈后再买入须等该标的浮盈回落到约定阈值（如 30%）才放开，避免止盈后立刻追高重复建仓
- 组合再平衡由用户手动执行，不在系统自动再平衡
- 实现或改回测时须与「只买不卖」的买入回测脚本区分，写在完整交易回测与 README 策略约束中
