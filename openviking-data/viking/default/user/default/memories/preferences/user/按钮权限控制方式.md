- 列表页操作按钮（新增、删除等）的显隐由权限字符控制，而不是写死 `permission: true` 或加端别门控
- 权限字符按 `moduleName:businessName:action` 规则命名，例如巡查记录页为 `electrocar:patrol:add`、`electrocar:patrol:delete`
- 期望拥有 `*:*:*` 的超管不被额外的前端门控挡住按钮
