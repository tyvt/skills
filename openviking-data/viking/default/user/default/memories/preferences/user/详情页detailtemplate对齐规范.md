- 详情页 DetailTemplate 对齐规范：垂直居中（标签与值同一行内垂直居中）+ 横向左对齐（标签、文本、金额等均左对齐）。
- 带「延期」按钮时，文字在左、按钮在右。
- 「通知书金额」「通知书有效日期」不应单独居中，应与同行其他字段（如「是否有合同」标签、「缴款单位」）一致。
