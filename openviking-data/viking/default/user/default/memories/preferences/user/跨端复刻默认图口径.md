- 跨端改默认图时，默认素材的权威源是 Android 原生工程同名资源（如 icon_header.png），以它为基准替换，不自行找图
- 小程序分包结构下同一 default-avatar.png 在各分包 static 下各有物理副本，须用 grep 引用路径 + 按 basename 全仓搜索两条线枚举所有副本并全部替换
- 每次改默认图都要顺带做一次冗余副本清理（删除主包与重复副本），否则下一次改图还会漏
- 近名字资源必须隔离判断：如 default-avatar-gary.png（灰色剪影，用于未登录/门卫端）不是同一文件，不替换不删除
- 同步改引用代码：页面改指新路径，utils/index.js 从分包映射移除已不存在的文件，否则映射表指向不存在文件
- 改完必须重新构建，dist 里仍是旧产物，不重建等于没改
