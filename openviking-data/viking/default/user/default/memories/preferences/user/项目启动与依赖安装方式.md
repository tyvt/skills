- 保持 npm install 装依赖，不强制使用 bun install；本机有 bun 的人可直接 bun run dev 运行项目
- bun run 只解析 node_modules，与 lockfile 无关，npm 装的 node_modules（含 .bin shim）bun 可直接读取
- 安装方式保持单一（npm），只有运行分岔，避免团队混用安装方式导致 node_modules 布局漂移
- 全新克隆无 node_modules 时，npm install 或 bun install 二选一即可；bun install 会生成 bun.lock（已加进 .gitignore）
