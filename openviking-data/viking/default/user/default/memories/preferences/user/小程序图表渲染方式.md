- 工单统计图表不可使用旧版 `<canvas canvas-id>` 与 `ctx.draw()` 渲染，否则导致图表穿屏及工单趋势空白。
- 改用 `<canvas type="2d">` 同层渲染，通过 `fields({node,size})` 查询节点并 dpr 缩放。
- 使用模块级 Promise 队列串行化 init，防止多图表并发串台。
- 辅以 20×100ms 尺寸重试机制。
