- 薄包装方法（如 `goLogin`、`persistPortalUserSnapshot`）增加冗余层级，应移除并在调用处直接内联（如 `onGateConfirm` 直调 `startLoginFlow()`）。
- 重复实名判断宜用 `isPortalVerified()` 替代多处重复判断，避免逻辑散落。
- 未使用工具函数（如 `formatDateYmd`）应删除，净减约25行且保持业务逻辑不变。
- 适用场景：小程序 pages/webview/externalWebview.vue、pages/webview/home.vue 等代码重构。
