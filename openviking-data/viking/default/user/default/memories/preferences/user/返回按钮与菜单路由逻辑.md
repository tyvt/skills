- 不要使用本地菜单配置；「返回」按钮优先走 `query.backUrl`，避免默认去掉 URL 最后一段导致落到空路由。
- 进入表单时带 `backUrl`：审核列表进表单=`backUrl` 为列表 path；项目详情进表单=`backUrl` 为详情 path；保存后 `changeFormState` 保留 query 使 `backUrl` 仍在。
- `limitAdd`/`limitCancel` 使用 `@back="handleOperationBack"` 优先 `query.backUrl`；解除限制无 `backUrl` 时解析 `building/houseLimitAudit/index` 对应列表 path。
- 验证：从审核列表进「新增解除限制」→ 保存 → 点返回，应回到限制审核列表；从项目详情进入应回到该项目详情。
