- 表格中只展示数字（金额/面积）的列，使用 `prop` + `:formatter`，由 zs-table-column 按列标题自动千分位并右对齐，不必再写插槽
- 模板里不要写 `{{ formatters.amountFormatter(...) }}` 这类「只为展示」的插槽写法；`amountFormatter` 仅用于 `formatter`、合计行 `summary` 或 formatter 方法体内
- 仍用插槽且合理保留的情况：可编辑金额（如 `amount-input` / `el-input`）、字典 `dict-tag`、操作列等
- 全库已无「只为展示」的 amountFormatter 插槽写法（预售/维修弹窗等已改为 `:formatter`）
