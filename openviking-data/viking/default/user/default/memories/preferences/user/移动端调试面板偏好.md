- 明确要求用 vConsole 替代 eruda 作为移动端调试面板（小程序/H5 项目）
- 封装 src/utils/vconsole.ts 的 initVConsole() 单例，内部判重避免重复创建，多处入口调用也只一个面板
- src/main.ts 在 H5 环境下根据环境变量或 localStorage 的 devtool 标记初始化 vConsole
- 调试开关按环境分档：development 默认关闭（VITE_APP_VCONSOLE=0），test/production 默认开启（=1）
- 保留隐藏入口：二手房详情页（pages_transaction/stockHouse/detail.vue）连续点击 10 次触发 initVConsole()，方便线上临时调试
- 依赖 eruda 换成 vconsole@3.15.1；环境变量 VITE_APP_ERUDA 重命名为 VITE_APP_VCONSOLE，各 .env（development/test/production）必须同步改名，漏改会导致开关静默失效
- 新增 H5/小程序页面或接入新调试能力时复用 initVConsole 单例与同一套环境变量命名，勿引入第二个调试库或另写开关逻辑
