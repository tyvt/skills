- 交付报告必须四段分开：代码改动（按模块列）、静态检查（ESLint 范围与结果数）、方法级验证（回归脚本与通过数）、真实页面/接口联调（做了什么、证据）

- 单列「未纳入提交的内容」，每条写清排除原因（与本次无关/非我改动/gitignore 产物）及补提方式

- 交付记录落盘到文档（如 docs/frontend/README.md、docs/flood/delivery-*.md），不只留对话
