- 在表格操作列优先使用公共组件 `<zs-operate-column :buttons="buttons" />`，而非手写 `zs-table-column` + `fixed="right"` + `el-button`，以沿用固定列白底样式、避免发证日期等从操作列透出
- `buttons` 计算属性与 `table.js` 里 `viewButton` / `editButton` 保持一致（`type: 'primary'` / `plain: true`，`permission: false`），行为与原先无权限校验一致
- 子表表格增加 `:table-tr` 与同页其他子表列宽计算方式对齐
