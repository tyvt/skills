- 门户 monorepo 安装依赖统一用 `npm install`，不包装 bun install，避免 `bun.lock` 与 `package-lock` 混用导致 node_modules 漂移。
- 运行分岔：本机有 Bun 的成员用 `bun run dev` 加速开发服，无 Bun 的同事继续用 npm/pm 脚本。
- `bun run` 直接解析已有 `node_modules`，不要求先 `bun install`；缺失依赖时报找不到 vite，补一次 `npm install` 即可。
- `bun install` 可选且应 gitignore `bun.lock`；`BUN_RUNTIME=1` 路径（如 `bun --bun run dev`）只依赖 Bun 运行时，与安装方式无关。
- 策略来源：会话 46380d5c，用户要求 bun 启动但团队可回退 node、仅改开发服。
