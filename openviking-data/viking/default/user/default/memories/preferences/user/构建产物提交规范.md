- 每次 build 后若出现 public/version.json 改动，一律 `git checkout -- public/version.json` 还原，不纳入提交
- 同类根目录临时文件（.build-log.txt、.tmp-zentao-*.png、.tmp-zentao-*-resolve.html）用具体路径暂存，绝不 `git add .`
- 只暂存本次真正改动的文件，避免夹带其他会话正在改的文件
- 汇报时明确写「构建产生的 public/version.json 已还原，未夹带提交」，防止下游 CI/发版误取旧哈希
