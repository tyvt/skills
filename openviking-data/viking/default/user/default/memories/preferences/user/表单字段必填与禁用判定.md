- 字段是否必填/禁用以业务口径为准，入口差异用organType/formMode/来源页显式判断，不复制同一套rules
- 放开禁用时同步把rules里对应required去掉，并复查看态与提交载荷是否兼容空值（空值分支有明确展示与后端约定）
- 拿不准的同类情况先问一句再动手，比事后回滚便宜
