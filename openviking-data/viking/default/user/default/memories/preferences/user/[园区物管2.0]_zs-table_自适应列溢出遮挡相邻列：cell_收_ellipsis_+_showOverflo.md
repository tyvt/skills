# [园区物管2.0] zs-table 自适应列溢出遮挡相邻列：cell 收 ellipsis + showOverflowTooltip，500px 封顶即可，无需状态类

什么情况：园区物管2.0（zhi2-web-admin，Element UI + 自研 zs-table）中，zs-table 的「自适应列宽」列在内容超长时会溢出遮挡右侧相邻列（如压住「启用标识」列）。为什么：自适应列的 .cell 沿用 element-ui 的 overflow: visible，内容超过分配宽度后直接溢出渲染，且此前尝试加 contentExceedsMax 状态、双套省略样式类（autoWidthClassName/zs-table-column--ellipsis）、均分时二次封顶等逻辑全是冗余。怎么做：只需两处收口——(1) element-ui.scss 里自适应列 .cell 改 overflow: hidden + text-overflow: ellipsis；(2) zs-table-column.vue 的自适应列开启 showOverflowTooltip: true，悬停看全文。列宽算法本身已有 MAX_COLUMN_WIDTH = 500 上限，封顶后 CSS 省略号自动生效，因此所有 JS 层的「是否超长」状态与样式类都可删除，均分多分到的宽度也不影响省略效果。与已知『窄屏列宽用横滚替代 ellipsis』不同：正常宽度表格走 ellipsis + tooltip，窄屏才走横向滚动。

**验证证据**：会话 db6b694f 最终结论：真正需要的只有 element-ui.scss 的 .cell overflow:hidden+ellipsis 与 zs-table-column 的 showOverflowTooltip:true；删除 contentExceedsMax、autoWidthClassName、canReceiveExtraWidth、二次封顶等冗余后效果不变（≤500px 完整显示，>500px 封顶省略+悬停全文）
