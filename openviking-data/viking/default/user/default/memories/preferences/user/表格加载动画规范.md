- 表格加载动画要求：loading 遮罩只盖住表体，表头始终可见
- 推荐写法：在 `zs-table` 上使用 `:loading="loading"`，不再使用 `v-loading`
- 兼容旧写法：保留 `v-loading="xxx"` 的页面（约 180 个），通过 `MutationObserver` + 布局同步将 `.el-loading-mask` 挪到与表体同宽同高
- 布局变化（窗口缩放、列宽均分、`doLayout` 等）时重新对齐遮罩
- 同一表格不要同时写 `v-loading` 和 `:loading`，否则可能出现两个 spinner
- 涉及文件：`zs-table.vue`、`ListTemplate.js`、`shareholder/index.vue`；所属项目：苏州市房地产监测V3
