- 按设计稿切图入库时，将中文名（如「收入金额.png」）或无语义名（如「切图 6@2x.png」）统一重命名为「语义前缀-含义-尺寸」英文命名（如 metric-income-amount.png、metric-account-count.png、metric-account-balance.png、metric-fund-expenditure.png）。
- 重命名后必须全局同步更新引用（模板 data/mock 配置里按 key 映射的引用点）。
- 同目录若已存在同名用途既有资产（如 metric-card-*@2x.png），核对恢复引用而非再放重复文件。
- 原因：中文文件名在构建环境易出编码/覆盖问题，无语义名在协作时易互相覆盖、引用断链导致缺图。
