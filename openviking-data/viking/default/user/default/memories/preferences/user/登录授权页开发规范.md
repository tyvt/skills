- 新增登录/授权类能力（如微信手机号授权快捷登录）要叠加在原登录页上，禁止另建中间页或替身登录页
- 授权弹窗直接挂在原登录页（如 login/index.vue），进入页面时弹出，「稍后再说」仅关闭弹窗、露出下方原有表单
- 原有验证码登录、账号密码登录、忘记密码一律保留，不做搬迁
- 不新增 sms.vue 之类中间页；若已建则删除页面文件并从 pages.json 移除路由
- 所有入口（全局跳转、我的页等）统一指回原登录页路由（如 /pages_main/login/index）
- 需求文档画成「独立页面」的辅助环节（其他方式登录、方式选择页），默认实现为原页面内弹窗或展开区，先问再拆页
- 用户对「多绕一层」跳转非常敏感，新增页面会带来登录方式被搬迁、多一层跳转、pages.json 多路由等必然后果
