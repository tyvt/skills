- 合同范本跳转优先使用 buildNavigationByFilePath 按文件路径动态查找路由，避免硬编码路由名（如原 gotoContractTemplate 硬编码 ContractTemplate/:type/:tableid 致不可靠）
- 以 pathHint 区分现售/预售，preferDetail 与 routeId 填范本ID，未找到提示无授权
- router.push 增加 .catch 防重复导航报错
