# 图表金额格式化误用取整函数导致 0.几万元显示为 0

什么情况：地图/统计大屏的资金余额、资金收支图表里，某区有 0.22 万元这类小数数据但页面显示为 0（宜兴市有数据没展示）。为什么：图表配置（图例总额、柱顶数值标签、Tooltip、Y 轴刻度）多处调用了 formatWanIntegerValue 这类「四舍五入取整」格式化函数，0.几万被取整成 0，数据丢失表现为「没展示」而不是报错，容易误判为接口或地图区域匹配问题。怎么做：金额/占比类图表格式化一律用保留小数的 formatWanValue（最多两位小数），取整函数只用于确定是整数计数的场景；且四处展示点（图例、标签、tooltip、轴刻度）必须同步换，漏一处就会出现同一数值不同显示。

**验证证据**：会话 dd77c94d：用户反馈宜兴市 fundBalance=0.22 未展示、资金收支 0.几显示为 0；结论为 buildFundIncomeExpenseOption 多处误用 formatWanIntegerValue，统一改为 formatWanValue
