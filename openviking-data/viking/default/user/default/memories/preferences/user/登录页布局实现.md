- 登录卡片高度由右侧表单撑开时，左侧插图默认使用 `object-fit: cover` 铺满左侧列，消除底部留白（可能轻微裁切装饰图边缘）。
- 登录页布局同步使用 `measureLoginFormHeight()` 以表单区域 `scrollHeight` 参与侧栏宽度与 `minHeight` 计算，而非仅按 CSS 最小高度约 500px。
- 使用 `ResizeObserver` 监听表单区域及 `.login-form`，在验证码加载、校验错误等导致内容变高时重新布局。
- 关闭侧图或销毁组件时断开 Observer，避免多余回调。
- 侧图裁切与完整显示的取舍可微调 `object-position` 或宽度计算（铺满优先 vs 完整显示优先）。
