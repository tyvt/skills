- 遇到「统一固定/统一排序/统一列样式」类需求时，先在同模块找一个已做对的页面作为模板，抄其写法，不自造一套。
- 用 grep 或遍历扫描同模块所有列表页，列出「已加/漏加」清单，只补漏项，不扩大改动面。
- 改完跑 `npx eslint` 确认无回归。
- 整列为空的列单独归类，优先判定为接口未返回字段而非前端映射问题，整理成待后端确认的字段清单随禅道备注提交。
- 验收清单落在「本模块还有无别的列表页漏加」上，而非只关掉报上来的单。
