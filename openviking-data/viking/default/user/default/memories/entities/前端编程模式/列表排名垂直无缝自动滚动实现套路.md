# 列表排名垂直无缝自动滚动实现套路
后台大屏榜单列表超出可视区域时的无缝自动滚动实现方案。
## 适用场景
- 后台大屏类页面的排名/榜单列表要求超出可视区域时自动无缝滚动展示
- 项目：园区物管2.0（zhi2-web-admin）
## 实现要点
- 超出才滚：比较列表总高与容器高，仅总高大于容器时复制数据渲染，用 translateY(-50%) 做无缝循环
- 动画时长随条数自适应，约 14s~48s，条数越多越慢
- hover 暂停便于看清某行
- 响应尺寸变化：监听 window.resize 与容器 ResizeObserver，重新判定是否滚动
- 数据更新（watch）后先停滚动再重测高，避免条数变化后状态错乱
