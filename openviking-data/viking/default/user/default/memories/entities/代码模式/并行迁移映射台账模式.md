# 并行迁移映射台账模式
同源复制项目长期新旧契约并存时，需建立字段命名与时序映射台账防止同名不同义静默错查。
## 背景
- 产品2.0 与苏州市房地产监测V3 / 泰兴小程序 / 苏住房G·C 同源复制
- 新旧并行：旧 api/lpgl/ 与新 building/ 视图，状态字段 recordState vs bizState
## 差异焦点
- 资源名单复数、主键缩略写 vs 驼峰语义名
- 列表接口 list vs page 分页
- 状态字段名不同
## 做法
- 迁移前产出对照台账：旧资源名→新资源名、旧主键→新主键、旧列表→新分页、旧状态→新状态
- grep 目录是否仍 import 旧 api 判断迁移进度，不凭目录名
- 写共享归一化/解析函数承接两套形态，页面层不各写一份
- 迁移完成后按台账逐条删旧兼容分支
