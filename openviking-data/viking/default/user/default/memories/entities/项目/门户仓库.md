# 门户仓库
D:\repository\门户 为 npm workspace 单体部署根（nginx→dist），门户 UI 均在 git 子模块 zhi2-web-admin。

## Description
- 父仓为 suzhufang，子模块 zhi2-web-admin 承载门户全部 UI
- 单体部署根通过 nginx 指向 dist 目录

## 技术栈
- Vue 2.7 + Vue Router 3 + Vuex 3
- Vite 5、Sass、UnoCSS
- Element UI（引用 @/utils/element.js）
- ECharts、Playwright E2E

## 首页横幅实现
- 对外首页横幅为静态图 + CSS 过渡（含新闻条），未引入 Swiper
- 操作指引用 driver.js（main.js 全局及 bProjectDialog 等）

## 涉及文件与归属
- 关键文件：zhi2-web-admin/package.json、src/views/home/UnifiedLogin.vue、src/main.js
- 所属项目：门户；代码基线：dfee5a6
