# 数据湖选股模块
数据湖项目中的「分析产出」目录，包含选股数据更新与沪深筛选脚本。

## 关键脚本
- `scripts/update_selection_lake.py` 是数据更新入口，抓取市场、基本面、事件及外部银行/股东数据入湖
- `screen_sh.py` 与 `screen_sz.py` 为筛选脚本，重新生成沪深筛选结果 CSV
- `final_portfolio_v3.py` 构建组合目标 `targets`：`_fill_metrics` 计算各标的指标（含 `payout2y`/`ocfd2y`），`_gov_of` 提供治理映射，`_cfg` 含 `margin`/`rules`/`targets` 字段，并输出 `panel_extra` 路径
- `分析产出/external_lake.py` 含 `configure_proxy()` 配置网络代理
- `cne backfill daily_bars --start <d1> --end <d2>` 可绕开当日盘中保护补历史行情（end<today 时通过）

## 代理与网络
