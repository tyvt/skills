# 智0后台管理H5
zhi0-web-admin-h5-g-unlimited 是用户维护的房管业务 Vue 前端项目，主分支为 develop/v1.0.0。

## 描述
- 仓库名 zhi0-web-admin-h5-g-unlimited，无子模块、无父仓库，上游分支 origin/develop/v1.0.0
- 含存量房产权登记模块，核心业务文件 src/views/stockHouseSys/propertyRegister/propertyRegisterInfo/propertyRegisterInfo.js
- 2026-11-02 修复后本地与远程同步（0/0），工作区仅含业务文件改动

## 业务规则
- 协议号前两位决定区县：22→淮阴区、25→涟水县、26→盱眙、23→淮安区、27→金湖
- 识别不出前缀时回落到涟水县；保存时号码为空则不拼接证号，避免空壳「苏(某年)某区不动产证明第号」
- 证号拼接示例：苏(2026)淮阴区不动产权第0027812号
