# 产品2.0（zhi2-web-admin）
产品2.0 是苏州市房地产监测相关的企业/机构管理前端项目，代码仓库为 zhi2-web-admin，技术栈 Vue 2.7 + Element UI + Vite。

## 企业侧 busCode 编码
- 真实 busCode 以登录后 GET /system/menu/listRouters 返回的 meta.busCode 为准，勿用苏州市房地产监测V3常量或旧版「路由信息.json」（旧 cyjg/* 快照，不含 company/companyManagement/* 与 company/companyRegister/* 新菜单树）。
- 「企业入网审核」≈ 外网注册：busCode=040900、menuId=60000001，列表 company/companyRegister/index、详情 company/companyRegister/detail，审批 /company/info/approval、提交 /company/info/submit。
- 外网注册 Step3 要件上传用 040100（开发企业注册要件），与审核页 040900 不是同一编码，配附件要件必须分开配，否则「配了但传了看不到」。
- 企业信息详情按机构类型分：可审批备案详情 040100（带 approvalApi/submitApi），只读查看详情 0401000（无审批接口）。
- 企业端 toB/companyRecord/detail 执照附件是 8（LICENSE_BUS_CODE），与管理端 040100 无关。

## 机构类型 busCode
- 机构类型 busCode：监理 040200、施工 040300、经纪 040500、物业 040600、设计 040700、招投标 041000、审价 041100、鉴定 041200、维修 041300、工程 041400、供应商 041500、金融 041700。

## 测试命令语义
- 仓库无任何单元测试框架（无 Jest/Vitest/Mocha，无 *.test.* / *.spec.* 文件）。
- npm test 实际是 vite build --mode test（测试环境构建），跑通仅代表构建成功、不验证任何行为；失败应先怀疑构建/环境问题。
- 唯一真实自动化测试是 Playwright E2E：配置 playwright.config.js，用例在 e2e/，npm run test:e2e 自动拉起 dev server(:8081)，另有 test:e2e:ui/flow/real-api/tob 分场景脚本。
- 运行前需按 e2e/.env.e2e.example 建 e2e/.env.e2e，配 PLAYWRIGHT_LOGIN_USER / PLAYWRIGHT_LOGIN_PASSWORD。
