# 苏服办人脸免重复识别机制
无锡H5在苏服办人脸认证后默认5分钟内免重复识别，bdc.vue须同时校验URL与时间戳防残留绕过。

## 机制与实现
- `sfbFaceAuth.js` 中 `markSfbFaceVerified()` 将时间写入持久化键 `sfb_face_verify_session`（localStorage + sessionStorage）
- `isSfbFaceRecentlyVerified(maxAgeMs = 5 * 60 * 1000)` 判断5分钟内有效
- `App.vue` 启动 `clearStaleSfbFaceState()` 清理过期记录；改时长需同步默认 maxAge 与清理阈值

## 生效点
- `pages/face/bdc.vue` 进入不动产授权：`verifyResult === 'true'` 且 `isSfbFaceRecentlyVerified()` 才放行，否则 `redirectToFaceVerify`
- 支付宝扫脸中断约10分钟 pending 恢复，与免识别非同一机制
