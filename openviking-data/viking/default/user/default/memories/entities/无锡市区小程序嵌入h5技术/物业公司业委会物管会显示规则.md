# 小区/项目信息页物业公司业委会物管会显示规则
在pages_owner/project/info等小区信息页展示物业公司时，业委会或物管会主体无法获取名称应显示「-」。

## 展示规则
- 物业公司字段取接口companyName
- 当物业主体为业委会或物管会时，后端往往无法给出名称，前端显示「-」
- 不要留空或误展示主体名称

## 实现要点
- 拉取小区/项目详情后按主体类型判断能否展示物业公司，再绑定companyName
- cherry-pick 02959e5→dev_shiqu修改project/info/index.vue
