# 部署看板（运维部署面板）
运维部署面板，用于登记各项目前端环境端口、dist 路径与登录凭据，并对站点做探活。

## 访问与数据
- 面板端口 18098；登记数据存 `registry.sqlite`，凭据以隐私引用存 `env_accounts.secret_ref`，registry 不含明文。
- 登记须填 ASCII key、`port_base`、`dist_root`。
- 无 delete 路由，删除登记只能直改 `registry.sqlite`，须先备份并留审计（2026-11-24 删 prod/local 即如此）。
- 凭据可注入看板内存供后续 reveal；2026-11-24 注入 `deploy_env-huishan-g-dev` 后 reveal 校验通过。

## 生成与探活
- `gen_nginx_sites.ps1` 按 registry 生成站点 conf 到 `env-sites/`，会覆盖所有项目；只改单个站点更稳的是直接改现有 conf。
- `api.py` 处理 upsert，配合 sync/gen 脚本；sync 脚本有 null 数组索引 bug 会中止。
- health 探活依赖看板解析的 listen 端口；2026-11-24 惠山二期G 实际已监听 8120，看板仍显示 `listen_ports:[8119]` 并判 health=down，属端口缓存/解析滞后。

## 惠山二期G 登记
- 2026-11-24 迁移后只剩 dev 槽位 8120（账号 {{ov_privacy:default:viking://~/privacy/credential/deploy_env-huishan-g-dev#/values/username}}）；prod（5777、port_base 5773）与 local（8119）记录已删。
