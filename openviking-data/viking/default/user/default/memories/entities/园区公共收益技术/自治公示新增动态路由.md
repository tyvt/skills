# 自治公示新增动态路由
园区公共收益项目自治公示模块动态菜单路由注册与从业务页发起公示的预填技术约定。

## 路由机制
- 路由不在 `router/index.js` 静态表，由后台菜单经 `permission.js` 的 `filterAsyncRouter` + `loadView` 注册
- 详情/新增共用 `autonomy/publicity/detail.vue`，路由 name 为 `Publicity/:tableid`（新增 `tableid=add`，查看为 publicityId），query 用 `formMode=add|view|edit`

## 发起公示预填
- 业务页推荐：`sessionStorage.setItem('TMP_PUBLICITY', JSON.stringify(业务行数据))` 后跳 `autonomy/publicity/detail` + 'add'
- 列表默认新增可用 listMixins：`${$route.path}/add?formMode=add`

## 关键字段
- `complexName`（同步 complexId/propertyCode/deptId）、`relBusinessCode`（关联 `relBusinessId`）、`publicityType`（字典 `t_mf_publicityType`）
