# 业委会工作人员状态字段分离
园区公共收益项目中，业委会工作人员列表与详情的任职状态、账号启停是两套独立字段与字典。

## 字段与字典
- `status` 表示任职状态，字典 `job_status`（在职/离职等）
- `enable` 表示账号启停，字典 `sys_normal_disable`
- 列表与详情须各展示一列/一项，两字典不可混用

## 禁止事项
- 禁止把两字典都改成同一套
- 禁止 watcher 把 `form.status` 同步到 `form.enable`
- 禁止 `getForm` 把 `enable` 强制设为 `status`
- `detailCallback` 应对 `status`、`enable` 分别转字符串

## 实现与恢复
- 误合并后可用 git 历史（如 eb20ab954、8788d7923）对照恢复
- 结论按历史提交拆字段并移除 status→enable 同步
