# 双表穿梭弹窗箭头布局
园区公共收益楼幢关联房屋双表穿梭弹窗中间箭头偏下问题的 CSS Grid 三行布局方案。

## 问题根因
- 左右双表 + 中间穿梭箭头弹窗，若中间按钮列 flex 相对左侧整块（标题、表格、分页）垂直居中，箭头明显偏下且列宽易失衡

## 推荐布局
- 外层 CSS Grid 固定三行：第1行左右标题；第2行 `1fr | 48px | 1fr` 放左右表格与箭头（箭头仅此行内居中）；第3行左侧分页、右侧等宽占位保持对称
- 左右表格列用 `1fr` 均分，中间按钮列固定约 48px

## 验证与归属
- 验证会话：e54269de（先前箭头相对整块居中偏下，改 CSS Grid 三行后第2行内居中）
- 文件：zhi2-web-admin/src/views/building/building/components/HouseScopeDialog.vue
- 所属项目：园区公共收益；代码基线：94b839a
