# 操作人员行内授权流程
园区公共收益项目从业主体操作人员详情子表操作栏可提供行内授权，写入用户授权模块。

## 交互与权限
- 操作栏增加「授权」按钮，权限 `company:operatorAuth:edit`
- 弹窗选物业管理区域：数据源 `/company/operatorAuthRange/bindSource/page`，多选名称与编号

## 接口与载荷
- 确认后 `POST /company/operatorAuth/authorize`
- 提交 `operatorId`、`companyRecordId`、`operatorAuthRangeList`
- 后端创建/更新用户授权及范围，结果出现在「用户授权」列表
