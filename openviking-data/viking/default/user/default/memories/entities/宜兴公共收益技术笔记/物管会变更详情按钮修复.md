# 物管会变更详情委员信息按钮缺失修复
宜兴公共收益项目（zhi2-web-admin）物管会变更详情页的「委员信息」子表新增/删除按钮不显示，根因是渲染时漏传 `editable` 参数，补传 `:editable="true"` 后修复，与超管权限无关。

## 问题原因
- 子表新增/删除按钮及左侧勾选列的显示条件为 `editable && bizState == '0'`，而 `editable` prop 默认值为 `false`
- `src/views/autonomy/change/property/detail.vue` 第 78 行渲染 `MemberInformationTable` 时只传了 `:form`、`:biz-state`，未传 `:editable`
- 与账号是否超管无关，超管同样看不到按钮

## 修复方案
- 在 `change/property/detail.vue` 第 78 行给子表补 `:editable="true"`（仅一行模板属性）
- 刻意不传 `businessType`：`BUSINESS_TYPE.PROPERTY` 为 `'3'`，传入会过滤掉截图里正常显示的「任职开始/结束日期」两列
- 对照：物管会记录详情页 `record/components/detail.vue:95`、`record/components/directDetail.vue:87` 均显式传 `:editable="true"`
- 业委会/监委会变更页（`change/industry`、`change/supervisory`）保持不传 `editable`，按原设计为只读
