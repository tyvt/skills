# 变更角标空值对比修复
淮安物管 detail-template 的 hasChangeIndicator 在字段「空→有值」时误判无变更，需重写对比逻辑并同步 originInfo 作基准。

## 问题现象
- 企业变更详情中字段从空变为有值（如成立日期 originInfo.foundingDate: null → 变更后 2026-06-30）却不显示变更角标。

## 根因与修复
- 根因一：hasChangeIndicator 在 getChangeBeforeRaw 为 null/undefined 时直接 return false，把「空→有值」误判为无变更。
- 根因二：changeBeforeObject 只等异步 beforeForm，未在详情加载后立刻合并接口已返回的 form.originInfo，对比基准在请求完成前为空或不完整。
- 修复：detail-template.vue 重写 hasChangeIndicator——字段在变更前对象中存在即参与对比，null/undefined 按空值与当前值比；formatDateTime 支持纯日期 YYYY-MM-DD。
- 业务详情（如 companyManagement/components/detail.vue）：changeBeforeObject 同步合并 form.originInfo；setChangeBeforeForm 先写入 originInfo 再异步拉完整备案数据补充。

## 验证与归属
- 与通用「变更角标」记忆互补，侧重空值与 originInfo 时序。
- 验证：会话 d95654c9 根因分析与修复后「成立日期」应显示角标、悬停「原值：（空）」。
