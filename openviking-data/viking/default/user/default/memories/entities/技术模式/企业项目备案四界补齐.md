# 企业项目备案四界补齐
苏州市房地产监测V3 为企业项目备案申请补齐四界能力，并与后端字段 eastAddress/westAddress/southAddress/northAddress 对齐。

## 项目信息表单
- `detail.vue` / `changeDetail.vue` 在「项目坐落」后增加四界-东/西/南/北界表单项（maxlength=256）
- 校验文案与后端 `@NotBlank` 一致
- 查看模式 `DetailTemplate` 同步展示四界；变更页带 `v-tooltip` 对比原值

## 宗地信息表单
- `ParcelDialog.vue` 原「四至范围」fourBounds 改为四个独立字段，新增时通过 projectForm 默认带入项目四界可修改，提交前校验必填
- `ParcelExtractDialog.vue` 保存时带上四界，外部数据无则回退为项目四界
- `ParcelTable.vue` 向两个弹窗传入 `:project-form="form"`

## 使用说明
- 先保存项目基本信息（含四界），再维护宗地（宗地区仅在非 add 且有 projectId 时显示）
- 宗地支持新增与变更
