# 公共组件抽取路径死链
从 pages_main 抽公共组件到 src/components 后编译报 Component is not found，因相对路径引用少一级。
## 现象
- 编译报 Component is not found in path "pages_main/collect/components/collectBtn"
- 伴随 componentPlaceholder 提示，易误导向分包/异步配置
## 根因
- collectBtn 已抽到 @/components/collectBtn/collectBtn.vue，houseCard 改对，但 StockHouse.vue、NewHouse.vue 仍用旧相对路径 ../../collect/components/collectBtn.vue
- 相对路径按引用者自身位置算，组件搬家后所有引用者路径需重算
## 修复做法
- 抽公共组件用 grep 搜组件名全仓排查引用，不能只改报错点名文件
- 公共组件一律用 @/components/xxx/xxx.vue 别名引用，杜绝跨目录相对路径
- 看到 Component is not found 先确认文件是否存在报错路径，再看 componentPlaceholder，不加占位掩盖
## 涉及文件与归属
- 涉及：houseCard.vue、houseMap/components/StockHouse.vue、NewHouse.vue、collectBtn/collectBtn.vue
- 所属项目：苏住房C；来源会话：3ae4dee9-19f6-4db4-8759-c97af7318eb7；代码基线：017efba
