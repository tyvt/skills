# 监管账户开户申请查看态字段展示
淮安物管公共收益「开户申请」详情在查看模式应始终展示银行账号字段，勿被 accountOpenType 隐藏。

## 问题现象
- 公共收益「开户申请」通过普通新增创建后，详情页「管理银行」区块看不到「银行账号」「银行账户名称」，但列表/编辑预期应能查看（尚未回传时可为空）。
- 新增单 accountOpenType 为 '0' 且无账号时，查看页把两字段整块隐藏，易被误判为接口未返回。

## 根因与修复
- benefit/pubRegulatoryAccount/detail.vue 用 showRegulatoryAccountFields 控制展示：查看模式原仅在已填账号或 accountOpenType === '1'（已开户备案）时显示。
- 区分模式：formMode === 'view' 时始终渲染银行账号、银行账户名称（位于「网点联系电话」与「备注」之间）。
- 编辑/新增仍按原 showRegulatoryAccountFields 业务条件控制是否可编辑/是否展示输入项；勿在查看态用「有无账号」反推整块隐藏。

- 验证证据：extracted source=cursor project=淮安物管

- 验收：刷新后打开新增开户申请详情应固定出现银行账号相关行，有值则展示，无值留空而非整块缺失。
