# 用户管理账号类型字段保存修复
苏住房G 项目 zhi2-web-admin 修复系统用户管理详情页历史数据「账号类型」为空时无法保存的问题。

## 问题原因
- 账号类型与用户编码自动生成关联，编辑模式下该字段默认禁用
- 历史数据 accountType 为空时字段仍不可编辑，但校验要求必填，导致无法保存

## 修改内容
- 修改文件：zhi2-web-admin/src/views/system/user/detail.vue
- 核心逻辑：仅当原始数据中账号类型已有值时才禁用；为空时允许编辑
- isAccountTypeDisabled：编辑模式下根据 originForm.accountType 是否为空决定是否禁用
- accountTypeOptions：账号类型为空时使用可选项字典 sys_account_type（非空时用只读展示用的 sys_account_type_all）
- isAccountTypeEmpty：统一判断 null、undefined、空字符串及纯空格
- detailCallback：将 originForm 赋值移到所有表单字段处理完成之后，避免取值不完整
