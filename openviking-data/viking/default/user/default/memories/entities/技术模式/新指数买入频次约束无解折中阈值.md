# 新指数买入频次约束无解折中阈值
为新宽基对齐年度买入占比时，若估值偏低导致双年频次区间无可行解，阈值搜索须记录无解并采用折中参数。

## 触发场景
- 新宽基（如中证1000）对齐 A500/创业板年度买入占比
- 某年历史估值偏低致「双年频次区间」约束无可行解

## 折中方案
- 阈值搜索应记录无解并采用折中参数（例：利差分位≥68%、PE 分位≤67%、距60日低点涨幅≤5.5%）
- 折中参数须写回 backtest 与 report 模块

## 验证与归属
- 验证证据：97f55495 会话：2024≤12% 且 2025 7–12% 下无同时满足组合，故采用折中方案并更新 logs/backtest
- 涉及文件：backtest_buy_signals.py、compare_broad_indices.py、config.py、a500_data.py
- 所属项目：投资推送；来源会话ID：97f55495-c511-45b5-a582-99a1ea8bf103
