# DetailTemplate图片撑高行致垂直空白
在 DetailTemplate 布局中，行内大图片会把整行高度撑高，使同行文字字段垂直居中，从而与前一行之间产生大段垂直空白，该问题与列数无关。

## 现象
- 对比原图（编号21043，2列×6行）与新图（编号21199，3列×4行），3列修复已生效，但测试人员圈出的仍是同类垂直空白。
- 原图圈出左列 `四界-西界` 与 `四界-北界` 之间的空隙；新图圈出 `宗地坐落` 与 `四界-南界` 之间的空隙。
- 两处空白均紧邻「土地出让合同」大图片所在行。
- 原图行距依次为 39→41→45→58→77，逐行递增；新图行距依次为 39→54→70，也递增，递增规律指向带图片的那一行把行高撑高。

## 根因
- 行内大图片把该行高度撑高，同行文字字段被垂直居中，导致与前一行之间出现大段空白。
- 属于行高被图片撑高导致的垂直间距，与列数无关；此前将空白归因于列数并实施3列修复的方向错误。

## 后续动作
- 需核对 DetailTemplate 的真实布局实现，定位行高与垂直居中样式的来源。
