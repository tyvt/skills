# 园区物管表格顶边修复
园区物管2.0 子模块 zhi2-web-admin 中，针对空数据时表格与边框下边距贴合、缺少顶边线的问题，在全局样式补表头顶边。

## Description
- 修复场景：列表卡片内 el-table 数据为空时，表格与边框下边距贴合、表头上方无顶边线。
- 修改文件：src/styles/index.scss 的 `.list-card .el-table` 选择器。

## Fix Detail
- 新增 `border-top: 1px solid #f0f0f0;`，与左右边框颜色一致，表头上方出现一条完整顶边线。
- 底边仍由分页区域或无数据时的 `--bottom-spacing` 单独处理，避免与固定操作列重复。
- 验证页面：pubChangeleadershipAudit（物业变更业委会审计）页面刷新即可见效果。
