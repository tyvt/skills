# 合同撤销详情页查看态修复
苏州市房地产监测V3 的 `commercialHousingSales/presale/contractRevoke/detail.vue` 修复了查看态表单样式异常问题。

## 问题根因
- 查看态仍用整表 `disabled` 的 `zs-input` / `textarea`，撤销原因、备注等呈现异常样式，与截图标注一致

## 修改内容
- 查看态（`formMode == 'view'`）：「基本信息」用 `DetailTemplate` + `contentInfo`；「撤销信息」用 `DetailTemplate` + `revokeContentInfo`（撤销类型用 `tag`，原因/备注用 `textarea` + `DETAIL_COL_FULL`）
- 新增/编辑态：保留原表单，列宽统一为 `FORM_COL_THREE` / `FORM_COL_FULL`，外层增加 `:gutter="24"`
- 写法与同模块换房（`exchangeContract/detail.vue`）、用款撤销（`usemoneyRevoke/detail.vue`）一致
- 在 `form` 初始对象补充 `projectId`、`buildingName`、`roomName` 保证响应式
