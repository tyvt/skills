# 数智页静态稿还原
苏住房防汛C端数智页面通过注入参考稿 DOM 与 Tailwind CSS 实现与设计稿同源还原的做法、关键数值与踩坑。

## 实现方式
- 页面通过参考页运行时导出的 DOM 与 Tailwind CSS 注入实现，字体在 index.html 静态声明；参考稿按 section 拆为 REF_SEC，2026-11-16 仅替换 REF_SEC1（第 4 节卡片，8867→7236 字符），e2e 基准页同步覆盖为 53914 字节
- chips 由动态 regionChipsHtml() 生成（非 REF_SEC0），首项应为「全市数据」（实现曾是「全市」），行尾含纯展示图标「更多」按钮（more_horiz，w-9 h-9 rounded-full）
- 区域顺序（共 11 项，按苏州行政区划补全）：全市数据、张家港市、常熟市、太仓市、昆山市、吴江区、吴中区、相城区、姑苏区、工业园区、高新区；2026-11-09 补全原被「…」折叠隐藏的区，<main> 内边距 pt-16→pt-4 消除顶部留白，末尾「…」省略按钮保留、是否删除待用户确认
- 参考稿关键数值：3,780 / 3,500 / 1,565 / 177、公共收益默认值 1,286.44、满意度占比 6/5/4、14,860；标题由「关键数据指标」改为「关键数据导航」
- 2026-11-11 提交 e7e0b61「feat(data): 数智页按最新设计稿重构,实现全部tab切换与图表」推 origin/dev（7089065..e7e0b61），改 data/index.vue、data/ref-assets.ts、tests/e2e/shuzhi-visual.spec.ts

## 踩坑
- uni-app 根字号 16.64px 需强制 16px、Material Symbols 图标字号易被覆盖、Vue ref 在 uni-app 自定义元素不绑定需改用 getElementById
- 2026-11-16 按新参考稿对齐 100% 还原：主根因是参考稿 main 开标签带 pt-16（64px 顶部内边距），实现侧 buildInnerHtml 漏掉该类导致像素 diff 36%；对齐设计稿应先比对 main 开标签 class
- 满意度占比接口返回带 % 的字符串时 statValue 原样透传（num() 会得 NaN）；新卡「关键数据导航」标签不在 API_STAT_LABELS，属纯静态免 mock
- typecheck 存在既有错误 Ref8443Inspection.vue 的 InspectionType，与数智页改动无关
