# 实盘挂单价与现价偏离根因
live 报告挂单价与现价大幅偏离的根因是调仓日历与筛选参数未对齐建仓日，而非单纯限价档位问题。

## 问题描述
- 报告若按指数年度调样（如1月）沿用放宽参数（如波动率上限固定50%），与用户任意日按现价建仓不一致
- 标的池、波动筛选与下次调仓日与回测曲线均不一致

## 解决方案
- 增加建仓周年调仓模式 `entry_anniversary`：建仓日视为首次调仓并按当日市场动态算筛选阈值
- 下次调仓为次年同月同日后首个交易日；回测用 `--rebalance-mode entry_anniversary` 且 `--start` 等于建仓日
- 收益预期应对齐该模式回测（调仓日收盘价+滑点成交）
- 新增 `DLV_LIVE_REBALANCE_MODE=entry_anniversary`、`--entry-date`；建仓周年波动上限由50%改为按日动态（示例40%）

## 涉及文件
- dividend_lowvol_rotation/report.py、strategy.py、backtest.py
- 所属项目：投资推送
