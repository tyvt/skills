# 楼幢列表空白修复
苏州市房地产监测V3 中楼幢管理列表（buildinginfo/index.vue）在「业务状态」与右侧固定「操作」列之间出现大块空白，已修复。

## 问题原因
- `zs-table` 剩余宽度分配算错：`zs-table-column` 用业务类型注册拉伸列
- Element UI 内部列类型常为 `default`，`getColumnRegistryUid` 原先拼成 `…|text`
- 已注册列被当成「非注册列」再次扣宽度 → 中间列无法撑满 → 固定右侧「操作」列前留白

## 修改要点
- `zs-table.vue`：`getColumnRegistryUid` 先按 `prop|label|` 前缀匹配 `stretchRegistry`，与 `zs-table-column` 注册 uid 对齐；在 `updated` 中调用 `refreshColumnOrderKey()`，自定义列顺序/显隐仍能触发表格重建（无需页面再绑 `:key="tableColumnsKey"`）
- `buildinginfo/index.vue`：去掉多余的 `:key="tableColumnsKey"`；补充 `:table-tr`、`:page-size` 与同项目其它列表页一致

## 验证与归属
- 验证：列应连续铺满，「操作」列紧贴「业务状态」
- 涉及文件：`zs-table.vue`、`buildinginfo/index.vue`
