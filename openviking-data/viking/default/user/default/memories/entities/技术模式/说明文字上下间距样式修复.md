# 说明文字上下间距样式修复
产品2.0 修复收益合同页面说明文字上下间距不一致的问题，统一使用全局样式 `operation-hint`。

## 问题原因
- 说明文字原先只用了内联样式 `padding-top: 10px`，没有设置下边距，导致文字偏下、上下间距不一致

## 修复要点
- 改为与资产租赁合同备案页相同的结构，使用全局样式 `operation-hint`
- 样式：`display: flex` + `align-items: center` 垂直居中，统一 `padding: 0 12px 12px` 和 `line-height: 22px`
