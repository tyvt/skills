# 物业管理区域详情企业管理员可编辑逻辑
苏住房G 项目 property/complex/detail.vue 针对 B 端企业管理员与从业人员的字段可编辑逻辑修复。

## 问题原因
- 原 isDisabled() 返回 this.$store.getters.isBTerminalPractitioner，对所有 B 端用户（含企业管理员）一律禁用关键字段（区域名称、坐落、行政区域），导致企业管理员新增时无法填写必填项。

## 修复内容
- G 端用户、B 端企业管理员：关键字段可编辑。
- B 端从业人员：仅在已绑定物业管理区域时禁用（与 bTerminalProjectMixin 一致）。
- currentProject 自动填充仅对从业人员生效，避免影响企业管理员新增。
- terminalUser.js / user.js 增强企业管理员识别：兼容后端返回 isCompanyAdmin 为 1 或 '1'，避免误判为从业人员。
