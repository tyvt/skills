# 基本信息间距修复
园区公共收益项目修复基本信息与物业用房列表间距缺失及左侧树形面板顶部空白问题。
## 问题原因
- pubHouse/detail.vue 局部样式把全局区块间距覆盖成 0：:deep(.collapse-container + .collapse-container) { margin-top: 0; }。
- RegionTreeLayout.vue 中有 .type-left-toolbar-spacer 占位元素（min-height:32px + margin:5px 0），左侧无内容形成约42px空白。
## 修复内容
- 删除 pubHouse/detail.vue 覆盖样式，恢复 Headline 组件全局间距（相邻区块 margin-top:12px），两区块合计约24px。
- 删除 RegionTreeLayout.vue 占位元素及其样式，该组件被约15个列表页共用，修改全局生效。
