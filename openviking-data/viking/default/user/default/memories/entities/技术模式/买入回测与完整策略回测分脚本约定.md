# 买入回测与完整策略回测分脚本约定
买入择时回测与含卖出规则的完整策略回测必须分脚本，文档须标明是否含卖出，避免策略文档与回测表冲突。

## 脚本分工
- `backtest_buy_signals.py` 验证「买入择时 + 假设长期持有」，默认不跑 README 中的移动止盈/估值卖点
- `backtest_trade_signals.py` 验证含止盈/估值卖出的完整链路
- 两脚本共用数据面板与买入信号，回测产物统一输出到 `output/backtest/`（由 config 的 `BACKTEST_OUTPUT_DIR` 指定）
- `backtest_buy_signals.py` 默认输出 `inception_present.md/html`；`backtest_trade_signals.py` 默认输出 `trade_inception_present.md/html`
- 全量入口 `run_backtest_inception.bat` 依次运行两脚本；`sell_trailing.py` 提供移动止盈/估值卖点，`backtest_metrics.py` 负责指标统计
- `backtest_buy_signals.py` 支持 `--from-inception` 输出 `output/backtest/{年}.md`（买入信号统计与定投收益）
- `backtest_trade_signals.py` 默认 2015 至今按日模拟（买卖波段 vs 持有对比）
- 宽基沪深300/科创50 等信号在 `cn_broad_signal.py`，创业板在 `cyb_signal.py`，价格位置卖点在 `price_position.py`
- 阈值与卖出开关集中在 `config.py`；优化与卖出诊断另有 `optimize_strategy_backtest.py`、`diagnose_sell_issues.py`

## 文档标注要求
- 报告或 README 须明确标注：「仅买入择时」或「含卖出规则」
- `inception_present.md` 卖出次数为 0 时仍可能显示较高收益率，不代表完整策略已回测
