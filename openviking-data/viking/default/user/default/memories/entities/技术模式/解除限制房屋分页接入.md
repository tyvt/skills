# 解除限制房屋分页接入
苏州市房地产监测V3 项目为解除限制详情页「关联房屋详情」子表接入分页接口。

## 问题原因
- limitFormMixin.js 中 useHouseLimitPageForSubTable 排除了解除限制（!this.isCancel），导致 limitCancel.vue 查看态仍用 projectLimit/detail 返回的 houseList 做前端分页，未调用新接口

## 改动说明
- limitFormMixin.js：查看态（formMode === 'view'）统一走服务端分页；解除限制调用 POST /building/houseLimit/pageLimitRemoval，新增限制仍调用 POST /building/houseLimit/page；请求参数为 projectLimitId + pageNum + pageSize；新增 normalizeHouseLimitRemovalLineRow 处理 limitNumbers 数组；查看态「涉及限制条数」优先读主表 involveLimitCount 或接口 summary.limitQty
- limitCancel.vue：查看态子表改为 houseLimitLineData + 服务端分页
