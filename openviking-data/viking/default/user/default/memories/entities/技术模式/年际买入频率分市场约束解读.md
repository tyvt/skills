# 年际买入频率分市场约束解读
对比回测分年买入占比时，须分市场、分约束维度解释，不能统一归为「都在高位」。

## A股约束
- 2022–2023高买入占比与2025–2026 A股宽基近零，优先解释各指数PE（及红利类股息利差）是否高于config分位上限
- 非怀疑阈值写错或策略失效

## 美股约束
- 同一时期美股可能仍频繁触发（如纳指在调整段占比高）
- 若10年期美债利率处历史极高分位（策略常要求≤92%而当前可达~99%），会在PE不贵时仍阻断买入

## 验证与归属
- 验证证据：会话573f590b用户问2022–2024买入多、今年少是否因高位；结论区分A股PE分位卡点与纳指美债分位卡点，纠正「2024已开始降频」时间线
- 涉及文件：logs/backtest/2022.md、logs/backtest/2026.md、config.py、us_index_data.py；所属项目：投资推送；来源会话ID：573f590b-5218-455b-bf77-02dc6bab7443
