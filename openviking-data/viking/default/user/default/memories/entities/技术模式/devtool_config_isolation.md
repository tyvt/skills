# 开发工具配置隔离于点开头目录
当前项目的开发工具配置按名称独立隔离存放在各自以 `.` 开头的目录下。

## 描述
- 当前目录包含 `.cursor`、`.docker`、`.bun`、`.android` 等以 `.` 开头的开发工具配置文件夹
- 各工具配置按名称独立隔离存放，互不混杂
