# 路由 404 全局拦截修复
产品2.0 在 `router/index.js` 全局前置守卫中增加对跳转 `/404` 的拦截与提示，避免渲染 404 页面。

## 实现说明
- `permission.js` 用通配路由 `{ path: '*', redirect: '/404' }` 重定向未匹配地址
- 在 `router.beforeEach` 开头、`handleExternalToken()` 之后增加判断：若 `to.path === '/404'` 弹 `Message.warning('页面未授权或不存在')`

## 跳转逻辑
- 若上一跳有有效匹配且不是 `/404`：`next({ path: from.fullPath, replace: true })` 留在原页并去掉无效跳转痕迹
- 否则（如首次打开非法地址）：`next({ path: '/index', replace: true })` 回首页
- `/404` 路由保留在配置里但实际不再渲染

## 涉及文件
- zhi2-web-admin/src/router/index.js
- zhi2-web-admin/src/store/modules/permission.js
- zhi2-web-admin/src/utils/index.js
