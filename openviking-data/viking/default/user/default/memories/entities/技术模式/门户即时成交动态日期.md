# 门户即时成交动态日期
对外门户商品房/存量房「即时成交信息」弹窗标题统计日需动态取当天，不可写死。

## 解决方案
- 新增 `resolvePortalTradeStatDate()`：默认按本地时区取今天，格式化为标题用的 `（YYYY/MM/DD）`
- `PortalDialogHost` 中 `tradeStatDate` 用 computed，每次渲染刷新
- 若接口返回统计日，可在 `resolvePortalTradeStatDate(apiDate)` 或 Host 内用接口字段覆盖

- 文件：zhi2-web-admin/src/views/home/publicPortal/PortalDialogHost.vue

- 用户要求：「日期改成当天的，动态，不要写死」
- 实现说明与刷新后标题示例确认动态日期生效
