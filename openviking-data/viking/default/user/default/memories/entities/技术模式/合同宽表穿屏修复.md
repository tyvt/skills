# 合同宽表穿屏修复
苏州市房地产监测V3 修复合同网签页买受人（及出卖人）宽表在 800px 版心下的穿屏问题。

## 问题现象
- 买受人/出卖人宽表在 800px 版心下超出屏幕，操作列 fixed="right" 与「联系电话」等列重叠。

## 修复内容
- chapter1.vue 将两张表外包 s16-party-table-wrap，在版心内横向滚动。
- 去掉操作列 fixed="right"，为各数据列设 min-width + show-overflow-tooltip；操作列加 nowrap 容器，三按钮并排不挤乱。
- sz-contract.scss 统一 .s16-party-table-wrap：overflow-x: auto、出卖人表 min-width 1080px、买受人表 min-width 960px。
