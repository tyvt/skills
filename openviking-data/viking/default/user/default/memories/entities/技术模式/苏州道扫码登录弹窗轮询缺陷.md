# 苏州道扫码登录弹窗轮询与回调缺陷
SuzhouDaoQrLoginDialog.vue 在关闭/销毁后仍可能轮询与误触发登录成功的 Code Review 缺陷（代码基线 dfee5a6）。

## CRITICAL 缺陷
- 缺陷①：getQrLoginParam().then 里无条件 startPolling()，弹窗已关仍会 setInterval；应在 then 内校验 visible 或使用 fetchGeneration，仅仍打开时启动轮询
- 缺陷②：stopPolling 仅 clearInterval，无法取消已发出的 scanLogin；关闭/销毁后 then 仍可能 $emit('login-success')
- 应维护 pollSessionId 或递增 generation，stopPolling 时失效旧代次，then 比对通过后再 emit；beforeDestroy 忽略过期回调
