# 外链免密登录缺参数兜底跳账号密码登录
江阴H5 外链免密登录链路中，读不到约定 url 参数时须直接跳转到账号密码登录页，避免页面静默白屏空转。

## 问题现象
- H5 通过带参数链接直接登录（免密/单点入口），链接参数没读到时页面既不报错也不跳转
- 默认状态为「等待参数」，缺参数时既不进登录页也不报错，真实投放或参数被截断才暴露

## 解决方案
- 登录入口先做参数判定：读不到约定 url 参数直接跳账号密码登录页，把缺参数变成明确路径而非静默失败
- 参数判定放在参数解析最前面，不等到换 token 失败才兜底
- 兜底页与正常登录页共用同一组件，不另写一套
- 换接口后必须连带验证兜底路径（换新接口后账号密码登录兜底路径才真正可用）
