# 投资推送按策略类型扩展新指数
投资推送仓库新增指数不依赖单一全局 registry，而是按策略族对齐各自的代码与报告注册方式。

## 策略族注册方式
- 红利族：走 `config.INDICES` + `dividend_data`/`core` + `report -m dividend --index CODE`
- A股宽基：在 `cn_broad_data.CN_BROAD_INDEX_BY_CODE` 增 code，共用 `cn_broad_signal` 与 `generate_cn_broad_report`
- 创业板/美股等：独立 `config.*_INDEX` + 成对 `*_data.py`/`*_signal.py`

## report.py 模块注册
- 需补 `MODULE_*` 常量、`generators` 映射与 `_resolve_modules()` 默认列表
- 接入前全库检索确认代码是否已存在（如恒生科技当时无 HSTECH 实现）

## 验证与归属
- 验证证据：探索会话归纳四类策略表与 report.py 模块注册方式，确认库内无恒生科技相关实现
- 涉及文件：config.py、cn_broad_data.py、report.py
