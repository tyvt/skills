# 预售历史表格修复
苏州市房地产监测V3 中预售许可详情历史表格不显示问题已修复，改动位于 `PermitHistoryPanel.vue`。

## 修复内容
- 新增 `normalizeHistoryRows()` 为每行生成 `_rowKey`（`presalePermitId`→`id`→`applyCode`→`history-${index}`），表格 `row-key` 改为 `_rowKey`，避免空值或重复导致 tbody 不渲染
- 增加 `ref="historyTable"`、`auto-height`、`:show-summary="false"`，数据加载后调用 `doLayout()` 解决 Tab 懒加载高度异常
- 自定义 slot 统一为 `{ scope }` + `scope.row`；新增 `formatPermitNo()`：无 `permitNo` 时显示 `applyCode`；无 `presalePermitId` 时禁用「查看」按钮
