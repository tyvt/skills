# 弹窗关闭残留修复
苏州市房地产监测V3 修复公共组件 `zs-dialog` 中选择弹窗关闭后仍显示的问题。

## 问题原因
- `zs-dialog.vue` 中为 wrapper 写 `display: flex !important` 做垂直居中
- Element UI 的 `el-dialog` 靠 `v-show` 关闭时会写内联 `display: none`
- `!important` 的 `display: flex` 压过内联样式，导致弹窗逻辑关闭但 DOM 仍显示，所有走 `zs-select-dialog` 的页面均受影响

## 修复方案
- 去掉 wrapper（及 compact 内层）上 `display` 的 `!important`，保留 `align-items`/`justify-content` 居中
- 关闭时 `v-show` 的 `display: none` 正常生效，打开时仍用 `display: flex` 居中
- 需硬刷新

## 涉及文件
- `zhi2-web-admin/src/components/zs-dialog/zs-dialog.vue`
- `zhi2-web-admin/src/components/zs-select-dialog/zs-select-dialog-func.vue`
