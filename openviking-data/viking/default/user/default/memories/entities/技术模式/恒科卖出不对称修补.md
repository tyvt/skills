# 恒科卖出不对称修补
恒科买入偏左侧、卖出仅 1 次等不对称时，需在卖出条件增加「现价高于近一年买入成本 +25%」前置。
## 策略规则
- 卖出前置条件：现价高于近一年买入成本 +25%，避免过早卖飞或买卖逻辑失衡
- 买入侧保留「近1年价格位置」作必选/确认条件以控制左侧时间成本
- 阈值变更后按 2021 至今或全窗口跑 backtest_trade_signals 验证买卖次数与波段收益
## 回测示例
- 买入 76、卖出 1、波段 +11.5% vs 仅买 +13.6%
## 验证与归属
- 验证证据：优化表「恒科 卖出时增加价格高于近1年买入成本+25%」
- 涉及文件：hstech_signal.py、config.py、backtest_trade_signals.py
