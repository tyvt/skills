# 从业人员备案详情修复
苏州市房地产监测V3 中 `company/staffManagement/components/detail.vue`（主管端从业人员备案申请与备案详情共用）重写了 `detailMixins` 的 `init()`，导致查看/编辑时未请求详情接口，已在 `init()` 末尾补回 `getDetail()` 调用修复。

## 问题根因
- `detail.vue` 重写了 `detailMixins` 的 `init()`，仅处理新增时从路由带入企业信息
- `formMode === 'view'` 或 `edit`（无 session 草稿）时走 `init()`，本应请求 `/company/personnelRecord/detail`
- 重写后链路断开，Network 中只有 `listAppendixPackage`（要件配置），无 detail

## 修复内容
- 在 `init()` 末尾补回查看/编辑逻辑：存在 `getId()` 时调用 `getDetail()`
- 同源修复企业端 `zhi2-web-admin/src/views/toB/personnelRecord/components/detail.vue`
