# 机构变更双请求模式
苏州市房地产监测V3 的 companyRecordAgency 变更详情 getDetail 串行调两个接口，审核按钮依赖 bizState==1。

## 请求说明
- `/company/companyRecordChange/detail` 变更单填 `form`、算工具栏状态
- `/company/companyRecord/detail` 原备案只写入 `beforeForm` 给变更对比用（无 `originInfo` 时才拉）
- DevTools 里两个请求都可能显示成 `detail`，易误以为覆盖表单

## 审核按钮条件
- `OperationBtnGroup` 里审核组件显示条件为 `bizState == 1`（待审核）
- 操作栏曾直接用变更单上的 `bizState`（已备案=2），导致审核按钮出不来
