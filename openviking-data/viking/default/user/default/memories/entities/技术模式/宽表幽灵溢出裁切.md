# 宽表溢出误判幽灵滚动致列裁切
苏州市房地产监测V3 的 zhi2-web-admin 修复宽表溢出误判导致右侧列被裁切的问题。

## 问题现象
- 旧逻辑在溢出宽度 ≤ 操作列宽度+48px 时隐藏滚动条，致多列宽表误设 overflow-x: hidden 裁切右侧列

## 解决方案
- 区分真实溢出与幽灵溢出：仅当内容最小宽度 ≤ 可分配宽度且溢出 ≤ 固定操作列宽才隐藏滚动条
- 内容超出设 overflow-x: auto，表格 body-wrapper 默认 overflow-x: auto
