# 美股限购取消冷却期约定
场外 QDII 限购下美股取消冷却期，以利润金额为目标用阈值放宽加单次基准金额换取更多可执行买入日。

## 优化策略
- 美股不宜再用冷却期压频次，在总投入大致不变（约 ±5 万）前提下以利润金额（非组合收益率）为目标回测优化
- 放宽 PE/PEG/年区间等阈值、下调 NDX/SPX 单次基准（如 NDX 880、SPX 210），配合分档金额
- 参数可通过 `push.env` / `config.py` 覆盖

## 验证与归属
- 验证证据：cf508db9 用户先要求限购取消冷却再全量回测；b796121d 利润 +408,550 vs 限购前 +409,120（-0.14%），NDX 买入 251 次×880、SPX 230 次×210
- 涉及文件：config.py、optimize_portfolio_amounts.py、output/backtest/us_quota_friendly.md、push.env
- 所属项目：投资推送；来源会话ID：cf508db9-302c-47aa-92bc-7a486f51d464, b796121d-9f78-410e-b0ba-d47165ed26ef
