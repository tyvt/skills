# 波动率分位诊断年化不等同月度调仓回测
投资推送 volatility_60d 分位 Band 验证须区分「固定20日」诊断年化与「月度调仓」可执行回测，后者优势弱且成本后更小。

## 口径差异
- 「固定持有 20 个交易日」诊断年化 Q3 约 13.85%
- 「月度调仓、持有至下次调仓」毛年化 Q3 约 9.69%，Q1 约 8.20%，配对月收益 t≈1.01
- Q3 单边换手约为 Q1 两倍，计入佣金/滑点/印花税后净优势更小

## 结论
- Band 方向仅弱支持，IC/诊断强度应下调
- 须单独检查策略约束与 Band 的兼容性

## 实现与验证
- 实现见 `scripts/backtest_volatility_quantiles.py`
- 验证证据：会话 rollout-2026-08-27T08-23-54 用户要求无约束分位回测验证 13.85%；结论表对比固定20日 vs 月调仓毛/含成本年化与换手
