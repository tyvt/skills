# 经纪人员字典冲突修复
苏州市房地产监测V3 中 `InfoCardDialog.vue` 的 `bizStateOptions` 同时在 `props` 与 `data()` 声明引发 Vue 警告，已采用方案 B（弹窗内自加载字典）修复。

## 问题根因
- `bizStateOptions` 曾在 `props` 与 `data()` 中同时声明（或 HMR 缓存旧版本）
- 触发 `vue.js:5108 [Vue warn]` 同名冲突警告

## 修复内容
- 移除 `bizStateOptions` prop，新增 `personnelStatusOptions`（`data` 字段，名称不同避免冲突）
- 打开弹窗时在 `loadCredential` 调用 `getDicts('personnel_business_status')` 加载字典（仅首次请求，后续复用缓存）
- 父组件 `AgencyPersonnelList.vue`、`AgencyPersonnelDetail.vue` 移除多余传参
