# 日志缓存回测目录分工
项目目录需明确区分运行时日志、外部数据缓存与回测产物，并在 .gitignore 中忽略。

## 目录规则
- logs/ 只放运行时日志（如 push.log）
- 外部数据缓存放 cache/（含 cache/us/）
- 回测 Markdown/HTML 放 output/backtest/

## 配置与引用
- 三者均应在 .gitignore 中忽略
- 路径集中在 config.py（LOGS_DIR、DATA_CACHE_DIR、BACKTEST_OUTPUT_DIR）
- data_cache.py 与 backtest_*.py 统一引用，避免回测产物或行情缓存误放进 logs

## 验证与归属
- 验证证据：迁移 15 个回测文件到 output/backtest，修复 logs 定义过宽问题
- 涉及文件：config.py、data_cache.py、.gitignore、README.md
