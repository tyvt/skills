# 惠山物管管理端登录自动化
惠山 dev 管理端（物管系统）的 Playwright 自动登录流程与踩坑点。

## 页面与接口
- 登录页为 hash 路由 `#/login`，提交接口 `/security/auth/login`
- 占位符：“请输入用户名/身份证号码/手机号码”“请输入用户密码”“请输入验证码”
- 验证码 `GET /code` 返回 `{data: base64, uuid}`，算术题用 captcha-recognizer 的 `solve-captcha.mjs` 求解

## 踩坑
- `.login-button` 需 `evaluate(el => el.click())` 直接点击
- OCR 偶发识别错误需重试
- Playwright 1.65 需 `channel:'msedge'`（chromium-1254 未下载）

## 账号结论
- zsbase / ZS001Aa! 在 2026-11-16 实测 code:200 登录成功；旧“1300异常”结论属门户系统，不适用于物管管理端
