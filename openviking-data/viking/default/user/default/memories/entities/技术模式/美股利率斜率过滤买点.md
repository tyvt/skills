# 美股利率斜率过滤买点
NDX/SPX 买入增加 21 个交易日美债 10Y 升幅 ≤ 40bp 的利率斜率过滤，用于拦截类似 2022 年利率急升阶段的误买。

## 配置规则
- 环境变量 `NDX_BUY_RATE_MAX_SLOPE=0.004`（更严可设 0.003）控制 21 日 10Y 升幅上限
- 报告中需展示「10Y 利率21日升幅」条件
