# 买点消融模块差异
美股可删无效硬门槛，宽基/恒科/红利误删核心条件会严重失真买入频次。
## 消融规则
- 美股 NDX/SPX：PEG、距低点、距高点回撤对 is_buy 几乎无过滤作用，可从买入判定中移除
- 恒科、A 股宽基、红利等模块若删掉 PE/PEG/股息率/价格位置/回撤/年区间/趋势等硬条件，回测买入占比严重失真（恒科约 6 次暴涨到 884 次）
- 精简买点时应逐模块回测对比买入次数与盈亏
- 区分「边际贡献为 0 的可选过滤」与「决定是否可买的核心门禁」
## 验证与归属
- 验证证据：会话 6fd513ab：恢复恒科全套买点后 HSTECH 买入占比回到 0.5%（6 次）；过度精简阶段宽基逻辑被误删导致频次不可作基准
- 涉及文件：us_index_signal.py、cn_broad_signal.py、cyb_signal.py、backtest_buy_signals.py、output/backtest/inception_present.md
- 所属项目：投资推送；来源会话ID：6fd513ab-4e8c-43a0-b981-c96a3b1bf31c
