# agent-browser 浏览器自动化用法
基于 CLI 的浏览器自动化工具，用于本地站点实机验证、截图核对与验证码处理。

## 命令与参数
- fill 填含 `@` 等特殊字符的值（如密码）时须用 `--` 分隔符，否则 `@` 被当成 ref 前缀解析失败
- screenshot 的输出路径是位置参数，不是具名选项；截图落临时目录，不落项目目录
- PowerShell 下 selector（如 `@e23`）会被吞掉，须用引号包裹后再传给 click

## 验证码与截图
- 登录页图形验证码可用视觉模型读图识别，例如 2026-11-24 读到算术题 `6 * 9 = 54`，填入 54 后登录
- 先填用户名密码再处理验证码；点击前先截图确认验证码是否已刷新
- 读取文件被探索门禁拦截时，改用带 offset/limit 的局部读

## 会话与流程
- 开工先检查残留后台任务，并按交接文档建同名会话，再打开本地站点（如 8101）
- 验证前跑 worktree 快照核对隔离状态，避免误动非本任务的 dirty 改动
