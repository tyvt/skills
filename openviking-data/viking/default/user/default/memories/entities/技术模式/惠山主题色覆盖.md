# 惠山H5主题色page选择器覆盖缺陷
uni-app H5 中 src/styles/index.css 的 page 选择器将 --primary-color 设为 #1677FF，覆盖 :root 的惠山深蓝 #0A3D62，导致 ZsButton primary 渲染为亮蓝。

## 问题根因
- src/styles/index.css 第 3 行 page{--primary-color:#1677FF} 覆盖第 10 行 :root 的 --primary-color:#0A3D62
- ZsButton 的 primary 背景使用 var(--primary-color)，按钮呈亮蓝 #1677FF 而非验收要求的深蓝 #0A3D62
- 属既有全局样式缺陷，新增返回按钮后首次暴露，非本次 14 页改动引入

## 验证与处置
- agent-browser 实机截图：决策页/预算页/消息页底部返回按钮均为亮蓝 #1677FF
- 用户决定接受亮蓝、维持现状，未修改 src/styles/index.css
- 关联禅道 2948；项目 zhi2-mobile-admin-h5-c-unlimited（惠山C端）
