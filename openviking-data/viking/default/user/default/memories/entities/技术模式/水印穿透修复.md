# 详情页水印穿透修复
苏州市房地产监测V3 将水印层挂到 document.body 并提升 z-index，解决详情页高层组件遮挡水印问题。

## 问题原因
- 吸顶操作栏（z-index:14）、表格固定列/合计行（约12-13）、局部 v-loading 遮罩（2000）遮挡 `#app-main` 的 z-index:5 水印

## 调整方案
- 水印层挂到 `document.body`，用 `position: fixed` 对齐 `#app-main` 可见区域（ResizeObserver + resize + 滚动更新）
- 全局样式 `z-index: 1990`，盖过页面内高层，仍低于 Element 下拉/弹窗（2000 起）
