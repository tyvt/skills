# 移动止盈峰值回撤阈值扫描规则
对启用移动止盈的指数，按峰值回撤阈值扫描并以波段收益提升≥1.5pp为采纳标准。

## 配置规则
- 采纳标准：波段收益较当前提升≥1.5个百分点
- 沪深300 峰值回撤阈值 10%→6%（波段 +3.6pp，卖点前移至 2021-02-24）
- 中证500 12%→10.5%（+3.2pp）
- 科创50 14%→12.5%（+8.4pp）
- 上证50/中证A100 等进一步收紧若收益边际不足或变差则保持原阈值

## 工程约束
- 改 config.py 后需重跑 inception_present / trade_inception_present 的 md 与 html

## 验证与归属
- 扫描表合计买卖波段收益 172.7%（10 次卖出）
- 2021 年 2 月下旬上证50/沪深300/中证A100 均触发卖出
- 涉及文件：config.py、sell_trailing.py、backtest_trade_signals.py、output/backtest/inception_present.md
