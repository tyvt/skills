# 中证A500(000510)与中证500(000905)是独立模块
中证A500 与中证500 为独立回测模块，无行情年份仍须显式输出主表行以防误判策略删除。

## 模块标识
- 中证A500 代码 000510、报告模块 `a500`
- 中证500 代码 000905、模块 `zz500`
- 日常用 `python report.py -m a500` / `-m zz500` 区分

## 行情与修复
- 本地行情自 2024-09-03 起，2021～2023 为 0 交易日
- 旧回测「当年无样本」时不写主表行，易被误认为策略删掉 A500
- 修复：无数据年份仍输出一行并备注「当年无行情（中证A500自2024-09发布，与中证500不同）」

## 验证与归属
- 验证证据：用户在 2021.md 看不到 A500 误以为删除；trade_2021_present 显示 A500 21 次买入（2024-09 后）、中证500 331 次
- 涉及文件：config.py、README.md、report.py、backtest_buy_signals.py、index_meta.py
