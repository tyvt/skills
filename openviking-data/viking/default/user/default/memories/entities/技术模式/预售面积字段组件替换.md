# 预售面积字段组件替换
苏州市房地产监测V3 项目将预售申请相关子表单中的面积字段从 amount-input 改为 zs-input-number（只读展示改为 zs-input）。

## 修改内容
- PresalePlanFillForm.vue：8 处面积输入（预测建筑面积、住宅/非住宅/综合楼/车库面积、物业服务用房/临时用房/社区用房面积）改为 zs-input-number，精度 2 位，单位 ㎡ 用旁注文字展示
- plan/detail.vue：土地总面积、规划总建筑面积改为 zs-input-number
- PermitInfoPanel.vue：预售面积（只读）改为 zs-input 展示，并移除未使用的 presaleAreaModel 计算属性
- 清理 PresalePlanFillForm 中已无用的 narrative-amount-input 样式
