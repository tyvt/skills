# 红利买入阈值放宽全窗口回测要求
红利买入阈值放宽须用 2015 至今全窗口回测，兼顾买入次数与长期收益。

## 配置示例
- 全局利差门槛 3.4%→3.0%
- 930955 PE 分位上限 65%→68%
- H30269 利差分位 56%→42%、PE 60%→72%
- 结果：930955 买入 +6、收益 +1.0pp；H30269 买入 +56、+6.7pp
- 再放宽会在 PE 极高、利差不足时损害长期收益

## 策略增强方向
- 优化动作文档中的「股息支付率≥80% 且利率分位>70% 减至目标权重 50%」
- PEG 分母用 min(近5年增速,近1年增速) 属策略增强方向，改阈值后同样要全窗口回测
- 用户表要求红利防价值陷阱与 PEG 保守分母
