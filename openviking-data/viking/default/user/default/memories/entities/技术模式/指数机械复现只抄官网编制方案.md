## 复现规则
- 对齐中证等指数时，复现阶段禁止发明规则（如行业内股息率排名、rank-sum 复合打分、凭记忆的 5% 权重或半年度调样）
- 官方多为串联漏斗（例：全市场股息率前 75 → 其内低波前 50 → 股息率加权），单股权重上限与调样频率以现行 PDF 为准
- 报告需注明「编制方案核对日期」
- 非官方改进（行业内选样等）只能记入后续阿尔法/7-B 预注册清单做增量评估

## 分红资格PIT
- 按调样日前三个完整自然年、每年均有现金分红，以除权除息日落入自然年计，不用宣告日
