# 空表底边修复
园区物管2.0 子模块 zhi2-web-admin 中，空表时底部边框线未显示且叠加多层变粗（约 2～3px），已精简为单一 1px 底边。

## 问题根因
- 空表时同时生效多层底边：.el-table border-bottom、.el-table::before、.el-table__fixed-right::before、合计行 footer 单元格 border-bottom、zs-table.vue 重复样式
- 多层叠加导致底边看起来偏粗

## 修复方案
- 空表仅保留 .el-table::before 这一条 1px 底边，其余全部关闭
- 去掉空表 border-bottom、隐藏固定列 ::before、去掉合计行单元格底边、删除 zs-table.vue 中的重复样式
