# 苏住房防汛后端接口约束
苏住房防汛C端巡检后端集成的数据契约与业务约束。

## 响应契约
- `JsonResult<T>`={code,msg,data}（code 200 成功）
- `PageResult<T>`={total,rows,code,msg,summary}
- `SubmitInfoDto`={id(业务数据id,必填),busCode?,deptId?,submitTittle?,procDefId?,variables?}

## 巡检业务约束
- 提交（submit）仅需传 `{id}`，服务端 FloodInspectionServiceImpl.submit(约289行) 自行以实体填充 busCode/deptId/submitTittle 并据 busCode 走 flowDefinitionService.startProcessInstance；无对应流程配置(vo==null)报「提交流程失败，请检查审批流配置」
- 保存（save）前置约束（requireEvent 约515-516行「预警备案后才能填报」）：须存在 bizState=FINISHED(已备案) 预警事件且严格阶段匹配（汛前单仅填汛前阶段事件）；save 后置 bizState=PENDING_SUBMIT

## E2E 前提
- 完整「填报→提交」前提：dev 存在各阶段 FINISHED 事件 + 巡检 busCode 对应 flowable 流程配置
- 用户须有 flood:inspection:add/submit 权限且为绑定小区的物业部门用户（subject=property）
- typeName2BusCode 将巡检阶段映射为 busCode

## 表单映射
- demo 表单字段→后端 items[](templateItemId/fillValue) 与头字段(patrolPersonNum/haveDanger 等) 映射须先取 GET /inspection/template 或 /event/{id}/items 真实模板数据方可定稿
