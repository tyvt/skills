# 像素遮罩背景带拉伸填满适配
像素遮罩比对图中间背景带原用 `cover` 只得 91.42% 相似度，改为拉伸填满 1920×110 后整条得分升至 92.491%。

## Description
- 对象：像素遮罩比对图中的中间背景带，目标尺寸为 1920×110。
- 原实现：背景图使用 `cover`（等比裁剪填充），相似度仅 91.42%。
- 调整方式：把背景图从 `cover` 改为拉伸填满 1920×110（不保持比例）。

## 效果与意义
- 调整后整条比对得分升至 92.491%，较原方案提升约 1.07 个百分点。
- 这是当时所有单项优化中提升最大的一处，说明该背景带更适配拉伸填满而非 cover。

## 状态与归属
- 状态：得分结果已验证为 92.491%，该尺寸设置尚待落入组件后再做一次验证。
- 来源：2026-11-15 的像素遮罩相似度调优记录。
