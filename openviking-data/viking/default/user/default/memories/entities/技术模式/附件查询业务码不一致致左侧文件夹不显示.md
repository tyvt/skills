# 附件查询业务码不一致致左侧文件夹不显示
园区V0项目EstateManagement中附件组件因业务码不匹配导致文件夹缺失的bug记录。

## Description
- `attachment.js` 中 `getDirData()` 调用 `FileUploadCfg` 接口，以 `this.busiCode` 按 `basetheName` 精确匹配查询。
- 后端无父级继承，页面业务码与配置值 `3003` 不一致致左侧文件夹不显示。

## Solution
- 须确保页面 `busiCode` 与附件配置值一致。

## Involved Files
- 涉及 mpfeChange 下多个 js/shtml 及 components/attachment.js、FileUploadCfgServiceImpl.java（路径 d:/repository/园区V0/...）。
