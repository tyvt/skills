# 股东表批量去列宽属性
苏州市房地产监测V3 批量移除 ShareholderPlainTable.vue 中所有 zs-table-column 的 width/min-width 属性。

## 改动内容
- 移除 width：序号(60)、股东类型(110)、证件类型(110)、持股比例(110)、认缴出资(130)、实缴出资(130)、认缴出资日期(120)、首次持股日期(120)。
- 移除 min-width：股东名称(140)、证件号码(160)。
- 共 10 列去掉 width/min-width，列宽由 zs-table-column 根据表头与内容自动测算。
- 序号列沿用组件内置 80px 固定宽（FIXED_TYPE_WIDTH.index）。
