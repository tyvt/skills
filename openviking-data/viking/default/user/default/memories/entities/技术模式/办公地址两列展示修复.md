# 办公地址两列展示修复
苏州市房地产监测V3 中将开发企业基本信息「办公地址」改为占两列（span=16）展示。

## 原因
- `FORM_COL_TWO`（span=12）在 `DetailTemplate` 里被 `normalizeDetailSpan` 转成 span=8，只占 1/3 宽
- 要占三列栅格中两列需使用 `FORM_COL_WIDE`（span=16）

## 修改内容
- `developerBasicInfoContent.js` 的 `buildOfficeContentInfo` 中「办公地址」layout 改为 `FORM_COL_WIDE`
- 涉及 `DeveloperBasicInfoForm.vue` 与 `detailLayout.js`
