# 管理银行编码赋值修复
淮安物管开户申请与物业模块选择「管理银行」时，监管银行编码字段错误取了银行网点代码，已修复为取银行编码。

## 问题根因
- `pubRegulatoryAccount/detail.vue` 的 `showBankDialog` 回调将 `regulatoryBankCode` 错赋为 `row.bankBranchCode`（如 01020000）。
- 后端期望 `row.bankCode`（如 102 或 313），与 `pubRegAccPropMgmt/detail.vue`、`pubRegAccountChange/detail.vue` 正确写法不一致。

## 修复内容
- 修改 `zhi2-web-admin/src/views/benefit/pubRegulatoryAccount/detail.vue` 与 `zhi2-web-admin/src/views/property/propertyAccount/detail.vue`。
- 两处均将 `regulatoryBankCode` 的赋值由 `row.bankBranchCode` 改为 `row.bankCode`。
