# 市场监测大屏字体系统默认化
将市场监测大屏所有字体统一为系统默认字体栈，去掉等宽与自定义字体。

## 问题现象
- 大屏数字/表格用 `font-mono` 等宽字体（Consolas 等），观感瘦长、与文字字体不统一。
- 原 HTML 曾引 Google Fonts（Plus Jakarta Sans / JetBrains Mono）但未实际带入页面。

## 根因
- Tailwind 的 `--font-sans` 与 `--font-mono` 变量及 `font-mono` 类指向等宽字体。
- 100+ 处 `font-mono` 若逐个改成本高，需一处集中覆盖。

## 解决方案
- 在 supplement.css（页面级、作用域 `.mm-dashboard`）把 `--font-sans` 与 `--font-mono` 两变量都归一为系统默认 UI 字体栈，并给 `.mm-dashboard` 及其所有后代统一 `font-family`。
- 系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB", sans-serif`。
- 页面从未引入 Google Fonts；echarts 图表内文字用 echarts 默认 sans-serif（不受页面 CSS 影响，无需额外处理）。

## 验证与归属
- 会话 2026-11-04 实测 `.font-mono` 元素 computed `font-family` 为上述系统栈。
- 重构建部署 http://127.0.0.1:8092/index.html#/market-monitor；E2E 29 项全通过；像素对比 95.08%（字体统一使数字宽度变化的预期差异）。
- 涉及文件：zhi2-web-admin/src/views/property/marketMonitor/assets/supplement.css、dashboard.css、index.vue、各组件与 echarts option。
