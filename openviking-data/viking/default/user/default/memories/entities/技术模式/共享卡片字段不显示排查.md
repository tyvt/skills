# 共享卡片字段不显示排查
在新页面使用共享卡片/列表组件（houseCard 一类）某块内容不显示时，按固定顺序排查，不要先改样式。
## 现象与规则
- 渲染层：模板有无结构，开关 prop 有无分支（如 show-type-prefix 传了但组件未实现，属开关空转）
- 条件层：显示条件是否被别的语义参数挡掉（如徽章要求 type 为空，二手房传了 type="stock"）
- 数据层：列表页是否把后端字段映射成卡片消费字段，最易反复
## 根因与字段不一致
- 同一含义字段在不同列表落成不同名字：新房侧用 publishRole，二手房列表给 publishUserType + agentCompanyName
- 两处需在各自列表页显式映射，不能指望卡片内部兼容两套字段名
## 修复与回归范围
- 修复后回归所有卡片入口页：houseCard 被首页收藏、二手房列表、新房列表共用，改条件映射要一次覆盖
- 涉及文件：houseCard.vue、stockHouse/index.vue、newHouse/index.vue、indexMore.vue、collect/index.vue 等
