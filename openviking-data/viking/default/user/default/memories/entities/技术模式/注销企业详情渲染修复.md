# 注销企业详情渲染修复
苏州市房地产监测V3 中 `CompanyCancelDetail` 的渲染错误已修复，根因是 `initDict` 加载字典后重渲染时部分字段未做防御性处理导致对 `undefined` 访问 `.length`。

## 原因分析
- `attachmentList` 不是数组（接口返回 null/字符串/对象或 sessionStorage 恢复异常），Element UI 校验规则 `{ type: 'array', min: 1 }` 访问 `value.length`
- 字典接口 `response.data` 非数组传给子组件后内部访问 `.length`
- 表单赋值不统一，`getDetail` / `loadSourceCompany` 后字段结构不一致

## 修复内容
- 新增 `normalizeAttachmentList`、`toDictOptions`、`buildCancelForm` 统一归一化
- `initDict` 保证所有字典选项始终为数组
- `getDetail` / `loadSourceCompany` 后字段结构统一

- 涉及文件：`companyCancel/detail.vue`、`companyManagement/components/AgencyBasicInfoForm.vue`
