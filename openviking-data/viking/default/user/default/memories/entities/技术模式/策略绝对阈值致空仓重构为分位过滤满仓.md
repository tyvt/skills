# 策略绝对阈值致空仓重构为分位过滤满仓
原策略采用 ROE/负债率绝对阈值过滤导致年份持仓为零，重构为单侧分位过滤强制满仓，显著提升持仓覆盖。

## 问题与重构
- 原策略采用 ROE/负债率绝对阈值过滤，导致年份持仓为零、年化仅 4.14%
- 重构为单侧分位过滤，删除绝对阈值，强制满仓与最少持仓
- 满仓时保持单股行业约束，不可行时显式报错（strategy_params.yaml:4）
