# 公共查询详情服务探活
淮安物管公共查询物业管理区域详情在进入收益等能力前，需按服务 key 前置探活，走 checkServiceHealth 工具。

## 背景与原因
- 公共查询「物业管理区域」详情（publicQuery/complex/detail.vue）进入收益相关能力前需确认后端 benefit 等服务可用。
- 页面内联 $get('/services/health') + console.log 会在 cherry-pick/合并时与新版 DetailTemplate、区域概览 UI 冲突。

## 解决方案
- 抽 src/utils/serviceHealth.js，封装 checkServiceHealth(serviceKey)（如 'benefit'），统一请求路径与成功/失败处理。
- 详情页只调用工具函数，不在页面散落健康检查与调试日志。
- 合并冲突时保留新版详情骨架（DetailTemplate、区域概览），健康检查逻辑以工具为准接入。

## 验证与归属
- 验证：会话 4044f12f（2026-06-15，基线 21fdd30）子模块 cherry-pick 冲突于 detail.vue；结论保留 DetailTemplate 新版 UI，新增 serviceHealth.js，页面改用 checkServiceHealth('benefit') 并去掉内联 API 与 console.log。
