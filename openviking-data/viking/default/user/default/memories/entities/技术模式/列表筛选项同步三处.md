# 列表页筛选项须同步data、formItems与init
在列表页新增字典筛选项时，`data`、`formItems` 与 `initDict()` 三者须同步，缺一不可。

## 核心规则
- `data` 定义 `*Options` 与查询参数
- `formItems` 绑定 `model` 引用字典
- `initDict()` 调用 `getDicts` 赋值三者缺一不可

## 示例
- 在 `leaseSecureProject/index.vue` 中新增字典筛选项时按上述规则实现
