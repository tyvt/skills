# 序号列宽度表头截断修复
苏州市房地产监测V3 修复了表格「序号」列表头显示不全与截断问题。

## 问题根因
- 全局在 `zs-table-column` 中定义 `FIXED_TYPE_WIDTH.index = 80`，但原逻辑「页面写了 `width` 就原样透传」，大量 `width="60"` 绕过全局设置；60px 扣除单元格 padding 后，加粗「序号」二字显示不全

## 核心修复
- `zs-table-column.vue`：页面写 `width="60"` 时与全局下限 `80px` 取较大值，约 90+ 处子表/弹窗无需逐页修改
- 序号列表头增加 `table-header--fixed` class，关闭 `ellipsis`，避免「序号」被裁切

## 原生 el-table-column 兜底
- `BuildingDialog.vue`、`SelectRoomDialog.vue`、`RegulatoryAccountDialog.vue`、`VotingItemsDialog.vue`：序号列宽度改为 `80`
