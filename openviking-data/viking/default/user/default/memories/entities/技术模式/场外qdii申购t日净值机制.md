# 场外QDII申购T日净值机制
跟踪美股的场外QDII基金在T日15:00前申购按T日基金净值确认份额，价格成分半已知。

## 成交规则
- 中国交易日15:00前申购，按该日（T日）基金净值确认份额，非按前一净值日标签口头理解成交
- T日净值主体通常为上一美股交易日指数收盘（如周二白天申购时周一美股收盘已公开）
- 下单时正式净值多未公布，最终数受基金估值汇率规则、现金/费率/跟踪误差影响

## 实操含义
- 周二15:00前买吃到周一美股收盘对应估值，周二美股涨跌进入后续净值日才体现
- 属「主要价格成分半已知」，非指数点位精确成交，更非完全盲买

## 验证与归属
- 验证证据：会话dc3d8ce8用户质疑「周二15:00前买是否等于已知周一夜间美股收盘价」
- 结论更正为T日净值日+周一收盘为输入、净值事后确认
