# 所属社区异步竞态转译失败
园区物管2.0 的 property/complex/detail 页「所属社区」查看模式下偶发转译失败，本质是异步竞态。

## 问题原因
- 查看模式通过 contentInfo 的 dictFormatter 转译「所属社区」，依赖 this.communityOptions。
- communityOptions 异步加载未就绪时 dictFormatter 找不到 dictLabel，返回原始值。
- dictFormatter 位于 zhi2-web-admin/src/main.js，按 column.property 加 Options 查找字典。

## 涉及代码
- detail.vue 调用 this.formatCommunityDisplay(this.form.community) 渲染 label。
- 涉及文件：zhi2-web-admin/src/views/property/complex/detail.vue、src/main.js。
