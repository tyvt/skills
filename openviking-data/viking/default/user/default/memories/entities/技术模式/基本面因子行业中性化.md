# 基本面因子行业中性化约定
多因子截面处理需全家一致、如实报告，毛利率与 ROE_TTM 做行业内 z-score，股息率与 PE 分位不中性化。

## 中性化规则
- 毛利率、ROE_TTM 做行业内 z-score（同行业 ROE 含义不可比）
- FCF/EV 先截面 z-score，纯化 IC 不过再考虑行业候选
- 股息率不中性化（行业息差本身是 alpha）
- PE 分位已是行业内时序分位，天然中性；低波/反转不中性化

## 验收要求
- 验收需用相关性热力图与纯化 IC 验证处理是否自洽
