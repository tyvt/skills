# 历史数据本地缓存与增量更新模式
回测/脚本读本地缓存，日报拉数增量写回缓存，避免重复拉取与指数截止日期停留旧快照。

## 缓存规则
- 回测所有基金自基日数据并缓存本地
- 后续回测与脚本优先读缓存
- 每日 report 增量更新须同步进缓存
- 报告输出应带统一格式的数据更新日期，拉取日志与输出日志格式一致便于对账

## 问题背景
- 科创50 报告截止到 2021、其他 A 股数据也不太对，因缓存未更新
- 用户要求 report 加上数据更新日期

## 验证与归属
- 验证证据：「科创50 报告截止到 2021」「其他 A 股数据也不太对」「report 加上数据更新日期」等诉求与缓存需求同批出现
- 涉及文件：data_cache.py、sync_data_cache.py、report.py、market_data.py、cn_broad_data.py
