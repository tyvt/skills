# 苏住房G 响应解密逻辑（expand.encrypt）
苏住房G 项目 zhi2-web-admin 已从子模块 develop/v2.6.1-yuanqu 分支迁移 expand.encrypt 响应解密逻辑。

## 实现要点
- 新增 src/utils/responseDecrypt.js：实现 expand.encrypt 响应解密，与服务端 ResponseEncryptAdvice 约定一致
- 解密流程：RSA/ECB/PKCS1Padding 解密 AES 密钥，AES/CBC/PKCS5Padding + 零 IV 解密正文
- 提供 isExpandEncryptedResponse() 和 decryptExpandResponse() 两个方法
- 更新 src/utils/request.js：在响应拦截器中于 returnRawResponse 判断之前插入解密逻辑；保留原有 returnRawResponse、noReject、Blob 错误处理
- 已安装依赖 jsencrypt@^3.3.2；index.html 已引入 /assets/js/crypto-js.min.js（public 下文件已存在）

## 配置要求
- 需在 env/.env（或对应环境 env 文件）中配置相关环境变量
