# 变更单保存提交按钮显隐缺陷
变更类页面用幂等取单预分配主键时，若按钮显隐仅判断主键存在，会导致未落库便显示提交按钮。
## 现象
- 企业端详情页点「变更」后「保存」「提交」同时出现
- 用户要求先保存再提交，直接提交会提空单
## 根因
- getLastChangeByLogin 幂等立即返回变更单 ID，页面挂上 companyRecordChangeId
- showSubmitBtn 只判断有无 ID，忽略详情接口是否真正命中（200）
- 草稿未持久化时走兜底，提交按钮误显
## 修复做法
- 新增独立状态位 changeDetailPersisted，仅详情接口 200 命中后置 true
- 按钮显隐 = 主键存在 && persisted
- 刚发起变更仅「保存」，保存成功或重开已保存草稿才出「提交」
## 验收要求
- E2E 同一用例断言两段：进入变更仅保存无提交，保存成功后才出现提交
