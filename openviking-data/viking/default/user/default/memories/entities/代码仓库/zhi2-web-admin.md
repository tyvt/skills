# zhi2-web-admin
房地产综合服务平台门户前端代码仓库，由苏州房产团队维护。

## Description
- 包含信用信息公示页（agency-credit portal）等公众门户页面。
- 信用信息公示页对应文件为 `src/views/home/publicPortal/pages/CreditPages.vue`。
- 信用信息公示页中统一社会信用代码列可点击，逻辑与「查看」按钮一致（打开同一详情弹窗）。

## Relations
- 是 `门户` 仓库的 git submodule。
- 构建输出位于父仓库 `D:/repository/门户/dist`（vite rootDir 为 `../`）。
