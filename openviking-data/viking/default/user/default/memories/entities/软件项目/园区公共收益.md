# 园区公共收益
前端管理后台项目，用于园区公共收益相关业务管理。
## 项目信息
- 代码仓库路径：d:\repository\园区公共收益\zhi2-web-admin
- 所属项目标识：园区公共收益
- 技术栈包含 Vue 与 element-ui 组件库（如 el-table）

## 功能特性
- 短信登录：platformConfig 可开启，app.js 缓存 smsLoginStatus，login.vue 按状态切换登录方式（用户名+密码+手机号+图形验证码+短信验证码）
- 驳回标识：全局统一为红色【驳回】，覆盖待办列表、流程处理、首页等页面
- 公共弹框滚动修复：BuildingTableViewTabs 翻页/切楼幢/切视图时重置滚动位置
- 开户明细列表修复：ScopeSelectDialog 重置后统一走搜索刷新链路并始终重排表格
- 房屋分配刷新：分配/删除房屋后，HouseScopeDialog 触发 refresh → unitTable 发 refresh-house → detail 中 houseTable 调 getList() 刷新
- 银行回单查询：手工核销前提下，无论选「未对账」或「已对账」均可点击「银行回单」查询，接口按当前对账状态返回数据
- 物业区域去重：工作人员新增弹框改用 /autonomy/ownerCommitteeWorker/pageComplex 并传 ownersCommitteeWorkerId 排除已关联区域
- 租赁合同字段：经营资源租赁合同详情页在租赁总额后展示「扣除管理费后归公共收益金额」（只读）与「管理费」（可编辑，失焦重算）
- 综合查询移除：物业管理区域详情页移除「综合查询」按钮及 StatisticsDialog 引用，清理 isQueryDialogVisible、projectList、contractList、getQueryData 等，组件文件保留
- 返回逻辑修复：OperationBtnGroup 无 backUrl 时不再用 router.go(-1)，改为从路径推导列表页并 router.push 带 query type=back
- 停车空间补参：parkingDialog 提交 addPubParkingSpaceDetail/updatePubParkingSpaceDetail 补充 projectId: this.baseInfo.projectId
- 头像点击修复：userAvatar.vue 移除 :hover 半透明蒙层与「+」号，保留 cursor:pointer，点击直接打开修改头像弹窗
