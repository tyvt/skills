# 园区物管2.0
园区物管2.0（榆林G）园区物业管理 Vue 前端，Vite + Vue，代码位于 zhi2-web-admin 子模块。

## 部署与构建
- 生产发版须整目录全量上传 dist/，逐文件易漏传致 chunk 502。
- vite.config.js 须 emptyOutDir:true 并为大页面单独分包（如 module-map-overview-[hash].js）；curl -I 验证 chunk 200 + application/javascript。
- 子模块 vite rootDir=__dirname/../ 解析到父目录 D:/repository/榆林G，各 worktree build 均写同一 dist 互相覆盖；用 CLI --outDir 指定独立目录（如 榆林G-bug6220-dist）并在 nginx-ui 建独立站点（如 8109）验证，避免占用共享站点 榆林G.conf(8108)。

## 已知问题
- 生产路由懒加载曾报 Failed to fetch dynamically imported module：根因发版不完整（主包更新但个别 chunk nginx 502，因 outDir 在根 dist/ 且 emptyOutDir=false 残留）；另因中文命名静态资源被打成中文名 chunk，URL 编码不友好致 404，须改英文短名（如 operatingAssets.vue 图片改 club.png 等）。
- zhi2-web-admin/src/permission.js 对 chunk 加载失败(404/502)自动刷新一次缓解 hash 不一致。

## 代码特征
- 自研 zs-table/zs-table-column 与 ECharts；图表交互须手动 dispatchAction highlight/downplay。
- 饼图图例仅展示 value>0 分类，无数据居中「暂无数据」。
- 表格列宽由 zs-table-column 计算，min-width 弹性列均分撑满；多附件字段逗号分隔，消费前拆数组。

## 分支
- 子模块含 develop/v2.6.1、v2.6.2、v2.6.2-yulin 并行分支；父仓库仅 develop/v2.6.1/v2.6.2，无 262-yulin，榆林变更仅落子模块。
- 关联文件：zhi2-web-admin/vite.config.js、src/permission.js。
