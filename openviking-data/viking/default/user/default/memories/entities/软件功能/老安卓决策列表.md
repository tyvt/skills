# 老安卓决策列表（homeland-android）
homeland-android 中决策待完成/已完成列表的筛选、按钮文案与刷新规则。

## 列表与筛选
- 待完成 Tab 用 SmCastVoteListApp 且 type=0 拉列表（DecisionsNoCompletedFragment.java:87）
- 已完成 Tab 用 type=1 拉列表（DecisionsCompletedFragment.java:86）
- 返回列表时 onRestart → refresh()，两个 Fragment 都会重新拉列表（DecisionsActivity.java:96-111）

## 按钮文案
- 主按钮文案只看 Tab（pageType）：pageType==0 → 前往决策，pageType==1 → 修改决策（DecisionsRecyclerItemPresenter.java:194-198）
- 没有「参与决策」四个字
- voteState 主要管状态角标、可点性，不驱动主按钮「参与/修改」切换

## 详情与分类
- 点「决策详情」进详情，详情里会调 SmUserVoteDetail
- 若详情接口把这条从「未完成」分到「已完成」（后端 busiState/列表 type 规则），刷新后从待完成 Tab 消失、在已完成 Tab 出现，按钮固定为「修改决策」
- 若仍留在待完成 Tab，文案仍是「前往决策」

## 与新 app 的差别
- 新 app：同一列表里 voteState 变了 → 按钮从参与→修改
- 老安卓：换 Tab + 每 Tab 固定文案，不是同一条上的「参与→修改」
