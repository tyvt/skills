# 禅道6281
项目管理模块楼幢变更维护页面在奇安信可信浏览器中滚动条仅控制基本信息、底部单元/房屋表格被裁的缺陷单。

## 页面定位
- 对应页面：zhi2-web-admin 的 projectManagement/buildinginfo/changeDetail.vue
- 结构：detail-container > detail-from-container（基本信息表单）+ zs-tabs type="card"（单元信息/房屋信息页签）
- zs-tabs 根 class 为 [tabs, zs-tabs, tabs--card]，buildingId 有值时才渲染页签

## 根因
- 整页滚动规则组依赖 CSS `:has()`，Chromium<105 内核（奇安信可信浏览器）不支持导致规则静默失效
- 与禅道6279完全同根因，页面结构同构

## 处置结论
- 由禅道6279双轨回退修复覆盖，本次无需新增代码
- 回退机制：main.js 探测打 no-has-support；index.scss 587–644 行纯类回退块覆盖 > .zs-tabs 分支
- 禅道状态：resolved/fixed，resolvedBy=tiany，指派回 zhunan，resolvedBuild=trunk
