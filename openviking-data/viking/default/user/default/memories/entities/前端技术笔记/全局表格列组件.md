# 全局表格列组件 tooltip 与自动放宽
园区公共收益项目全局表格列组件 zs-table-column.vue 增强，修复表头与单元格截断无法悬浮查看的问题。

## 修改内容
- 表头增加 title 属性，截断时可悬浮查看完整列名
- 文本单元格增加 title 属性，长内容（如楼幢坐落）可悬浮查看，绕过 Element UI 自带 show-overflow-tooltip 的限制
- 当页面配置的 width 小于表头所需宽度时，自动放宽，避免表头被截断
