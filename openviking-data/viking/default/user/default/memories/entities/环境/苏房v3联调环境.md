# 苏房V3 联调环境

苏州市房地产监测V3（苏房V3）的本地开发网关、nginx 代理与认证依赖环境，2026-11-02 完成接口联调验证。

## 网关与代理
- API 源站由 VITE_APP_PROXY_ADDRESS 决定，真实接口在开发网关 /api/v3.0/...；网关须 fat jar（68.6MB），repackage 前须停网关（PID 8136→17316）。
- nginx 8098 代理开发网关，保 /api 并显设 Host 为网关域名返回 401、鉴权通过；location /api/v3.0/ 曾误转发远程 dev 致交替 200/400，备份 nginx.conf.bak-flood-20261102-191756 已修正指向本地网关。

## 认证与依赖
- 验证码：jar 靠 Nacos；security.captcha.enabled true；POST /v3.0/code 需 Accept: text/plain 返回 captcha+uuid；登录流程 captcha→login→JWT（permissions=*:*:*）。
- Nacos：本地 192.168.1.129:9214（新 PID 24060），旧 192.168.1.134:9214 须 enabled=false 移除。
