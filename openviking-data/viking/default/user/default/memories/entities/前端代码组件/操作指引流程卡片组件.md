# 操作指引流程卡片组件
操作指引页面「我是开发商」九步流程中使用的卡片组件与样式定义。
## 位置
- 源文件位于 `zhi2-web-admin/src/views/home/operationGuide/components/OperationGuideBody.vue`。
- 相关样式集中在该文件约 527-532 行，作用于 `.og-flow-card` 系列类名。
- 卡片描述区使用 `.og-flow-card-body` 类。
## 结构与样式
- 「我是开发商」流程共 9 张卡片，第 2、5 张描述为两行，其余为一行。
- 描述区文本行数不同会直接影响卡片高度，需预留固定高度才能等高。
