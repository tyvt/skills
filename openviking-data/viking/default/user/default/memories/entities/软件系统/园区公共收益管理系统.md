# 园区公共收益管理系统
园区公共收益（zhi2-web-admin）是基于 Vue 的园区公共收益管理后台前端系统。

## 项目描述
- 前端工程目录为 zhi2-web-admin
- 涵盖楼栋视图、选择户室、单位代缴、待办任务、流程审批等模块

## 主要模块与文件
- BuildingTableViewTabs.vue：楼栋表格视图标签页组件
- zs-select-dialog.vue：通用选择弹框组件
- ScopeSelectDialog.vue：单位代缴缴存范围选择弹框
- todoTask.js：待办任务工具函数（含驳回标识处理）
- flowApi.js 与 process.vue：流程审批与撤回逻辑
