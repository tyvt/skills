# 楼幢单元编辑宗地号未带出修复
园区公共收益项目修复楼幢信息详情中单元「编辑」弹窗宗地号（地号）未带出问题。

## 问题原因
- 编辑模式下通过 /building/unit/{id} 拉取单元数据，接口返回无 landPlotCode（宗地号），而弹窗该字段必填且禁用，显示为空、无法通过校验保存
- 新增单元时由父级楼幢详情 props 传入宗地号；编辑时 loadDetail() 之前只用接口数据，无兜底

## 修改内容
- 文件：UnitDialog.vue 的 loadDetail() 中，接口未返回时，用父级楼幢详情传入的字段回填 landPlotCode
- 新增单元 initAddForm() 已正常从父级传入，不受影响
