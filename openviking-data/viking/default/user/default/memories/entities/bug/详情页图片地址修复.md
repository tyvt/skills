# 机构注册备案详情页图片地址修复
园区公共收益项目修复账号授权管理下机构注册备案详情页图片地址问题。

## 问题原因
- DetailTemplate 组件中营业执照等图片地址走 resolvePublicAssetUrl，会把 zhi2/2026/... 转成 /zhi2/2026/...（站点根路径绝对路径），必须依赖 /zhi2 反代才能访问

## 修改内容
- 文件：detail-template.vue 改为使用 resolveServerAssetUrl（与 ImageUpload 等组件一致）
- 后端返回 zhi2/2026/a/5/q/xxx.png → 保持相对路径；返回 /zhi2/2026/... → 按当前页面地址解析为相对 URL
- 开发环境可在 zhi2-web-admin/vite.config.js 删除 /zhi2 反代配置（约 245-247 行）
