# 《列宁选集》1992年版
1992年出版的列宁著作选集，分四卷共230章，按时间轴排列。

## 描述
- 卷数与章节：分四卷，共230章
- 时间范围：涵盖1894—1923年，从革命至新经济政策时期
- 排列方式：依时间轴排列
- 1992年版重编理由：译文更准确、选材更合理，增收方法论与社会主义建设文献

## 分卷结构
- 第一卷（1—45章）：1894—1907，批民粹派、建党、1905年革命
- 第二卷（46—94章）：1908—1916，哲学论战、帝国主义、一战
- 第三卷（95—163章）：1917—1919，十月革命、建国、内战
- 第四卷（164—230章）：1919—1923，经济建设、新经济政策、晚年著述
