# 泰兴小程序
一款面向设备维修保养的微信小程序项目。

## Description
- 项目名称为泰兴小程序，是一个维修保养类小程序。
- 代码仓库路径包含 D:/repository/泰兴小程序/src。

## Relations
- 包含 pages_maintain_project 模块，涵盖维修申请、施工管理、三方鉴定详情等功能。
- 使用 maintainProject.js 聚合维修项目相关接口与 store 业务逻辑。

## Significance
- 用户持续在此项目中进行接口对接与页面开发，是长期维护的产线项目。
