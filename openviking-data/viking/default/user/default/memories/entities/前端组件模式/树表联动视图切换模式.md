# 树表联动视图切换模式
带左侧部门/区域树的列表页在树状/平铺视图切换时保持查询条件与树状态一致的模式。
## 问题
- 原切视图直接调父组件resetQuery()清空全部搜索条件违反列表跟随查询条件
- 切回树状时树停留旧子节点选中态与列表不一致
## 正确做法
- 切平铺：仅清parent.queryParams.parentDeptId并重置pageNum后getList，保留表单条件
- 切树状：用pendingTreeDefaultReset标志+treeRenderKey自增强制树重挂默认态，初始化后nodeClick设根节点刷新
- 绝不调resetQuery()
## 共用与影响
- RegionTreeLayout.vue被complex/assetLeaseApply/assetsLeaseContractFiling等列表页共用，修一处全域生效
- 相关文件：RegionTreeLayout.vue、complex/index.vue、listMixins.js
