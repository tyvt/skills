# Summary
在苏州市房地产监测V3项目中，查看从业人员详情时 `loadDetail` 将原写死 `personnelType` 为「专业人员」触发证书查询导致弹窗报错。修改 `AgencyPersonnelDetail.vue`：`handlePersonnelTypeChange` 与 `queryProfessionalCertificateByIdNumber` 在 view 模式下直接返回，不再发起 `/company/agencyPersonnel/queryByIdNumber` 查询。新增、编辑时选专业人员仍按身份证号查证，保存校验不变。
