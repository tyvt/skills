# Summary
MicroCommunityWeb 的 externalCodeLoginHandler.js 中，接口返回的 data 为单个用户对象，但代码按数组用 data[0] 处理，导致 completeLogin(undefined) 访问 token 报错并显示「单点登录失败」。已新增 normalizeLoginUsers() 兼容单用户（{ data: { userId, token, name, ... } }）与多用户（{ data: [{ ... }, { ... }] }）两种返回格式，用带 code 的链接测试可正常登录并跳转首页。
