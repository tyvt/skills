# Summary
修复昆山市民小程序物业合同附件在 H5 环境显示空白页的问题。原因为物业合同详情页 detail.vue 直接调用 uni.openDocument（微信小程序专用 API），在 H5 下跳转空白页无法预览 PDF。解决方案：引入 pdfjs-dist（Mozilla PDF.js），新增 src/pages/common/filePreview.vue 用 pdf.js 逐页渲染 canvas，支持相对/绝对路径并自动携带登录 Token；更新 src/utils/index.js 的 filePreview 工具函数（H5 下 PDF 跳转预览页、微信小程序保持 uni.openDocument、图片继续用 uni.previewImage、其他文件触发下载）；修改 detail.vue 点击附件改为调用统一 filePreview 方法。决策相关材料、维修资金附件、选举材料等原本已使用 filePreview 的模块一并受益。所属项目：昆山市民。
