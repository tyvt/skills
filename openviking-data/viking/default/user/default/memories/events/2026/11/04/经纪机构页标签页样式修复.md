# 2026-11-04 (Wednesday) ChatLog:
**user**: 【记忆类型】bug
【标题】下划线式 tab 视觉错位的根因是 align-self:stretch 把按钮拉满工具栏高度，不是字号或下划线粗细
【内容】【什么情况】门户经纪机构页表格工具栏里嵌的「交易记录 / 信用记录」tab 被判定「样式不对，参考项目里面的其他 tab」，用户连说两次不对。
【为什么】原实现 `.broker-record-tabs { display:flex; align-self:stretch; gap:32px; }` + `button { border-bottom: 3px solid transparent }`：`align-self: stretch` 让按钮这个 flex item 被拉满 60px 工具栏高度，文字垂直居中在约 30px 处，而 3px 下划线贴在**工具栏最底边**（y≈57–60），于是视觉上是「一行字 + 一条离得很远的粗线」。20px 字号与 3px 线宽只是放大了这个错位，不是病灶。
【怎么做】① 先调研项目里已有的 tab 写法再动手（门户里 `zs-tabs` 被 39 处业务页使用，激活态 = `::after` 2px 下划线 + `font-weight:500`，bar 高 40px、字号 14px、`margin-right:32px`；另有 OperationGuideTabs 的 `#2a5faa` 蓝底白字块、components/TabBar.vue 的白底主色字、index.vue 的描边小方块等）；② 对齐项目通用样式：按钮固定 40px 高、在 60px 工具栏内垂直居中（顶部留白 10px），下划线改由按钮自身 `::after` 绘制（2px、贴住文字底部），不再依赖按钮高度；③ 激活态用 `--portal-accent`(#3f669c) + `font-weight:500`，未激活 #333，间距 32px，字号 20px 与工具栏标题同级；④ 保留无障碍属性 `role="tab"`/`aria-selected`/`tabindex`/左右方向键，类名由 `.broker-record-tabs` 改为 `.portal-tabs`/`.portal-tab`；⑤ 改完补 e2e 结构断言把「间距 32px / 高 40px / 字号 20px / 激活色与字重 / ::after 高 2px 且贴按钮底边 / 顶部留白 10px」锁死，防止下划线又贴回工具栏底边。
【验证证据】会话 session-2a8f309e-c78b-4fa1-a092-4b9460fcf9bf（基线 d8addc3）用户诉求 1「tab标签样式不对，参考项目里面的其他tab，然后把指标分类去掉」；子代理只读调研结论 0 节指出「关键病灶不是字号，而是 align-self: stretch……3px 下划线贴在工具栏最底边（y≈57–60）」并给出 5 套候选 tab 的对照表（zs-tabs 用 39 处）；最终结论落地为固定 40px 高 + ::after 2px 下划线 + 激活态 #3f669c/500，并补 e2e 断言。
