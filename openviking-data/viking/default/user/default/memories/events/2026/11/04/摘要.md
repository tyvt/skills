# 摘要
`vite:vue2` 编译器不允许在 `<template v-for>` 上写 `:key`，与 Vue 3 ESLint 规则冲突。使用带 `:key` 的 `.flow-step-group` 包裹步骤并设置 `display: contents`，使 `.flow-step` 与 `.flow-arrow` 仍作为 `.flow-steps` 的直接 flex 子项排版。 涉及文件: index-new.vue, package.json, portal-home-visual.spec.ts. 验证证据: portal/021.md.
