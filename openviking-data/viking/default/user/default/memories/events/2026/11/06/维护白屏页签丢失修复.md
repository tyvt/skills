# 2026-11-06 (Friday) ChatLog:
**user**: 【标题】苏州房产监测V3：点「维护」出现整页白屏、页签全丢的根因与修法（禅道 bug 6285）

【现象】商品房门户「预售许可 → 预售许可申请」新增页点「预售方案-维护」，偶发（多在发版后第一次跳转出现）整页白屏一瞬、页签栏从 10 个只剩 1 个、图标短暂显示方框，页面又回到申请页。

【根因】不是「维护」业务逻辑，而是「发版后未刷新的旧页面被静默整页刷新」：
1. src/utils/version-check.js 覆写了 history.pushState/replaceState，任何一次路由跳转都会拉 version.json 比对，发版后 buildTime 变化即 forceRefresh() 直接 window.location.reload()；
2. src/store/modules/permission.js 的 importWithChunkRetry 在懒加载 chunk 404（旧 chunk 被清理）时静默 location.reload()；
3. store/modules/tagsView.js 的 visitedViews 不落盘，整页刷新必然清空已打开页签（表单草稿没事：页面已写 sessionStorage[$route.path]，刷新后自动回填）。

【修法（用户定：保留自动整页刷新语义，版本校验强刷是刻意机制不改弹窗确认）】新增 src/utils/autoRefresh.js：reloadWithOverlay() 刷新前显示全屏遮罩提示并把已打开页签写入 sessionStorage；version-check.js 的 forceRefresh() 与 permission.js 的 chunk 兜底改走它；TagsView/index.vue 在自动刷新后校验路由仍存在再还原页签。

【可复用判断】看到「整页白屏 + 页签清空 + URL 未变」，先查是不是 location.reload()（版本校验/chunk 兜底），而不是业务代码；zhi3 的 tagsView 不持久化，整页刷新必丢页签。

【涉及文件】zhi2-web-admin/src/utils/autoRefresh.js、src/utils/version-check.js、src/store/modules/permission.js、src/layout/components/TagsView/index.vue；子模块提交 d2cbc1742，合入 develop/v3.0.0 合并提交 a2862e39c；父仓库 zhi3-web-admin-h5-g-unlimited 提交 7a7fa89。
