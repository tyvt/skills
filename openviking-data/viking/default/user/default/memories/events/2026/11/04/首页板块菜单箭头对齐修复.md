# 2026-11-04 (Wednesday) ChatLog:
**user**: 【记忆类型】pattern
【标题】装饰箭头对齐卡片中心线：让箭头盒与菜单卡片同高同顶再 flex 居中，别用 top 偏移推算
【内容】【什么情况】门户首页板块菜单（商品房 / 存量房 / 面积管理 / 住房租赁）的箭头被要求「和图标垂直居中」「箭头和菜单容器要垂直居中」。
【为什么】原实现把箭头用 `top` 偏移硬编码（例如 `top: 29px`）去「推」到大致位置，这种对齐依赖父容器的 padding、字号、行高和菜单数量，任何一处变化（板块菜单增删、字号调整）都会重新错位；肉眼看「差不多」也不算数。
【怎么做】① 在菜单容器上定一个统一高度变量（如 `--biz-item-height: 93px`），菜单卡片 `height: var(--biz-item-height)` + `box-sizing: border-box`，让卡片高度确定；② 箭头盒与卡片**同高同顶**（同一行 flex、同样高度），盒内用 flex 居中 → 箭头中心必然等于卡片中心线，不再依赖 padding/字号推算；③ 验证用几何量而不是肉眼：取真实矩形比较「卡片中心 Y」与「箭头盒中心 Y」，本批实测商品房/存量房偏差均为 0px，连 svg 图形本身偏差也是 0px（面积管理与住房租赁走 `showStepArrows:false` 无箭头）；④ 附带收益是四个板块菜单卡片高度统一为 93px（原来靠 padding 自然撑开，各板块可能差零点几像素），文字底部留白 12.75px 无裁切。
【验证证据】会话 session-26583b70-9311-4669-81de-5a735c71d2ca（基线 65275e9）用户诉求 4「商品房和存量房的箭头都和图标垂直居中」、诉求 5「箭头和菜单容器要垂直居中」；最终结论给出改法（`--biz-item-height: 93px` + 箭头盒与卡片同高同顶 + 盒内 flex 居中）与实测表（商品房 93/399.5/399.5/偏差 0/svg 偏差 0）。
