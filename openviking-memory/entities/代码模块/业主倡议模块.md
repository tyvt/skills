# 业主倡议模块
Su住宅G-end后端中的业主倡议模块（子模块 zhi2-web-admin）已从Yulin版本迁移，位于 src/views/autonomy/suggest/。

## 目的
- 后端中的业主倡议模块（owner initiative），对应于C端的倡议和签名
- 核心差异：C端增加了签名步骤，签名图片必须在后端展示

## 主要文件
- detail.vue: 倡议详情页面，信息区域包含签名字段 (signatureUrl) 的单图展示
- components/ResponseDialog.vue: 业主回复详情对话框，展示“回复签名”图片
- ResponseTable.vue: 回复列表，列“回复签名”展示 signatureUrl（已在主分支存在）

## 字段兼容性
- 签名字段兼容多个别名：signatureUrl / signature / initiatorSignature
- 后端任务 #2145 已关闭，提供签名字段返回
