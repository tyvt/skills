# 深市专用标准治理参数致零入选
数据湖深市选股专用标准因治理参数配置导致零入选的排查结论与复核。

## 问题背景
- 深市专用标准筛选结果返回 0 只，用户预期应能筛出若干标的
- 筛选漏斗显示财务条件已过 39 只，结果文件却为空

## 根因与口径
- 入选要求为「治理明确通过」
- 上次重跑使用了「跳过治理」参数，因治理口径不满足故写入 0 只

## 处置与验证
- 按正常治理口径重新跑批，结果为 23 只（平安银行、格力电器、兴蓉环境在列，另含五粮液、东莞控股、粤高速A、现代投资、华润三九、招商公路、涪陵榨菜、宁波银行、湖北能源、浙江交科、城发环境、贵州轮胎、陕国投A、国药一致、陕天然气、博深股份、华西证券、长城证券、山西证券、国元证券），与仓库上次提交名单一致
- 沪市同口径 8 只全过；沪深合计 31 只，远多于原持仓面板 9 只
