# 《投资者的未来》
杰里米·西格尔以标准普尔500长期数据论证“增长率陷阱”的投资著作。

## 描述
- 作者：杰里米·西格尔（Jeremy Siegel），沃顿商学院教授，《股市长线法宝》作者
- 核心论点：长期回报由股利再投资、合理估值与全球化配置驱动，而非单纯利润增速
- 关键概念：提出"增长率陷阱"（growth rate trap）
- 中文版：含译者序（姚振山）与推荐序

## 相关作品
- 数据来源：标准普尔500指数长期数据
- 关联著作：《股市长线法宝》（作者同为此书作者）
