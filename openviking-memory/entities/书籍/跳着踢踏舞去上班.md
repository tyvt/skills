# 《跳着踢踏舞去上班》
本书由卡萝尔·卢米斯辑录《财富》杂志文章而成，并非全新撰写的巴菲特传记。

## 描述
- 编者：卡萝尔·卢米斯（Carol Loomis）将《财富》杂志 1966—2012 年文章辑录成书
- 主题人物：沃伦·巴菲特的投资理念与决策
- 呈现方式：以时间轴排列，而非另写全新传记
- 中文版：2017年北京联合出版公司出版
- 书名寓意：取自巴菲特"跳着踢踏舞去上班"的说法，寓意以热爱与从容投入投资

## 相关作品
- 来源刊物：《财富》（Fortune）杂志
- 关联人物：沃伦·巴菲特（书中主题人物）
- 推荐序作者：邱国鹭、比尔·盖茨
- 来源刊物：《财富》（Fortune）杂志
- 关联人物：沃伦·巴菲特（书中主题人物）
