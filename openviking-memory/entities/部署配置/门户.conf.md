# 门户.conf
nginx 站点配置文件，用于本地部署旧「门户」前端（分支 develop）以供预览验证。
## Description
- 监听端口 8092，网站根目录为 `D:/repository/门户/dist`（旧项目门户，分支 develop）；2026-11-11 曾误改为 门户H5/dist 后已还原。
- 磁盘真实配置文件为 `D:/nginx/conf/sites-available/门户`，`D:/nginx/conf/sites-enabled/门户.conf` 是指向其的符号链接（编辑须改链接目标，勿破坏符号链接结构）。
- 该站点与新建的 `门户H5` 站点（配置 门户H5，端口 8091）相互独立。
## Purpose
- 本地构建后通过该站点以无头浏览器截图验证门户页面（如 agency-credit 信用信息公示页）。
