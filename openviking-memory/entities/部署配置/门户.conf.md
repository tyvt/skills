# 门户.conf
nginx 站点配置文件，用于本地部署门户前端以供预览验证。

## Description
- 监听端口 8092，网站根目录为 `D:/repository/门户/dist`。
- 对应前端项目为 `zhi2-web-admin`（父仓库 `门户`）。

## Purpose
- 本地构建后通过该站点以无头浏览器截图验证门户页面（如 agency-credit 信用信息公示页）。
