# ZenTao Bug 6938
管理 APP 现场检查表单（project-check 表单）在防汛C端移动查询 H5 中的缺陷，由 lichandan 在禅道产品 9、项目 141、执行 142 下创建。

## 缺陷与修复
- 现象：满分/无扣分项时总体情况步骤缺少「整改通知书」区块；期望行为对应禅道原型图 24152。
- 根因：`v-else-if="isOverall"` 区块内的通知模块（模板 532-546 行）被 `v-if="hasRectifyItems"` 门控包裹。
- 修复：在 `src/pages/project-check/form/index.vue` 去掉该门控，使总体步骤始终渲染通知区块。
- 修复随提交 `c6fb38e`（作者 `ty`，即处理人 tiany，2026-11-24 15:54）发布，已在 `origin/dev`，0 个未推送提交，工作区干净。

## 页面行为
- 不带 `checkRecordId` 打开 `/form` 显示「检查单不存在」；页面从本地草稿（`local=1&checkType=1`）或后端 `checkRecordId` 加载。
- `totalCount=0` 且分类为空时进入总体步骤，即此前隐藏通知区块的满分场景。

## 验证与状态
