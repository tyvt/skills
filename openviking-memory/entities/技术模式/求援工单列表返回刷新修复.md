# 求援工单列表返回刷新修复
苏州住房保障 C 端 H5 求援工单列表页从填报表单返回后不刷新的问题，通过 onShow 重新加载列表修复。

## 问题原因
- 禅道 bug 7034：H5 求援工单列表页 index.vue:116 仅在 onLoad 加载列表
- form.vue:76 通过 navigateBack() 返回时列表不重新加载，保留旧数据

## 修复要点
- index.vue:7 导入 onShow
- index.vue:116-117 改为 onLoad 仅刷新角色、onShow 调用 loadList，共两行修改
- 本地调试环境为 http://localhost:8150/
