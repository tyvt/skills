# 楼表单元格误用长短图例且宽度自适应致图标拥挤
V3楼表误用 short+long 图例且宽度自适应导致图标拥挤换行，已恢复默认并加开关。

## 缺陷描述
- V3楼表使用 short+long 8项图例且 `.table-icon` 改为 `width:auto`
- 导致单元格图标拥挤换行异常

## 修复方案
- 默认仅用 short 图例与 cellStateList 两图标位
- 恢复 `.table-icon` 宽110px与换行布局
- 扩展状态通过 `VITE_APP_BUILDING_TABLE_EXTENDED_STATES=true` 开启
