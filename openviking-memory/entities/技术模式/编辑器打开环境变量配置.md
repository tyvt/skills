# 编辑器打开环境变量配置
苏州市房地产监测V3 项目因 `VITE_LAUNCH_EDITOR='false'` 导致 Vue DevTools 无法打开组件。

## 原因
- `env/.env` 中 `VITE_LAUNCH_EDITOR = 'false'` 禁用了 launch-editor 中间件
- `vite.config.js` 仅在该变量不为 `'false'` 时注册 `/__open-in-editor` 中间件，用 `cursor --goto` 打开文件
- Vue DevTools 依赖此中间件把文件交给 Cursor，关闭后点击「打开组件」失败

## 处理步骤
- 本地开发将 `env/.env`（及 `env/.env.audit` 若使用）中改为 `VITE_LAUNCH_EDITOR = 'true'` 或删掉该行
- 重启开发服务（改 `.env` 不会热更新）
- 本机 `cursor` 命令已在 PATH，CLI 不是问题

## 涉及文件
- `env/.env`
- `zhi2-web-admin/vite.config.js`
