# 标签页子表冗余内框且工具栏未与标题同行
苏州市房地产监测V3 中详情页 zs-tabs 内 .collapse-container 有多余边框与间距，工具栏未置于标题右侧。

## 问题现象
- 详情页 zs-tabs 内 .collapse-container 存在冗余边框与间距
- 子表工具栏未置于标题右侧，与标题不同行

## 修复方案
- zhi2-web-admin/src/styles/index.scss 去除内层 border/radius
- 调整 .collapse-header 为 min-height:40px padding:0、.collapse-content 顶部距
- 用 :not(.collapse-container--border-only) 保留仅边框模式
- 对 .tabs-content .collapse-container（排除 border-only、appendix-section）设 border:none !important 压过 Headline scoped 边框
- .collapse-header 设 flex+nowrap 使标题区与 #right 工具栏分列
- .collapse-header--right .operation-button-container 清零 margin/padding，与 zs-tabs.vue 的 DOM 对齐
- 脚本 move-subtable-toolbar-to-headline-right.mjs 核查无需改动
