# 实盘剩余额度与回测年度预算两套分配模型
投资推送项目存在实盘剩余额度动态分配与历史回测年度预算估算两套不同的资金分配模型。

## 实盘模型
- `REMAINING_INVESTMENT_BUDGET`（兼容旧名 `ANNUAL_INVESTMENT_BUDGET`）表示当年剩余可投
- 由 `buy_amount_allocation.py` 按当前年区间位置 + 买入就绪度动态分配
- 可外推预计全年投入（`ANNUAL_INVESTMENT_TARGET` 可选）

## 回测模型
- 历史回测用收益率排名 + `get_annual_budget()`（默认按 7.2 万/年估算）
- 避免用「剩余天数比例」污染历史模拟

## 涉及文件
- buy_amount_allocation.py、buy_amount_ranking.py、push.example.env、config.py
- 所属项目：投资推送
