# [投资推送] 红利同规则多指数未同买：PE 分位与近1年区间低位豁免
中证红利低波类指数共用同一套买入门禁时，仍可能因 PE 分位与近1年区间位置联动豁免差异导致「A/B 有信号、C 无信号」。

## 分叉机制
- 常见分叉点：PE 十年分位上限（例 74%）与「近1年区间位置」联动豁免
- 近1年区间位置处于极低位（例 ≤20%，规则另有 ≤62% 低位判定门槛）时，PE 分位上限可放宽固定幅度（例 +12 → 86%）
- 年区间偏上（例 33%）拿不到豁免，PE 持续高于常限会整月无买入

## 排查建议
- 应逐日对照指标表排查，而非先怀疑数据缺失

## 验证与归属
- 验证证据：会话 23e57464 中 2024-09 东证红利低波 931446 无买入而 H30269/930955 有信号；9/11 表 PE 81.9%>74% 且近1年位置 33.1% 未触发豁免，另两只 PE 超 74% 但年位置 0–4.2% 触发 +12 放宽
