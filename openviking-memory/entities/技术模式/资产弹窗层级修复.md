# 资产弹窗层级修复
惠山公共收益项目资产弹窗有时从后面弹出，根因是弹窗 z-index 压不过页面高层级遮罩，已通过提升 z-index 与去除 scoped 样式修复。

## 问题根因
- 资产弹窗 `el-dialog__wrapper` 原 z-index 仅 2012，且写在 scoped 样式中对内部渲染的 wrapper 生效不确定
- 统计地图页面存在更高层级：RightPanel `.rightPanel` z-index 40000、Map `.modal` z-index 99998，显示态时盖住弹窗

## 修复方案
- 在 `src/components/zs-dialog/zs-dialog.vue` 针对 `wrapper-class="zs-dialog-above-drawer"` 设置 `.el-dialog__wrapper.zs-dialog-above-drawer { z-index: 100000 !important; }`
- 移除四个资产弹窗组件（AdvertiseAssetDialog、VenueAssetDialog、ParkingAssetDialog 等）中原本 scoped 的 `.el-dialog__wrapper { z-index: 2012 !important; }`

## 验证与归属
