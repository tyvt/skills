# 公共查询楼幢表列对齐
淮安物管公共查询楼幢表需与物业管理楼幢范围表对齐，补「权利人数」「业主认证数」两列。

## 背景与原因
- 公共查询与物业管理模块共用 property/complexRange（或同源 range）接口，后端已返回 houseObligeeNums、userIdentityNums。
- 物业管理 houseTable.vue/rangeTable.vue 已展示，公共查询 buildingTable.vue 未补列导致「有数据不显示」。

## 解决方案
- 对照物业管理列顺序，在公共查询楼幢主表「房屋套数」后增加「权利人数」「业主认证数」。
- 楼幢下「房屋清单」弹窗表同步补列。
- 列名与物业模块保持一致（本项目为「业主认证数」，非口语「业主房屋数」），改列即可无需新接口。

## 验证与归属
- 验收：公共查询楼幢列表与弹窗与物业模块同字段可见；接口响应含上述 key 时单元格有数。
- 验证：会话 174955b1（2026-06-22，基线 f125763）用户贴图对比；结论在 buildingTable.vue 主表与房屋清单弹窗补两列。
