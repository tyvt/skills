# 门户切图英文命名规范
门户 homeNew 与 UnifiedLogin 的中文切图统一改为英文语义文件名，经 unifiedLoginAsset 引用。

## 重命名规则
- public/assets/images 下 homeNew 与 UnifiedLogin 的中文切图（如「组 xxx」「切图 xxx」）改为英文语义名（如 platform_banner_bg/desc/tag_bg/tag_text.svg）
- 页面通过 unifiedLoginAsset('platform_banner_*.svg') 引用

## 校验与清理
- 改完后全仓 grep 确认无中文资源名残留
- 本地仍见旧图时强刷或重启 dev server
