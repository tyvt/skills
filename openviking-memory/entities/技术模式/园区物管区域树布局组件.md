# 园区物管区域树布局组件
园区物管2.0 的 region-tree-layout 侧边栏组件，统一区域树与工具栏布局及样式，被多个业务页面复用。

## Description
- 组件文件：zhi2-web-admin/src/views/property/complex/components/RegionTreeLayout.vue
- 使用页面含物业管理区域备案（complex/index.vue）、经营用房（pubHo...）等。

## Migration
- 15 个 Vue 文件批量迁移到 RegionTreeLayout 组件（complex/index.vue 跳过）。
- 涉及 benefit/assetLeaseApply、property/complexChange、benefit/pubParkingRate、benefit/parkingManage、benefit/assetsLeaseContractFiling、benefit/pubHousePartChange、benefit/housePart 等页面。
- 来源会话：38d04607-ad49-4ec4-b96b-def4a3dbe6b0

## Style Update
- 按无锡智慧物业服务平台 / 经营用房样式更新：新增 `type-left-toolbar-spacer` 使左侧树与右侧「收起侧边栏 / 树状展示」工具栏垂直对齐。
- 边框由双层（外层灰底 + 内层白底圆角框）改为单层 `1px solid #e5e5e5`、无圆角无背景色。
- 搜索框移除自定义输入框高度、边框色等样式，改用项目默认 `zs-input`。
- 树节点移除 RegionTreeLayout 内额外 hover / 选中高亮，保留 32px 行高，选中态由 `regionTree.vue` 统一处理。
- 收起行为：收起时完全隐藏，不残留细条。
- 来源会话：c139564f-5fea-434a-a6ad-ac69d9c550e9

## Configurable Tree API
- 新增 `treeUrl`、`treeParams` 属性并透传给 `region-tree`，支持可配置树接口（如工单列表页使用 `/system/dept/complexTree`）。
- `treeParams` 为空时不传查询参数；新接口返回 `id`、`label`、`children` 结构兼容现有树组件。
- 来源会话：ca01e574-0616-48a5-8f5a-4a6bbe304b4b
