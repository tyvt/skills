# 要件上传星号控制
苏州市房地产监测V3 在详情/查看态下隐藏要件上传的红色必填星号。

## 修改内容
- `AppendixRequirementCard.vue` 新增计算属性 `showRequiredMark`：仅当 `operable === true` 且 `isRequired === '1'` 时显示红色 `*`
- 详情/查看：`AppendixPackageSection` 传入 `operable=false` → 不显示星号
- 编辑/登记：`AnnexUpload` 传入 `operable=true` → 必填要件仍显示星号
- 校验逻辑 `checkRequiredAppendix` 未改动，各业务 `detail.vue` 无需调整

## 验证与归属
- 可在企业基本信息详情等带 `requirement-grid` 的页面刷新确认「要件上传」区域已无红色必填星号
