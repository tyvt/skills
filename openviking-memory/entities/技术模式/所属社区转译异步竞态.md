# 所属社区转译异步竞态
园区物管2.0 的 property/complex/detail.vue 中，「所属社区」偶发转译失败的根因与定位。

## 问题
- 查看模式下「所属社区」通过 contentInfo 的 dictFormatter 转译，偶发不能转译成功
- 本质是异步竞态问题，非单纯字典配置缺失

## 原因分析
- detail.vue 中 value: this.formatCommunityDisplay(this.form.community) 调用 dictFormatter
- dictFormatter（main.js）按 column.property + "Options" 从 this.communityOptions 查找 dictLabel
- communityOptions 异步加载，若未就绪则找不到对应名称

## 验证与归属
- 涉及文件：zhi2-web-admin/src/views/property/complex/detail.vue、main.js
- 所属项目：园区物管2.0；来源会话：2bea6416-3e83-4b54-af77-1e2e56704a2a；代码基线：none
