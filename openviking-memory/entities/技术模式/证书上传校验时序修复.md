# 证书附件上传校验时序修复
苏州市房地产监测V3 修复了 `FileUpload` 上传成功后再同步 v-model 导致的证书附件校验误报「不能为空」问题。

## 问题根因
- `FileUpload` 上传成功后先触发 `@getList`，再同步 `v-model`
- `onCertificateFileChange` 立即执行 `validateField` 时 `form.certificateFile` 仍为空，UI 已显示文件但校验仍报「证书附件不能为空」

## 修改内容
- `FileUpload/index.vue` 调整 `handleUploadSuccess` 顺序：先 `handleFileListChanged()`（同步 v-model），再 `$emit('getList')`
- 两处证书弹窗（`staffManagement/components/certificatesDialog.vue` 与 `staffManagement/personnelRecord/certificatesDialog.vue`）逻辑一致，已同步修复
