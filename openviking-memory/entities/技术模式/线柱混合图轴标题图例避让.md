# 线柱混合图轴标题图例避让
园区物管2.0 的 fundPanorama 页线柱混合图中，左右 Y 轴单位与图例重叠的修复方案。

## 问题
- 左右 Y 轴单位原放在轴顶端，与左右上角图例叠在一起抢同一区域

## 修复方案
- 左轴：nameLocation: 'middle' + nameRotate: 90，「单位：个」竖排在轴线中段
- 右轴：nameLocation: 'middle' + nameRotate: -90，「单位：万元」竖排在右轴中段
- grid.top 略收为 38，图例 top: 6、left/right: 8，留稳定一行高度
- tooltip 增加 confine: true，提示框尽量画在图表区域内减少遮挡
