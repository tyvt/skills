# 禅道工时日志定时任务
DSH 定时任务，每日自动把当天会话产生的禅道工时日志按任务标题写入，禁止提交哈希格式。

## 基本信息
- 任务 ID `schedule-78e071ef-6feb-4d59-ad04-67c6cffedc50`，2026-11-24 创建，target=new，全自动写入。
- 每日 00:00（Asia/Shanghai）执行，处理当天记录；首次运行 2026-11-25 00:00。
- 用户原先手工改造的「会话记录 → 禅道工时日志」脚本在工作区、`.dsh/scripts`、会话历史中均不存在，任务按 prompt 逻辑重建，不依赖旧脚本。
- 2026-11-24 已修正 159 条内容错误的历史工时日志（内容改为对应禅道任务标题），复核 0 残留。

## 内容规则
- 工时日志内容一律使用对应禅道任务标题（`zt_task.name`），不得写「提交:仓库/分支·hash·时间」。
- 写入新禅道库（DBX 连接「新禅道」，192.168.1.87:13306）的 `zt_effort` 表 `work` 字段。

## 实现要点
- DBX 调用须传 `sql` 字段并同时路由 `connection_id` 与 `session_id`；事务内校验后提交，提交后再用独立连接复核。
- `zt_effort` 现有记录全部为 `objectType='task'`，不支持 bug 类型工时（2026-11-24 核实）；product 需经 execution 关联 `zt_project` 反查。
- 2026-11-24 以单个多行 INSERT 事务补录 2026-11-20~24 缺失工时 5 行（id 3082–3086，`deleted=0`，work 取 `zt_task.name`）：11-23 补 2741=1.5h、2728=2h、2757=3h；11-24 补 2768=4h、2769=4h。
- 11-20 保留原有 4h（当天仅此一任务），11-21/22 为周末不填；存量行 3016/3023 的「完成了任务 :」前缀按交接约束未改动。
