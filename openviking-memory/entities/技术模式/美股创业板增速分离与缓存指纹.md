# 美股创业板增速分离与缓存指纹
collect_index_states / buy_amount_allocation 中需严格区分美股与创业板增速来源，且磁盘缓存指纹须包含两者以避免错误命中。

## 增速参数规则
- 美股 snapshot 必须使用 task 的 us_growth（CLI --us-growth），禁止误用 CYB_EXPECTED_GROWTH
- 创业板使用 cyb_growth（CLI --growth）
- report.generate_reports 须将 CLI 增速传入额度预计算

## 缓存指纹要求
- 磁盘缓存 key/指纹必须包含 cyb_growth、us_growth
- 否则自定义增速会命中错误缓存（如默认增速）

## 验证与归属
- 验证证据：report 与回测一致性审查第 2 项修正；示例 `python report.py -m us --us-growth 0.15`
- 涉及文件：buy_amount_allocation.py、report.py
- 所属项目：投资推送；来源会话ID：a0bac9cb-3ed5-40d8-a564-374e4481e671
