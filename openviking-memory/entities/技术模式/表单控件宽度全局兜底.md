# 表单输入控件宽度全局兜底无需手写width:100%
园区物管2.0 中 zs-input / amount-input 等表单输入控件普遍带冗余的 width:100% 内联样式，全局 element-ui.scss 已兜底。

## 问题现象
- 页面里 zs-input / amount-input 等输入控件上普遍带 :style="{ width: '100%' }" 或 style="width: 100%"，属冗余样板代码
- src/styles/element-ui.scss 中 .el-form 与 .el-form-item__content > * 已全局设置 width: 100%，zs-input 及 amount-input 上的 width:100% 内联样式冗余

## 根因
- src/styles/element-ui.scss 已有两条全局兜底规则，表单内控件宽度已被全局保证
- 规则一：.el-form .el-input/.el-input-number/... { width: 100%; }
- 规则二：.el-form-item__content > * { width: 100%; max-width: 100%; }

## 解决方案
- 全项目清理时只删「纯 100% 宽度」的 style 写法（含单双引号、可选分号），不动带其他样式值的复合 style
- 范围按组件类型（zs-input、amount-input）圈定，清理后用 grep 复查归零并跑 lint 确认无新增错误
- 实际已在 zhi2-web-admin/src 清理 140 个文件纯 100% 宽度写法，lint 无报错
- 新页面写表单控件时不要再补 width:100%
