# 红利就绪行实时价字段输出约定
红利模块 log_fetch_done 就绪行须与其它模块一致拼接实时价与涨跌幅，避免被误判为接口失败。

## 问题描述
- 宽基/创业板/美股在 `log_fetch_done` 就绪行会带「实时 …」
- 红利模块（如 H30269 / csH30269）曾漏传实时字段，控制台只显示「就绪 | 数据截至 … | 历史 …」
- 正文分析里可能已有实时价，但就绪行缺失易被误判为接口失败

## 修复方案
- 红利就绪行同样拼接实时价与涨跌幅
- 拉取失败重试 1 次
- 开头增加「实时行情已获取」或「实时暂无」汇总
- 修复后示例：`实时 10,915.98 -2.01% …`

## 验证与归属
- 验证证据：会话 efd15316 最终结论，腾讯 csH30269 可正常拉取，根因是红利 log_fetch_done 未传实时字段
- 涉及文件：d:/repository/投资推送/dividend_data.py、report.py
- 所属项目：投资推送；来源会话ID：efd15316-7993-488b-8278-c5e62b92d106
