# el-input-number 全局迁移为 zs-input-number
园区物管2.0 项目中所有业务页面的 el-input-number 已统一替换为 zs-input-number。

## 改造范围
- 共修改 49 个 Vue 文件，模板中 `<el-input-number>` / `</el-input-number>` 改为 `<zs-input-number>` / `</zs-input-number>`
- 涉及系统管理（菜单、角色、部门、字典等）、信用评估/评价指标、设施维护/设施定义、产权/指令/合同、补偿安置、问卷调查、自治投票等模块

## 样式与注册
- element-ui.scss：表单内 `.zs-input-number` 宽度 100%
- zs-search-form.vue：搜索表单样式兼容 `.zs-input-number`
- zs-input-number 已在 main.js 全局注册，业务页面无需额外 import
- 组件默认带有 `min: 0`

## 保留不变
- zs-input-number.vue 内部仍使用 el-input-number 作为底层实现（封装组件本身）
- 第三方 CSS（element-ui.css）中的 `.el-input-number` 类名选择器未改动
