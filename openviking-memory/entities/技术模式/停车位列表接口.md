# 物业管理区域停车位列表接口（苏住房G）
苏住房G 项目物业管理区域查询详情页的「停车位」Tab 由子组件 parkingTable.vue 渲染，实际请求停车位分页接口。

## 接口信息
- 请求方式：GET
- 路径：/benefit/pubParkingSpace/page（完整 URL 如 api/v2.0/benefit/pubParkingSpace/page）
- 查询参数：projectId（即物业管理区域 complexId）、pageNum（默认1）、pageSize（默认10）

## 代码位置
- views/publicQuery/complex/components/parkingTable.vue
- mixins/table.js（subTableMixins → getList，默认 apiSuffix 为 page）
- views/publicQuery/complex/index.vue、detail.vue
