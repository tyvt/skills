# 一般表决列表「业务类型」空白：字典过滤与详情不一致
惠山二期G 业主自治一般表决列表的「业务类型」列在详情可选 decisionBusinessType='0' 时显示空白，而「其他表决」正常。

## 问题根因
- 列表页 initDict 把 dictValue '0'（及原逻辑里的 '2'）从 decisionBusinessTypeOptions 过滤掉，自定义 formatter 只能在过滤后的 options 里找 label，找不到就空。
- 详情页未排除 '0'，数据合法但列表展示断层。

## 修复方案
- 列表列改为与同模块一致的 type: 'dict'，字典码 decision_business_type，走完整字典而非过滤后的 options。
- 搜索区 initDict 过滤条件与详情对齐（仅排除 '2'，保留 '0' 可筛）。
- 推广：任意「详情可选、列表 formatter 依赖局部 options」的字典字段，都要核对列表/搜索/详情三处字典子集一致；列表优先 type:'dict'，避免手写 formatter + 局部 options 组合。

## 验证与归属
- 验证证据：一般表决详情页选择业务类型列表页不展示；详情允许 decisionBusinessType='0' 而列表原先过滤掉 '0' 导致 formatter 找不到 label；列改为 type:'dict' 走 decision_business_type；initDict 过滤从排除 ['0','2'] 改为仅排除 ['2']。
- 涉及文件：zhi2-web-admin/src/views/autonomy/general/index.vue、zhi2-web-admin/src/views/autonomy/general/detail.vue。
- 所属项目：惠山二期G；来源会话：24864aca-3eff-4a2b-8d94-e4ce7b40b21d；代码基线：bda09e5。
