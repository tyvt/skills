# 变更表单同值隐藏角标
苏州市房地产监测V3 项目修复变更编辑页在当前值与原值语义相同时仍显示红色「原值」角标的问题。

## 问题现象
- 变更编辑页对字典字段、行政区划、金额等，当前值与原值仅格式或空白差异时仍误显红色「原值」角标。

## 修复内容
- 新增 formChangeTooltip.js：resolveFormChangeTooltip 对变更前/当前值用同一套 formatValue 后再比较。
- normalizeChangeCompareText 统一「/」与空白（如「江苏省 / 苏州市」与「江苏省 苏州市」）。
- formatAmountForChangeCompare 处理 108.89 与 "108.89" 等类型差异。
- pickRegionFieldValue 让区划取值与详情展示一致，空数组不挡住 administrativeArea。
- DeveloperBasicInfoForm.vue 字典字段改为 v => dictLabel(..., v) 双侧格式化；行政区划用 changeProvinceCityAreaTooltip + pickRegion。
