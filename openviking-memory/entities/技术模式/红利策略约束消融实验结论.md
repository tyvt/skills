# 红利策略约束消融实验结论
投资推送红利策略的十年消融实验表明，硬约束显著降低回撤但并非全部来自因子选股，评估时须综合多项指标。

## 关键发现
- 完整硬约束（Full）最大回撤约 -28%，显著低于 Baseline 约 -62%
- Full 相对市场年化超额可为负，降回撤不等于相对市场超额收益
- 平均持仓仅约 7 只、平均投资比例约 56%，部分年份零持仓
- 风险改善有相当部分来自现金暴露，不能全部归因于因子选股

## 评估建议
- 写实验结论或调参目标时应同时看年化、回撤、夏普与持仓/投资比例
- 避免只凭回撤改善认定策略 alpha
