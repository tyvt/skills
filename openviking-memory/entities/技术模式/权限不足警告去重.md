# 权限不足警告去重
全局权限不足时统一通过 console.warn 打印警告并去重提取按钮名，避免路由切换重复打印。

## 实现做法
- 在 `src/utils/permission.js` 新增 `warnMissingPermi()` 函数，去重提取按钮名。
- `v-hasPermi` 指令与 `src/main.js` 的 `checkPermission()` 调用该警告函数。
- 路由切换前在 `src/permission/index.js` 重置缓存，避免重复打印。
