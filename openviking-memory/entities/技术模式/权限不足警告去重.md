# 权限不足警告去重
全局权限不足时统一通过 console.warn 打印警告并去重提取按钮名，避免路由切换重复打印。

## 实现做法
- 在 `src/utils/permission.js` 新增公共方法：`hasPermiMatch()`（统一权限判断）、`warnMissingPermi()`（去重后打印警告）、`getPermiElementLabel()`（从 DOM 提取按钮名称）、`setPermiWarnRoute()`（路由切换时重置去重缓存）。
- `v-hasPermi` 指令与 `src/main.js` 的 `checkPermission()` 调用该警告函数；`v-hasPermi` 无权限时打印 `[权限不足] 权限字符: system:user:add, 按钮名称: 新增`，`checkPermission()` 的 `v-if` 场景按钮名默认为「未知」。
- 路由切换前在 `src/permission/index.js` 重置缓存，避免重复打印。

## 控制台输出示例
- `[权限不足] 权限字符: system:user:add, system:user:edit, 按钮名称: 新增`
- `[权限不足] 权限字符: estate:maintainDecision:revoke, 按钮名称: 撤回`
