# 业委会物管会变更委员锁定
淮安物管业主自治变更详情页在保存后限制委员增删，并调整联系人必填规则。

## 实现要点
- 物管会/业委会变更详情页向 MemberInformationTable 传 :editable="form.bizState == '0'"（草稿可增删）、:businessType（物管会 3 / 业委会 2）、:complexId。
- 联系人/电话改为非必填：物管会移除 secretaryName、secretaryPhone 必填；业委会移除 contactName、officePhone、secretaryName、secretaryPhone 必填；均保留电话格式校验。
- MemberInformationTable 行内删除：editable=true 时操作列增加「删除」按钮（DELETE /autonomy/ownerCommitteeMember/{id}），顶部保留批量删除。
- 物管会变更页 businessType 由错误 '2' 修正为 '3'。
