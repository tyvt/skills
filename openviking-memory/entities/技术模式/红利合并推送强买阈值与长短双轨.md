# 红利合并推送：强买阈值与长短期双轨文案
多指数合并推送后，「强烈买入」要求股债利差 > 3.2%（2%～3.2% 为常规买入/加倍定投视估值分区而定），每条指数同时输出长期定投与短期波段两行建议。

## 强买阈值与估值分区
- 强烈买入：股债利差 > 3.2%；2%～3.2% 为常规买入/加倍定投（视估值分区）
- 黄金坑：PE<7.5 且股息率>5.5%；击球区：PE 7.5–8.5；观察区：PE 8.5–9.5；高估区：PE>9.5 或股息率<4.5%

## 长短双轨建议
- 每条指数同时输出「长期定投」与「短期波段」两行建议
- 短期卖出含：PE≥10 且股息率<4%、高估区、利差<1% 止盈、<0.5% 强烈卖出等
