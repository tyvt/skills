# 企业变更详情变更角标接入
淮安物管企业变更详情查看页需接入与物业区域备案变更一致的字段级变更角标（红三角+悬停原值）。

## 背景与原因
- 行业管理→企业变更详情查看页需字段级变更角标，而非仅弹窗变更记录。
- DetailTemplate 依赖 change-before-object 与每项 field 与 beforeForm 对齐；企业变更 contentInfo 若缺 field 无法 diff。
- 行政区域比编码与比展示文案不一致会误报/漏报；与变更记录弹窗、审核后变更角标缺失互补，本条是查看态接入与特殊字段对比口径。

## 解决方案
- companyManagement/components/detail.vue 查看模式给 DetailTemplate 传 :change-before-object="changeBeforeObject"（变更单 beforeForm/原备案）。
- 为 contentInfo、contentInfo2 各展示项补 field 与 beforeForm 键一致。
- 行政区域项配置 changeCompareValue + formatDisplay，按区划名称对比，避免代码与中文名不一致。
- 开户行 bankTable 等子表区块若产品未要求可暂不接入角标；编辑模式原有 v-tooltip 标注保持不变。

## 验收与归属
- 验收：企业变更查看页有改动的普通字段出现角标；行政区域仅名称变化时也能标出；交互与 complexChange 详情一致。
- 验证：会话 f45bc30e（2026-06-23，基线 57275a6）用户要求查看模式接入一致标注；结论修改 detail.vue，说明 field 映射、changeCompareValue 及 bankTable 暂不标注。
