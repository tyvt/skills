# 门户面包屑组件约定
对外门户仅层级页展示面包屑，抽取共享 PortalBreadcrumb 组件并用 .public-portal 前缀压全局 gap。

## 展示规则
- 从首页进入、存在层级关系的二级页需面包屑（如可售楼盘→楼栋列表→销控表、公示公告列表→公告正文）
- 纯列表/空态/无层级页不展示

## 实现约定
- 抽取共享 `publicPortal/components/PortalBreadcrumb.vue`，样式与原经纪页逐像素一致
- 选择器加 `.public-portal` 前缀以压过全局 `gap: 24px`
- 层级项可回跳并保留项目上下文
- BrokerPages 改用共享组件，保留 `.broker-breadcrumb` 类名以免影响 E2E 选择器

## 涉及文件与归属
- 文件：PortalBreadcrumb.vue、PropertyPages.vue、InformationPages.vue、BrokerPages.vue（均在 zhi2-web-admin/src/views/home/publicPortal/ 下）
- 所属项目：门户；来源会话：02ffa87f-5b2c-4899-8321-3dac3ef60f31；代码基线：8c17ba3

## 验证证据
- 用户：「首页链接点击的，有层级关系的都需要补充面包屑」
- 最终结论列出页面范围、组件提取与全局 gap 处理
