# 企业变更返回修复
苏州市房地产监测V3 修复开发企业基本信息变更编辑态点击「返回」无法返回且误保存草稿的问题。

## 问题现象
- 变更编辑态修改联系人后点「返回」，URL 仍含 formMode=edit，详情页不出现「变更」按钮，可能回显未保存联系人。
- E2E 用例 01b 首次失败：测试账号联系人空值导致 getByText('') 误匹配空标题节点。

## 修复内容
- 改为仅在联系人有非空值时断言详情页回显，避免空值误匹配。
- 返回后 URL 变为 formMode=view，详情页再次出现「变更」按钮，不出现未保存联系人。
- 再次进入变更时输入框仍为服务端原值，不恢复未保存草稿。
