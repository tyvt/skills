# 价格备案总价输入限制修复
价格备案申请编辑房屋备案价格弹窗的「备案总价」字段因 v-money 指令竞态导致整数小数位限制失效，通过原生输入收敛与提交兜底修复。

## 问题根因
- `v-money` 指令在 onpaste/onblur 直接改写原生 input 显示值并 emit 完整超长数值，`update` 钩子聚焦时跳过回显同步
- 仅修改 `this.form.recordAmountNew` 无法使可见输入框收敛，粘贴/失焦后仍显示超长值（如 15 位整数）

## 修复方案
- 新增 `normalizeRecordAmount`：整数≤10位、小数≤2位，兼容千分位逗号
- `handleRecordAmountInput` 同时收敛原生 input 显示值并保持光标
- 校验规则补「小数≤2位」
- `submitForm` 提交前再兜底归一化一次，三重防护
