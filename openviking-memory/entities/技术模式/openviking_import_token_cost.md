# OpenViking导入token成本随项目规模平方增长
记忆全量导入时，同一项目内各批次累计token呈阶梯式上升，总成本随项目内已有记忆量平方增长。

## 现象与原因
- 每个新批次都要带上该项目已积累的全部实体卡片，导致累计token阶梯上升（如20k→40k→60k→…→266k）
- 大项目尤其昂贵：淮安物管52条耗26.7万token；苏州市房地产监测V3（659条、165批）估算累计可达2500万token
- 转化率偏低：全量已耗809万token仅产出184条记忆（4.5%），因多数内容合并进已有实体卡片，边际成本随项目内记忆量上升

## 验证与归属
- 观察来源：2026-11-02全量导入84个项目会话；涉及项目：淮安物管、惠山二期G、无锡市房地产监测V3等
