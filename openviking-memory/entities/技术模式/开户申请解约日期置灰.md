# 开户申请解约日期字段
淮安物管公共收益模块「开户申请详情页」（pubRegulatoryAccount/detail.vue）的解约日期字段在所有模式下均置灰且新建时无赋值逻辑。

## 字段行为
- 模板中写死 `disabled`，联系人、联系电话同样写死，任何模式（新建/编辑/查看）均不可编辑。
- 查看/编辑已有记录时，值来自 `getPubRegulatoryAccount(accountId)` 后端返回的 `terminationDate`。
- 新建时初始为 `undefined`，且页面没有任何赋值逻辑。
