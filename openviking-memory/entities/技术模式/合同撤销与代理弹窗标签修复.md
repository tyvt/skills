# 合同撤销与销售代理弹窗标签修复
苏州市房地产监测V3 项目中修复了 `contractRevoke/detail.vue` 与 `saleAgencyDialog.vue` 的 Vue 标签不匹配导致的 Vite 报错。

## 问题根因
- `contractRevoke/detail.vue` 第 207 行使用了闭合标签 `</el-input>`，但组件已统一为 `zs-input`，导致 Vite 报错
- `saleAgencyDialog.vue` 第 38 行使用了 `</el-button-group>`，应为 `</zs-button-group>`

## 修改内容
- `contractRevoke/detail.vue` 第 207 行 `</el-input>` 改为 `</zs-input>`
- `saleAgencyDialog.vue` 第 38 行 `</el-button-group>` 改为 `</zs-button-group>`

## 验证与归属
- 验证：`commercialHousingSales` + `contract` 目录下全部 Vue 模板扫描通过，输出 `OK: no tag mismatch errors`
- 刷新 Vite dev server 后 `contractRevoke/detail` 页面可正常编译
