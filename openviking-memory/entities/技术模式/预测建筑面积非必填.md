# 房屋维护/变更 predictFloorArea 改非必填须双页同步
惠山二期G 产品要求「预测建筑面积」可选时，须在房屋维护与房屋信息变更两处同步删除 rules 的 required。

## 修改要点
- 在 building/house/detail.vue（房屋维护）与 building/houseChange/detail.vue（房屋信息变更）两处 computed.rules 同步删除 predictFloorArea 的 required: true，不要只改表单展示或某一页。
- 仍应保持必填的常规项：项目、楼幢、单元、房号、实测建筑面积、物理层、名义层、房屋用途等（以各页当前 rules 白名单为准）。
- 与「可选字段 houseNum 靠 rules 白名单」同一套路，但 predictFloorArea 是从必填降级的典型字段名。

## 验收与注意
- 标签前红色 * 消失、清空后前端 validate 通过。
- 若保存仍报「预测建筑面积不能为空」，说明后端 DTO/校验未放宽，需后端同步，前端无法单独闭环。

## 验证与归属
- 验证证据：会话 925383ae 用户要求预测建筑面积改为非必填；两文件 computed.rules 删除 required:true；其余必填项未动并提示后端可能仍校验。
- 涉及文件：zhi2-web-admin/src/views/building/house/detail.vue、zhi2-web-admin/src/views/building/houseChange/detail.vue。
- 所属项目：惠山二期G；来源会话：925383ae-ed0a-489f-85a3-b976ba1ec9e0；代码基线：d13ee4f。
