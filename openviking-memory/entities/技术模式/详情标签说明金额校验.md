# DetailTemplate 字段标签说明 labelTooltip 与可选金额校验
惠山二期G 维保竣工等详情页新增带说明的可选金额字段时的标准做法（Vue2 + Element UI + detailMixins）。

## 标准做法
- 公共组件 detail-template.vue 增加 labelTooltip：有文案时在标签旁渲染问号图标（建议 tabindex="0" 改善键盘可达性）。
- 编辑态：el-form-item 的 slot="label" 内用 el-tooltip 包图标，文案放 content（勿 v-html）。
- 查看态：contentInfo 对应项配置 labelTooltip（可与编辑态共用 computed 文案），type:'amount' + unit:'元'，与表单顺序一致；编辑有说明而查看没有属于产品一致性缺口，按需补。
- 可选金额校验：rules 用自定义 validator，空值直接 callback()；非空用 this.patterns.moneyValidator（Vue.prototype.patterns），value 用 String() 适配数字型 v-model；trigger 可 blur，validateForm 仍会全表校验。

## 数据流与规范
- form 初始字段、setProjectItem 回填、getForm() 提交、detailCallback 全量合并均需覆盖新字段，避免详情有值提交丢失。
- 金额单位写在值侧（type:'amount'），字典列用 type:'dict' 而非 computed dictLabel。

## 验证与归属
- 验证证据：added offlineCheckFeeAmount field with el-tooltip on label、contentInfo with labelTooltip；detail-template.vue 增加 labelTooltip 支持；空值放行非空用 moneyValidator；form 初始/回填/提交/合并均覆盖 offlineCheckFeeAmount。
- 涉及文件：zhi2-web-admin/src/components/detail-template/detail-template.vue、zhi2-web-admin/src/views/maintenance/completion/detail.vue、zhi2-web-admin/src/mixins/detailMixins.js。
