# 红利类回测：全收益指数 ≠ 价格指数 + 现金分红
项目红利回测使用全收益指数等价于分红自动再投，改用价格指数或基金A类NAV会低估收益。

## 回测实现
- dividend_data.attach_total_return_close 合并 total_return_close，_simulate_dca_returns 买卖与估值均用该列，等价于分红自动再投
- 涉及文件：dividend_data.py、backtest_buy_signals.py、config.py、market_data.py

## 口径差异
- 改用价格指数 close 严重低估长期收益（例：930955 十年价格约 +27% vs 全收益约 +85%）
- 基金 A 类「NAV 涨跌 + 现金分红不复投」也不等于全收益指数（021550/020602 实测差数个百分点）
- 业绩比较基准为价格指数×95%+活期，非全收益

## 建模建议
- 贴近现金分红持有体验需单独建模分红现金
- 贴近再投假设应继续用全收益指数
- akshare 可拉 021550、020602 历次分红每份金额验证

## 验证与归属
- 验证证据：akshare 分红数据；基准为价格指数×95%+活期
- 所属项目：投资推送；来源会话ID：3200971f-eca9-40ab-9bff-7d222c281889
