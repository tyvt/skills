# drop_to_buy涨幅熔断反向推演
在 drop_to_buy.py 已有「再跌多少可买」逻辑上，新增昨日已买入时当日涨幅使买入失效的反向推演。

## 反向推演逻辑
- 当昨日估值面板已满足买入时，对当日做价格上浮模拟
- 二分搜索使买入失效的最小当日涨幅，精度与「再跌可买」侧一致，搜索上限约 35%
- 推演重跑完整买入判定（PE/PEG 分位、距低点涨幅等），不限于价格一项

## 报告文案
- 形如「按昨日数据已满足买入条件；当日涨幅超 X% 将不再满足买入」
- 若涨幅需超过上限仍不破买入，则只保留前半句
- 红利、创业板、纳指及 A 股宽基等模块需同步接入

## 验证与归属
- 验证证据：纳指收紧与 report 需求后新增反向逻辑；A500 示例输出涨幅超 0.3% 不再买入
- 涉及文件：drop_to_buy.py、report.py
