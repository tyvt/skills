# 线柱混合图轴单位图例修复
园区物管2.0 的 fundPanorama 页线柱混合图修复左右 Y 轴单位与图例重叠的问题。

## 问题描述
- 左右 Y 轴单位原本挤在轴顶端，与左右上角图例叠在一起造成视觉冲突。

## 修复方案
- 左轴改为 nameLocation: 'middle' 加 nameRotate: 90，「单位：个」竖排在轴线中段。
- 右轴改为 nameLocation: 'middle' 加 nameRotate: -90，「单位：万元」竖排在右轴中段。
- grid.top 收为 38，图例 top: 6、left/right: 8，tooltip 增 confine: true 减少遮挡。
