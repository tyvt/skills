# 资产名称网格滚动修复
惠山公共收益项目 operatingAssets.vue 中「资产名称」区域因无高度上限且外层 overflow:hidden，数据量大时被裁切且无法滚动，已通过限制高度与内部滚动修复。

## 问题根因
- `.operating-assets__name-grid` 为六列网格且无高度上限
- 外层 `.operating-assets__table` 使用 `overflow: hidden`，在抽屉+Tab 固定高度布局中多出的格子被裁掉且无滚动区

## 修复方案
- 为 `.operating-assets__name-grid` 增加 `max-height: min(55vh, 520px)` 限制高度，兼顾不同屏幕
- 增加 `overflow-y: auto` 使超出部分在「资产名称」格子内纵向滚动
- 增加 `overflow-x: hidden` 避免横向误滚
