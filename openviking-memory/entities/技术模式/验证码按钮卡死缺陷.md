# 验证码按钮卡死缺陷
忘记密码页图形码错误后获取验证码按钮永远停在「发送中…」，用户被卡死无法重试。
## 现象
- 填错图形验证码点获取验证码，Toast 提示错误，但按钮不倒计时也不恢复
- 控件内部置 sending=true，复位依赖调用方回调，失败分支未处理致永置 loading
## 根因
- VerifyCode/index.vue 点击即置 sending=true，复位依赖传入的成功/失败回调
- PhoneForm.vue 的 sendCode 只处理成功分支，接口失败不调 onFail 也不刷新图形码
## 修复做法
- 控件用 settle 统一收敛成功/失败，保证只结算一次、任何分支都复位
- 调用方在每条异常路径显式 onFail，最好 try/finally 兜底
- 图形码失败必须 resetImageCode()（刷新图片+清空输入）
- 成功回调仅在接口 code 200 后调，本项目无独立图形码校验接口，不要造两段式
- ImgCode组件增ref，失败时resetImageCode()清空输入；sendCode对齐phone.vue模式，成功countDown()、失败resetImageCode()+onFail()，并补全form的imageCode、udid字段
