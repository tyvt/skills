# 租赁合同详情页撤销终止续期
在 @zhi2-web-admin 的 leaseContract/detail.vue 中参照 indemnity/contract/detail.vue 新增合同撤销、终止、续期功能。

## 模板修改
- operation-btn-group 内「直接签约」后新增撤销/终止/续期按钮，仅 form.bizState == '2' 时显示
- previewBill 后新增「合同续期」对话框，确定时调用 confirmRenew

## 数据与方法
- 数据：renewDialogVisible、renewEndDate（初值 null）
- handleRevoke/handleTerminate 二次确认后提示成功并调用 getDetail()
- handleRenew 打开弹窗默认带出 form.endDate
- confirmRenew 校验日期并格式化
