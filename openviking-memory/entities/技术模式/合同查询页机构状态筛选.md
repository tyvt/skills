# 合同查询页机构状态筛选
在 @zhi2-web-admin 的 query.vue 中新增「机构信息」「申请状态」两个查询条件，支持按机构名称和审批状态筛选合同。

## 修改内容
- queryParams 增加 companyName、approvalFlag 两个参数（初值 undefined）
- data 增加 approvalFlagOptions 用于申请状态下拉
- formItems 在「项目名称」后增加机构信息输入框（model: companyName）与申请状态下拉框（model: approvalFlag）
- initDict() 请求字典 project_verification_approval_flag 并赋值 approvalFlagOptions

## 查询栏顺序
- 项目名称 → 机构信息 → 申请状态 → 产权单位（按页面类型）→ 项目类型
