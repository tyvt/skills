# 红利低波轮动止损与优化流水线
投资推送的红利低波轮动子项目全库无 ATR 止损，卖出侧为固定百分比止损，并配有超参优化流水线。

## 止损与卖出
- 全库 grep ATR 零匹配，无 ATR 止损实现
- 固定百分比止损 `resolve_stop_loss_pct`（risk_regime.py）：低波约 -12%，池中位波动≥25% 时约 -8%
- 其他卖出：紧急大跌、静态止盈、移动止盈、动量卖出

## 选股约束
- `scoring.select_with_industry_cap` 从约 `top_n*3` 候选贪心选股
- 单行业权重超 `MAX_INDUSTRY_WEIGHT`（默认约 34%）则跳过该行业下一档

## 超参优化流水线
- `backtest_optimize.py`：`screen` 单参扫描 → `grid` 粗网格（如 top_n×rebalance_days×sell_rank_multiplier 共 27 组）→ `bayesian` 精调
- 任务开关 `--task screen|grid|bayesian|all`

## 验证与归属
- 验证证据：grep ATR 零匹配并列卖出类型与 COARSE_GRID 三维网格
- 涉及文件：backtest.py、scoring.py、backtest_optimize.py、risk_regime.py
- 所属项目：投资推送；来源会话ID：7d8be0ac-1851-4d3b-9493-fbdadb789d12
