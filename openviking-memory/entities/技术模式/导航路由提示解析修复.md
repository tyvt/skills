# 导航路由提示解析修复
苏州市房地产监测V3 中 `buildDetailNavigation` 用路由 name 第一段作 `pathHint`，导致合同缴款/退款误命中定金路由，已在 `ruoyi.js` 新增 `resolveListRoutePathHint` 修复。

## 问题根因
- `buildDetailNavigation` 用路由 name 第一段作 `pathHint`（`Notice` / `Refund`）
- 合同缴款与定金缴款共用 `notice/detail`，合同退款与定金退款共用 `refund/detail`
- 解析时总是命中第一个详情路由（定金）

## 修复内容
- `zhi2-web-admin/src/utils/ruoyi.js` 新增 `resolveListRoutePathHint`，按路由模式提取有区分度的 hint
- `Notice/CONTRACT_PAYMENT_NOTE` → `CONTRACT_PAYMENT_NOTE`；`Refund/contract` → `contract`
- `ACCOUNT_OPEN/account` → `ACCOUNT_OPEN`；`additional`/`correction` 等 → path 末段
- 新增验证脚本 `scripts/resolve-list-route-path-hint.test.mjs` 与 e2e `deposit-payment-refund-navigation.spec.js`
