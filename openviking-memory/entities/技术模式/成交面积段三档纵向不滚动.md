# 成交面积段三档卡片纵向并排不滚动
「商品房/存量房(全部)」视图右侧「成交面积段」三档卡片改为纵向均分、一屏可见、不滚动。

## 问题现象
- 切到「商品房/存量房(全部)」时，右侧「成交面积段」三档卡片（<=90㎡ / 90-144㎡ / >=144㎡）挤在一起。
- 文字（90㎡、商品房 23.3%、存量房 38% 等）互相重叠溢出、排不下。

## 根因
- 面积段面板被 `flex-1 min-h-0` 挤压，三档卡片在有限右列高度里塌缩导致内容溢出到相邻卡片。
- 上半行右列高度约 356px，不够放三档加结构条。

## 解决方案
- 三档卡片改为 `flex-1 min-h-0` 在面板剩余高度内纵向均分（各占 1/3），去掉 `overflow-y-auto`（不再滚动），容器 `overflow-hidden`。
- 顶部「全域面积段结构」色条 `h-3` 改为 `h-2.5`、图例字号收至 `text-[11px]` 以腾出高度。
- 每卡内部表头与子块去掉多余边框与 `justify-between`，改用 `justify-center + gap`；字号收紧（合计 text-base、子块 text-sm、标签 text-[11px]/[10px]），每卡约 75px 内商品房/存量房两列数值、百分比、面积完整不重叠。

## 验证与归属
- 会话 2026-11-04 构建后三档卡片高度各 75px、bottom 597/678/759 均在面板可视区内、无滚动无重叠。
- E2E 29 项全通过；像素对比 93.98%（面积段版式重排加字体统一的预期差异）。
- 涉及文件：zhi2-web-admin/src/views/property/marketMonitor/components/AreaStructurePanel.vue。
