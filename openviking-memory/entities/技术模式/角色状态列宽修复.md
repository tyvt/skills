# 角色状态列宽修复
苏州市房地产监测V3 项目中角色管理列表「状态」列因宽度不足导致开关与「创建时间」列重叠，已修复。

## 问题根因
- 角色管理「状态」列使用 `type: 'custom'` + `el-switch`，列宽按开关列默认 60px 计算
- 60px 装不下开关和单元格 padding，开关绘制到相邻「创建时间」列

## 修复方案
- `zs-table-column.vue` 中 `FIXED_TYPE_WIDTH.switch` 从 `60` 调整为 `96`（与管理员列表 `slot-width="96"` 一致）
- `system/role/index.vue` 状态列增加 `slotWidth: 96`，避免被压窄
