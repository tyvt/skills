# 合同签订页按钮组公共封装改造
苏州市房地产监测V3 项目中，预售和现售合同签订详情页 `contract/index.vue` 已改用 `OperationBtnGroup` 公共组件替换自定义 toolbar。

## 改造内容
- 合同签订场景（`comeFromMainInfo`）：用 `OperationBtnGroup` 替换自定义 `toolbar`
- 内置承担保存、提交（`ZsSubmit`，修复原未注册的 `<Submit>`）、附件
- slot 保留业务按钮：审批、撤销、重签、人工备案、缴款、数据变更、打印
- 编辑、返回走自定义逻辑（`handleEdit` / `goBackToListPage`），避免与全局 `changeFormState` 冲突
- 新增 `contract-info-bar` 展示合同编号与抵押/托管提示

## 其它场景与新增
- 范本/变更等其它场景继续用原 `toolbar`，行为不变
- 新增 computed：`showContractEdit` / `showContractSave` / `showContractSubmit` 控制按钮显示

## 验证与涉及文件
- 验证：Linter 无报错；E2E 因环境登录凭据失败（用户密码错误），与本次改动无关
- 涉及文件：`contract/index.vue`、`components/OperationBtnGroup/index.vue`、`commercialHousingSales/presale/contractRevoke/detail.vue`
- 所属项目：苏州市房地产监测V3；来源会话：29d17583-217e-40d1-b67e-272fdaa2a94d
