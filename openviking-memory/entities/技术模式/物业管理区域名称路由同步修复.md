# 物业管理区域名称路由同步修复
产品2.0 的 complexChange/index.vue 修复列表首次请求未从路由 query 同步物业管理区域名称的问题。

## 问题原因
- `listMixins` 在 `created` 里先读本地缓存再立即执行 `init()` → `getList()`，不会把 `$route.query` 合入 `queryParams`
- 带 `?complexName=xxx` 进入时，表单和首次请求都拿不到该值

## 修复要点
- 新增 `syncComplexNameFromRoute()`：从 `$route.query.complexName` 取值（兼容数组），写入 `queryParams.complexName`
- 重写 `init()`：先 `syncComplexNameFromRoute()`，再 `initDict`，最后 `getList()`，确保首次拉列表前名称已进搜索条件

## 涉及文件
- zhi2-web-admin/src/views/property/complexChange/index.vue
- zhi2-web-admin/src/views/property/complex/detail.vue
- zhi2-web-admin/src/mixins/listMixins.js
