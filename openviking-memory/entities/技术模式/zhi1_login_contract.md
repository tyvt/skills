# zhi1 企业注册登录契约（太仓物管）
太仓物管 zhi1-web-admin 企业注册优化流程中关于机构编码、匿名临时账号、凭证交接与验证码的行为契约集合。

## 机构与业务编码
- 机构类型短码 `01/04`。
- 附件业务码 `040100/040600`。

## 匿名临时账号
- 首页 `createTempAccount` 创建匿名临时账号，有效期 7 天，密码仅在创建响应返回一次。
- 登录后回注册页可编辑回填五项基础信息；凭证失效（401）时需重新登录。
- 需绕过临时账号的动态路由生成。

## 凭证交接与验证码
- 凭证弹窗进登录时预填账号与密码，并显示带账号名的续填提示。
- 按原型用 Vuex 内存一次性交接、登录页读取后立即清空；路由只带 `tempAccount=1`，凭据不入 URL 或持久存储（2026-11-14 核对原型脚本）。
- 验证码在登录与注册页默认隐藏，仅接口明确返回开启时才显示并校验，详见实体卡「zhi1 登录注册验证码默认隐藏」。

## 归属
- 所属项目：zhi1-web-admin（太仓物管前端）企业注册流程优化。
