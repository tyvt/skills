# 多选列宽度修复
苏州市房地产监测V3 中 `zs-table-column` 把多选列（`type="selection"`）当成普通可拉伸列，导致无数据右侧留白时多选列被拉宽，已修复。

## 问题原因
- 表格无数据、右侧留白较多时，多选列被均分拉得很宽，复选框仍靠左，与「序号」列之间像空了一大块
- `zs-table-column` 将多选列等同于普通可拉伸列参与剩余宽度分配

## 核心修复
- `zs-table-column.vue`：多选列固定宽度 55px（与 Element UI 默认一致）
- 多选列与序号列一样不参与剩余宽度均分
- `limitAdd` / `limitCancel` 编辑态带勾选列的页面一并变好

## 验证与归属
- 验证：刷新「限制审核列表」详情页「关联房屋详情」表格查看
- 若序号列仍偏宽，可把 `width="60"` 改为 `80` 或提期望宽度
- 涉及文件：`zs-table-column.vue`、`houseLimit/detail.vue`、`houseLimit/limitAdd.vue`
- 所属项目：苏州市房地产监测V3；来源会话ID：8983ad7d-8f26-4431-a6d1-191eab39fdfc
