# 本地报告与微信推送脚本分离约定
投资推送项目将本地看报告与微信推送脚本分离，职责清晰划分。

## 职责划分
- core.py：仅保留红利模块库函数（如 generate_report()），已移除 main() 与 if __name__ == "__main__" 入口，不再作为本地 CLI
- push.py：生成报告并走 Server酱，供定时任务；推送行为统一为仅显式 --push 时才推送
- notify.py：承载推送实现

## 验证与归属
- 验证证据：用户「推送解耦」「运行 core.py 没有输出」；结论表 core.py / push.py / notify.py 职责划分
- 涉及文件：core.py、push.py、notify.py、run_push.bat（run_report.bat 已不再维护）
- 所属项目：投资推送；来源会话ID：44ec2513-8219-4016-9443-488909474cfe, ed0c79a0-7954-45ec-a6e8-6498987b7dc4
