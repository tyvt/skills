# 楼幢选择弹窗右侧空白修复
苏州市房地产监测V3 修复楼幢选择弹窗右侧空白问题，通过全局样式与重算列宽让表格拉满。

## 问题原因
- `building-table-mode` 样式类挂在 `el-dialog` 根节点，原先写在 `scoped` 里部分规则未生效
- 弹窗缩放动画结束时表格未重算列宽，表头按列宽之和收缩，右侧留白

## 本次改动
- 楼幢选择弹窗增加全局样式，保证 `dialog-box` → 表格整条链路 `width: 100%`，表头/表体 `table` 拉满
- 弹窗 `opened` 与数据加载后调用 `scheduleBuildingTableLayout()`，重新 `doLayout` + 均分剩余列宽
- `zs-table` 在容器尺寸变化时触发列宽均分；楼幢模式下强制 `fit=true`

## 涉及文件与归属
- 涉及：`presale/permit/components/PresaleSelectBuildingDialog.vue`、`presale/cashsale/components/CashsaleSelectBuildingDialog.vue`
- 所属项目：苏州市房地产监测V3；来源会话ID：04b888af-55b7-4c21-b814-11469c4ecc4f
