# 宽基买入信号年际频率估值分位分析
投资推送项目中宽基买入信号年际频率骤降时优先查估值分位而非仅调阈值的分析规则。

## 分析原则
- 对比 2022–2024 高买入占比与 2025–2026 接近零信号时，常见解释是当前宽基估值处于高位（分位偏高），而非单一阈值写错
- 微调创业板等指标后，部分年份仍为 0 买入天（如 2020、2021），说明当年低点估值分位本身不满足条件

## 操作方法
- 用多年 logs/backtest 分年表做指标松紧分析时，应分指数独立阈值并记录买入占比与信号收益，再决定改 config 还是接受「高位少买」

## 验证与归属
- 2025–2026 A 股宽基（含中证500、科创50）零或近零信号；创业板微调后 2020/2021 仍为 0 天
