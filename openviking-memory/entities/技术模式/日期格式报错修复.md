# 日期格式报错修复
`el-date-picker` 的 `value-format` 含末尾空格且 `applyTime` 未转字符串，导致非 Date 对象调 `getHours` 报错，已通过格式化修复。

## 问题根因
- `el-date-picker` 的 `value-format` 含末尾空格。
- `applyTime` 未转为 `yyyy-MM-dd` 字符串，致 `modifyDate` 拿到非 `Date` 对象调用 `getHours` 报错。

## 修复方案
- 将 `value-format` 改为 `yyyy-MM-dd`。
- 在 `getDetail` 赋值 `form` 后使用 `this.parseTime(applyTime, '{y}-{m}-{d}')` 格式化。
