# 租赁机构注册登录弹窗跳转带参
苏州市房地产监测V3 中登录页「机构注册」弹窗未接入租赁机构注册路由，修复后由弹窗选项跳转 `/leaseInstitutionRegister` 并带参。

## 问题根因
- 登录页「机构注册」弹窗未接入 `/leaseInstitutionRegister` 路由入口
- 仅展示经纪机构注册，缺少租赁机构注册入口

## 关键修复
- `OrgTypeDialog.vue` 增加 `data-testid="org-type-lease"` 租赁选项
- `login.vue` 选择后跳转 `/#/leaseInstitutionRegister` 并传递 `organType=lease`、`busCode=030300` 参数

- `src/views/company/institutionRegister/index.vue`
