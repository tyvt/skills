# 苏住房防汛前端远程模式
苏住房防汛C端前端在 demo 与远程后端之间切换的集成策略。

## 开发约束
- 前端整体在 master 上未跟踪(`??`)，无干净基线；因 solo master 且无其他 worktree，直接在目录开发（不建 worktree）

## 数据模型
- 页面强耦合 demo store 的 `FloodRecord` 形状(values/status/createdAt/kind/id)
- 远程模式「藏」在现有 store 接口后：保持 FloodRecord 为对外模型，remote 模式各方法调后端并映射 VO→FloodRecord

## 接口路由
- 草稿(draft)在 remote 模式仍仅存本地(uni storage)，提交才发后端
- 提交走 POST /inspection/save(bizState draft) 再 /inspection/submit 或合并
- 历史页走 GET /inspection/page + /rescue/page，详情走 GET /inspection/{id} 或 /rescue/{id}
