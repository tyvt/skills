# 物业大屏排名区留白修复
淮安物管物业数据大屏全屏后排名列表底部留白，需改 flex 链撑满并用 ResizeObserver 算可见行。

## 问题现象
- 物业管理大屏（property/dashboard）全屏后，左侧「项目负责人技能等级排名」等卡片变高，但列表底部仍大片空白。
- rankingList.vue 的 .ranking-list-box 写死 height:160px（约5行）；父级 grid 已用 grid-template-rows:1fr 拉高卡片，列表高度不跟涨。
- 滚动动画若固定用「行数>5」判断，全屏后可见行数变大仍会误判。

## 解决方案
- baseCard.vue：卡片 height:100% + 纵向 flex，内容区 flex:1。
- rankingList.vue：列表区 flex:1 + min-height:160px（非全屏保底），ResizeObserver 按容器实际高度算可见行数，仅当数据行数超过可见行才开滚动动画。
- dashboard/index.vue：排名卡片加 ranking-card，content-box 设 min-height:0 让 grid 子项高度向下传递。
- 大屏/数据看板同类组件（largeScreen 下 rankingList）改法一致。
