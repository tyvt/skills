# 物业合同变更从备案详情发起
淮安物管物业/前期物业合同变更只能从已备案的备案详情发起，变更列表隐藏「新增」按钮，通过路由参数预填合同。

## 业务要求
- 合同变更不能在变更列表里点「新增」再手选备案合同，只能从已备案的备案详情发起，与物业管理区域、项目等模块一致。

## 实现要点
- propertyContract/components/index.vue 在 businessType === CHANGE 时列表工具栏只保留「删除」，隐藏「新增」。
- propertyContract/components/detail.vue 在备案详情（businessType = ADD 且 bizState === '2' 已备案）展示「变更」，跳转变更新增页并通过路由参数 propertyContractId 带入当前合同。
- 物业合同走 propertyContractChange/detail，前期物业合同走 propertyContractTemporaryChange/detail。
- 变更新增页增加 initContractFromRoute：检测到 propertyContractId 时自动调用 setContract 预填，等价于原变更页手动选合同编号。

## 验证与归属
- 验证：会话 3a4b31d6 变更说明与使用流程四步；用户明确要求去除合同变更中「新增」并与其它功能变更流程保持一致。
- 涉及文件：propertyContract/components/index.vue、propertyContract/components/detail.vue、propertyContractChange/detail.vue、propertyContractTemporaryChange/detail.vue
- 所属项目：淮安物管；来源会话：3a4b31d6-e54c-4328-a573-791c837f3ea3；代码基线：22a1d9d
