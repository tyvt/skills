# 资产部位名称点击修复
园区公共收益项目修复资产部位详情页「资产信息综合查询」弹框中部位名称点击无反应及操作列隐藏错误。
## 问题原因
- 点击「部位名称」会 router.push 到当前资产部位详情页；若已在该页，Vue Router 不重复跳转，表现为无反应。
- 操作列隐藏逻辑写成 currentRoute == 'HousePart'，实际路由名是 PubHousePartDetail，判断一直不生效。
## 修复内容
- 当前记录不可点击：在资产部位详情页时，列表中与当前记录相同的「部位名称」显示为普通文本，不再显示链接样式。
- 同路由提示：若仍触发跳转且目标路由与当前一致，提示「当前已在该页面」。
- 修正操作列：在 PubHousePartDetail 页面隐藏「查看」按钮（与部位名称逻辑一致）。
