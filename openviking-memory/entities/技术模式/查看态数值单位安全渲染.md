# 查看态数值单位安全渲染
产品2.0 物业合同详情页带单位的数值字段必须走 type:'amount' + unit，禁止在页面侧用模板字符串预拼单位，避免 undefined 穿透判空显示「undefined㎡」。

## 问题现象
- 物业合同详情页「物业管理区域」占地面积/总建筑面积在数据未维护时显示「undefined㎡」。

## 根因
- 查看态字段配 type:'text'，展示值手动拼接模板字符串 `${this.form.landArea}㎡`。
- landArea 为 undefined 时拼出非空字符串「undefined㎡」，DetailTemplate 空值判断被绕过，永远轮不到「-」占位。

## 解决方案
- 带单位的数值字段查看态一律配 type:'amount' + unit:'㎡'（需小数位再配 dot:2）。
- 原始数值交给 DetailTemplate 的 getAmountDisplay 处理——值为空自动显示「-」、有值时才拼单位。
- 禁止在页面侧用模板字符串预拼单位。

## 验证与涉及
- 验证证据：根因是模板字符串拼接 `${landArea}㎡` 在值为 undefined 时产出非空字符串绕过判空，改为 type:'amount' + unit:'㎡' 交给 getAmountDisplay 统一处理。
