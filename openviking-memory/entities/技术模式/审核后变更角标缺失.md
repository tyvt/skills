# 审核后企业变更角标缺失修复
淮安物管企业变更单审核通过后，变更详情字段对比角标（红色三角、悬停原值）全部消失，根因为详情误读已更新的主档作变更前。

## 问题现象
- 企业变更单审核通过后打开变更详情，已改字段的变更角标与悬停「原值」全部消失。
- 变更记录弹窗或字段对比逻辑仍期望有「变更前」，但前后值相同导致 diff 失效。

## 根因与修复
- 审核通过后企业主档 companyRecord 已是变更后数据；详情若从该接口或当前主档取「变更前」，前后值相同使 diff 失效（与空→有值 hasChangeIndicator 问题不同，本条是数据源选错）。
- 在 companyManagement/components/detail.vue 增加 setChangeBeforeForm：优先用变更单详情返回的 originInfo/originalObj（审核时快照），无则回退查当前备案（适用于审核中）。
- detailCallback 加载变更详情后调用 setChangeBeforeForm；changeBeforeObject 计算属性增加对 form.originInfo/form.originalObj 的回退。
- 同步修复 toB/companyRecord/detail.vue 等同逻辑；若仍无角标核对 /company/companyRecordChange/{id} 是否在审核通过时持久化快照字段。

## 验证与归属
- 验证：会话 de0cc397（2026-06-26，基线 202a641）根因定为审核后主档已更新仍用其作变更前，结论为 setChangeBeforeForm + detailCallback + changeBeforeObject 回退。
- 验收：审核后查看企业变更详情，已改字段应显示角标，悬停可见「原值：xxx」，与物业管理区域备案变更表现一致。
