# 门户表格链接加粗约定
对外门户二级页表格可点击链接加粗时，`font: inherit` 简写会冲掉 `font-weight`，须调整书写顺序。

## 问题根因
- 公共类 `.portal-link` 使用 `font: inherit` 简写，将 `font-weight` 重置为继承值
- 导致后续 `font-weight: 700` 无效或部分链接仍不加粗

## 修复约定
- `font-weight: 700` 必须写在 `font: inherit` 之后
- 经纪机构/经纪人列表编号链用独立类 `.broker-index-link`，不在 `.portal-link` 覆盖范围内，需单独设字重
- 门户仅提供 SourceHanSansCN-Regular 时 700 为浏览器合成粗体

## 涉及文件与归属
- 文件：zhi2-web-admin/src/views/home/publicPortal/portal.scss、zhi2-web-admin/src/views/home/publicPortal/pages/BrokerPages.vue
- 所属项目：门户；来源会话：session_f4b84f4ec133d87666e8098da70a6b80；代码基线：dfee5a6

## 验证证据
- portal.scss 注释：「font 简写会重置字重，故 font-weight 须写在其后」
- BrokerPages `.broker-index-link` 补字重及全表 computed 字重 700 验证
