# 人防车位筛选空数据根因
园区物管2.0 中 `zhi2-web-admin` 仓库搜索无 `StandingBook` 等 Java 后端文件致人防车位筛选显示为空。

## 问题根因
- 前端仓库不含后端 Java 文件（如 StandingBook），本地搜索/构建缺失相关定义
- 前端采用字典解析与标签匹配方式处理筛选

## 解决方案
- 切换筛选时带参请求 `selectParkingSpaceList` 接口重拉列表（后续 operatingAssets.vue 改为纯前端过滤，见 parking_filter_frontend）
- 不依赖缺失的后端文件，靠前端字典与标签匹配

## 涉及文件与归属
- 涉及文件：benefit/statisticsMap/operatingAssets.vue、benefit/pubParkingSpace/components/parkingDialog.vue、benefit/statisticsMap/components/ParkingAssetDialog.vue、benefit/parkingSpace/index.vue、benefit/pubParkingSpace/components/parkingTable.vue、benefit/statisticsMap/assetLease.vue、benefit/pubParkingRate/detail.vue、benefit/statisticsMap/mockApi.js
- 所属项目：园区物管2.0；来源会话：a9ba015b-6bbe-4dd8-aec5-80470e748ad2
