# 银行回单核销业务约定
园区物管2.0 的 benefit/pubVerificationReceipts 模块对接后端时，借贷方向字段与回单流水号编辑态锁定的业务契约与技术做法。

## 业务契约
- 借贷方向字段 loanDirction 后端收中文「借/贷」而非 1/2 数字字典值，语义相反需归一化。
- 回单流水号与子表单据列表强绑定：重选回单需删除已选子表单据全部重选，故编辑态禁止换选。

## 实现做法
- 抽 normalizeLoanDirction 归一化函数，在保存(getForm)、详情回填(detailCallback)、选回单回填(fillFormFromBankReceipt)三处统一把 1/2 或字典值转成「借/贷」；选回单弹窗按业务语义筛选：收入类传「贷」、支出类传「借」。
- 用 isReceiptSerialEditable 控制回单流水号仅新增态可点选/清空，编辑态 disabled 并在选择弹窗入口和清空函数加守卫。
- 通用启示：与「子表数据来源于某个主选择项」的单据，编辑态应锁定主选择项而非允许换选后再批量清理。
