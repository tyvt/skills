# 企业新增变更角标修复
淮安物管修复物业服务企业新增时输入框误显红色变更角标的问题。

## 问题根因
- 详情页通过 v-tooltip 指令在输入框右上角显示红色变更角标。
- getChangeTooltip 把当前值与 beforeForm 对比；新增时 beforeForm 为空，填写即判为「有变更」并显示（空）提示。

## 修复方案
- 变更角标仅在变更模式（isChange === true）下展示，普通新增、编辑不再显示。
- getChangeTooltip 首行增加 if (!this.isChange) return '' 提前返回。
- 从已有企业发起「变更」时，变更标识仍正常显示。
