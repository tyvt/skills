# 买入金额排名重复计算与磁盘缓存优化
全量报告慢的主因之一是各指数/图表重复触发收益率排名，通过并行预加载与落盘缓存修复。

## 问题背景
- 各指数/图表重复触发收益率排名（单次约 25s，红利+宽基可各占 ~173s）
- 组合模式下 get_chart_buy_amount 重复触发排名

## 修复方案
- 并行预加载面板、排名结果落盘 cache/ranking_allocation.json（数据未变则秒级命中）
- config 侧对 get_cn_broad_signal_config 使用 lru_cache
- 修复组合模式下 get_chart_buy_amount 重复触发排名的问题
- 数据更新后需跑 sync_data_cache.py 刷新排名缓存

- 验证证据：优化后报告冷启动 ~26s、缓存命中 ~8s
