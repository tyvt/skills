# 自治变更单草稿态委员管理
淮安物管业委会/物管会变更单在草稿态（bizState=0）放开委员子表增删，并与备案页字段必填口径对齐。

## 业务背景
- 业委会变更、物管会变更保存后不能新增/删除委员，且联系人、联系电话被设成必填，与「业委会/物管会备案」不一致。

## 实现要点
- 两个变更详情页向共用子表 MemberInformationTable 传入 :editable="form.bizState == '0'"（草稿态才可增删）、:businessType（物管会 3、业委会 2）、:complexId（新增委员选户室）。
- 联系人相关字段去掉 required，保留电话格式校验——物管会：secretaryName/secretaryPhone；业委会：contactName/officePhone/secretaryName/secretaryPhone。
- editable=true 时操作列增加行内「删除」，调用 DELETE /autonomy/ownerCommitteeMember/{id}，顶部保留批量删除。
- 核对物管会变更页勿误传 businessType='2'。
