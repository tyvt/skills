# 报销利息对话框

用于利息报销的分离计算与确认实现模式。

## 描述
- «报销利息计算» 对话框的宽度调整为 900px。
- «利息结算时间» 字段重命名为 «报销利息计算时间»。
- 调用 `calAmountRefund` 显示表格（列：业务账户、房产位置等）。
- 调用 `refundAmountInterest` 以保存。
- 房产位置优先使用 `position` 或拼接。

## 关系
- 计算和确认分为独立步骤。
