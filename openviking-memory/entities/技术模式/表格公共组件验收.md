# 表格公共组件验收规范
设计稿一致性验收须先确认是否复用公共组件，表格类区域被点名后必须用 zs-table + zs-select-column。

## 验收顺序
- 用户验收顺序：先用公共组件 → 再对齐设计稿，像素对齐但手写表格仍不过
- 手写 el-table 会丢失列宽测算、选中行高亮、空态、固定列、剩余宽度均分等公共能力

## 改造做法
- 复选框列用 zs-select-column，不手写 type=selection
- 序号列用 zs-table-column type="index" 并绑 :index=tableIndex
- 操作列按钮用 plain 边框档（编辑灰框、删除红框，宽度自适应参照 #875）
- 批量删除走 mixins 的 multiDeleteButton
- 表底统计统一 zs-pagination（:show-pagination="false" 只留统计见 #521）
- 样式微调写在列/组件配置，不给 el-table 加页面级覆盖

## 验证与归属
- 会话 58064992（基线 9fb6c2c）用户诉求 5「UI问题」→ 诉求 6「表格没有用公共的组件」
- 最终结论：zs-select-column 复选框列、序号列蓝色、操作列 plain 边框 160px、表底「共 X 条」
