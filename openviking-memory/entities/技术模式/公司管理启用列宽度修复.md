# 公司管理启用列宽度修复
苏州市房地产监测V3 修复 companyAdmin 中「是否启用」列因自定义插槽导致过宽的问题。

## 原因
- zs-table-column 里带 el-switch 的自定义插槽会被当成「复杂插槽」。
- 未声明 type="custom"/"switch" 等固定宽类型时，该列走 isStretchableColumn 参与剩余宽度均分，导致开关列显宽。

## 修改
- 为「是否启用」列加 prop="enableState"、type="custom"、slot-width="96"，走 isFixedWidthCustomSlot 不再均分。
- 可参照 FranchiseTable 等固定宽自定义列；若略紧/宽可微调 88~104。

## 涉及文件
- zhi2-web-admin/src/views/company/companyAdmin/index.vue
