# 腾讯地图坐标安全校验
产品2.0 统计地图页因多边形坐标串分隔符解析错误导致 NaN，所有 LatLng 构造必须走安全校验函数。

## 问题现象
- 统计地图页（benefit/statisticsMap）mounted 阶段抛腾讯地图异常「LatLng 传入参数 (NaN, 120.311972) 非合法数字」。
- 一条脏数据让整个地图初始化崩溃。

## 根因
- 后端返回园区多边形 path 字符串用「;」分隔各点、「,」分隔经纬度，解析函数却按空格 split(' ') 切分，首个点解析成 NaN。
- 构造 LatLng 前无合法性校验。

## 解决方案
- 解析函数统一按 ';' 切点、',' 切经纬度，对接字符串型几何数据必须先确认实际分隔符。
- 封装 createSafeLatLng(lat, lng)，内部 Number 转换 + isFinite 校验，非法值返回 null 并跳过该点。
- initMap、updateCenter、区域标注 nameLocation 等所有构造坐标入口都走安全构造。

## 验证与涉及
- 验证证据：会话结论根因是解析错分隔符，新增 createSafeLatLng 统一转数字校验，getBuildingPaths 从 split(' ') 改为按 ';' 切分，相关入口全改安全构造。
