# 密码登录接口换新须补齐图形验证码三件套
江阴H5 密码登录接口停用换新后，须配套图形验证码展示、刷新、失败重试与防重复提交，换接口是一整套状态接线而非改 URL。

## 问题现象
- 旧密码登录接口停用换带图形验证码新接口，只摆验证码图片功能仍不可用
- 验证码点不动、过期无法重取、连点重复提交、失败后无重试入口
- 提交体少验证码值，后端笼统登录失败，前端无法区分密码错与验证码错

## 解决方案
- 登录页同时提供：验证码图形展示 + 点击刷新（重请求并清空已填值）+ 校验失败时刷新图形并清空输入
- 提交按钮做防重复提交（loading + 禁用），避免同张验证码并发提交两次
- 提交前本地校验验证码值非空，拦在前端不交后端报错
- 验证码接口地址与图形展示组件分离，后端换路径只改一处
- 换接口后回归覆盖四种场景：图形刷新、密码错、验证码错、连续失败锁定
