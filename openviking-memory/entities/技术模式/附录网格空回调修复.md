# 附录网格空回调修复
苏州市房地产监测V3 中只读路径下 `AppendixRequirementGrid` 因回调默认 `null` 触发 `[Vue warn]: Invalid prop` 的问题已修复。

## 问题原因
- 只读路径下 `AppendixPackageSection` 使用 Grid 时不传 `onBeforeUpload` 等回调
- 原先 Grid 默认 `null` 仍会绑定到 `AppendixRequirementCard`，触发 `Expected Function, got Null`

## 核心修复
- `AppendixRequirementGrid.vue` 增加 `appendixUploadNoop` 与 `appendixBeforeUploadNoop`（返回 `true`，与 Element Upload 的 `before-upload` 一致）
- `onBeforeUpload` / `onUploadError` / `onExceed` / `onUploadSuccess` 默认值从 `null` 改为上述 noop
- 编辑态 `AnnexUpload` 仍传入真实 handler，行为不变
