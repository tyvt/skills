# 业委会候选人证明必填修复
园区公共收益项目修复业委会候选人征集时物业费结清证明未必填显示的问题。
## 问题原因
- CandidateDialog.vue 中 showPropertyFeeCertificate 显示条件原为「仅筹备组 + 业主身份」，导致业委会候选人征集（业主身份）未显示必填项。
## 修复内容
- 将 showPropertyFeeCertificate 显示条件改为「业主身份」：showPropertyFeeCertificate() { return this.isOwnerIdentity }。
- 业委会候选人征集中 isOwnerIdentity 恒为 true，「物业费结清证明」显示在「自我介绍」与「其他材料」之间且必填。
- 筹备组征集：业主身份仍显示且必填；非业主身份仍不显示；校验、回显、提交逻辑已绑定无需改动。
