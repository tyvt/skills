# 禅道周报生成
基于禅道完成项与历史 Excel 模板生成研发前端周报的流程。

## 数据源
- 新禅道库 `tiany`，取周一至周五完成的 Bug 与任务，按完成日期排序。
- 该版本禅道无 `zt_execution` 表，改用 `zt_project` 承载执行。
- 无 MySQL 驱动时，直接从已保存的禅道查询结果文件解析数据。

## 模板规则
- 历史周报模板位于工作区根目录，结构为 12 列、两个 sheet。
- 沿用历史映射规则：项目简称→分支、Bug 统一 0.5h、任务取禅道 consumed、类型/备注/进度口径。
- 下周计划 sheet 若本周无新建待办任务则仅留空表头。

## 交付
- 输出如「研发-前端-田野-本周工作总结(2026.11.23-11.27).xlsx」，仅文档交付，不执行 Git 提交。
