# 回测报告慢因逐行遍历与排名未缓存
投资推送回测与报告性能瓶颈源于 `iterrows` 逐行判断及排名重复计算未缓存，已通过向量化与缓存优化。

## 性能瓶颈
- `iterrows` 逐行判断买卖信号，效率低下
- 排名重复计算且未缓存，重复开销大

## 优化措施
- `cn_broad_signal.py` 新增 `vectorized_cn_broad_buy_mask` 并设 `buy_only=True` 跳过卖出
- `backtest_buy_signals.py` 改用向量化掩码与 `build_daily_table_range` 批量构建
- `buy_amount_ranking.py` 并行预加载并将排名落盘 `cache/ranking_allocation.json` 命中缓存
- `config.py` 增加配置缓存
