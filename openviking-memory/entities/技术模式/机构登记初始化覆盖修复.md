# 机构登记初始化覆盖修复
苏州市房地产监测V3 在 detail.vue 覆盖 detailMixins 的 init() 避免请求错误路径。

## 问题根因
- `detailMixins` 在 `formMode: 'view'` 时走 `init()` → `getDetail()`，按 `moduleName` + `businessName` 拼出错误路径 `/company/institutionRegister/detail`

## 修改内容
- 在 `detail.vue` 覆盖 `init()`，避免进入详情页时自动请求不存在的路径
- 保留 `created()` 里的 `loadDetail()` 正常调用 `/company/companyRegister/detail` 加载数据
- `zljg/institutionRegister/detail` 等包装页共用同一核心组件，一并生效

## 涉及文件与归属
- 涉及：`detail.vue`、`api/company/institutionRegister.js`、`api/institution/institutionRegister.js`
- 所属项目：苏州市房地产监测V3；来源会话：1412adc3-5a64-46ef-9d42-ab80e4e6c02f
