# 组织工作人员列表列空白修复
自治域「组织工作人员」分页接口 `/autonomy/ownerCommitteeWorker/page` 与系统用户列表口径一致：组织类型字段为 `accountType`（字典 `sys_account_type_all`），用户状态为 `userStatus`（字典 `sys_normal_disable`）。

## 问题现象
- 从其它模块拷贝列表时若仍绑定 `businessType`、`committee_type` 或 `enable`，列与筛选项会整列空白

## 修复要点
- 组织类型 `businessType`→`accountType`、字典 `committee_type`→`sys_account_type_all`
- 用户状态 `enable`→`userStatus`
- 同步改表格列 `prop`、字典 `dict-type` 及 `queryParams`/搜索表单项的 `model`，搜索 `queryParams` 同步
