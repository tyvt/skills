# 门户横幅 SVG 动效与无障碍
UnifiedLogin 平台横幅将文字与图片拆成多行静态 SVG 后，需同步桌面/移动端入场动效时序并满足无障碍。

## 双 SVG 拆分与无障碍
- 装饰文案拆为 line1/line2 两张静态 SVG（unifiedLoginAsset 路径：platform_banner_desc_line1.svg、platform_banner_desc_line2.svg）
- 子 img 使用 alt=""，整段可读文案由外层 platform-banner-desc-wrap 的 aria-label 承担
- 建议给外层 wrap 加 role="img" 以明确图像组语义，与 badge 区 aria-hidden 分工一致（MEDIUM 建议）
- 动效挂在 platform-banner-desc-wrap 上而非单张 desc SVG

## 动效时序
- intro 与 badge 的淡入动效要在 @media (max-width: 1200px) 为 platform-banner-desc-enter-mobile 补与桌面一致的 animation-delay（如 0.25s）
- 在 @media 内用 animation 简写覆盖桌面规则时，必须同时重写 animation-delay（简写会把未声明的 delay 重置为 0），否则小屏 intro 与 badge 淡入时序会与桌面不一致
- 避免窄屏两行错开时序不一致
- 桌面端原 animation-delay 过大（文案 1.6s、角标 2.5s）导致入场偏晚，已下调为文案 0.25s、角标 1.05s
- 横幅已在视口内时，骨架揭开后立即加 platform-banner--intro，避免依赖 IntersectionObserver 高 threshold 延迟触发
- 横幅在视口下方时，IntersectionObserver 设 threshold: 0 并 rootMargin: '0px 0px 20% 0px' 提前进入可见区即播；仍晚可 delay 改 0 或加大 rootMargin
