# 投资推送代码库模块分层与运行时目录约定
投资推送仓库按职责分层组织代码，并在运行时通过 cache/、logs/、output/ 等目录管理本地产物。

## 模块分层
- 入口脚本：report.py、push.py、sync_data_cache.py、backtest（回测）、optimize（调参）
- 策略数据模块：dividend_data、cn_broad_data、cyb_data、hstech_data、us_index_data
- 策略信号模块：core、*_signal
- 买入金额模块：buy_amount_*
- 回测与 HTML：backtest_metrics、backtest_html
- 共享库：config、data_cache、data_sources、market_data、notify 等

## 运行时目录
- cache/ 按市场分子目录：cn/、cyb/、hstech/、us/，含 position_allocation、ranking_allocation
- logs/ 存放运行日志；output/backtest/ 存放回测产物；push 相关输出目录
- env 为 gitignore 的本地产物，不纳入版本控制
