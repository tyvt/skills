# 用户管理导出能力
淮安物管后台用户管理页（system/user）已对齐公共组件 /export 的导出实现套路。

## 实现要点
- 新增 exportLoading 状态控制导出按钮 loading，防止重复点击。
- operationButtons 在「新增」「删除」后增加「导出」，权限标识 system:user:export。
- handleExport 先用当前 getQueryParams()（含左侧部门树）调 page 预检，有数据则 download('system/user/publicExport', …)。
- 预检与下载共用同一套 params，保证条件一致。

## 验证与归属
- 本地用具备 system:user:export 的账号：选部门、设筛选后点「导出」验证文件与条件一致。
- 涉及文件：zhi2-web-admin/src/views/system/user/index.vue
- 所属项目：淮安物管；来源会话：b5237c44-2fc2-414b-95f7-dfb35674462c；代码基线：none
