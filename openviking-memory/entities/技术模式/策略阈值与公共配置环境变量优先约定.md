# 策略阈值与公共配置环境变量优先约定
投资推送项目将指数列表、数据源 URL、策略阈值、超时等集中在 config.py，环境变量覆盖优先级明确。

## 配置集中
- 指数列表、数据源 URL、策略阈值（如 STRONG_BUY_SPREAD、BUY_CONDITION_SPREAD）、超时等集中在 config.py
- 买入条件利差业务口径为 3.2% 时设 BUY_CONDITION_SPREAD=0.032
- 示例见 push.example.env，密钥仍放 push.env

## 覆盖顺序
- 系统环境变量优先
- push.env 启动时加载且不覆盖已有环境变量

## 验证与归属
- 验证证据：用户纠正「大于3.2%才符合买入条件」；结论「环境变量优先」「push.env 不覆盖已有环境变量」
