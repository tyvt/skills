# 开户申请列表物业管理区域名称链接跳转修复
苏住房G 项目 benefit/pubRegulatoryAccount/index.vue 修复「物业管理区域名称」列点击跳错页面的问题。

## 问题原因
- 「物业管理区域名称」列配置为链接，但点击回调用 handleView，会进入开户申请详情而非物业管理区域详情。

## 修改内容
- 引入 getRouterPathByFilePath。
- 新增 handleViewProject：用行数据的 projectId 或 complexId 跳转到 property/complex/detail。
- 将该列 function 从 handleView 改为 handleViewProject（与同模块 pubBankAccountBalance、pubProjectAccount 一致）。

## 验证与归属
- 所属项目：苏住房G；验证证据：extracted source=cursor project=苏住房G。
- 涉及文件：benefit/pubRegulatoryAccount/index.vue、pubBankAccountBalance/index.vue、pubRegulatoryAccount/detail.vue。
