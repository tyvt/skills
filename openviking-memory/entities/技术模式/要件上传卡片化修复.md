# 要件上传卡片化修复
苏州市房地产监测V3 将要件宫格上传改为 ImageUpload 一致的 picture-card 样式。

## 修改内容
- `AppendixRequirementCard.vue` 标题行只保留要件名称与必填 `*`，可编辑用 `el-upload` + `list-type="picture-card"`
- `AnnexUpload` / `AppendixRequirementGrid` 新增 `removeAppendixFile`，`getList()` 返回 Promise 避免删除后列表回弹
- `EntrustSaleAddAppendix.vue` 接入 `:on-remove-file` 与宫格删除行为一致
- E2E 助手兼容 picture-card 列表项
