# 纳指估值买入阈值与分位参数联动
宽基/纳指模块用 Forward PE 分位、PEG(Forward)、10Y 利率分位等多门槛联合触发买入，放宽单一阈值会非线性增加持仓天数。

## 触发规则
- 宽基/纳指模块采用 Forward PE 分位、PEG(Forward)、10Y 利率分位等多门槛联合触发买入
- 放宽单一阈值会非线性增加持仓天数（例：PE 分位 58%→60%、PEG 1.25→1.28、10Y 分位 86%→88% 使 2025/2026 触发天数上升）

## 调参注意事项
- 继续放宽会纳入更早月份信号，需在 config 调参后对照回测表而非只看单日 PE 报道
- 仍可能 1 月不触发

## 验证与归属
- 验证证据：纳指买入阈值表：2025 5天→9天、2026 8天→31天；仍可能 1 月不触发
- 涉及文件：config.py、compare_broad_indices.py、market_data.py
- 所属项目：投资推送；来源会话ID：60bb7ce4-2e38-4d46-af4c-7a6f738d7055
