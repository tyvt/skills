# 回测估值面板共用优化
回测中排名分配与波段回测曾各自构建估值面板造成双倍开销，需统一预热一次避免重复构建。

## 性能瓶颈
- 排名分配与波段回测各自 BacktestPanels() 全量构建两遍估值面板，约 81s

## 优化方案
- 统一 get_panels() 启动并行预热一次
- 同一交易日买卖信号评估去重缓存
- 热点循环用 itertuples 替代 iterrows
- 多只 A 股宽基回测线程池并行

## 效果与归属
- 优化后约 20–24s 且结果一致（默认 55–81s → ~23s，--portfolio 32s → ~19s）
- 涉及文件：backtest_trade_signals.py
- 所属项目：投资推送；来源会话ID：1b77f0f7-5996-4a5c-bf83-b80f9cb43f04
