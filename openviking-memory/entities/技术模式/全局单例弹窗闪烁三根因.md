# 全局单例弹窗首次打开闪烁三根因
全站级项目选择弹窗（bProjectDialog）首次打开时遮罩/内容闪烁，且先显示「暂无可用物业区域」再切列表，由三个叠加根因导致。

## 问题现象
- 全站级项目选择弹窗（bProjectDialog）首次打开时遮罩/内容闪烁
- 先显示「暂无可用物业区域」空态再切换为列表

## 根因
- ① layout/index.vue 和 Navbar.vue 各挂了一个弹窗实例，两个 el-dialog 同时挂 body（双实例挂载）
- ② layout 的 watcher 在 bProjectData 接口返回前就把 visible 置 true（数据未就绪先开）
- ③ onOpen 里重复调用 initRegionList() 重建列表触发重渲染（打开时重复初始化）

## 解决方案
- 弹窗实例全局只保留一个（Navbar 移除副本，点击时 emit open-project-dialog 事件由 layout 统一管理状态）
- 弹窗内容加载加 dataLoading，loading 期间不渲染空态、接口返回后再决定是否自动弹出
- onOpen 不再重复初始化，缓存恢复仅在弹窗未显示时执行，避免手动切换被自动关闭

## 验证与归属
- 验证：会话 99e0bdb9 最终结论，移除 Navbar 重复挂载、数据就绪后再展示、onOpen 不再 initRegionList，三点修改后闪烁消失
- 涉及文件：zhi2-web-admin/src/layout/index.vue、zhi2-web-admin/src/layout/components/Navbar.vue、zhi2-web-admin/src/views/home/bProjectDialog.vue
- 所属项目：园区物管2.0；代码基线 49e7729ce；来源会话 99e0bdb9-a041-402c-9293-6e332ef231d4
