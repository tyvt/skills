# 趋势图弹性布局修复
园区物管2.0 的 fundPanorama 页修复趋势图高度被压成 0 导致收入/支出图重叠的问题。

## 问题原因
- 趋势图设固定高度后外层容器仍用 flex: 1 1 0 加 min-height: 0，容器高度压成 0 致图表溢出重叠。

## 修复方案
- 恢复趋势区块弹性布局，flex 比例由 1 调为 0.65，趋势图比原来更小。
- 趋势图外层容器改为 flex: 1 1 auto，确保正确撑开高度。
- 各区账户余额横柱状图保持 280px 高度不变。
