# 物业费申报详情行政区域显示编码修复
苏住房G 项目 zhi2-web-admin 修复物业费申报详情页查看模式下「行政区域」显示区划编码而非名称的问题。

## 问题原因
- 查看模式下 DetailTemplate 只渲染 item.value，不执行 formatDisplay
- 「行政区域」的 value 直接绑定区划编码 form.region（如 320585），页面显示编码而非名称

## 修改内容
- 修改文件：zhi2-web-admin/src/views/property/feeDeclare2/detail.vue
- 新增计算属性 regionName，通过 provinceFormatter 将区划编码转为名称（如「昆山市」）
- 在 basicInfo 中将行政区域的 value 从 this.form.region 改为 this.regionName
- 与列表页 regionFormatter、complex/detail.vue 先格式化再展示的做法一致
