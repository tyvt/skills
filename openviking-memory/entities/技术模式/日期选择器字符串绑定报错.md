# 日期选择器字符串绑定报错
Element UI `el-date-picker` 配置 `value-format` 绑定字符串时因内部按 Date 对象调用 `getHours()` 而类型不匹配报错。

## 问题根因
- `el-date-picker` 内部按 Date 对象调用 `getHours()`
- 配置 `value-format` 绑定字符串导致类型不匹配报错

## 修复方案
- 移除 `value-format`，`v-model` 绑定 Date 或 null（`renewEndDate` 初值 null）
- 弹窗打开时 `new Date(this.form.endDate)` 转换
- `confirmRenew` 中用 `getFullYear()` 等格式化 `yyyy-MM-dd` 字符串
