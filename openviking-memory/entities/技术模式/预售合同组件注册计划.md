# 预售合同组件注册计划
苏州市房地产监测V3 中预售合同页用 `data.js` 小写 `comp` 做动态组件，而 `loadComponents` 仅按 SFC 的 PascalCase `name` 注册，导致 `Unknown custom element`，已规划用 `require.context` 双注册修复（当前仍 Plan 模式未改）。

## 问题根因
- `data.js` 使用小写 `comp`（`cover`、`chapter1`…）做动态组件
- `loadComponents` 只按 SFC 的 PascalCase `name` 注册，章节未被识别

## 修复方案
- 在 `zhi2-web-admin/src/views/contract/index.vue` 用与存量房一致的 `require.context`
- 按文件名 + `ctrl.name` 双注册章节组件
