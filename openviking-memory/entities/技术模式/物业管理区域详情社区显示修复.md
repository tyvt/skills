# 物业管理区域详情所属社区显示编码修复
苏住房G 项目 property/complex/detail.vue 修复「所属社区」异步加载前显示编码的问题。

## 修改内容
- contentInfo 计算属性开头增加 `void this.communityOptions`，确保社区列表异步加载后重新计算。
- 「所属社区」由 dictFormatter 改为 formatCommunityDisplay(this.form.community)。
- 新增 formatCommunityDisplay 方法：从 communityOptions 按编码匹配名称，处理 trim / 类型差异，与 complexChange/detail.vue 保持一致。

## 原因说明
- 详情页原用全局 dictFormatter 回显社区，选项异步加载完成前先显示编码；Vue2 计算属性对 communityOptions 依赖收集不稳定。
- 列表页使用 communityFormatter 且全量加载选项，显示正常。
