# 投资推送：实盘报告与回测对同一指数的信号口径刻意分叉
README/配置约定中，报告与回测路径对同一指数采用刻意不同的买卖信号口径，改阈值或卖点前须分清路径。

## 信号口径分叉
- 创业板指：报告与回测均仅买、无卖点
- 宽基卖出：报告中仅移动止盈（中证1000 回撤兜底、科创50 分批），去掉估值卖点
- 红利/美股：报告侧仅买，回测可经智能轮动触发移动止盈（美股回测另有估值卖点）

## 买入与分配
- 买入默认「位置分配 + 年度预算缩放 + 涨跌缩放」
- 实盘与回测各有一套分配逻辑，缓存 cache/position_allocation.json
- backtest_trade_signals 默认走智能轮动（共享资金池 + 轮动门控）

## 验证与归属
- 验证证据：会话 d293249a 按 config.py/report/backtest 脚本补全 README；红利近1年区间阈值 58% 与 config 对齐
