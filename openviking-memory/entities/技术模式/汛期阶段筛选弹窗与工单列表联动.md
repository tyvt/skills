# 汛期阶段筛选弹窗与工单列表联动
苏住房防汛C端工作台汛前/汛中/汛后入口改为弹窗筛选，并把物业管理区域与预警事项参数透传到工单列表页。

## 交互实现
- StageFilterDialog.vue 复刻 tanchuang.html，弹窗内选择物业管理区域与预警事项；确认后 uni.navigateTo 跳 /pages/history/index?kind=..&complexId=..&complexName=..&eventId=..&eventName=..，参数均 encodeURIComponent
- history 页 onLoad 解析 URL 参数存入 selection；顶部双信息卡（theme.css .selection-cards）展示已选区域与预警事项、可清除；有选择时 uni.setNavigationBarTitle；query/refreshCounts 透传 complexId/eventId
- flood.ts：fetchHistoryPage/countHistory 透传 complexId/eventId（后端是否支持待定），并新增 fetchStageEventOptions
- 阶段参数：汛前=2、汛中=3、汛后=4
- 汛前检查 fetchTemplate 原调 /v2.0/safety/flood/event/page（FloodEventServiceImpl.page 带 @DataScope 按部门过滤），致物业账号看不到市住建预警（禅道 Bug 6413，2026-11-10），后改走 B 端 /event/options（只返已备案且阶段匹配，不受部门权限）

## 已知坑
- 分页接口 request raw:true 无 {code,data} 信封（PageVo 直出），mock/联调不要包信封
- 求援分页无 eventId 维度，无法按预警事项过滤
- bun install 会清掉 eslint，验证走 vitest + build
- playwright 需 channel:'msedge'（ms-playwright 缓存缺失）；确认弹窗跳转的 URL 是 uni.navigateTo 二次编码，DOM 断言用 .selection-card/.ticket/.filters
