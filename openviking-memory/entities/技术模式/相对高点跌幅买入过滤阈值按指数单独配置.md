# 相对高点跌幅买入过滤阈值按指数单独配置
为剔除「大跌后仍不合算」的买入，各指数应维护独立的相对近期高点跌幅百分比阈值。

## 配置规则
- 各指数维护独立的相对近期高点跌幅百分比阈值（默认 7%）
- 创业板、纳斯达克100 等需单独放宽或收紧
- 中证红利低波 2024-03、创业板 2024-01 曾密集误买，需剔除

## 调参约束
- 纳指波动大，同一阈值往往过严
- 调参后须用该指数历史信号回测验证
- 勿用单一全局百分比套所有标的

## 验证与归属
- 验证证据：会话 2610cc62，用户要求剔除 3 月不合算买入、全指数加指标且百分比单独设置默认 7%；单独反馈创业板 1 月误买多、纳指限制过严
- 涉及文件：d:/repository/投资推送/config.py、cyb_signal.py、drop_to_buy.py、a500_signal.py
- 所属项目：投资推送；来源会话ID：2610cc62-f656-43bd-a61b-6bb14a5dd85f
