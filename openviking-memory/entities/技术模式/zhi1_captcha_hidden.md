# zhi1 登录注册验证码默认隐藏
太仓物管前端 zhi1-web-admin 的登录与注册页图形验证码按原型默认隐藏，只有接口明确返回开启时才显示并校验。

## 规则
- 登录页与注册页的图形验证码都默认隐藏，原型中本就没有该图形验证码。
- 仅当接口明确返回「开启」时才显示验证码并进行校验。
- 原有开启状态下的登录验证路径必须保留，不得因默认隐藏而删除。
- 默认关闭属已批准的计划决策，原因是视觉基线与原型不一致、后端 worktree 在本环境不可见而无法确认接口要求。

## 变更过程
- 2026-11-14 复核发现登录页也残留原型没有的图形验证码，已加入红测覆盖登录与注册两处默认隐藏行为。
- 后续需在后端明确开启时回归验证码显示与校验链路。

## 归属
- 所属项目：太仓物管前端 zhi1-web-admin（禅道任务 2334 企业注册流程原型还原范围）。
- 代码基线：本地仓库 `D:\repository\太仓G\zhi1-web-admin`。
