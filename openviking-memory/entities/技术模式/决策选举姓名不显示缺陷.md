# 决策选举姓名不显示缺陷
决策记录列表与我的选举页投票人姓名列空白，根因是姓名来自不同数据层级且选举页未同步插槽。
## 现象
- DecisionResult.vue 决策记录列表姓名空白，选举页同样问题
- 意见颜色误改为全黑，未保持同意绿/不同意红/弃权橙
## 根因
- 记录行自带 decisionPlayerName（脱敏「田*」），详情 recordMap 键为 decisionResponseId 字符串，需按链对齐取「李*丹」
- 选举页照抄决策页取数逻辑但 CardCell 插槽没同步，两边一起坏
## 修复做法
- 收敛 resolvePlayerName(row) 单函数（候选 decisionPlayerName → recordMap[x].decisionPlayerName，键 String 归一），两页共用
- 小程序端 CardCell 的 label 属性冲突，显示姓名用 #label 具名插槽
- 改姓名时一并回归意见颜色绑定
## 涉及文件与归属
