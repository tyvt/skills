# 企业基本信息变更单提交修复
苏州市房地产监测V3 企业端「企业基本信息」走变更单时「提交」按钮不显示问题已修复。

## 问题根因
- 企业端「企业基本信息」走变更单（`company-record-change-detail`）保存后切到 `formMode=view`，但 `showSubmitBtn` 原先要求 `isChangeApplyPage`，只有「变更申请」菜单才显示「提交」
- 从基本信息点「变更」编辑保存的场景不满足该条件，导致看不到「提交」

## 修改内容
- `toB/companyRecord/detail.vue`：「提交」显示逻辑与经纪 toB 对齐：`view` 态 + 有 `companyRecordChangeId` + `shouldShowAgencyChangeSubmit(form)`（按 `displayStatus` 判断待提交）
- 「编辑」工具栏用 `resolveAgencyChangeToolbarBizState`，避免已备案企业 `bizState=2` 时误判
- 点击「提交」调用 `submitCompanyRecordChange`
- `api/company/companyRecord.js`：新增 `submitCompanyRecordChange` → `POST /company/companyRecordChange/submit`

- 涉及文件：`toB/companyRecord/detail.vue`、`api/company/companyRecord.js`、`company-helpers.js`
