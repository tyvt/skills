# 划拨通知书变更详情引用错误修复
苏州市房地产监测V3 修复 noticeChange/detail.vue 中 TransactionDetailTable 未导入导致的 ReferenceError。

## 原因
- components 里用了 ES6 简写 TransactionDetailTable 但未 import，模块加载报 ReferenceError。

## 修改
- noticeChange/detail.vue 第 250 行改为异步懒加载注册：TransactionDetailTable: () => import('@/views/supervision/deposit/notice/components/TransactionDetailTable.vue')
- 与同模块 notice/detail.vue 写法一致，无需额外 top-level import。

## 涉及文件
- zhi2-web-admin/src/views/supervision/unblock/noticeChange/detail.vue

## 验证与归属
- 刷新后进入「划拨通知书变更」详情页，控制台不再出现 TransactionDetailTable 报错。
