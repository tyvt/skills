# 回测报告性能优化提速
投资推送项目回测与报告生成经向量化与缓存改造，报告从 ~40s 降至 ~8s，回测全套从 ~194s 降至 ~74s。

## 优化效果
- 报告（排名缓存命中）：~40s → ~8s
- 报告（冷启动，需重算排名）：~46s → ~26s
- 回测全套（买入+买卖）：~194s → ~74s

## 主要改动
- 宽基买入信号向量化（cn_broad_signal.py）：新增 vectorized_cn_broad_buy_mask，回测不再逐行调用 evaluate_cn_broad_buy；回测路径增加 buy_only=True 跳过卖出评估
- 回测循环优化（backtest_buy_signals.py）：用向量化掩码替代 iterrows 逐行判断；build_daily_table_range 批量构建图表数据
- 排名计算加速（buy_amount_ranking.py）：并行预加载全部面板（约 28s → ~18s）；排名结果落盘到 cache/ranking_allocation.json，数据未变时秒级命中；并行计算各指数收益率
- 配置缓存（config.py）：新增 get_cn_broad_signal_config 缓存

## 验证与归属
- 验证证据：用户要求「报告40秒，回测194秒。优化提速一下」，优化后效果如上
- 涉及文件：cn_broad_signal.py、backtest_buy_signals.py、buy_amount_ranking.py、config.py、cache/ranking_allocation.json
- 所属项目：投资推送；来源会话ID：17bbafc8-a23f-4d2e-9dc4-3980f571ac77
