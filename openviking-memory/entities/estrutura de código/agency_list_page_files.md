# Arquivo principal da lista de instituições de corretagem contém filtro e paginação
No projeto Suzhou Real Estate Monitoring V3, o módulo 经纪机构管理 (/jjjg) tem menu em institution-menu-config.js com filePath institution/agencyPersonnel/index.

- A entrada src/views/institution/agencyPersonnel/index.vue renderiza AgencyPersonnelList.vue.
