# 经纪机构入网保存接口
苏州市房地产监测V3前端中「经纪机构入网」对应两条业务线，保存接口不同。

## 接口说明
- 企业端「入网申请」（登录后B端认证）对应 `AgencyEntryNetworkDetail.vue` 保存按钮
- HTTP: `POST /company/companyRecord/entryNetwork/save`
- 封装函数: `saveAgencyEntryNetwork`（内部去掉 `qualificationList` 再调 `saveEntryNetwork`）
- 定义位置: `zhi2-web-admin/src/api/company/companyRecord.js` 第216-234行

## 业务规则
- 开发企业需传 `qualificationList`；经纪/租赁机构用 `saveAgencyEntryNetwork` 不传资质
- 该保存接口支持草稿/驳回后反复保存
