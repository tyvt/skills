# 企业管理员等级展示逻辑
苏州市房地产监测V3中公司管理员列表根据机构类型展示不同管理员等级字段。

## 展示条件
- 仅经纪机构入口（`organType` 为 agency）展示「管理员等级」
- 开发企业入口展示「管理员类型」（字典 `company_admin_type`）

## 字段与映射
- 查询参数与列表字段均为 `isMainAdmin`
- 前端写死文案: `1` → 主管理员，其他 → 附属管理员
- 实现见 `zhi2-web-admin/src/views/company/companyAdmin/index.vue` 的 `MAIN_ADMIN_OPTIONS`、`formatMainAdmin`，详情页 `detail.vue` 的 `adminLevelLabel`

## 业务规则
- 主管理员不可注销、不可批量删除
- 仅已注销且非主管理员的行可选中删除
