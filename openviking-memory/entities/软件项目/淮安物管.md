# 淮安物管
淮安物管是一个包含 zhi2-web-admin 前端的物业管理项目。

## Description
- 基于 Vue 2 框架开发的物业管理系统前端项目。
- 代码仓库路径为 d:\repository\淮安物管\zhi2-web-admin。
- 使用 Vite 构建并配置代理，env/.env 中存在代理地址配置。

## Modules
- 收入合同管理（pubRevenueContract）与支出合同管理（pubExpenditureContract）模块。
- 系统分支信息（branchInformation）模块。
- 统计地图（statisticsMap）模块，含 map.vue 组件。

## Relations
- 多个代码修复事件（按钮无响应、代理端口、Sass 弃用、保存事件名）均发生在该项目下。
