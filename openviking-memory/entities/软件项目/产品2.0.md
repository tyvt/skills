# 产品2.0
产品2.0是园区物业管理相关的Vue前端项目，代码位于`d:\repository\产品2.0\zhi2-web-admin`，使用Vite+Vue。

## 模块与功能
- dataProperty：procedure详情、流程表格与弹窗组件
- autonomy：企业注册真实接口（regulation/record/detail.vue等）
- property/serviceItem、building/unit等列表页采用ListTemplate.js规范的list-card结构
- property/bill 物业费账单管理，含分类型入口
- property/spFeeBill 物业费账单导入与收款（import/upload/collection组件）

## 验证与归属
- 代码基线：none
- 来源会话：多次迭代累积，各修复记忆分别记录具体会话ID
