# 园区物管2.0
园区物管2.0（亦称产品2.0，项目代号 2-0）是用户维护的园区物业管理 Vue 前端项目，采用 Vite + Vue，前端代码位于 zhi2-web-admin，构建产物 outDir 在仓库根 dist/（不在 zhi2-web-admin 内），与苏房V3 同源，属 DeepSeek Harness 工作区实际业务项目。

## 部署约定
- 生产环境发版必须整目录全量上传 dist/，逐个传文件极易漏传导致 chunk 502。
- Vite 默认 emptyOutDir=false，需在 vite.config.js 设 emptyOutDir:true，并为大型页面单独分包（如 module-map-overview-[hash].js）。
- 验证 chunk 用 curl -I 确认返回 200 且 Content-Type 为 application/javascript。

## 已知问题
- 生产路由懒加载曾报 TypeError: Failed to fetch dynamically imported module，根因是发版部署不完整（主包更新但个别 chunk 在 nginx 上 502），非源码或路由代码问题。
- 另一类动态模块加载失败根因：源码中文命名静态资源被 Vite 打成中文名 chunk，子路径/CDN 对 URL 编码中文路径不友好致 404，需改英文短名（见前端技术笔记/vite_chinese_chunk_404）。
- zhi2-web-admin/src/permission.js 对 chunk 加载失败（404/502）自动刷新一次，缓解发版后 HTML 与 JS hash 不一致。

## 描述与代码特征
- Vue 前端项目，自研 zs-table、zs-table-column 与 ECharts 图表模块。
- 业务含资产详情弹窗、运营报告 Tab、统计卡片、函数式选择弹窗等。
- 图表交互需手动配对 ECharts dispatchAction highlight/downplay。
- 表格列宽由 zs-table-column 计算，min-width 弹性列可均分撑满。
- 多附件字段逗号分隔多路径，消费前拆数组逐张处理。

## 关联说明与文件
- 各类技术模式（表格布局、图表样式、选择弹窗、菜单缩进等）作为独立「技术模式」实体维护，不在此罗列。
- 关联文件：zhi2-web-admin/vite.config.js、zhi2-web-admin/src/permission.js。
