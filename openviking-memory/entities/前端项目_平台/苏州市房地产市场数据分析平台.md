# 苏州市房地产市场数据分析平台
苏州房产市场数据监测前端平台，代码仓库为 zhi2-web-admin。

## Description
- 前端大屏页面，路由路径 /market-monitor，展示成交面积段、商品住房/存量住房交易等面板。
- 左上角标题静态文案为「苏州市房地产市场数据分析平台」。

## Relations
- 全局配置平台名 platformName、系统图标 sysLogo 存于 $store.state.app.platformConfig。
- 主要组件：AreaStructurePanel.vue、TradePanel.vue、MarketHeader.vue。
- 全局字体定义于 index.scss / element-ui.scss：'Microsoft YaHei','PingFang SC','Helvetica Neue',Arial,sans-serif。

## Key Facts
- 本地部署地址 http://127.0.0.1:8092/index.html#/market-monitor。
- E2E 测试 29 项断言全通过。
