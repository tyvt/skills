# 我的民意调查列表页
民意调查模块"我的民意调查"列表页及其请求接口说明。

## 页面信息
- 页面文件：src/pages-survey/list.vue
- 所属项目：zhi2-mobile-shimin-h5-zhishu-c（苏州园区市民H5）

## 列表接口
- 接口：POST /version/1/app/SmQuestionnaireListApp
- 封装函数：SmQuestionnaireListApp（定义于 src/api/common.ts:375）
- 请求参数：{"type": "<0待完成/1已完成>", "roomNo": "...", "projectCode": "...", "pageNumber": <页码>, "countPerPage": <每页条数>}
- 截图处于"待完成"tab，即 type:"0"；"已完成" type:"1"
- 返回取 res.MtplQuestionList 渲染卡片

## 关联接口与跳转
- 进度数据可能来自 SmQuestionnaireReplyRate（POST /version/1/app/SmQuestionnaireReplyRate，参数 tableId、projectCode）
- 房屋列表前置：POST /version/1/app/SmQuestionnaireHouseListApp
- 点"参与调查"进入填写页 src/pages-survey/index.vue，使用 SmQuestionnaireGoHandleApp（详情）+ uploadQuestionnaireReply（提交）
