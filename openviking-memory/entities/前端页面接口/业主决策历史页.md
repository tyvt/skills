# 业主决策历史页
业主决策模块"已完成"列表页及其请求接口说明。

## 页面信息
- 页面文件：src/pages-decision/decision/history.vue
- 所属项目：zhi2-mobile-shimin-h5-zhishu-c（苏州园区市民H5）

## 列表接口
- 接口：POST /version/1/app/SmCastVoteListAppHistory
- 封装函数：SmCastVoteListAppHistory（定义于 src/api/common.ts:146）
- 请求参数：{"type": "1", "pageNumber": <页码>, "countPerPage": <每页条数>}
- type:"1" 固定为"已完成"标签；"待完成"走 SmCastVoteListApp
- 返回取 res.MtplOwnerVoteList 渲染卡片

## 卡片操作与附加接口
- "决策详情"跳转 /pages-decision/decision/detail，详情页用 SmUserVoteDetail 等接口
- "决策结果"跳转 /pages-decision/decision/statistics，统计页用 getVoteAnalysis
- "修改决策"在已过期时禁用，无请求
- 待办数量角标：POST /version/1/app/CommonMessageAppNotHandle
