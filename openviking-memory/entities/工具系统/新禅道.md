# 新禅道
新禅道是禅道项目管理系统的一个实例，访问地址为 http://zentao-biz.zhi.com，用于管理任务类工单。

## 用途
- 承载 type=task 的任务工单，供团队登记、查询与回写任务状态。
- 任务完结需要在 zt_action 写备注，并同步更新任务状态、工时与指派信息。

## 访问与数据源
- 禅道数据的查询与回写统一通过 MCP dbx 完成，连接名为「新禅道」。
- 另存在老禅道库，老禅道库禁止写入，只允许对新禅道库操作。

## Relations
- 用户的禅道任务处理规范针对本系统内的任务类工单：改为已完成状态、填写 consumed 工时、指派给 openedBy 创建人。
