# 苏服办投票H5扫脸成功后多余调用handleFaceSuccess缺陷
苏服办App内业主再次进入投票H5时因人脸成功后又调后端接口导致失败，修复后删除多余调用。

## 问题现象
- Android苏服办实机二次进投票H5表现「人脸识别失败」或跳过扫脸误入后续页
- 扫脸成功可能toast「是否存在重复实名账号信息不能为空」
- 绑定房屋多次扫脸无冲突，因绑定链路未走多余同步

## 根因
- face.vue在SDK扫脸成功后调用syncFaceSuccessToBackend→POST /security/ctUserRealName/handleFaceSuccess
- 该接口在已实名/重复校验场景失败，打断后续跳转

## 修复方案
- 删除syncFaceSuccessToBackend及对handleFaceSuccess的调用
- completeFaceVerifySuccess仅提示「人脸认证成功，请选择房屋」约1s后跳转bdc，不再请求后端
