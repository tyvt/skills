# 共有资金总览查询约定
共有资金「查询明细」页顶部查询时间与账户余额统一取自 accountStatistics 接口，避免本地冗余状态。

## 数据来源
- 查询时间取 `/benefit/app/accountStatistics/{projectId}` 返回 `bankAccountUpdateTime`
- 账户余额取同接口 `bankBalanceAmount`，格式化为 `YYYY.MM.DD HH:mm:ss` 展示

## 实现要点
- 点击查询明细先调 `getBenefitList` 刷新 `benefitInfo`
- 去掉本地冗余状态与 `bankReceiptDetail` 兜底，避免与主统计接口不一致
- 监管银行字段绑 `benefitInfo.regulatoryBankName`，其下新增一行「开户支行」绑 `openbankName`，勿将监管银行误绑 `openbankName`（验证会话 8f524774）
