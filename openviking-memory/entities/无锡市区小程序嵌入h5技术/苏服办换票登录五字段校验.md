# 苏服办换票登录五字段校验
从苏服办 location 进入 H5 换票登录前必须校验五个 query 字段齐全，缺一即 toast 且不请求。

## 校验规则
- 必须校验 query 字段：token、name、idType、idNumber、phone
- 任一缺失则 toast 列出缺少项（如「缺少手机号」），不调用登录接口及后续业务接口
- 不能把 SDK 的 token 误当作业务鉴权 token
- 无 token 时整站应短路后续 API

## 调试与排查
- 调试阶段可打印换票接口入参与响应
- 涉及文件：src/utils/h5Context.js、src/App.vue、src/api/security.js
