# 门户双入口业主决策链路
苏服办门户首页「业主决策」外链与「共有资金表决」内嵌页是两条独立链路，勿混淆首页路由。

## 入口区分
- 苏服办实际首页为 pages/webview/home，勿与 pages/index/home 混淆
- 快捷菜单「业主决策」ownerDecisionVoteExternal 走灵犀外部投票 H5（usePortal → 选屋 → openOwnerDecisionVoteH5 → webView）
- 卡片「共有资金表决」handleVote 走内嵌 /pages_owner/decision/index

## 外链流程
- 登录/实名 → 确认弹窗 → /pages/face/bdc 灵犀选屋 → portalPostAction=ownerDecisionVote → 后端取投票 URL 再 navigateToExternalUrl
- 内嵌列表走 selectAppDecisionList 等 autonomy 接口，不是同一套入口
