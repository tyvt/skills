# 无锡H5子模块dev_wuxi-sfb与dev_shiqu功能同步方式
仓库业务代码在子模块zhi2-mobile-admin-h5-c-unlimited，并行分支dev_wuxi-sfb与dev_shiqu，同步用merge或cherry-pick。

## 分支与同步
- dev_wuxi-sfb承载苏服办/嵌入场景，dev_shiqu承载市区交付
- 整分支git merge dev_wuxi-sfb可能带入同期苏服办、人脸等改动
- 单功能cherry-pick指定提交到dev_shiqu再git push
- 维修资金交易详情/列表链路合并冲突时以 dev_wuxi-sfb 较完整实现为准（如 getAccountTransInfos、setTransDetailPayload 及相关排版），避免回退 dev_shiqu 旧逻辑导致字段缺失（验证会话 b06c94d8；dev_wuxi-sfb 提交 69363c8、dev_shiqu 合并 50b65d1 解决 index.vue/utils.js 冲突、父仓 main-sfb 4883b08）

## 父仓指针
- 父仓若在main-sfb不会自动更新子模块指针
- 仅子模块远程dev_shiqu更新时，需另行在父仓提交子模块引用才算父仓同步

## 验证与归属
- 维修资金与物业公司功能均通过merge或cherry-pick到dev_shiqu并推送
- 涉及文件：zhi2-mobile-admin-h5-c-unlimited/src/pages_owner/maintain/index.vue、src/pages_owner/maintain/info.vue、src/utils/transaction.js
- 所属项目：无锡市区小程序嵌入H5；来源会话：9626bae5-9774-468d-8608-444c5c9cb360、73334c2d-8d67-4f00-8197-643417601177、b06c94d8-8cb8-4f4c-8390-dfa9fb3028aa；代码基线：289666e
