# 无锡H5维修资金页房屋历史交易明细展示约定
无锡客户要求在维修资金页底部展示当前房屋历史交易明细，明细取accountTransInfos，项目信息仅当proDeal有值展示。

## 列表字段映射
- transDateTime→交易日期
- direction：0=支、1=收→交易类型
- transMoney→交易金额
- balance→余额；右箭头进详情

## 详情页规则
- 交易明细区：交易日期、类型、金额、余额、摘要
- 项目信息区：项目名称、使用方式、预算金额、结算总额，仅当proDeal有值时展示，否则整块不出现

## 交付与验证
- 交付文件：TransactionTable.vue、transDetail.vue、utils.js、pages.json注册路由；联调通过后移除mock
- 涉及文件：zhi2-mobile-admin-h5-c-unlimited/src/pages_owner/maintain/index.vue、components/TransactionTable.vue、transDetail.vue、utils.js
