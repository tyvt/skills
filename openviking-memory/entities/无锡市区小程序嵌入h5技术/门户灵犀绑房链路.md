# 门户灵犀绑房链路
苏服办门户经不动产授权完成灵犀选屋绑房，调用 selectMyHouse 并同步业主房屋列表，与 H5 自助绑房区分。

## 流程与接口
- 从 `pages/webview/home` 经小程序 `pages/face/bdc` 回 H5 带 `authCode` 完成选屋
- `usePortal` → `runLingXiSelectMyHouse` 调用 **POST** `/external/lingXi/selectMyHouse`（`selectMyHouseByLingXi`）
- 入参含 `userId`、`phone`、`authCode`、`name`、`idNumber`
- `code==='200'` 合并 `res.data` 到本地房屋并设 `portalStore.houseBoundViaAuth=true`
- `authCode==='0'` 不调接口只提示

## 同步列表
- 成功后 **GET** `/property/ctUserIdentity/listByTokenAndIdentityTypeAndIdentityStatus`（`identityType:1`,`identityStatus:2`）同步列表

## 验证与归属
- H5 自助绑房另走 `addOwnerDirectly` 链路，勿与灵犀混淆
- 验证证据：会话 2782b86f 用户问绑房与首页业主决策接口，结论列出参数及 portal.js 片段
- 涉及文件：src/utils/portal.js、src/api/portal.js、src/store/portal.js
- 所属项目：无锡市区小程序嵌入H5；来源会话：2782b86f-c8ca-4f8c-8d4e-27ba92d8c485；代码基线：38bd192
