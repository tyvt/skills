# presale_headtitle
Páginas de detalhe de pré-venda integram `HeadTitle` unificando estilo e removendo duplicação no projeto 苏州市房地产监测V3.
## Mudanças
- `CashsaleDetail.vue` e `permit/components/detail.vue` mostram número de solicitação/status/tempo de criação via `HeadTitle`
- `CashsaleInfoPanel.vue` e `PermitInfoPanel.vue` adicionam `Headline` em modo visualização
- `DetailTemplate` remove campos duplicados da barra superior; linha de título alinhada a 56px
## Arquivos
- HeadTitle/index.vue, CashsaleDetail.vue, permit/components/detail.vue, CashsaleInfoPanel.vue, DeveloperBasicInfoDetail.vue, pubVerificationReceipts/detail.vue, autonomy/record/components/detail.vue, PermitPlanPanel.vue
