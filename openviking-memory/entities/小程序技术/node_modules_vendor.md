# 分包node-modules组件vendor路径修正
苏住房C小程序分包内uni-datetime-picker因require指向分包common/vendor.js不存在而白屏，需relocate脚本补vendor路径修正并接入dev构建。

## 问题现象
- 分包 pages_main 加载 uni-datetime-picker 报 module 'pages_main/common/vendor.js' is not defined
- require args '../../../../../common/vendor.js'，页面白屏/报错

## 根因
- uni-app 复制 node-modules 组件到分包 node-modules 但 require 相对层级仍指向分包自身 common/vendor.js
- 实际 vendor.js 由主包产出于 dist/common/vendor.js；relocate-z-paging.mjs 有修正但未覆盖 datetime-picker，且后处理脚本不在 npm run dev 链路

## 解决方案
- relocate-datetime-picker.mjs 增 patchVendorRequiresInDir，把 require 层级改到主包（多退一级），做成通用工具
- vite.config.ts 加 closeBundle 插件自动跑 patch 脚本，dev/build 都生效
- relocate-z-paging.mjs 补 dist/dev/mp-weixin 输出路径；已生成 dist 就地执行修复并清缓存重编译
- 排查启发：报错指向「分包/common/vendor.js」直接查 dist 产物组件 require 层级
