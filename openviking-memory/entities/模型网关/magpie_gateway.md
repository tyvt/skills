# magpie 网关
magpie 网关是提供 auto/hy3 模型的模型网关。

## 描述
- 提供 auto/hy3 模型供 VLM 记忆抽取复用

## 关系
- 其 auto/hy3 模型被 OpenViking 的 VLM 记忆抽取复用
