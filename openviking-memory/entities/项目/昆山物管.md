
# 昆山物管
昆山物业公共服务平台，与苏住房防汛C端同机 nginx 部署的项目。

## Description
- 项目目录位于 D:epository\昆山G
- 通过本地 nginx 站点 D:
ginx\conf\sites-enabled\昆山物管.conf 部署

## Deployment
- nginx 监听端口 8103，server_name localhost
- 页面标题为「昆山物业公共服务平台」
- 2026-11-03 前与苏住房防汛C端共用 8103 端口冲突，防汛C端迁至 8095 后恢复独立访问

## Relations
- 同机 nginx 监听 8094-8103 端口段，含多个站点配置
- 同目录另有「昆山市民」项目（vite 端口 8227）与「昆山G」项目
