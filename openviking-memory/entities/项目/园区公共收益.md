# Park Public Benefit (园区公共收益)
Vue frontend project (repo zhi2-web-admin) for park property management, focused on the public-benefit module.

## Description
- Vue frontend project sharing the zhi2-web-admin base with 园区物管2.0.
- Business covers property-management-area four-map slots, account splitting, building-table view, and benefit new-pages (use-money apply, expenditure contract filing, etc.).
- Branch naming examples: develop/v2.6.2-suzhufang, develop/v2.6.2-yuanqu.
