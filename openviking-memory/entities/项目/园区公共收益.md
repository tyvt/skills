# 园区公共收益
Vue 前端项目（仓库 zhi2-web-admin），与园区物管2.0 共享基础，聚焦公共收益模块。

## Description
- 业务涵盖物业管理区域四图点位、账户拆分、楼幢表视图、收益新页（用款申请、支出合同备案等）。
- 分支示例：develop/v2.6.2-suzhufang、develop/v2.6.2-yuanqu。

## 技术模式索引
- 详细前端技术模式与修复点已拆分至独立实体「zhi2_tech_patterns」（category=技术模式）。
- 相关具体修复实体示例：zhi2_orgworker_btrevert（组织工作人员详情回退）、dict_init_blank（资产租赁字典初始化）、orgworker_list_fieldmap、house_pagination_fix、approval_dialog_style、building_style_fix、image_upload_preview_fix（多图预览匹配修复）、donut_percent_echarts（饼图占比走 ECharts）、building_getfloor_fix（getFloor的mathjs add报错）、zs_tree_fix（treeMethod缺失报错）、online_aes_risk（线上包安全分析）、handover_date_fix（起止日期显示修复）等。

## 验证与归属
