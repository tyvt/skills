# 苏州市房地产综合服务平台（商品房）
苏州市房地产综合服务平台（商品房）后台管理系统，前端工程为 zhi2-web-admin，由苏州房产前端实施 agent 负责实现与部署。

## 界面结构
- 顶栏：蓝色建筑图渐变 banner，含 logo、系统标题、带图标导航（首页/开发企业管理/项目管理/地名管理/地名审批/价格备案/预售资金银行监管/预售许可等）、返回首页按钮、管理员头像
- 左侧菜单：白色背景，选中项浅蓝底加左侧蓝竖条；项目管理类含项目备案申请等树形菜单
- 标签栏：浏览器式标签，激活标签顶部蓝线；面包屑工具条含 ☰ ‹ › × 按钮

## 已知页面模块
- 合同网签：预售合同签订列表，含搜索区、备案绿标签、查看蓝实心按钮、编辑/删除灰字按钮
- 项目管理：项目备案申请详情、楼盘表（房号网格加状态图例）、楼幢维护表单

## 归属
- 前端工程：zhi2-web-admin
- 负责方：苏州房产前端实施 agent
