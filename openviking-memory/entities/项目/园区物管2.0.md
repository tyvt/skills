# 园区物管2.0
Vue 前端项目（仓库 zhi2-web-admin），与园区公共收益等项目共享基础。

## Description
- 业务涵盖资产全景（dataSandbox/assetPanorama）、资金全景（dataSandbox/fundPanorama）、统计地图（benefit/statisticsMap）、权利人同步（property/syncObligee）等模块
- 使用 ECharts 绘制环图/饼图/趋势图，腾讯地图 GL（TMap）用于点位展示

## 技术模式索引
- 环图空数据与全0展示：donut_all_zero_label
- 同步弹窗统一 sub-container 样式：sync_subcontainer_style
- 资产全景环图标签与引导线：mapoverview_donut_fix
- 资金全景区县饼图标签格式化：fundpanorama_label_location
- 资金全景趋势图双Y轴格式化：fund_trend_fix
- 腾讯地图 TMap.Map 实例校验报错：tmap_error_fix

## 验证与归属
- 所属项目：园区物管2.0；多来源会话
