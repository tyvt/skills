# 租房管理小程序
用户维护的 uni-app 前端项目（对话中编号为 project 0，未给出正式名称），主路径含 pages-rent、pages-iHome、pages-user 等分包。

## 技术特征
- 使用 uni-app 框架，组件库含 wd-popup、wd-datetime-picker（wot-design-ui 风格），API 用 uni.showToast 等
- 分包页面需在 src/constants/rent/subPackages.js 配置才会注册，由 pages.config.ts 与 subPackages.js 生成 pages.json
- 开发命令如 pnpm dev:mp-weixin

## 已知模块与功能
- pages-iHome/subsidy.vue：补贴在线申请 mock 表单
- pages-iHome/my/contractDetail.vue：合同详情，含变更/撤销/终止/续期按钮
- pages-rent/contractEdit.vue：合同编辑页
- src/components/zs-sign-canvas：手写签名组件
- myAgreementDetail.vue：协议详情与签字
