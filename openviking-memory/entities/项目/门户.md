# 门户
门户是用户维护的面向公众的房产门户前端项目，代码仓库为 zhi2-web-admin（作为某 monorepo 子模块），与园区物管2.0 同仓不同子模块/项目。

## 描述
- 含 UnifiedLogin 首页、publicPortal 二级页、侧栏菜单、v2 网关接口等
- 视觉底座默认要求设计目录 24 张 PNG 与 PORTAL_DESIGNS 对应

## 技术特征
- monorepo：父仓管 env/.env 与 deploy/nginx.conf，子模块 zhi2-web-admin 内含 portalApiRewrite.js、public/sign.js 等
- 侧栏菜单可见性由 menuVisibility.js 等工具层统一处理

## 关联说明
- 各类技术模式（设计稿同步、菜单可见性、网关前缀、骨架屏）作为独立「技术模式」实体维护
