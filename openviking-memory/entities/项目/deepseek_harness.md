# DeepSeek Harness
DeepSeek Harness 是一个采用 OpenViking 作为长期记忆方案的项目。

## 描述
- 使用 OpenViking 作为长期记忆解决方案

## 关系
- 原本使用已损坏的旧 long-term-memory 库，现由 OpenViking 替代
