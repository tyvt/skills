# 授权绑定类详情页编辑态锁死被授权方主数据字段
行业管理→用户及授权→企业授权等「把某主体授权给某对象」的详情/编辑页，编辑态须禁用被授权方选择器，新增态才允许选择。

## 问题背景
- 新增与编辑共用同一份 detail 页，企业选择器只在新增时需要；编辑态允许改等于允许把授权记录悄悄改成指向另一家企业，主数据与已发生授权关系脱节。
- 用户反馈编辑时「企业名称」还能点开选择框改，与同屏统一社会信用代码、办公地址等只读字段口径不一致。

## 解决方案
- 编辑态把企业名称控件置为 disabled，与统一社会信用代码、办公地址等只读字段保持一致的视觉与交互口径。
- 判断依据用页面 formMode/isView 单一谓词（新增可编辑、编辑只读），不要按路由 id 是否存在散落判断。
- 新增态保持可正常选择企业，不套用同一个禁用开关。

## 验证与归属
- 验证：会话 e96ee884 用户提出编辑时企业名称应禁止编辑；修改 companyRecordAuth/detail.vue 编辑模式禁用企业名称，新增模式仍可选择。
