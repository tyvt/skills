# Work Order Action Buttons Logic
Work order action buttons are determined by the ORDER_STATUS constant and order type together.

## Logic
- constants.js uses ORDER_STATUS to unify status values
- actionButtons generated by `form.orderStatus`: pending acceptance shows accept and reject
- Pending processing adds reply, transfer, urge; processing adds complete; closed and returned show none
- Repair order replaces reply with add progress and hides transfer
