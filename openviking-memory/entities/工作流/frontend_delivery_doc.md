# 前端交付附配置说明文档规范
前端改完需后台配合的交付，要在仓库放配置说明文档，写明菜单授权与后端发布核对要求，不留在聊天里。

## 适用场景
- 跨项目（榆林G+苏住房G）同步修复工单迁移权限标识后，除代码推送还需配置说明 `zhi2-web-admin/docs/task-2095.md`
- 权限标识需后台菜单授权、后端同批标识发布，否则前后端不匹配

## 核心做法
- 交付放文档含：菜单授权清单（模块/业务/动作/权限字符）、后端发布核对项、验证方式
- 禅道回写写入文档路径、提交号、验证结果、发布注意事项；权限标识按接口附件核对大小写，跑通 108 组权限场景及 ESLint
- 交付表列全「四仓库×两级」分支与提交号，注明子模块任务分支尚未合并；禅道状态回写带工时（done、指派 huzhihao、消耗0.5h、剩余0h）
