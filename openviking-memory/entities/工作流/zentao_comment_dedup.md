# 禅道工单重复备注合并
禅道工单多次「提交推送+改状态」产生重复备注时，保留权威解决备注、清空其余备注正文、操作历史保留。

## 适用场景
- 禅道 bug 因多次提交推送被写入多条重复备注（如 bug 5767 的 #81705、#81710），措辞不一致令验收方困惑

## 操作步骤
- 先看工单当前状态与已有备注，确认由测试关闭还是自己关闭
- 选一条权威解决备注（示例保留 #81705），其余重复记录清空备注正文、保留操作历史
- 状态保持 closed / fixed（已由测试关闭则不改状态）
- 同步核对代码侧已推送且与远端一致，无需重复提交
- 明确写出「未纳入本次提交」的内容，保持工单备注与提交范围一致
