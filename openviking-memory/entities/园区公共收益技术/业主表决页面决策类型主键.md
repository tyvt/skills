# 业主表决页面决策类型主键
园区公共收益项目四类业主表决页面路由、decisionType 映射与详情主键约定。

## 路由与 decisionType
- 视图在 `src/views/autonomy/`：NORMAL→general、OPTION→option、SORT→sort、MULTIPLE_ISSUES→multiply
- 列表/详情 component 即菜单 filePath（flattenTree 写入 meta）
- URL 由后台菜单动态生成，跨模块用 `getRouterPathByFilePath('autonomy/general/detail')` 解析

## 主键与组件
- 前三类详情路由用 `decisionId`，多议题用 `decisionManageId`
- 全库无 decisionSituation 模块；「表决情况」展示走 `calculationChart` + VoteView/VoteResult
