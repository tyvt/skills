# 资金缴款通知书合同名称跳转
园区公共收益项目资金缴款详情页通知书子表「合同名称」查看态改为链接并跳合同详情的技术约定。

## 实现做法
- 在 `pubPaymentNotice/detail.vue` 的 `contentInfo2` 将字段 `type` 从 `text` 改为 `link`，点击走 `goToContractDetail`
- 路由按 `contractType` 分分支：`0`→经营用房租赁合同，`1/2/4`→资源租赁（广告位/场地/其他），`3`→车位租赁合同，其他→通用收入合同

## 数据契约
- 选合同时持久化 `revenueContractId`、`contractType`
- 老数据无 ID 时先按 `contractNo` 查询解析出 ID 再跳转，避免历史行无法点开
