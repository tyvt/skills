# [园区物管2.0] 腾讯 GL 地图点位「不显示」的四类根因与排查套路

什么情况：腾讯位置服务 GL 地图（MultiMarker/MultiLabel）页面里小区/项目点位不显示或部分不显示，控制台还报「Map中已存在id为area_bubble_0的图层，无法重复添加」「所传入参数并非TMap.Map的实例」。为什么有四类独立根因：1) 多个 MultiMarker 的几何 id 都写死 'marker'/'label'，部分 GL 版本下多实例 id 冲突导致后续点位不渲染；2) 坐标字段不止 xcoordinate/ycoordinate，台账类接口会带 mapXCoordinate/mapYCoordinate（平台约定 X≈纬度、Y≈经度），不参与解析的点被过滤掉；3) 下钻到街道后地图仍停在「街道气泡」中心，小区点在视野外，看起来像没出来；4) 搜索只传 projectName 而后端只认 complexName。怎么做：几何/图层 id 按索引唯一化（project_marker_geom_${index} 等）；归一化函数里对经纬度做 mapXCoordinate/mapYCoordinate 兜底；第三层下钻列表非空时按所有点范围算中心与缩放（单点用专用 zoom 常量），且后续点击不再用固定中心覆盖拟合结果；搜索参数 projectName 与 complexName 双传兼容。

**验证证据**：会话 7936e37a：最终结论四条原因归纳与修改说明（normalizeProjectList 加字段兜底、applyCommunityLayerView 视野拟合、MultiMarker 图层/几何 id 索引化、双参搜索）

**涉及文件**：zhi2-web-admin/src/views/benefit/statisticsMap/index.vue、zhi2-web-admin/src/views/benefit/statisticsMap/components/map.vue

**所属项目**：园区物管2.0
