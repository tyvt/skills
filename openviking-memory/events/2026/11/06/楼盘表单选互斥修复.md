# Summary
在园区公共收益项目(zhi2-web-admin)中，修复自治筹备组征集新增报名选择户室的问题：列表视图为单选，但切换到楼盘表(BuildingTable.vue)后可批量勾选整单元或多选，切回列表仍有多个选中。修复方案：BuildingTable.vue 新增 singleChoice prop(默认 false，不影响多选场景)及 clearAllChecked()；CandidateDialog.vue 新增 enforceSingleChecked() 并在 syncListSelection() 开头兜底、onCellClick() 在列表视图触发同步，统一 checked 为 '1'/'0' 字符串。多选场景(如 DecisionRangeTable)未传 singleChoice 保持原行为。
