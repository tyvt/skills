# Summary
修复昆山市民小程序选项表决页面显示 undefined 的问题。原因为页面写死读取 optionGroupList[0].minOptionNum 与 mixOptionNum，但接口实际可能返回 optionNum、mixOptionNum（位于分组或决策详情上），字段名不一致导致显示 undefined。修复方式：新增 src/utils/optionLimit.js 统一解析最小/最大可选数量（最大兼容 mixOptionNum→optionNum 分组级到决策级，最小兼容 minOptionNum 分组级到决策级）；更新 vote.vue 改由工具函数读取限制数量，选择时校验最大可选数、下一步校验最小/最大可选数。重新编译后正确显示“最少选择1个，最多选择3个”类提示。涉及 vote.vue、src/stores/vote.js、src/api/modules/vote.js、src/stores/election.js、optionResult.vue 等。所属项目：昆山市民。
