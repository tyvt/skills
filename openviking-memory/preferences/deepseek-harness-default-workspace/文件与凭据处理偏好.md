- 临时文件重定向：.tmp-* 统一重定向到系统临时目录（如 $env:TEMP），避免仓库内残留；缺陷相关截图/文件统一落 <repo>\.tmp-bug<id>\，不写仓库根目录（如 bug6420_screenshot.png 应入 .tmp-bug6420/）。
- 截图/图片分析默认用 mcp__magpie-vision__analyze_image（返回 1-2k 文字描述）替代 read_image（返回图片附件进主上下文并按图计费）；仅 OCR 密集场景才走 magpie-vision 慢通道。简单列宽类 bug 不读截图，grep label 定位即可。
- 凭据文件（如 credentials.py）仅脚本内部读取，不将明文密码（如 Field123456）注入模型上下文。
- zentao-analyzer 多张附件先查看业务页，再查看角色或权限页；截图统一下载到 $env:TEMP。
