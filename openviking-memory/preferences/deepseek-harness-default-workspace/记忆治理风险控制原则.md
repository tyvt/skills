- 治理存量记忆时禁止一刀切删除；拿不准的条目一律归档并打 archived/stale 标签，而不是直接删掉。
- 归档后必须同步配置检索过滤，未配过滤的归档视为未完成。
- 动手改动前先走 plan→plan_review→人工确认；冲突巡检只产出清单交人工复核，不自动处理。
- 优先按主题 find/search 圈定高风险热点范围，不做全量遍历。
- 分级处理：STALE 类用 edit 原地修改；INVALID 类用 forget 前必须人工确认。
