- 接口返回图片地址如 /zhi2-pro/2025/i/1/w/xxx.png 时，统一规范为无前导斜杠相对路径 zhi2-pro/2025/i/1/w/xxx.png
- 当前分支(非苏服办)请求域名整体反代到 zhi2-pro，不使用绝对URL也不拼域名
- 收口到 utils 的 resolveMediaUrl / toMediaPath 单点处理，去掉开头斜杠
- ZsImage 展示侧、ZsUploader 上传回传均走此函数，页面不各自拼域名
- 不写「相对路径就补域名」兜底，避免错误前缀拼串
- 后续切苏服办分支只改策略函数，业务页不动
