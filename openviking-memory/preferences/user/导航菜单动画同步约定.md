
- 根因：ResizeObserver 触发布局同步调用 `updateNavIndicator({animate:false})` 与菜单切换 `$nextTick` 更新抢同一帧，无过渡更新覆盖过渡动画
- 关键修复：区分 layoutOnly 位置同步与 activeMenuItemPath 监听（始终允许过渡）
- 切换后 400ms 内保留过渡动画
- 使用双 `requestAnimationFrame` 提交上一帧位置
- `isActive` 用 `normalizeMenuPath` 归一化路径
- 涉及文件：layout/components/Navbar.vue、styles/variables.css
