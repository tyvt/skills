- 产品化前端不要用环境变量配域名，后端相对路径资源统一用 resolveServerAssetUrl 以浏览器当前地址（location）为基准拼接
- 所有图片与文件绑定处（<img>、FileUpload/AnnexUpload 的 FileList、登录页配图等）全部收敛到 resolveServerAssetUrl 一个函数，不留手写拼串
- Vue2 模板通过 import 引入并在 methods 首项挂上（methods: { resolveServerAssetUrl }）直接调用，不要挂 Vue.prototype.$resolveServerAssetUrl
- 独立入口（如 login.vue）若和 admin 的 @ 别名不一致，用相对路径引同一个工具文件
- 收尾跑 npm run build 并全库 grep 残留的 img 直接拼域名写法，确保无遗漏
