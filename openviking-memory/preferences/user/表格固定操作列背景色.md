- 表格固定操作列（fixed="right" 的 el-table-column）背景色要求为纯白（#ffffff），不要透明，避免滚动时透出下方行内容。
- 实现上通过给 el-table-column 设置 class-name 与 label-class-name 为 `zs-operate-column-cell`，并加不带 scoped 的样式 `.el-table .zs-operate-column-cell { background-color: #ffffff !important; }` 作用到表格真实渲染的 td。
