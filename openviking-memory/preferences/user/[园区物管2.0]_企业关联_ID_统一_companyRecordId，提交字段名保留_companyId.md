# [园区物管2.0] 企业关联 ID 统一 companyRecordId，提交字段名保留 companyId

什么情况：园区物管2.0 后台（zhi2-web-admin）中凡涉及物业/开发商/企业关联的字段，一律只认 companyRecordId，不再兼容 companyId 作为取值来源；但表单提交给后端的字段名仍是 companyId / propertyCompanyId（与后端契约一致），只是值取自 companyRecordId。为什么：列表/弹窗选择返回的行里只有 companyRecordId 是稳定主键，companyId 命名在不同接口间含义漂移，做「多候选回退」反而会把错误 ID 带进自动带出逻辑（如选择物业管理区域后物业服务企业信息不回填）。怎么做：选择弹窗赋值方法（setDeveloperCompany/setPropertyCompany）只取 row.companyRecordId；companylist/propertyCompanylist 过滤只按 item.companyRecordId 判断；fillDeveloperInfo/fillPropertyCompanyInfo 从 company.companyRecordId 取值；删除 getCompanyRecordId 之类回退 companyId 的兼容方法，提交时才把值写进 companyId 字段名。新写企业关联功能时直接按此约定，不要引入双候选兜底。

**验证证据**：会话 0a8622de：用户明确「一律使用companyRecordId」；最终结论列出移除 getCompanyRecordId、赋值/过滤/带出五处统一、提交字段名仍为 companyId/propertyCompanyId

**涉及文件**：zhi2-web-admin/src/views/maintenance/guaranteeDepositAgreement/detail.vue、zhi2-web-admin/src/views/maintenance/initiation/detail.vue、zhi2-web-admin/src/views/maintenance/apply/detail.vue
