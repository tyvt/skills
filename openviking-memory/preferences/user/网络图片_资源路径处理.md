- 网络图片、附件等应使用相对路径，按当前页面 URL 解析，自动适配 `/test/`、`/sz/` 等任意子路径部署
- `resolvePublicAssetUrl` 应调用 `resolveServerAssetUrl`（内部用 `new URL(relative, window.location.href)`），不写死子路径前缀
- 下载或跳转类路径（如批量导入错误文件）禁止使用 `window.location.origin + path`，统一改用 `resolveServerAssetUrl`
