- 一级菜单 `path` 为 `/` 且有子菜单时，仅当父级未设 `alwaysShow` 才展平取首个子菜单作为顶栏项；设了 `alwaysShow: true` 则不展平，避免 `meta.title` 误显子菜单名。
- 在 `ruoyi.js` 新增 `shouldFlattenRootTopNavMenu` 控制展平逻辑，`collectTopNavMenus` 统一调用并规范化 `parentPath`。
- `Navbar.vue` 的 `topMenus` 改调 `collectTopNavMenus` 以对齐顶栏菜单逻辑。
- 路由转换阶段须保证 `navbarRouters` 节点保留 `alwaysShow: true`，避免被 `permission` 代码丢弃。
