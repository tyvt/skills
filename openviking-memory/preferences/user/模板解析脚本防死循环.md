- 模板解析脚本须在每次外循环及内层迭代均做 Date.now() 超时检查（5秒），防止内层循环卡死致外层超时失效。
- 内层加 maxAttrLoops 次数上限与 quoted < template.length 长度上限，避免提取属性、带引号属性值时的死循环。
