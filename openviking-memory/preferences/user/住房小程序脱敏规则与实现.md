
- 住房类小程序中「系统自动获取」的姓名/手机号/身份证号必须脱敏，规则由用户统一指定，各页面不得自行决定
- 中文姓名保留第 1 位其余用 *（示例：朱楠→朱*，李小明→李**）
- 身份证号保留前 2 位和后 2 位（示例：32**************34）
- 手机号保留第 1 位和后 2 位（示例：18360916552→1********52）
- 三个脱敏函数（含新增 blurIdNumber）统一收口在 src/utils/formatter.js，页面只引用 userStore.secureUsername / securePhone / secureIdNumber
- secure* 字段必须是 getter 由原始数据实时计算，不能是 state 缓存值，避免旧 session 缓存使新规则不生效；改完需提示用户重新登录刷新用户信息
- 适用口径为「展示层脱敏，提交仍用原始值」，覆盖加装电梯、业代报名、房源网签、房源核验、电子业主卡、个人信息、我要买房等自动填充场景
