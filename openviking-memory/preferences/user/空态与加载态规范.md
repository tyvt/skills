- 空态统一用 ZsEmpty（图片+文案），文案固定「暂无相关数据」，禁止用「正在加载...」混作空态
- 加载中与无数据是两状态，不用 ZsPageLoading 长期占位复用同一视觉
- 调接口传 noReject:true，将取不到数据的 reject 转正常空返回，避免弹 toast 打断操作
- 筛选/列表为空、筛选后无数据均走同一套 ZsEmpty 空态
- 筛选项激活时图标与文字同步高亮（灰/蓝切换），不能仅文字变蓝
- 菜单名与页面标题须与设计稿一致（如「日常服务」改为「工作动态」）
- 无数据是常态而非异常，反对用 toast 表达正常无数据
