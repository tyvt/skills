- 首页关键数据导航（keyRegionCode）与检查数据导航（checkRegionCode）各自维护独立区域，切换互不影响。
- 检查数据请求用 checkRegionCode，关键数据及下方公益/报修/学习/待办仍用 keyRegionCode。
- 两者初始值为空对应「全市」，去掉根据 platformConfig.region 覆盖首页区域的做法。
- RegionTabs.vue 用 String 比较判断选中态，避免数字/字符串编码不一致导致「全市」不高亮。
