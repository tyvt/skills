- 物业费申报等固定后端字段的明细表（如 feeBindScopeTable），普通列直接 bind prop，一个 formatter 都不挂。
- 只有金额/面积列（actualFloorArea、billAmount、discountAmount、actualAmount、arrearsAmount）统一用公共 formatters.amountFormatter。
- 禁止为固定字段写私有格式化方法（如 formatBillAmountColumn 等）和兜底字段映射（如 billAmountSum、actualReceivedAmount），并删除这类方法。
- 用户连续三轮纠正：不要加格式化工具，直接用后端字段；整表都不要格式化工具，只有金额用公共工具。
- 与已知条差异：162 讲兼容层收尾时机，1105/270 讲该用 formatter 处不要手搓插槽；本条相反——固定字段连 formatter 都不该加，仅金额类走公共工具。
