- 经营资产接口（如 `getBusinessAssetDistribution`）返回的 `count` 本身已是「百个」单位，图表渲染时不要额外调用 `hundredFromCount` 做除以 100 的转换。
- `chartOptions.js` 的 `buildOperatingAssetsOption` 直接使用接口原始数值，`parseMetric(item.count)` 仅做数值解析不做单位换算。
- 示例：停车泊位接口返回 3.83 百个，刷新页面后柱状图应正确显示该原始值。
