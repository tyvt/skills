- 偏好柱状图 Y 轴最大值不要远超数据峰值，避免出现大量空白（园区物管2.0 数据沙盘）。
- 要求采用精细刻度步长（1/1.2/1.5/2/2.5/3/4/5/6/8/10），在峰值上方约留 10% 空间后向上取整。
- 横向柱状图（如本月新增）的 X 轴也应按数据动态计算，不写死固定 max。
- 经营资产、物业管理区域数量、资金余额、资金收支等 Y 轴及本月新增 X 轴均应遵循此动态刻度规则。
