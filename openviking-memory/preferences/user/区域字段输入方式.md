- 在已使用 `region` 的页面（如 `pubBankAccountBalance`）保留 `region`；`subdistrict`/`community` 仍为文本输入，不要改为代码下拉框。
- 在无区域的页面（如 `pubRegAccountChange`）移除新增的 `regionCode`；详情页中写入 `regionCode` 的逻辑予以保留。
