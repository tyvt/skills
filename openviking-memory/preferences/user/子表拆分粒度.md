- 详情页内嵌子表的表格列配置直接耦合写在子表 vue 文件内部，不单独抽成独立的 xxxColumns.js（避免逻辑散落多文件、阅读来回跳转）。
- 「弹窗式子表」单独抽成独立组件并配合子表 mixin 使用，接口对接分页接口（如 /benefit/pubReceiptVerificationDetail/page）。
- 与泰兴小程序「接口逻辑内聚到页面域 JS」方向不同：园区物管2.0 Web 后台遵循「列配置不外抽、弹窗组件要外抽」。
- 最终交付示例：VerificationReceiptDetailTable.vue 独立弹窗组件 + 列配置内联；涉及 detail.vue、listMixins.js。
