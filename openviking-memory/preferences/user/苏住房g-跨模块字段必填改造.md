- 多模块同类字段（如必填/非必填）改造时，先按「字段名 + 模块」列表逐个文件核对 rules，输出「模块 / 文件 / 现状」对照表。
- 只给缺规则的模块追加 rule，编辑态表单项本就存在，加规则即连带生效红星。
- 顺带核对提示文案与字段名是否一致，发现不符（如成立日期文案误写为起止日期）则一并修正。
- 改造后明确告知需重新构建部署才生效。
