- 前端缺陷修复的实机验证采用本地部署：本地 nginx（惠山二期G 为 8119）跑修复后的 dist，网关/接口指向生产后端，而不是直接登录生产站点操作。
- 验证用的密码要求写入看板数据库（以隐私引用存入 `env_accounts.secret_ref` 并注入看板内存），不能只留在本机或明文写进注册表。
- 倾向按部署面板/编排器的既有流程登记环境与注入凭据，而非手工改 nginx 配置。
